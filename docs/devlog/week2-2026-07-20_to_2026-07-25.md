## 2026-07-20 (星期一)

### 今日重点

开始在 `src/toolDefinitions.ts` 中添加 13 个未注册命令的工具描述常量（`DESCRIPTION_*`），覆盖高优先级 PCB 操作类工具。

### 详细工作内容

**功能实现**

- 在 `src/toolDefinitions.ts` 中新增 6 种 `ToolAnnotations` 常量分类，为 13 个新工具提供语义标注：
  - `annotationsReadOnlyLive`：只读工具（`readOnlyHint: true`，`idempotentHint: true`）
  - `annotationsConfigWrite`：配置写入（仅写 `config.json`）
  - `annotationsNodeOnly`：Node 本地（无 Altium 进程）
  - `annotationsSchematicEdit`：原理图编辑（`destructiveHint: true`）
  - `annotationsPcbWrite`：PCB 编辑（`destructiveHint: true`）
  - `annotationsOutputGenerate`：输出生成（产生文件，非破坏性）

- 编写高优先级 PCB 操作工具的描述常量，每个遵循统一格式（Purpose / When to use / Parameters / Returns / Prerequisites / Errors）：
  - `DESCRIPTION_SET_COMPONENT_POSITION`：设置单个元件位置与旋转，参数 `designator`、`x`、`y`（PCB 内部单位 mils*10000）、`rotation`（可选）
  - `DESCRIPTION_MOVE_COMPONENTS`：批量移动元件，参数 `designators[]`、`x_offset`、`y_offset`（mils）、`rotation`（可选）
  - `DESCRIPTION_CREATE_NET_CLASS`：创建网络类并添加网络，参数 `class_name`、`net_names[]`

**技术决策**

- 坐标单位选择：`set_component_position` 使用 PCB 内部单位（mils * 10000），因为 Altium API 的 `SetState_X()` / `SetState_Y()` 方法直接接受此单位；`move_components` 使用 mils 作为偏移量，因为偏移量更直观，在 DelphiScript 端乘以 10000 转换。
- `ToolAnnotations` 的 `destructiveHint: true` 用于 PCB 写操作，让 MCP 客户端（如 Trae）在调用前向用户确认。

## 2026-07-21 (星期二)

### 今日重点

完成剩余 10 个工具描述常量的编写，覆盖 PCB 查询、布局复制、截图、库操作、输出作业五大模块。

### 详细工作内容

**功能实现**

- 新增 10 个 `DESCRIPTION_*` 常量：
  - **PCB 查询**：`DESCRIPTION_GET_SELECTED_COMPONENTS`（获取选中元件坐标，无参数）
  - **PCB 操作**：`DESCRIPTION_SET_PCB_LAYER_VISIBILITY`（切换层可见性，参数 `layer_names[]`、`visible`）
  - **布局复制**：`DESCRIPTION_LAYOUT_DUPLICATOR`（发现可复制组件组）、`DESCRIPTION_LAYOUT_DUPLICATOR_APPLY`（应用布局复制，参数 `source_designators[]`、`destination_designators[]`）
  - **截图**：`DESCRIPTION_TAKE_VIEW_SCREENSHOT`（截取 PCB/SCH 视图，参数 `view_type` 可选 `pcb`/`sch`）
  - **库操作**：`DESCRIPTION_GET_LIBRARY_SYMBOL_REFERENCE`（获取库符号引用）、`DESCRIPTION_SEARCH_LIBRARY_SYMBOL`（搜索库符号，参数 `symbol_name`、`library_path` 可选）、`DESCRIPTION_CREATE_SCHEMATIC_SYMBOL`（创建原理图符号，参数 `symbol_name`、`pins[]`、`part_count` 可选、`description` 可选）
  - **输出作业**：`DESCRIPTION_GET_OUTPUT_JOB_CONTAINERS`（获取输出容器列表）、`DESCRIPTION_RUN_OUTPUT_JOBS`（执行输出作业，参数 `container_names[]`）

**Bug修复**

- 发现 `DESCRIPTION_CREATE_SCHEMATIC_SYMBOL` 的 `pins` 参数描述不够清晰，最初仅写 "pin definitions"，未说明格式。参考 `schematic_edit.pas` 中 `SchEditPlaceComponent` 的参数解析逻辑后，明确为 `"number,name,electrical_type"` 格式（如 `["1,IN+,I","2,OUT,O"]`），electrical_type 支持 I/O/B/P 四种。

**技术决策**

- `create_schematic_symbol` 使用 `annotationsPcbWrite` 而非 `annotationsSchematicEdit`，因为虽然它操作的是原理图符号库（`.SchLib`），但本质上是一个库管理操作，且 DelphiScript 端实现位于 `schematic_utils.pas` 而非 `schematic_edit.pas`，与原理图编辑的 action 分发机制无关。

### 明日计划

在 `src/index.ts` 中通过 `registerLiveCommand` 注册 13 个新工具，并编写对应的 Zod 输入 Schema。

## 2026-07-22 (星期三)

### 今日重点

在 `src/index.ts` 中注册全部 13 个新工具，编写 Zod 输入 Schema，完成从工具定义到桥接调用的完整链路。

### 详细工作内容

**功能实现**

- 在 `src/index.ts` 中通过 `registerLiveCommand` 工厂函数注册 13 个工具，按功能模块分组：
  - **PCB 选择查询**：`get_selected_components` → bridge command `get_selected_components_coordinates`
  - **PCB 写操作**：
    - `set_component_position` → `set_component_position`（参数：`designator`、`x`、`y`、`rotation?`）
    - `move_components` → `move_components`（参数：`designators[]`、`x_offset`、`y_offset`、`rotation?`）
    - `create_net_class` → `create_net_class`（参数：`class_name`、`net_names[]`）
    - `set_pcb_layer_visibility` → `set_pcb_layer_visibility`（参数：`layer_names[]`、`visible`）
  - **布局复制**：
    - `layout_duplicator` → `layout_duplicator`（无参数）
    - `layout_duplicator_apply` → `layout_duplicator_apply`（参数：`source_designators[]`、`destination_designators[]`）
  - **截图**：`take_view_screenshot` → `take_view_screenshot`（参数：`view_type?` 枚举 `pcb`/`sch`）
  - **库操作**：
    - `get_library_symbol_reference` → `get_library_symbol_reference`（无参数）
    - `search_library_symbol` → `search_library_symbol`（参数：`symbol_name`、`library_path?`）
    - `create_schematic_symbol` → `create_schematic_symbol`（参数：`symbol_name`、`pins[]`、`part_count?`、`description?`）
  - **输出作业**：
    - `get_output_job_containers` → `get_output_job_containers`（无参数）
    - `run_output_jobs` → `run_output_jobs`（参数：`container_names[]`）

- 每个工具的 Zod Schema 直接内联在 `registerLiveCommand` 调用中，使用 `z.string()`、`z.array()`、`z.number()`、`z.boolean()`、`z.enum()` 等构建器，并添加 `.describe()` 提供参数说明。

**重构优化**

- 在 `index.ts` 中添加功能模块分隔注释（如 `// --- PCB selection query ---`、`// --- PCB write operations ---`），提升可读性。
- 确认 `registerLiveCommand` 的 `shape` 参数类型为 `z.ZodRawShape`，与 `z.object()` 兼容，无需额外类型适配。

**Bug修复**

- `set_component_position` 的 `rotation` 参数最初设为必填，但 DelphiScript 端 `SetComponentPosition` 支持省略 rotation（保持当前值）。改为 `.optional()` 并在描述中注明 "Omit or -1 to keep current rotation"。

更新 `src/mcpInstructions.ts` 中的工具映射表和文档聚焦规则，确保新工具在 MCP 客户端初始化时可见。

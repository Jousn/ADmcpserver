### 1. PCB 工具增强（基于 scripts-libraries-master 参考库）

根据 `scripts-libraries-master` 中的代码，对现有 MCP 工具进行全面增强。

#### 1.1 pcb_edit 工具扩展（8 → 17 个操作）

| 操作 | 函数 | 参考来源 |
|------|------|---------|
| add_region | PcbEditAddRegion | CreateRegionQuery.pas |

#### 1.2 pcb_component 工具扩展（4 → 11 个操作）

新增 7 个元件操作：

| 操作 | 函数 | 功能 |
|------|------|------|
| set_height | PcbComponentSetHeight | 设置元件高度 |
| set_moveable | PcbComponentSetMoveable | 锁定/解锁元件 |
| set_name_visibility | PcbComponentSetNameVisibility | 显示/隐藏位号 |
| set_comment_visibility | PcbComponentSetCommentVisibility | 显示/隐藏注释 |
| set_autoposition | PcbComponentSetAutoPosition | 设置位号/注释自动位置 |
| get_3d_bodies | PcbComponentGet3DBodies | 查询 3D 模型体信息 |
| set_lock_strings | PcbComponentSetLockStrings | 锁定/解锁字符串基元 |

| 工具 | 增强内容 |
|------|---------|
| get_component_pins | 返回 30+ 焊盘属性（三层尺寸/形状、孔信息、阻焊覆盖、测试点、平面连接等） |
| pcb_component (get_properties) | 返回 25+ 元件属性（component_kind, moveable, lock_strings 等） |
| pcb_drc | 返回违规规则名称和类型 |

| pcb_polygon_info | 返回完整覆铜属性和顶点 segments[] 列表 |
| pcb_net_info | 返回网络对象列表和连接数 |

### 4. Bug 修复（20 个）

#### 严重级别（8 个）

| 编号 | Bug | 根因 | 修复 |
|------|-----|------|------|
| B12 | add_rectangle 损坏原理图文件 | LineWidth 赋值为 MilsToCoord(10)（Int64 坐标值），应为枚举值 eMedium | 改为 eMedium，eCreate_GlobalCopy 改为 eCreate_Default |
| B13 | place_component 创建空壳元件 | SchObjectFactory 创建无引脚/封装的空元件 | 移除工厂创建，返回 PLACE_COMPONENT_NOT_SUPPORTED 错误 |
| B14 | modify_track 修改所有走线而非选中走线 | selected_only 默认值逻辑反，不传参数时 DoSelect=False | 反转逻辑：不传参数时默认 True（只修改选中） |
| B19 | get_component_info 多个属性访问错误 | Comp.Designator 返回 COM Dispatch 对象 | 改用 Comp.Designator.Text, Comp.Comment.CalculatedValueString, Comp.ComponentDescription |
| B01 | set_component_position 单位双重转换 | TS schema 描述为 mils*10000 | 改为 mils |
| B02 | pcb_edit Zod schema 不完整 | 只定义 action 参数 | 添加全部 22 个参数 |
| B03 | SchEditSetComponentTransform 类型溢出 | Integer(32位) 替代 TCoord(64位) | 改为 TCoord |
| B10 | ShowMessage 阻塞 MCP 桥接 | 模态对话框暂停脚本 | 移除全部 11 处 ShowMessage |

### 5. DelphiScript API 验证发现

基于 scripts-libraries-master 参考库和 API 文档，确认以下 API 规范：

| 接口 | 属性/方法 | 正确用法 | 错误用法 |
|------|----------|---------|---------|
| ISch_Component | Designator | Comp.Designator.Text | Comp.Designator |
| ISch_Component | Comment | Comp.Comment.CalculatedValueString | Comp.Comment |
| ISch_Component | Description | Comp.ComponentDescription | Comp.Description |
| ISch_Component | Mirrored | 不存在（Mirror 是方法） | Comp.Mirrored |
| ISch_Component | CurrentPartId | 不存在 | Comp.CurrentPartId |
| ISch_Pin | IsHidden | Pin.IsHidden | Pin.Hidden |
| IPCB_ComponentBody | Rotation | 不存在 | Body.Rotation |
| IPCB_ComponentBody | x/y | 不存在 | Body.x / Body.y |
| IPCB_Polygon | MinTrack | Polygon.MinTrack | Polygon.MinTrackWidth |
| IPCB_Board | LayerStack_V7 | Board.LayerStack_V7 | Board.LayerStack (MasterLayerStack) |
| ISch_Rectangle | LineWidth | eMedium (枚举) | MilsToCoord(10) (坐标值) |
| IPCC_Region | SetOutlineContour | Region.SetOutlineContour(Contour) | Region.SetState_Outline(Contour) |

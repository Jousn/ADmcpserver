## 2026-08-20 (周三) — Bug 修复与测试（14 个 Bug）

### 6. set_component_position 单位双重转换 (严重)

**现象**：调用 `set_component_position` 设置元件位置时，元件放到极远处

**根因**：TS schema 描述为 `mils * 10000 (PCB internal units)`，AI 据此发送已转换的值，DelphiScript 又调用 `MilsToCoord()` 再乘 10000

**修复**：
- `src/index.ts` — `x`/`y` 参数描述改为 `mils`
- `src/toolDefinitions.ts` — 同步描述
- `src/mcpInstructions.ts` — 补充 PCB 写入操作单位说明
- MCP 工具描述缓存文件 (`set_component_position.json`) — 同步更新

### 7. pcb_edit Zod schema 不完整 (严重)

**现象**：`pcb_edit` 工具调用时坐标参数被剥离

**根因**：Zod schema 只定义了 `action` 一个参数，`safeParseAsync` 会剥离所有未定义的 key

**修复**：`src/index.ts` 为 `pcb_edit` 添加全部 22 个参数定义（坐标、宽度、层名、网络名等）

### 8. SCH SchEditSetComponentTransform 类型溢出

**现象**：原理图元件位置设置时大坐标值截断

**根因**：`NewX, NewY` 声明为 `Integer`（32位），`TCoord` 是 `Int64`（64位）

**修复**：`schematic_edit.pas` — `Integer` → `TCoord`

### 9. Altium_API.pas 浮点解析未处理逗号小数点

**根因**：中文 Windows 区域设置中小数分隔符为逗号，`StrToFloat` 直接调用会解析错误

**修复**：`Altium_API.pas` — 6 处 `StrToFloat` 添加 `StringReplace(ParamValue, ',', '.', MkSet(rfReplaceAll))`

### 10. set_pcb_layer_visibility 显示层时其他层消失

**现象**：调用 `set_pcb_layer_visibility` 显示指定层时，其他所有层都被隐藏

**根因**：`Visible = true` 分支错误地隐藏了所有未指定的层（排他显示逻辑）

**修复**：`pcb_utils.pas` — 移除 `Visible = true` 分支中的 3 个 `else` 子句

### 11. pcb_edit 报错 Undeclared identifier: LayerToString

**根因**：代码中使用 `LayerToString`，正确函数名是 `Layer2String`（数字 2）

**修复**：`pcb_utils.pas` — 5 处 `LayerToString` → `Layer2String`

### 12. edit_schematic enum 缺少 action

**现象**：`add_port`、`add_junction`、`add_line`、`add_rectangle`、`get_component_info` 被 Zod 拒绝

**根因**：描述中列了 18 个 action，但 enum 只有 13 个

**修复**：
- MCP 缓存 `edit_schematic.json` — enum 补全 5 个 action，properties 补全 8 个参数
- `src/tools/editSchematic.ts` — Zod schema 同步补全

### 13. search_library_symbol 弹出文件对话框

**现象**：未提供 `library_path` 时弹出 `TOpenDialog` 让用户手动选择文件

**修复**：完全重写 `SearchLibrarySymbol` 函数，三模式自动搜索：
1. 提供 `library_path` → 搜索指定文件
2. 未提供 + 有焦点项目 → 自动遍历项目中所有 .SchLib
3. 未提供 + 无焦点项目 → 检查已打开的 .SchLib
4. 都没有 → 返回 JSON 错误（不弹窗）

### 14. get_library_symbol_reference 编译错误

**现象**：`Undeclared identifier: ObjectID`

**根因**：`ISch_Document` 没有 `ObjectID` 属性

**修复**：全部 8 处 `CurrentLib.ObjectID = eSchLib` → `Pos('.SchLib', CurrentLib.DocumentName) > 0`

### 15. get_library_symbol_reference 运行时错误

**现象**：`No SCHLIB document found in the project`

**根因**：函数要求用户先手动打开 SchLib，否则直接报错

**修复**：完全重写 `GetLibrarySymbolReference`，与 `SearchLibrarySymbol` 一致的三模式搜索

### 16. ShowMessage 弹窗阻塞 MCP 桥接 (严重)

**现象**：AI 调用工具时 Altium 弹出错误对话框，脚本暂停等待用户点击 OK，导致 MCP 超时

**根因**：`ShowMessage` 是模态对话框，会阻塞脚本执行

**修复**：移除所有 `ShowMessage` 调用（11 处），替换为 JSON 错误响应：
- `Altium_API.pas` — 8 处
- `other_utils.pas` — 2 处
- `get_library_symbol_reference` 加入 `FocusDocumentIfNeeded` 跳过列表

### 17. SchLibIterator_Create 编译错误

**现象**：`Undeclared identifier: SchLibIterator_Create`

**根因**：`SchServer.GetCurrentSchDocument` 返回 `ISch_Document`，该接口有 `SchIterator_Create` 但没有 `SchLibIterator_Create`（后者属于 `ISch_Lib`）

**修复**：`schematic_utils.pas` — 8 处 `SchLibIterator_Create` → `SchIterator_Create`

### 18. PrimObjectIdToString 新增函数

**问题**：`pcb_utils.pas` 调用未定义的 `ObjectToString(Prim)` 函数

**修复**：新增 `PrimObjectIdToString(ObjId: TObjectId)` 函数，将 PCB 对象 ID 映射为可读字符串（14 种类型）

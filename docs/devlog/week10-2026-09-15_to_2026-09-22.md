## 1. P0 模板系统实机验收 + B29

P0（buck-input-stage 模板 + instantiate_module，编码于 09-14 深夜）在 Sheet2 空白图纸实机验收：**一次调用 100 秒**——6 元件自动分配位号落位、4 网布线全过、参数覆盖生效（c_bulk_uf=220 → C1=220uF）、编译网表子集校验 all_module_nets_compiled=true。"模板承载设计知识、模型只选型填参"的系列化路线拿到第一块实证。另：Diode 18TQ045 实测引脚为数字编号（3=A 朝左 / 1=K 朝右），模板初稿的 A/K 字母猜测定稿前修正。

**B29（事故）**：AD 重启后每次桥接调用弹脚本错误框、ping 超时。根因：`schematic_utils.pas:1994` 三向解析器 `else if RealMatch <> nil` 漏写 `then`——RunScript 每次整体编译脚本工程，一处语法错误使**全部**命令不可用。grep `nil$` 且无 `then` 的行定位，三个解析器副本仅此一处笔误；修复后 ping 恢复 1.6s。教训：Pascal 侧无编译检查兜底，多副本结构性改动必须逐副本 diff。

**Sheet1 从零重绘回归**：应用户要求清空整图按首次绘制状态重画（14 元件含上次中断的半成品全删 → 快照恢复库引用/数值 → 双轨布局 → 布线 → 端口吸附），编译分区与黄金网表逐引脚一致、0 错误 0 警告。

## 2. 实机美学反馈闭环（模板 v2→v3）

用户对成图两条反馈："元件旋转没考虑引脚方向"“标号重叠”。机器实测坐标判定确认：

| 问题 | 根因 | 修复 |
|------|------|------|
| J1 引脚朝左背对电路，导线穿本体 | 模板 rot 拍脑袋 | rot180 引脚朝右 |
| 分压链上下颠倒，GND 轨从两电阻中间穿过，EN 绕行 1000mil | Res1 rot90=pin1 底（实测） | 双改 rot270（pin1 顶）头尾相接 |
| 无轨道概念 | 布局按格点估 | 实测热点偏移反解位置：VIN 轨直穿四热点，间距计入标签文本宽（60mil/字符） |

**B30**：`Component.BoundingRectangle` 对旋转符号返回错误矩形（R1 rot270 的包围盒甚至不含自己的引脚热点）。修复：弃用导出值，`componentKeepOutRects()` 用**实测引脚热点 ∪ 原点凸包**构造禁入区（抗旋转）。配套：路由器 bodyRects 节点封锁 + **边穿越检查**（100mil 网格步长可一步跨过 80mil 薄阻挡带）；标签碰撞回避 `pickLabelAnchor`（沿本网导线 50mil 采样，文本框 vs 凸包+已放标签，优选水平段）。Sheet2 v3 重部署：4 网全过、三标签净空、97/97 测试。

## 3. 锚点引脚放置（anchor_pin）——旋转甩位的结构性消除

用户点破机制：**AD 绕元件 Location 原点（通常偏心）旋转，转 90° 整个符号甩位**——引脚朝向错乱与 B30 的共同根源。解法：放置语义从"放原点"升级为"放接口点"：

- `rotateOffsetCCW`（CCW 旋转矩阵，实机标定：Res1/Header2/Cap/Diode 四符号多旋转复现）+ `pinHotspotOffsetAtRot0`
- `anchoredOrigin`：origin = target − rotate(rot0 偏移, θ)；instantiateModule 放置后**回读验证 + >5mil 自动纠偏**（自愈）
- `place_component` 工具面直接暴露 `anchor_pin`（index.ts 拦截解析）
- 模板 v4：全槽位锚点化，layout 即轨道坐标——**VIN 轨由构造保证笔直**（v3 的 100mil 台阶消失）；实机六元件矩阵反解与实测逐 mil 一致、零纠偏触发；101/101 测试

**模板 authoring 语义升级**：v4 起 layout = 接口点坐标（"C_BULK.1 落 x=1500, y=0"），新模板不再需要测量-反解循环。

## 本周经验沉淀

1. **用户反馈是最准的验收标准**：三轮美学反馈各驱动一次架构升级（朝向纪律→锚点语义→规划强制化）——每轮都先机器实测定位，不猜
2. **AD 的旋转是绕偏心原点的甩动**：一切几何以引脚落点表达（anchor_pin），原点位置是工具内部细节
3. **能实测的几何绝不信导出值**（B30）；**能落盘的状态绝不留在对话里**（台账）
4. **门禁的默认值就是它的性格**：严格覆盖默认开、宽松显式申请（DRIVE 漏网的制度性修复）
5. **门禁的价值看拦截记录**：Sheet3 一战三个真错误全被拦在成图之前——错误不是不出，而是出在纸上而不是图上
6. **部署包要独立自检**：staging 副本跑通完整 smoke 才算交付；npm 坏了就写依赖闭包计算器，不等环境修好

## 6. 维护说明

1. **级别调整原则**：error 仅用于已造成过事故的模式（当前 12 条无 error 默认级，待孙金亮按公司事故史决定是否升级个别规则）；
2. 阈值修订须同步：本表版本号 ↑、emc_audit 调用配置、《EMC规则阈值表》在 altium-mcp 说明书 4.11 节的引用；
3. 晶振/去耦等"存在性检查"规则无阈值参数，如需数值化（如 ESR 上限）先改 emcAudit.ts 再更新本表；
4. 本表不含任何虚构标准条款号；正式引用安规条款时以公司受控标准清单为准。

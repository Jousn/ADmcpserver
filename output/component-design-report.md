# DC-AC逆变器电路设计报告

## 一、元件选型报告

### 需求摘要
- **电路类型**：DC-AC逆变器（方波输出）
- **输入电压**：5V DC
- **输出电压**：5V AC（方波）
- **输出频率**：400Hz（中频）
- **输出功率**：>50W（大功率）
- **隔离要求**：需要电气隔离

### 选型说明

- **U1 (运算放大器)**：用于产生400Hz方波信号。选择FET输入运放，输入阻抗高，功耗低。
- **Q1-Q4 (MOSFET)**：组成H桥驱动电路。Q1、Q2为N沟道，Q3、Q4为P沟道，实现推挽输出。
- **T1 (变压器)**：1:1隔离变压器，实现输入输出电气隔离，同时提供功率传输。
- **R1-R2**：运算放大器振荡频率设定电阻，决定输出频率。
- **R3-R4**：MOSFET栅极限流电阻，防止振荡。
- **R5**：输入限流电阻，保护电路。
- **C1-C3**：电源去耦电容，滤除高频噪声。
- **D1-D4**：续流二极管，保护MOSFET免受反向电压冲击。

### 元件来源统计
- **库内可用**：16个（无需创建符号）
- **需新建符号**：4个（变压器、连接器）
- **需Web确认参数**：0个

### 连接方案说明

1. **振荡器部分**：运算放大器U1与R1、R2、C3构成施密特触发器振荡器，产生400Hz方波信号。
   - 振荡频率计算：f = 1/(2*R*C*ln((1+β)/(1-β)))
   - 其中β = R1/(R1+R2) = 11K/(11K+11K) = 0.5
   - R = 11KΩ, C = 0.1μF
   - 计算得：f = 1/(2*11e3*0.1e-6*1.0986) = 413.7Hz ≈ 400Hz

2. **H桥驱动**：Q1-Q4组成H桥电路，将单端方波信号转换为差分驱动信号。
   - 当OSC_OUT为高时，Q1和Q4导通，电流从VCC→Q1→T1→Q4→GND
   - 当OSC_OUT为低时，Q2和Q3导通，电流从VCC→Q2→T1→Q3→GND
   - 实现变压器初级的交流驱动
   - 电流计算：P = V*I → I = P/V = 50W/5V = 10A（最大）
   - MOSFET选型：IRFZ44N（N沟道，49A，0.022Ω），IRF4905（P沟道，74A，0.02Ω）

3. **变压器隔离**：T1为1:1隔离变压器，实现输入输出电气隔离，同时传递功率。
   - 初级电压：5V方波
   - 次级电压：5V方波（400Hz）
   - 功率要求：60W以上（留有余量）
   - 匝数比：1:1
   - 初级电感量：L = V/(4*f*I) = 5/(4*400*10) = 312.5μH（最小）

4. **保护电路**：D1-D4为续流二极管，保护MOSFET免受变压器反电动势冲击。
   - 二极管选型：1N4007（1A，1000V）
   - 反向电压：5V
   - 正向电流：10A（峰值）

5. **电源设计**：输入5V DC，通过C1、C2滤波后为整个电路供电。
   - C1：100μF电解电容，储能滤波
   - C2：0.1μF陶瓷电容，高频去耦
   - R5：10Ω限流电阻，限制浪涌电流

- **信号网络**：OSC_OUT, OSC_INV, H_BRIDGE_A, H_BRIDGE_B

## 三、设计注意事项

### 功率计算
- 输出功率：P = V*I = 5V * I
- 若要求P > 50W，则I > 10A
- MOSFET选型：
  - N沟道：IRFZ44N（49A，0.022Ω，Vgs=10V时Rds(on)=0.0175Ω）
  - P沟道：IRF4905（74A，0.02Ω，Vgs=10V时Rds(on)=0.02Ω）
- 变压器：需能承受10A以上电流，建议使用铁硅铝磁环

### 散热设计
- MOSFET功耗：P_mos = I²*Rds(on) = 10²*0.022 = 2.2W（每个）
- 总功耗：4个MOSFET ≈ 8.8W
- 散热片要求：热阻 < 5°C/W
- 建议使用铝型材散热片，尺寸至少100x50x25mm

### PCB布局
- 功率回路走线：宽度至少10mm（载流10A）
- 输入输出连接器：靠近变压器放置
- 去耦电容：紧靠IC电源引脚
- 地线设计：单点接地，避免地环路
- 散热过孔：MOSFET下方打散热过孔

### 保护功能
- 输入过流保护：15A保险丝
- 输出过压保护：TVS二极管（双向）
- 过热保护：温度开关（85°C触发）
- 输入反接保护：P沟道MOSFET或二极管

### 变压器绕制参数（参考）
- 磁环：铁硅铝，外径50mm，内径30mm，高度20mm
- 初级：0.8mm漆包线，50匝
- 次级：0.8mm漆包线，50匝
- 电感量：初级约300μH
- 额定电流：10A（连续）

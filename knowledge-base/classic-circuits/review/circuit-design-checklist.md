# 经典电路设计审查总清单

> 本文档为经典电路设计全流程审查清单，覆盖电源完整性、信号完整性、EMI/EMC、热设计、安全、可制造性及接口设计等关键审查领域。面向 AI Skills 在设计审查阶段的结构化检索与自动核查。

---

## 1. 电源完整性审查

电源完整性审查确保各电源轨在稳态和瞬态条件下的电压稳定性、纹波控制和去耦完整性。

| 编号 | 检查项 | 要求 | 通过标准 | 风险等级 | 对应模块 |
|------|--------|------|----------|----------|---------|
| PI-01 | LDO 压差裕量 | Vin_min - Vout >= Vdropout + 0.3V | 全温区满足 | 高 | 01-ldo |
| PI-02 | LDO 功耗与散热 | Pd < Pd_max(考虑温升) | Tj < 125C | 高 | 01-ldo |
| PI-03 | LDO 输出电容 ESR | 在数据手册稳定窗口内 | 无振荡 | 高 | 01-ldo |
| PI-04 | Buck 电感饱和电流 | >= 1.2 * Ipeak_max | 全输入范围满足 | 高 | 02-buck |
| PI-05 | Buck 输入电容 RMS 电流 | >= Iout*sqrt(D*(1-D)) | 电容规格满足 | 高 | 02-buck |
| PI-06 | Buck 续流二极管耐压 | >= 1.3 * Vin | 留余量 | 中 | 02-buck |
| PI-07 | Boost 升压比 | < 5:1（实际工程限制） | 占空比 < D_max | 高 | 03-boost |
| PI-08 | Boost 电感峰值电流 | < IC 电流限制 * 0.8 | 不触发电流限制 | 高 | 03-boost |
| PI-09 | MCU VDD 去耦 | 每个 VDD 引脚 100nF + 全局 4.7uF | 电容紧贴引脚 | 高 | 04-mcu |
| PI-10 | MCU VDDA 滤波 | 铁氧体磁珠 + 1uF + 100nF | 模拟电源隔离 | 高 | 04-mcu |
| PI-11 | 电源上电时序 | 多电源轨按序上电 | 核心先于 IO 或按手册 | 中 | 04-mcu |
| PI-12 | 电源轨纹波 | LDO < 10mV, Buck < 50mV | 满足负载要求 | 中 | 01/02 |

## 2. 信号完整性审查

信号完整性审查覆盖高速信号、差分对、时钟和总线的传输质量。

| 编号 | 检查项 | 要求 | 通过标准 | 风险等级 | 对应模块 |
|------|--------|------|----------|----------|---------|
| SI-01 | USB2.0 差分阻抗 | 90 ohm +/- 15% | 阻抗计算/TDR 验证 | 高 | 08-usb |
| SI-02 | USB2.0 差分等长 | D+/D- 长度差 < 5mil | 蛇形补偿 | 高 | 08-usb |
| SI-03 | USB 参考平面 | D+/D- 下方完整 GND | 无平面分割 | 高 | 08-usb |
| SI-04 | USB3.0 超速差分对 | 90 ohm +/- 10%, 等长 < 3mil | 阻抗+等长 | 高 | 08-usb |
| SI-05 | SPI 串联匹配电阻 | 22~33 ohm (高速时) | 抑制反射 | 中 | 10-spi-i2c |
| SI-06 | SPI 等长控制 | SCLK/MOSI/MISO < 50mil 误差 | 高速时必须 | 中 | 10-spi-i2c |
| SI-07 | I2C 上拉电阻 | Vcc=3.3V/400kHz: 2.2k~4.7k | 上升时间达标 | 高 | 10-spi-i2c |
| SI-08 | I2C 总线电容 | < 400pF (Standard/Fast) | 走线+器件总电容 | 中 | 10-spi-i2c |
| SI-09 | 时钟走线 | HSE 晶振走线 < 5mm, 两侧铺 GND | 保护环完整 | 高 | 04-mcu |
| SI-10 | 运放反馈环路面积 | < 10mm^2 | 反馈走线紧凑 | 中 | 05-opamp |
| SI-11 | 运放 GBW 校验 | GBW > Av * f_signal * 10 | 带宽裕量充足 | 高 | 05/06-opamp |
| SI-12 | 运放压摆率 | SR > 2*pi*f*Vpeak | 无压摆率限制失真 | 高 | 05/06-opamp |

## 3. EMI/EMC 审查

EMI/EMC 审查确保电路满足电磁兼容标准，包括传导/辐射发射和抗扰度。

| 编号 | 检查项 | 要求 | 通过标准 | 风险等级 | 对应模块 |
|------|--------|------|----------|----------|---------|
| EMC-01 | Buck 输入回路面积 | < 10mm^2 | Cin 紧贴 IC VIN/GND | 高 | 02-buck |
| EMC-02 | Buck SW 节点处理 | 走线短, 下方铺 GND | 减少辐射 | 高 | 02-buck |
| EMC-03 | Boost SW 节点 | 短而宽, 远离敏感信号 | EMI 可控 | 高 | 03-boost |
| EMC-04 | 时钟走线保护 | 晶振下方禁止走线 | GND 保护环 | 高 | 04-mcu |
| EMC-05 | USB 共模电感 | 90 ohm @ 100MHz CMC | 共模噪声抑制 | 中 | 08-usb |
| EMC-06 | RS485 差分走线 | A/B 平行等长, 差分阻抗 | 信号完整性 | 中 | 09-rs485 |
| EMC-07 | GND 平面完整性 | 电源/信号区域无分割 | 回流路径完整 | 高 | 全部 |
| EMC-08 | 20H 规则 | 电源平面内缩 20H | 辐射抑制 | 中 | 全部 |
| EMC-09 | 去耦电容位置 | 紧贴 IC 电源引脚 (< 5mm) | 就近滤波 | 高 | 全部 |
| EMC-10 | ESD 保护器件位置 | 距连接器 < 5mm | 先于内部电路动作 | 高 | 11-tvs |

## 4. 热设计审查

热设计审查确保所有发热器件在最大环境温度下结温不超过安全限值。

| 编号 | 检查项 | 要求 | 通过标准 | 风险等级 | 对应模块 |
|------|--------|------|----------|----------|---------|
| TH-01 | LDO 结温计算 | Tj = Ta + Pd*Rth_ja < 125C | 全温区满足 | 高 | 01-ldo |
| TH-02 | LDO 散热铜皮 | SOT-223 >= 100mm^2 GND 铜 | 过孔阵列散热 | 高 | 01-ldo |
| TH-03 | Buck IC 结温 | Tj < 125C (考虑开关损耗) | 热仿真/计算 | 高 | 02-buck |
| TH-04 | Boost 电感温升 | 电感温升 < 40C (Irms 条件) | 选型满足 | 中 | 03-boost |
| TH-05 | TVS 功率降额 | Ppp_actual < Ppp_rated * 0.8 | 留功率余量 | 高 | 11-tvs |
| TH-06 | PTC 散热空间 | 周围 > 2mm 间隙 | 不影响周边器件 | 中 | 12-fuse |
| TH-07 | PCB 铜皮载流 | 满足 IPC-2152 电流要求 | 温升 < 20C | 高 | 全部 |

## 5. 安全与保护审查

安全审查确保电路在异常条件下保护人身和设备安全。

| 编号 | 检查项 | 要求 | 通过标准 | 风险等级 | 对应模块 |
|------|--------|------|----------|----------|---------|
| SF-01 | 输入端 Fuse/PTC | 额定电流 >= 1.25*In/Kt | 熔断特性匹配 | 高 | 12-fuse |
| SF-02 | Fuse 分断能力 | >= 最大短路电流 | 不发生拉弧 | 高 | 12-fuse |
| SF-03 | Fuse I2t 校验 | Fuse I2t > 浪涌 I2t | 不误熔断 | 中 | 12-fuse |
| SF-04 | TVS Vc 选择 | < 器件耐压 * 0.8 | 钳位安全 | 高 | 11-tvs |
| SF-05 | TVS Vwm 选择 | >= 工作电压 * 1.2 | 正常不导通 | 高 | 11-tvs |
| SF-06 | ESD 保护等级 | IEC 61000-4-2 Level 4 (8kV) | 接触放电通过 | 高 | 11-tvs |
| SF-07 | 浪涌保护 | IEC 61000-4-5 (4kV) | 差模/共模通过 | 高 | 11-tvs |
| SF-08 | TVS + Fuse 协调 | TVS 存活到 Fuse 熔断 | 能量协调 | 高 | 11/12 |
| SF-09 | VBUS 过流保护 | PTC 或 eFuse 限流 | USB 500mA 限制 | 中 | 08-usb/12-fuse |
| SF-10 | RS485 隔离耐压 | >= 2500Vrms (工业) | 隔离间距 >= 2mm | 高 | 09-rs485 |

## 10. 审查流程与优先级

### 10.1 审查优先级

```
P0 (必须通过, 阻断性):
  PI-01~PI-08 (电源核心)
  SI-01~SI-04 (高速信号)
  EMC-01~EMC-04 (核心 EMI)
  SF-01~SF-08 (安全保护)
  MC-01~MC-05 (MCU 核心)

P1 (应当通过, 重要):
  PI-09~PI-12 (电源质量)
  SI-05~SI-12 (信号质量)
  EMC-05~EMC-10 (EMI 补充)
  TH-01~TH-07 (热设计)
  AN-01~AN-10 (模拟电路)

P2 (建议通过, 改进性):
  IF-01~IF-10 (接口规范)
  MC-06~MC-08 (MCU 补充)
  MF-01~MF-08 (可制造性)
```

### 10.2 审查流程

```
设计输入 -> 原理图审查 -> PCB 审查 -> 样机验证
    │           │           │           │
    ├─PI审查    ├─SI审查    ├─EMC审查   ├─ESD测试
    ├─SF审查    ├─AN审查    ├─TH审查    ├─浪涌测试
    └─IF审查    └─MC审查    └─MF审查    └─温升测试
```

## 1. 概述

运算放大器（Operational Amplifier, OpAmp）是模拟电路设计的核心器件。本模块覆盖最常见的放大电路拓扑，包括反相放大器、同相放大器、差分放大器和仪表放大器，提供完整的增益计算公式、器件选型指南和 PCB 布局规范。

## 2. 反相放大器

### 2.1 电路拓扑

```
                Rf
Vin ──Rin──┬──/\/\/──┬── Vout
            │         │
            └──/\/\/──┘    (-) 输入端
                │
           ┌────┤
           │    ┤(-)
      Vref │    │ OpAmp
           │    ┤(+)
           └────┤
                │
               GND (或 Vref 偏置)
```

### 2.2 增益计算

```
Av = Vout / Vin = -Rf / Rin
```

示例（Rin=10k, Rf=100k）：

```
Av = -100k / 10k = -10 (增益 20dB)
```

### 2.3 输入阻抗与输出阻抗

```
Zin = Rin (输入阻抗等于输入电阻)
Zout -> 0 (闭环输出阻抗极低)
```

### 2.4 设计要点

- Rin 选择：输入阻抗要求决定 Rin 下限，Rin 一般 1k~100k
- Rf 选择：Rf/Rin 决定增益，Rf 一般 10k~1M
- Rf 过大：增大噪声和失调电压误差
- Rf 过小：增大功耗和降低输入阻抗
- 偏置电阻：(+) 输入端接 Rb = Rin || Rf 消除偏置电流误差

### 2.5 偏置电流补偿

```
同相端补偿电阻:
Rb = Rin || Rf = (Rin * Rf) / (Rin + Rf)

示例: Rin=10k, Rf=100k
Rb = (10k * 100k) / (10k + 100k) = 9.09k -> 取标准值 9.1k
```

## 3. 同相放大器

### 3.1 电路拓扑

```
         ┌──────/\/\/──────┐
         │       Rf        │
         │                 │
Vin ──┬──┤(+)               ├── Vout
      │   │     OpAmp       │
      │   └──┤(-)           │
      │       │             │
      │      Rin            │
      │       │             │
      └──────┤             │
             GND            
```

### 3.2 增益计算

```
Av = Vout / Vin = 1 + Rf / Rin
```

示例（Rin=10k, Rf=90k）：

```
Av = 1 + 90k / 10k = 10 (增益 20dB)
```

### 3.3 输入阻抗

同相放大器的输入阻抗极高：

```
Zin = Zin_OpAmp * (1 + A_ol * beta) (闭环增益提升)
```

其中 A_ol 为开环增益，beta 为反馈系数。典型 Zin > 1G ohm（JFET/CMOS 输入）。

### 3.4 设计要点

- 输入阻抗高，适合高阻抗信号源
- 增益最小值为 1（电压跟随器，Rf=0, Rin=开路）
- 输入共模电压范围需满足（非轨到轨运放需留裕量）
- 共模抑制比（CMRR）影响精度，高精度场合选精密运放

### 3.5 电压跟随器

当 Rf=0, Rin=开路时，Av=1：

```
Vin ──┤(+)     ── Vout
      │ OpAmp  │
      └──┤(-)──┘
```

用途：阻抗变换、缓冲、隔离前后级。

## 4. 差分放大器

### 4.1 电路拓扑

```
V1 ──R1──┬──R2── Vref
          │
          ├──┤(-)
          │  │   OpAmp ── Vout
V2 ──R3──┬──┤(+)
          │
          R4
          │
         Vref
```

### 4.2 增益计算（电阻匹配条件）

当 R1=R3, R2=R4 时：

```
Vout = (V2 - V1) * (R2 / R1)
Av = R2 / R1
```

示例（R1=R3=10k, R2=R4=100k）：

```
Av = 100k / 10k = 10
Vout = (V2 - V1) * 10
```

### 4.3 电阻匹配要求

差分放大器的精度完全依赖电阻匹配：

```
CMRR = 20 * log10((1 + R2/R1) / (4 * delta_R / R))
```

其中 delta_R 为电阻失配量。

| 电阻精度 | CMRR（Av=10） | 适用场景 |
|---------|---------------|---------|
| 5% | 34dB | 低精度 |
| 1% | 48dB | 通用 |
| 0.1% | 68dB | 精密 |
| 0.01% | 88dB | 高精度 |

推荐使用 0.1% 精度电阻或精密差分放大器 IC（如 AD8276）。

### 4.4 输入阻抗限制

基本差分放大器输入阻抗不对称：

```
Zin_V1 = R1 (反相输入阻抗低)
Zin_V2 = R1 + R4 (同相输入阻抗高)
```

输入阻抗不对称可能导致传感器负载不匹配。解决方案：使用仪表放大器。

## 5. 仪表放大器（Instrumentation Amplifier）

### 5.1 三运放仪表放大器拓扑

```
V1 ──┬──────────────────┐
      │   Rg             R2
      └──/\/\/──┬──/\/\/─┐
                │         │
              ┌─┴─┐      ┌─┴─┐
              │A1 │      │A2 │
              └─┬─┘      └─┬─┘
                │           │
                └──┬────────┘
                   │ Rg
                   └──/\/\/──┘
                   
V2 ──┬──────────────────┐
      │
      └──/\/\/──┬──/\/\/─┘
                Rg      R2

A1/A2 输出 → 差分放大器 A3 → Vout
```

### 5.2 增益计算

```
Av = (1 + 2*R1/Rg) * (R3/R2)
```

通常差分级增益 R3/R2=1，则：

```
Av = 1 + 2*R1/Rg
```

示例（R1=25k, Rg=5k）：

```
Av = 1 + 2*25k/5k = 1 + 10 = 11
```

### 5.3 AD620 仪表放大器

AD620 集成了三运放仪表放大器，仅需外接 Rg 设定增益：

```
Rg = 49.4k / (Av - 1)
```

| 目标增益 | Rg 计算值 | 标准电阻值 | 实际增益 |
|---------|----------|----------|---------|
| 1 | 开路 | — | 1.000 |
| 10 | 5.49k | 5.49k(1%) | 10.00 |
| 100 | 499 ohm | 499(1%) | 100.0 |
| 1000 | 49.4 ohm | 49.3(1%) | 1003 |

### 5.4 仪表放大器优势

| 特性 | 基本差分放大器 | 仪表放大器 |
|------|--------------|-----------|
| 输入阻抗 | 低（~R1） | 极高（> 1G ohm） |
| CMRR | 依赖电阻匹配 | 内部激光修调，> 100dB |
| 增益调节 | 需改多颗电阻 | 仅改 Rg |
| 成本 | 低 | 高 |

## 6. 增益带宽积校验

### 6.1 GBW 概念

```
GBW = Av * f(-3dB)
```

运放的增益带宽积为常数，设定增益越大，可用带宽越小。

### 6.2 带宽计算

```
f_max = GBW / Av
```

示例（LM358: GBW=1MHz, Av=100）：

```
f_max = 1MHz / 100 = 10kHz
```

若信号频率为 10kHz，LM358 在增益 100 时已到带宽极限。

### 6.3 GBW 选型表

| 信号频率 | 增益 | 所需 GBW | 推荐运放 |
|---------|------|----------|---------|
| DC~1kHz | 100 | 0.1MHz | LM358, OPA2333 |
| 1kHz~10kHz | 100 | 1MHz | TL084, OPA2376 |
| 10kHz~100kHz | 100 | 10MHz | AD8606, OPA2376 |
| 100kHz~1MHz | 10 | 10MHz | AD8606 |
| > 1MHz | 10 | > 100MHz | AD8055, LM7171 |

### 6.4 压摆率校验

```
SR_min = 2 * pi * f_max * Vpeak
```

示例（f=100kHz, Vpeak=3V）：

```
SR_min = 2 * pi * 100k * 3 = 1.885 V/us
LM358 SR = 0.5 V/us (不足!) -> 需要选 TL084 (SR=13V/us) 或更快的运放
```

## 7. 供电设计

### 7.1 单电源供电

单电源运放需要虚拟地（偏置电压）：

```
3.3V ──┬── V+
       │
      运放
       │
      GND ── V-

信号偏置: Vref = V+/2 = 1.65V

Vref 产生方法:
  3.3V ──┬── R1(10k) ──┬── Vref(1.65V)
         │              │
         │             C1(1uF)
         │              │
         └── R2(10k) ──┘
                        │
                       GND
```

### 7.2 双电源供电

高精度模拟电路推荐双电源供电：

```
+12V ── V+
  运放
-12V ── V-
```

双电源供电不需要虚拟地，信号以 0V 为中心，动态范围更大。

### 7.3 电源去耦

每个运放供电引脚必须就近放置去耦电容：

```
V+ ──┬── 100nF ── GND
V- ──┬── 100nF ── GND
     │
    10uF (全局储能，多个运放共用)
```

高频/低噪声应用增加 10nF 并联：

```
V+ ──┬── 100nF ──┬── 10nF ── GND
```

## 8. PCB 布局指南

### 8.1 信号走线原则

1. **输入走线最短**：反相输入端走线尽量短，减少寄生电容
2. **反馈走线紧凑**：Rf 和 Rin 紧贴运放引脚，反馈环路面积 < 10mm^2
3. **对称布局**：差分放大器的匹配电阻对称布局，温度梯度一致
4. **模拟/数字分离**：运放区域与数字电路物理隔离，GND 分割

### 8.2 高精度布局

```
┌─────────────────────────────┐
│         Rf  ┌──────┐         │
│  Rin ──┬───┤      │         │
│        │   │ OpAmp├── Vout   │
│        └───┤(-)   │         │
│            │      │         │
│      Vref ─┤(+)   │         │
│            └──────┘         │
│     100nF  │      │  100nF  │
│     V+ ─┤├─┘    └─┤├─ V-   │
│                            │
│  █████ GND 平面 ████████      │
└─────────────────────────────┘
```

### 8.3 保护环

高阻抗输入（如 pH 传感器、光电二极管）使用保护环防止漏电流：

```
              ╔══════════╗
              ║          ║
         ┌────╫─┐      ┌─╫────┐
   保护环 │    ║ │      │ ║    │ 保护环
   ───┐  │    ║(-)    (+)║    │  ┌───
       │  │    ║          ║    │  │
       └──┘    ╚══════════╝    └──┘
    保护环连接到低阻抗信号
    (如运放同相输入端的缓冲输出)
```

## 9. 常见设计陷阱与解决方案

### 9.1 自激振荡

**原因**：反馈环路不稳定、电源去耦不足、负载电容过大

**解决**：
- 增加电源去耦电容（100nF + 10uF）
- 反馈电阻并联小电容（几 pF）构成主极点补偿
- 容性负载串联隔离电阻（50~100 ohm）

### 9.2 失调电压大

**原因**：偏置电流误差、输入失调电压、电阻热噪声

**解决**：
- 使用偏置电流补偿电阻
- 选择低失调运放（OPA2333, AD8606）
- 降低反馈电阻阻值（< 100k）

### 9.3 带宽不足

**原因**：GBW 不够、压摆率不足

**解决**：
- 计算所需 GBW = Av * f_signal * 10（留 10 倍裕量）
- 验证压摆率 SR > 2*pi*f*Vpeak
- 选择更高 GBW 的运放

### 9.4 交越失真

**原因**：单电源运放在 0V 附近交越区非线性

**解决**：
- 使用真轨到轨运放（如 AD8606）
- 双电源供电
- 偏置信号到 V+/2 避开交越区

## 10. 设计检查清单

| 检查项 | 要求 | 通过标准 |
|--------|------|----------|
| GBW 校验 | GBW > Av * f * 10 | 满足 |
| 压摆率 | SR > 2*pi*f*Vpeak | 满足 |
| 偏置补偿 | 同相端接 Rb=Rin||Rf | 满足 |
| 电源去耦 | 100nF + 10uF 每路 | 满足 |
| 反馈环路面积 | < 10mm^2 | 满足 |
| 电阻精度 | 差分电路用 0.1% | 满足 |
| 共模电压范围 | 输入信号在 CMVR 内 | 满足 |
| 输出电压范围 | 负载要求在输出摆幅内 | 满足 |

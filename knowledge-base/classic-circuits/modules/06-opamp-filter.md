# 运算放大器有源滤波器设计知识库

> 适用范围：运算放大器有源滤波器电路设计（LPF/HPF/BPF/Sallen-Key/MFB）
> 目标受众：AI 设计辅助 Skill，用于 OpAmp 有源滤波器设计咨询与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

有源滤波器使用运算放大器配合 RC 网络实现频率选择性滤波，相比无源 LC 滤波器具有增益可调、无需电感、阻抗匹配灵活等优势。本模块覆盖 Sallen-Key 拓扑和多路反馈（MFB）拓扑的低通/高通/带通滤波器设计。

### 1.1 滤波器类型对比

| 滤波器类型 | 通带 | 阻带 | 典型应用 |
|-----------|------|------|---------|
| 低通滤波器（LPF） | 0 ~ fc | fc ~ inf | 抗混叠、噪声滤除 |
| 高通滤波器（HPF） | fc ~ inf | 0 ~ fc | 隔直、交流耦合 |
| 带通滤波器（BPF） | fL ~ fH | 其余 | 信号选频 |
| 带阻滤波器（BEF） | 其余 | fL ~ fH | 工频陷波 |

### 1.2 滤波器逼近类型

| 逼近类型 | 通带特性 | 阻带特性 | Q 值 | 适用场景 |
|---------|---------|---------|------|---------|
| 巴特沃斯（Butterworth） | 最平坦 | 缓慢下降 | 中 | 通用 |
| 切比雪夫（Chebyshev） | 有纹波 | 快速下降 | 高 | 陡峭截止 |
| 贝塞尔（Bessel） | 平缓 | 最缓慢 | 低 | 相位线性 |
| 椭圆（Elliptic） | 有纹波 | 最陡下降 | 最高 | 极陡截止 |

## 2. Sallen-Key 低通滤波器

### 2.1 电路拓扑

```
         C1
Vin ──R1──┬──/\/\/──┬──┤(+)── Vout
          │         │   │
          C2        R3  OpAmp (电压跟随器或同相放大)
          │         │   │
          └──R2────┘   └──┤(-)──┐
                              │  │
                             R4  R5 (可选增益设定)
                              │  │
                             GND GND
```

### 2.2 单位增益 Sallen-Key LPF

最简形式（增益=1，运放接成电压跟随器）：

```
Vin ──R1──┬──R2──┬──┤(+)── Vout
          │      │   │
         C1     C2  电压跟随器
          │      │   │
          └──────┴── GND(通过运放同相输入)
```

截止频率计算：

```
fc = 1 / (2 * pi * sqrt(R1 * R2 * C1 * C2))
```

当 R1=R2=R, C1=C2=C 时（等元件设计）：

```
fc = 1 / (2 * pi * R * C)
Q = 1 / 2 (Butterworth 需调整)
```

### 2.3 等元件设计示例

设计目标：fc = 1kHz, Butterworth 响应, 增益=1

```
取 R1 = R2 = R, C1 = C2 = C

Butterworth 条件: Q = 0.707
等元件 Sallen-Key Q = 1/2 = 0.5 (不满足)

需调整: 设增益 Av = 1.586 (=1+R5/R4), 则 Q=0.707
```

等增益法设计：

```
取 C1 = C2 = 10nF (标准值)
R1 = R2 = 1 / (2 * pi * fc * C) = 1 / (2 * pi * 1000 * 10nF) = 15.9k -> 取 16k

fc_actual = 1 / (2 * pi * 16k * 10nF) = 995Hz (误差 0.5%)

增益: Av = 1.586 (实现 Butterworth Q=0.707)
R4 = 10k, R5 = 5.86k -> 取 5.6k + 270ohm = 5.87k
Av_actual = 1 + 5.87/10 = 1.587
```

### 2.4 K 值设计法（非等元件）

更灵活的设计方法，使用不同的 R 和 C 值实现目标 Q 值：

```
取 C1 = n * C2 (n 为比例系数)
R1 = R2 = R

fc = 1 / (2 * pi * R * sqrt(n) * C2)
Q = sqrt(n) / (n + 1)
```

Butterworth (Q=0.707) 要求 n=1，即等元件。需用增益调整 Q。

Chebyshev (Q=1.0, 3dB 纹波) 要求 n=0.414 或 2.414。

## 3. 多路反馈（MFB）低通滤波器

### 3.1 电路拓扑

```
                R2
Vin ──R1──┬──/\/\/──┬──┤(-)
          │         │   │
         C1        C2  OpAmp ── Vout
          │         │   │
          └─────────┘   ┤(+)
                        │
                       GND
```

### 3.2 传递函数

```
H(s) = -R2 / R1 * 1 / (1 + s*R2*C2 + s^2*R1*R2*C1*C2)
```

增益和频率参数：

```
Av = -R2 / R1 (直流增益，反相)
fc = 1 / (2 * pi * sqrt(R1 * R2 * C1 * C2))
Q = sqrt(R1 * R2 * C1 * C2) / (R1 * C1 + R1 * C2 + R2 * C2)
```

### 3.3 MFB 设计示例

设计目标：fc = 1kHz, Butterworth (Q=0.707), Av = -1

```
取 C1 = C2 = 10nF

Butterworth 条件 + Av = -1 (R1 = R2 = R):
fc = 1 / (2 * pi * R * C)
R = 1 / (2 * pi * 1000 * 10nF) = 15.9k -> 取 16k

Q = 1/3 = 0.333 (不满足 Butterworth!)

需调整 C2: 取 C2 = 2 * C1 = 20nF
Q = sqrt(R*R*C1*2C1) / (R*C1 + R*2*C1 + R*2*C1)
  = sqrt(2) / 5 = 0.283 (仍不满足)

正确解法: 使用设计表或软件工具
Butterworth 二阶 MFB, Av=-1, fc=1kHz, C1=10nF:
  C2 = 2 * C1 = 20nF
  R1 = R2 = 1/(2*pi*fc*C1*sqrt(2)) = 11.25k -> 取 11.3k
```

### 3.4 Sallen-Key vs MFB 对比

| 特性 | Sallen-Key | MFB |
|------|-----------|-----|
| 增益极性 | 同相 | 反相 |
| 最小增益 | 1（跟随器） | 任意 |
| Q 值灵敏度 | 较高 | 较低 |
| 元件数 | 少（2R+2C） | 少（2R+2C） |
| 高频性能 | 好（正馈） | 好 |
| 相位 | 同相 | 反相 |
| 适用场景 | 通用 | 高 Q 值 |

## 4. Sallen-Key 高通滤波器

### 4.1 电路拓扑

将 LPF 中的 R 和 C 互换即得到 HPF：

```
Vin ──C1──┬──C2──┬──┤(+)── Vout
          │      │   │
         R1     R2  电压跟随器
          │      │   │
          └──────┴── GND
```

### 4.2 截止频率

```
fc = 1 / (2 * pi * sqrt(R1 * R2 * C1 * C2))
```

### 4.3 设计示例

设计目标：fc = 100Hz, Butterworth, 增益=1.586

```
取 C1 = C2 = 100nF
R1 = R2 = 1 / (2 * pi * fc * C) = 1 / (2 * pi * 100 * 100nF) = 15.9k -> 取 16k

Av = 1.586 (Butterworth Q=0.707)
```

## 5. 带通滤波器（BPF）

### 5.1 多路反馈 BPF 拓扑

```
         C1
Vin ──R1──┬──┤(-)
          │   │ OpAmp ── Vout
         R2   │
          │   ┤(+)
          └── GND
          
     (C2 并联在 R2 上)
     C2
  ┌──┤├──┐
  │      │
  └──R2──┘
```

### 5.2 关键参数

```
中心频率: f0 = 1 / (2 * pi * C) * sqrt((R1+R2)/(R1*R2*R3))
(简化: R1=R2=R3=R 时 f0 = 1/(2*pi*C*R*sqrt(2/3)))

品质因数: Q = f0 / BW (BW 为 -3dB 带宽)

增益: Av = -R2 / (2 * R1)

带宽: BW = f0 / Q = 1 / (pi * C * R2)
```

### 5.3 设计示例

设计目标：f0 = 1kHz, Q = 10, Av = -1

```
取 C1 = C2 = C = 10nF

Av = -1 -> R2 = 2 * R1
Q = 10 -> R2 = Q / (pi * f0 * C) = 10 / (pi * 1k * 10nF) = 318k -> 取 316k
R1 = R2 / 2 = 158k -> 取 158k
R3 = R2 / (4*Q^2 - 2) = 316k / 398 = 794 ohm -> 取 806 ohm

f0 = 1/(2*pi*10nF) * sqrt((158k+316k)/(158k*316k*806))
   -> 验算后调整
```

> 实际设计推荐使用滤波器设计软件（如 TI FilterPro, Analog Filter Wizard）。

## 6. 高阶滤波器级联

### 6.1 级联方法

高阶滤波器通过级联多个二阶节实现：

```
Vin → [二阶节1] → [二阶节2] → ... → Vout
```

偶数阶：N/2 个二阶节
奇数阶：(N-1)/2 个二阶节 + 1 个一阶节

### 6.2 各节 Q 值分配

Butterworth 4 阶滤波器需要两个二阶节，Q 值不同：

| 阶数 | 节号 | Q 值 | fc 缩放因子 |
|------|------|------|------------|
| 4 | 1 | 0.5419 | 1.000 |
| 4 | 2 | 1.3065 | 1.000 |

| 阶数 | 节号 | Q 值 | fc 缩放因子 |
|------|------|------|------------|
| 6 | 1 | 0.5176 | 1.000 |
| 6 | 2 | 0.7071 | 1.000 |
| 6 | 3 | 1.9319 | 1.000 |

### 6.3 各节参数计算

每个二阶节独立设计，fc 相同但 Q 值不同：

```
4 阶 Butterworth LPF, fc=1kHz:
  节1: Sallen-Key, Q=0.5419, Av=1.152
  节2: Sallen-Key, Q=1.3065, Av=2.235

  总增益: 1.152 * 2.235 = 2.575 (8.2dB)
```

## 7. 运放选型要求

### 7.1 GBW 要求

```
GBW > Av * f_stop * 100
```

其中 f_stop 为阻带起始频率（通常取 10 * fc）。

示例（fc=10kHz, Av=10, 4 阶）：

```
f_stop = 10 * 10k = 100kHz
GBW > 10 * 100k * 100 = 100MHz -> 需要高速运放

简化: GBW > 100 * Q_max * fc = 100 * 1.3 * 10k = 1.3MHz
```

### 7.2 压摆率要求

```
SR > 2 * pi * fc * Vpeak_out * (阶数/2)
```

### 7.3 运放选型表

| 滤波器频率 | 增益 | 推荐运放 | GBW |
|-----------|------|---------|------|
| DC~10kHz | 1~10 | LM358 | 1MHz |
| 10kHz~100kHz | 1~10 | TL084 | 3MHz |
| 100kHz~1MHz | 1~10 | OPA2376 | 5.5MHz |
| > 1MHz | 1~10 | AD8606 | 10MHz |
| > 10MHz | 1~5 | AD8055 | 300MHz |

## 8. 元件容差影响

### 8.1 容差与截止频率偏移

```
delta_fc / fc = sqrt((delta_R/R)^2 + (delta_C/C)^2)
```

| 电阻精度 | 电容精度 | fc 偏移 |
|---------|---------|--------|
| 5% | 10% | +/-11.2% |
| 1% | 5% | +/-5.1% |
| 0.1% | 1% | +/-1.0% |
| 0.1% | 0.1% | +/-0.14% |

### 8.2 Q 值灵敏度

```
S_C1^Q = dQ/Q / dC1/C1 (Q 对 C1 的灵敏度)
```

Sallen-Key HPF 的 Q 值对元件变化较敏感（灵敏度 > 1），高 Q 值时需要精密元件。

## 9. PCB 布局指南

### 9.1 布局原则

1. **信号路径最短**：输入到输出路径紧凑，减少寄生参数
2. **反馈环路紧凑**：R/C 反馈网络紧贴运放引脚
3. **元件对称**：差分级和滤波级的对称元件对称布局
4. **GND 平面完整**：运放区域保持完整 GND 平面
5. **电源去耦**：每路 V+/V- 就近放置 100nF + 10uF

### 9.2 寄生电容控制

高频滤波器（fc > 100kHz）的寄生电容影响显著：

```
C_parasitic = eps_r * eps_0 * A / d
PCB 走线寄生: ~1pF/cm (50mil 线宽, FR4)
```

设计措施：
- 反相输入端走线尽量短（< 5mm）
- 反相输入端下方禁止铺 GND（减少寄生电容）
- 使用隔离走线（guard ring）

## 10. 常见设计陷阱与解决方案

### 10.1 截止频率偏移

**原因**：元件容差、PCB 寄生、运放输入电容

**解决**：
- 使用 1% 电阻 + 1% NPO/C0G 陶瓷电容
- 高频时考虑 PCB 寄生电容补偿
- 关键应用使用可调电阻微调

### 10.2 Q 值过高导致峰化

**原因**：增益设置不当、元件不匹配

**解决**：
- 降低增益使 Q 回到设计值
- 使用 MFB 拓扑（Q 灵敏度低）
- 使用精密元件

### 10.3 高频馈通

**原因**：运放 GBW 不足、PCB 寄生耦合

**解决**：
- 选择 GBW > 100 * Q * fc 的运放
- 输入/输出走线远离开关电源
- 增加 GND 保护环

### 10.4 通带纹波大

**原因**：Chebyshev 设计的正常纹波、元件不匹配

**解决**：
- 改用 Butterworth 逼近（通带平坦）
- 使用 0.1% 精度元件
- 使用有源调谐电路

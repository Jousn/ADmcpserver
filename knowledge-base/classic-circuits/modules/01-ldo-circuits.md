# LDO 线性稳压器电路设计知识库

> 适用范围：板级低压差线性稳压器（LDO）电路设计
> 目标受众：AI 设计辅助 Skill，用于 LDO 稳压器电路设计咨询与审查
> 版本：v1.0 | 更新日期：2026-08

## 1. 概述

LDO（Low Dropout Regulator）低压差线性稳压器是电子系统中最常用的电源转换器件之一。与开关电源相比，LDO 具有噪声低、纹波小、外围简单、成本低等优势，广泛用于 MCU 供电、模拟电路供电、射频电路供电及敏感信号调理电路等场景。

### 1.1 LDO 与 DC-DC 对比

| 特性 | LDO 线性稳压器 | Buck DC-DC |
|------|---------------|------------|
| 效率 | 较低（Vout/Vin * 100%） | 高（85%~95%） |
| 纹波 | 极低（< 1mV） | 较高（10~50mV） |
| 噪声 | 极低 | 较高（开关噪声） |
| 外围元件 | 2 电容 | 电感 + 二极管 + 电容 |
| 成本 | 低 | 中 |
| EMI | 几乎无 | 需要处理 |
| 散热需求 | 高（压差大时） | 低 |

### 1.2 LDO 选型决策树

```
输入输出压差 < 0.5V？
  ├─ 是 → 超低压差 LDO（如 LT1763, TPS7A4700）
  └─ 否 → 压差 < 1.2V？
            ├─ 是 → 通用 LDO（如 AMS1117, LM1117）
            └─ 否 → 考虑 Buck DC-DC（效率要求高时）
```

### 2.2 选型关键参数说明

- **Dropout Voltage（压差）**：LDO 维持稳压所需的最小 Vin-Vout 值，直接决定最低输入电压
- **PSRR（电源纹波抑制比）**：LDO 对输入纹波的抑制能力，射频/模拟电路需要 > 60dB
- **Noise（输出噪声）**：LDO 自身产生的噪声电压，精密 ADC/DAC 供电需要 < 30uVrms
- **Quiescent Current（静态电流）**：LDO 自身消耗的电流，电池供电系统需要 < 10uA

## 3. 输出电压计算

### 3.1 固定输出型

固定输出 LDO（如 AMS1117-3.3）无需外部反馈电阻，直接输出标称电压。实际输出精度通常为 +/-2%。

### 3.2 可调输出型

可调 LDO（如 AMS1117-ADJ, LT1763-ADJ）通过外部分压电阻设定输出电压：

```
Vout = Vref * (1 + R2/R1)
```

其中：
- Vref：内部基准电压，AMS1117 为 1.25V，LT1763 为 1.22V，TPS7A4700 为 1.4V
- R1：从 Vout 到 ADJ 引脚的电阻（上分压）
- R2：从 ADJ 引脚到 GND 的电阻（下分压）

### 3.3 电阻选型计算示例

以 AMS1117-ADJ 设计 3.3V 输出为例：

```
已知: Vref = 1.25V, Vout = 3.3V
求: R2/R1 比值

Vout = Vref * (1 + R2/R1)
3.3 = 1.25 * (1 + R2/R1)
R2/R1 = 3.3/1.25 - 1 = 1.64

取 R1 = 120 ohm (标准值)
则 R2 = 120 * 1.64 = 196.8 ohm -> 取标准值 200 ohm

验算: Vout = 1.25 * (1 + 200/120) = 1.25 * 2.667 = 3.333V (误差 1%)
```

> **注意**：ADJ 引脚电流（约 60uA）会在 R1 上产生附加压降，高精度场合需要补偿：
> `Vout = Vref * (1 + R2/R1) + Iadj * R2`

### 3.4 分压电阻取值原则

- R1 电流应远大于 ADJ 引脚电流（> 100 倍），一般取 R1 = 100~120 ohm
- 阻值过小：功耗增大，降低效率
- 阻值过大：ADJ 引脚电流影响精度，且易受噪声干扰
- 推荐精度：1% 精度金属膜电阻

## 4. 电容选型

### 4.1 输入电容（Cin）

输入电容用于提供瞬态电流并减小输入电源阻抗，防止 LDO 输入端振荡。

| 参数 | 要求 | 典型值 |
|------|------|--------|
| 电容量 | >= 10uF（AMS1117 推荐） | 10uF~22uF |
| ESR | < 2 ohm | 0.1~1 ohm |
| 类型 | X5R/X7R 陶瓷电容或钽电容 | MLCC / Tantalum |
| 耐压 | >= 1.5 * Vin | Vin=5V 取 10V |

### 4.2 输出电容（Cout）

输出电容是 LDO 稳定性设计的关键，其 ESR 必须在数据手册规定的稳定窗口内。

```
AMS1117 稳定窗口:
  ESR 范围: 0.5 ohm ~ 8 ohm (典型)
  电容量: >= 22uF (钽电容) 或 10uF (陶瓷电容 + 串联电阻)
```

| 电容类型 | ESR 特性 | 适用性 | 注意事项 |
|---------|---------|--------|---------|
| 钽电容 | 0.1~3 ohm | 适合 | 注意耐压降额，有起火风险 |
| 铝电解 | 0.5~5 ohm | 适合 | 寿命有限，低温 ESR 增大 |
| 陶瓷 MLCC | < 0.05 ohm | 需注意 | ESR 过低可能导致振荡，需串电阻 |
| POSCAP | 0.03~0.5 ohm | 适合 | 体积小，低 ESR |

### 4.3 陶瓷电容 ESR 过低问题

现代 MLCC 陶瓷电容 ESR 极低（< 50m），对于某些老式 LDO（如 AMS1117），可能导致环路不稳定而振荡。解决方案：

```
方案1: 串联 1~2 ohm 电阻补偿 ESR
  Cout = 22uF MLCC + 1 ohm 串联电阻

方案2: 钽电容 + 陶瓷电容并联
  Cout = 22uF Tantalum || 0.1uF MLCC

方案3: 选择支持低 ESR 陶瓷电容的新型 LDO
  如 TPS7A8300, RT9013 等
```

### 4.4 旁路电容（Bypass）

对于低噪声 LDO（如 LT1763, TPS7A4700），Bypass 引脚外接旁路电容可显著降低输出噪声：

```
Cbypass = 10nF (推荐值)
噪声改善: 从 100uVrms 降至 20uVrms
注意: 旁路电容不接入时 LDO 仍可工作，但噪声较大
```

## 5. 压差与功耗分析

### 5.1 压差（Dropout Voltage）

压差是 LDO 正常工作时 Vin 与 Vout 之间的最小电压差。压差与输出电流正相关：

```
Vdropout = Rds_on * Iout (简化模型)
```

其中 Rds_on 是内部调整管的导通电阻。典型值：

| 型号 | Imax=100mA | Imax=500mA | Imax=1A |
|------|-----------|-----------|---------|
| AMS1117 | 0.4V | 0.8V | 1.2V |
| LT1763 | 0.1V | 0.2V | 0.3V |
| TPS7A4700 | 0.2V | 0.3V | 0.41V |

### 5.2 功耗计算

LDO 的功耗完全转化为热量，计算公式：

```
Pd = (Vin - Vout) * Iout + Vin * Iq
```

其中 Iq 为静态电流，通常远小于 Iout，可忽略。

示例计算：

```
AMS1117-3.3: Vin=5V, Vout=3.3V, Iout=800mA

Pd = (5 - 3.3) * 0.8 = 1.36W
效率 = Vout/Vin = 3.3/5 = 66%
```

### 5.3 热设计

LDO 的结温计算：

```
Tj = Ta + Pd * Rth_ja
```

其中：
- Ta：环境温度
- Rth_ja：结到环境热阻（取决于封装和 PCB 布局）

| 封装 | Rth_ja (静止空气) | Rth_ja (PCB 优化) | Imax @ Ta=25C | Imax @ Ta=70C |
|------|-------------------|-------------------|---------------|---------------|
| SOT-223 | 62 C/W | 30 C/W | 1A | 500mA |
| SOT-23-5 | 220 C/W | 150 C/W | 150mA | 80mA |
| WSON-8 | 45 C/W | 20 C/W | 1.5A | 800mA |
| TSSOP-20 | 35 C/W | 18 C/W | 2A | 1A |

### 5.4 最大允许功耗

```
Pd_max = (Tj_max - Ta) / Rth_ja
```

以 AMS1117 SOT-223 为例（Tj_max = 125C, Ta = 70C, Rth_ja = 30C/W 优化后）：

```
Pd_max = (125 - 70) / 30 = 1.83W
```

若功耗超过封装极限，必须改用 Buck DC-DC 或增加散热措施。

## 6. PSRR 与噪声分析

### 6.1 PSRR 定义

PSRR（Power Supply Rejection Ratio）衡量 LDO 抑制输入纹波的能力：

```
PSRR(dB) = 20 * log10(Vin_ripple / Vout_ripple)
```

### 6.2 PSRR 频率特性

LDO 的 PSRR 随频率变化显著，高频时下降明显：

| 频率 | AMS1117 | LT1763 | TPS7A4700 |
|------|---------|--------|-----------|
| 100Hz | 65dB | 80dB | 85dB |
| 1kHz | 40dB | 75dB | 76dB |
| 10kHz | 25dB | 60dB | 65dB |
| 100kHz | 15dB | 40dB | 50dB |
| 1MHz | 5dB | 20dB | 30dB |

### 6.3 提高 PSRR 的设计方法

1. **选择高 PSRR 器件**：射频/模拟前端优先选 TPS7A4700、LT1763 等
2. **增加前置 RC 滤波**：在 LDO 输入端串联电阻 + 电容构成低通滤波
3. **两级 LDO 级联**：前级 Buck + 后级 LDO，兼顾效率与噪声
4. **优化 Cout**：增加输出电容量，降低高频输出阻抗

## 8. PCB 布局指南

### 8.1 布局原则

1. **电容就近放置**：Cin 尽量靠近 Vin 引脚，Cout 尽量靠近 Vout 引脚，走线 < 3mm
2. **大面积铺铜散热**：SOT-223 的 GND tab 是主要散热路径，连接大面积 GND 铜皮
3. **反馈走线短而直**：可调型 LDO 的 ADJ 反馈走线尽量短，远离干扰源
4. **输入输出分离**：输入走线与输出走线不交叉，避免耦合

### 8.2 散热铜皮设计

| 封装 | 推荐 GND 铜皮面积 | 过孔数量 | 过孔尺寸 |
|------|-----------------|---------|---------|
| SOT-223 | >= 100mm^2 (顶层) | 4~6 个 | 0.3mm |
| WSON-8 | >= 50mm^2 | 4 个 | 0.25mm |
| TSSOP-20 | >= 200mm^2 | 8 个 | 0.3mm |

### 8.3 布局示例（俯视）

```
┌──────────────────────────────┐
│        ┌─────────┐            │
│  Cin  │ VIN  VOUT│   Cout    │
│  ──┤├──│         │──┤├──     │
│        │  GND tab │            │
│        └────┬────┘            │
│              │                  │
```

## 9. 常见设计陷阱与解决方案

### 9.1 输出振荡

**现象**：输出电压存在高频振荡（MHz 级）

**原因**：Cout ESR 不在稳定窗口内（过低或过高）

**解决方案**：
- 检查 Cout 类型，确保 ESR 在 0.5~8 ohm 范围
- 陶瓷电容串 1 ohm 电阻补偿 ESR
- 更换为钽电容或 POSCAP

### 9.2 输出电压偏差大

**现象**：实际输出电压与设计值偏差 > 5%

**原因**：分压电阻精度不足、ADJ 引脚电流影响、PCB 走线压降

**解决方案**：
- 使用 1% 精度电阻
- 降低分压电阻阻值（R1 < 200 ohm）
- 检查负载端到 LDO 输出端的走线压降

### 9.3 带载能力不足

**现象**：带载后输出电压跌落，轻载时正常

**原因**：输入电压不足导致压差不够、热保护触发

**解决方案**：
- 检查 Vin 是否 >= Vout + Vdropout + 余量(0.3V)
- 检查结温是否超过 Tj_max，增大散热铜皮
- 减小负载电流或更换更大电流的 LDO

### 9.4 上电浪涌电流过大

**现象**：上电瞬间输入电流尖峰很大

**原因**：Cin 过大，上电瞬间充电电流大

**解决方案**：
- 限制 Cin 电容量（一般 < 47uF）
- 增加输入端软启动电路（NMOS + RC 延迟）
- 使用带软启动功能的 LDO（如 TPS7A8300）

## 10. 设计检查清单

| 检查项 | 要求 | 通过标准 |
|--------|------|----------|
| 压差裕量 | Vin_min - Vout >= Vdropout + 0.3V | 满足 |
| 功耗 | Pd < Pd_max (考虑温升) | 满足 |
| Cout ESR | 在数据手册稳定窗口内 | 满足 |
| 散热铜皮 | 面积满足热阻要求 | 满足 |

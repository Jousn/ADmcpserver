# UART/RS485/RS232 接口电路设计知识库

> 适用范围：UART、RS232、RS485 通信接口电路设计（电平转换、隔离、终端匹配）
> 目标受众：AI 设计辅助 Skill，用于串行通信接口电路设计咨询与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

UART/RS232/RS485 是工业控制和嵌入式系统中最常用的串行通信接口。UART 为 MCU 原生逻辑电平通信，RS232 用于短距离点对点通信，RS485 用于长距离多点差分通信。本模块覆盖这三种接口的电路设计要点。

### 1.1 三种接口对比

| 特性 | UART (TTL) | RS232 | RS485 |
|------|-----------|-------|-------|
| 电平 | 0~3.3V/5V | +/-3~15V | 差分 +/-0.2~6V |
| 传输方式 | 单端 | 单端 | 差分 |
| 最大距离 | < 30cm | 15m | 1200m |
| 最大速率 | 几 Mbps | 115.2kbps | 10 Mbps |
| 节点数 | 2 (点对点) | 2 (点对点) | 32~256 (多点) |
| 抗干扰 | 差 | 中 | 好 |
| 拓扑 | 点对点 | 点对点 | 总线 |
| 共模范围 | GND~Vcc | +/-15V | -7~+12V |

## 2. UART 接口设计

### 2.1 UART 信号定义

| 信号 | 方向 | 功能 |
|------|------|------|
| TX | 输出 | 发送数据 |
| RX | 输入 | 接收数据 |
| RTS | 输出 | 请求发送（流控） |
| CTS | 输入 | 允许发送（流控） |
| GND | — | 公共地 |

### 2.2 UART 电平标准

```
TTL 3.3V UART:
  逻辑 0: 0V
  逻辑 1: 3.3V
  空闲: 3.3V (高电平)

TTL 5V UART:
  逻辑 0: 0V
  逻辑 1: 5V

注意: 3.3V 和 5V UART 互连时需要电平转换
```

### 2.3 3.3V 与 5V 电平转换

```
方案1: 电阻分压（5V -> 3.3V）
  TX(5V) ── R1(1k) ──┬── RX(3.3V)
                      │
                     R2(2k)
                      │
                     GND
  分压: 5 * 2k/(1k+2k) = 3.3V

方案2: 双向电平转换 IC（推荐）
  TX(5V) ─┬── TXS0108E ─┬── TX(3.3V)
          │              │
  RX(5V) ─┤              ├── RX(3.3V)

方案3: MOSFET 双向转换（低成本）
  Vcc_3.3V
    │
    R(10k)
    │
3.3V侧 ──┬──── BSS138 ────┬── 5V 侧
         │     (G D S)     │
         └─────────────────┘
  BSS138: NMOS, Vds > 20V, Rds_on < 50m
```

## 3. RS232 接口设计

### 3.1 RS232 电平标准

```
RS232 电平:
  逻辑 0 (SPACE): +3V ~ +15V (典型 +/-12V)
  逻辑 1 (MARK): -3V ~ -15V (典型 -12V)
  空闲: -12V (MARK, 与 UART 空闲高电平相反)

注意: RS232 电平与 UART TTL 电平相反!
  UART TX=1(高) -> RS232 输出 = -12V (MARK)
  UART TX=0(低) -> RS232 输出 = +12V (SPACE)
```

### 3.2 RS232 收发器选型

| 型号 | 通道数 | 供电 | 速率 | 内置电荷泵 | 封装 | 特点 |
|------|--------|------|------|----------|------|------|
| MAX3232 | 2TX+2RX | 3.0~5.5V | 250kbps | 是 | SOIC-16 | 最常用 |
| MAX3233 | 2TX+2RX | 3.0~5.5V | 120kbps | 是(低噪) | SOIC-16 | 低噪声 |
| MAX3243 | 3TX+5RX | 3.0~5.5V | 250kbps | 是 | TSSOP-20 | 多通道 |
| MAX3182 | 1TX+1RX | 3.0~5.5V | 250kbps | 是 | SOT-23-6 | 单通道 |
| SP3232 | 2TX+2RX | 3.0~5.5V | 235kbps | 是 | SOIC-16 | MAX3232 兼容 |
| ST3232 | 2TX+2RX | 3.0~5.5V | 250kbps | 是 | SOIC-16 | 国产替代 |

### 3.3 MAX3232 典型电路

```
        MAX3232
        ┌────────┐
MCU TX ─┤T1IN T1OUT├── RS232 TX (DB9 Pin 3)
        │         │
MCU RX ─┤R1IN R1OUT├── RS232 RX (DB9 Pin 2)
        │         │
   VCC ─┤V+       ├── C1+ ──┤├── C1- (电荷泵电容)
   VCC ─┤V+       ├── C2+ ──┤├── C2- (电荷泵电容)
        │         │
   VCC ─┤VCC   V-├──┤├── GND
        │         │
  GND ─┤GND      │
        │         │
   VCC ─┤C1+   C2+├── (内部连接)
        │C1-   C2-├── (内部连接)
        └────────┘

外围电容:
  C1 = 0.1uF (V+ 电荷泵)
  C2 = 0.1uF (V- 电荷泵)
  C3 = 0.1uF (V+ 滤波)
  C4 = 0.1uF (V- 滤波)
  C5 = 0.1uF (VCC 旁路)

全部使用 X7R MLCC 陶瓷电容
```

### 3.4 RS232 ESD 保护

```
RS232 信号线 ESD 保护:
  TX ──┬── TVS(15V) ── GND
  RX ──┬── TVS(15V) ── GND
  
  推荐 TVS:
    SMAJ15CA (双向, Vwm=15V, Vc=24.4V)
    或 SRV05-4 (多线 ESD 保护)
```

## 4. RS485 接口设计

### 4.1 RS485 电平标准

```
RS485 差分信号:
  逻辑 1 (MARK): VA - VB < -200mV
  逻辑 0 (SPACE): VA - VB > +200mV
  空闲: VA ≈ VB (差分 ≈ 0V, 靠 fail-safe 偏置)

共模范围: -7V ~ +12V
最大差分电压: +/-6V
```

### 4.2 RS485 收发器选型

| 型号 | 速率 | 节点数 | 供电 | 隔离 | 半/全双工 | 封装 | 典型应用 |
|------|------|--------|------|------|----------|------|---------|
| MAX485 | 2.5Mbps | 32 | 5V | 无 | 半双工 | SOIC-8 | 经典通用 |
| MAX487 | 2.5Mbps | 128 | 5V | 无 | 半双工 | SOIC-8 | 多节点 |
| MAX3485 | 2.5Mbps | 32 | 3.3V | 无 | 半双工 | SOIC-8 | 3.3V 系统 |
| SP3485 | 2.5Mbps | 32 | 3.0~5.5V | 无 | 半双工 | SOIC-8 | MAX3485 兼容 |
| MAX13442 | 16Mbps | 32 | 3.0~5.5V | 无 | 半双工 | SOIC-8 | 高速 |
| ADM2483 | 500kbps | 32 | 5V | 是(2.5kV) | 半双工 | SOIC-16 | 隔离 RS485 |
| ADM2587 | 500kbps | 32 | 3.3~5V | 是(2.5kV) | 全双工 | SOIC-20 | 隔离+DC-DC |
| ISO1500 | 500kbps | 32 | 3.0~5.5V | 是(5kV) | 半双工 | SOIC-16 | 高隔离 |

### 4.3 MAX485 典型电路

```
            MAX485
            ┌────────┐
       RO ──┤RO       ├─ VCC(5V)
            │        │
  MCU RX ──┤RO      A├── RS485 A 线
            │        │
 MCU /RE ──┤/RE     B├── RS485 B 线
            │        │
 MCU DE ──┤DE      G├── GND
            │        │
 MCU TX ──┤DI       │
            └────────┘

DE 和 /RE 通常连在一起控制收发方向:
  输出模式: DE=/RE=1 (发送)
  输入模式: DE=/RE=0 (接收)

方向控制:
  MCU GPIO ──┬── DE
             └── /RE (反相或直接连接)
```

### 4.4 终端匹配

RS485 总线两端需要 120 ohm 终端电阻匹配差分阻抗：

```
     120 ohm
A ──/\/\/── B (总线两端各一个)

终端电阻位置: 只在总线物理两端各放一个
中间节点不放终端电阻

终端电阻功耗:
  P = Vdiff^2 / R = (5V)^2 / 120 = 208mW (使用 1/4W 电阻)
```

### 4.5 Fail-Safe 偏置

当总线空闲或所有节点都不发送时，差分电压为 0V，接收器输出不确定。需要偏置电阻确保空闲时输出确定电平：

```
     Vcc(5V)
       │
      Rb(680 ohm) 上偏置
       │
       ├── A 线
       │
      Rt(120 ohm) 终端电阻
       │
       ├── B 线
       │
      Rb(680 ohm) 下偏置
       │
      GND

偏置电压计算:
  Vab = Vcc * Rt / (Rb + Rt + Rb) = 5 * 120/(680+120+680) = 0.38V
  Vab > 200mV -> 确保空闲时输出逻辑 0 (或定义的安全状态)

偏置电阻只需在总线一端放置一次
```

### 4.6 隔离 RS485 设计

工业环境中需要隔离 RS485 以保护 MCU：

```
方案1: 光耦隔离 + 隔离电源

MCU 侧                    总线侧
                  ┌──────┐
MCU TX ──┬── 6N137 │      │── DI ── MAX485
         │         │ ISO  │
MCU /RE ──┬── 6N137 │      │── /RE ── MAX485
         │         │      │
MCU RX ──┬── 6N137 │      │── RO ── MAX485
         │         │      │
         │    ┌────┘      │
  隔离DC-DC │            │
  (B0505S)  │            │
         └────┘          │
MCU GND                BUS GND (隔离地)

方案2: 集成隔离 RS485 (推荐)
  MCU ─── ADM2587 ─── RS485 总线
  (内部集成隔离+DC-DC+收发器)

方案3: 数字隔离器
  MCU ─── ADuM1201 + ADuM5000 + MAX3485 ─── RS485 总线
```

### 4.7 隔离器件选型

| 器件 | 类型 | 隔离耐压 | 速率 | 通道数 | 封装 |
|------|------|---------|------|--------|------|
| 6N137 | 光耦 | 3000Vrms | 10Mbps | 1 | DIP-8/SMD |
| ADuM1201 | 磁耦 | 2500Vrms | 25Mbps | 2 | SOIC-8 |
| ADuM1200 | 磁耦 | 2500Vrms | 25Mbps | 1 | SOIC-8 |
| SI8621 | 电容隔离 | 5000Vrms | 150Mbps | 2 | SOIC-8 |
| B0505S-1W | DC-DC | 3000Vrms | — | 1W | SIP-4/SMD |

## 5. RS485 总线拓扑

### 5.1 菊花链拓扑（推荐）

```
节点1 ──── 节点2 ──── 节点3 ──── ... ──── 节点N
  │           │           │                    │
 Rt(120)    stub        stub                Rt(120)
  │       <30cm       <30cm                    │
 GND                                                    GND
```

- 主干线两端各放 120 ohm 终端电阻
- 节点分支线（stub）尽量短（< 30cm）
- 总线总长度 < 1200m（1Mbps 以下）

### 5.2 星型拓扑（不推荐）

```
      节点1
        │
节点2 ──┼── 节点3
        │
      节点4
```

星型拓扑会导致信号反射，尽量避免。如必须使用，需要特殊终端设计。

### 5.3 节点数计算

```
RS485 单位负载 = 12k ohm (标准定义)
收发器输入阻抗:
  MAX485: 12k ohm (1 单位负载) -> 32 节点
  MAX487: 48k ohm (1/4 单位负载) -> 128 节点

最大节点数 = 32 / (单位负载数)
```

## 6. PCB 布局指南

### 6.1 RS485 布局

```
┌─────────────────────────────────┐
│  MCU ── MAX485 ── A/B ── 连接器 │
│         │           │            │
│     去耦电容     终端电阻        │
│     100nF+10uF   120 ohm        │
│         │           │            │
│        GND         GND          │
│                                 │
│  隔离区域（如使用隔离方案）:       │
│  ┌─────────┐  ┌──────────┐     │
│  │ MCU 侧  │  │ 总线侧   │     │
│  │ GND1    │  │ GND2     │     │
│  │         │光耦/磁耦 │      │
│  └─────────┘  └──────────┘     │
│  隔离间距: >= 2mm (2kV)        │
└─────────────────────────────────┘
```

### 6.2 布局要点

1. **A/B 走线差分**：A 和 B 线尽量平行走线，等长
2. **终端电阻就近**：120 ohm 电阻紧靠收发器 A/B 引脚
3. **去耦电容**：100nF + 10uF 紧贴 VCC 引脚
4. **隔离间距**：隔离器件两侧 PCB 间距 >= 2mm（对应 2kV 耐压）
5. **地平面分割**：隔离区两侧 GND 平面不连接，保持隔离

### 6.3 RS232 布局

1. 电荷泵电容紧贴 MAX3232 的 C1+/C1-/C2+/C2- 引脚
2. 电荷泵电容走线短而粗（承载脉冲电流）
3. VCC 旁路电容紧贴 VCC 引脚
4. RS232 信号线远离敏感模拟电路

## 7. 常见设计陷阱与解决方案

### 7.1 RS485 通信不稳定

**原因**：无终端电阻、stub 过长、节点数过多、偏置缺失

**解决**：
- 总线两端加 120 ohm 终端电阻
- 缩短分支线（< 30cm）
- 增加偏置电阻确保空闲电平
- 降低波特率

### 7.2 RS232 通信乱码

**原因**：电荷泵电容不足、波特率不匹配、电平反转

**解决**：
- 确认电荷泵电容全部 0.1uF X7R
- 检查 MCU 和对端波特率一致
- 确认 MAX3232 内部已自动反转电平
- 检查 GND 是否共地

### 7.3 隔离 RS485 不工作

**原因**：隔离电源不足、隔离器速率不够、方向控制时序

**解决**：
- 确认隔离 DC-DC 输出电流 > RS485 收发器峰值电流
- 选择速率 > 信号波特率 10 倍的隔离器
- 方向切换时增加延时等待数据发完

### 7.4 ESD 损坏

**原因**：无 ESD 保护、GND 不共地、长线感应

**解决**：
- A/B 线增加 TVS（SMAJ6.5CA）
- VBUS 增加 GDT + MOV 保护
- 确保设备良好接地

## 1. 概述

Boost（升压型）DC-DC 变换器用于将低输入电压升压到高输出电压，典型应用包括锂电池（3.7V）升压至 5V/12V、5V 升压至 12V/15V、LED 驱动背光、OLED 供电等。Boost 电路在便携式设备、电池供电系统及需要高电压供电的模拟前端中应用广泛。

### 1.1 Boost 工作原理

```
    ┌── L ──┬── D ──┐
Vin │       │       │
    └── Q ──┘      Cout ── Vout
         │           │
        GND         GND
```

- Q 导通：电感 L 储能，二极管 D 反偏截止，Cout 向负载供电
- Q 关断：电感 L 释放能量，通过 D 向 Cout 和负载充电

### 1.2 典型应用场景

| 输入电压 | 输出电压 | 输出电流 | 典型应用 |
|---------|---------|---------|---------|
| 3.0~4.2V | 5V | 500mA~1A | USB 充电宝 |
| 3.0~4.2V | 12V | 200mA~1A | LED 背光 |
| 5V | 12V | 500mA~2A | 运放供电 |
| 5V | 15V | 100~500mA | LCD 偏压 |
| 5V | 24V | 100~300mA | 传感器供电 |
| 12V | 24V | 500mA~2A | 工业控制 |

## 3. 关键参数计算

### 3.1 占空比

Boost 电路 CCM 模式下的占空比：

```
D = 1 - (Vin * eta) / Vout
```

简化计算（忽略效率）：D = 1 - Vin / Vout

示例：

```
Vin=3.7V(锂电池), Vout=5V, eta=0.9
D = 1 - (3.7 * 0.9) / 5 = 1 - 0.666 = 0.334 (33.4%)
```

> **注意**：Boost 电路最大占空比通常受限（90~95%），决定最大升压比。

### 3.2 最大升压比

```
Vout_max / Vin_min = 1 / (1 - D_max)
```

当 D_max = 0.9 时，最大升压比为 10:1。但实际受电感饱和、二极管压降、开关管压降等限制，实际升压比通常 < 5:1。

### 3.3 电感选型

```
L = Vin * D / (dI_L * fsw)
```

其中 dI_L 为电感纹波电流，取 Iout 的 30%~50%：

```
dI_L = 0.3~0.5 * Iin_avg
Iin_avg = Iout * Vout / (Vin * eta)
```

示例（MT3608: Vin=3.7V, Vout=5V, Iout=500mA, fsw=1.2MHz, eta=0.9）：

```
Iin_avg = 0.5 * 5 / (3.7 * 0.9) = 0.752A
dI_L = 0.4 * 0.752 = 0.301A
L = 3.7 * 0.334 / (0.301 * 1.2e6) = 3.42uH

取标准值: L = 4.7uH
```

电感额定电流：

```
I_sat >= Iin_avg + dI_L/2 = 0.752 + 0.15 = 0.9A
Irms >= Iin_avg = 0.752A
```

### 3.4 二极管选型

Boost 电路的二极管承受的反向电压为 Vout，正向电流为电感峰值电流：

| 参数 | 要求 | 说明 |
|------|------|------|
| 反向耐压 Vr | >= 1.3 * Vout | 留余量 |
| 正向电流 If_avg | >= Iout | 平均整流电流 |
| 正向压降 Vf | < 0.4V | 肖特基优先 |
| 反向恢复时间 | < 10ns | 快速恢复 |

常用肖特基二极管：

| 型号 | Vr | If | Vf@If | 封装 | 适用 |
|------|-----|-----|-------|------|------|
| SS14 | 40V | 1A | 0.55V | SMA | MT3608, 低电流 |
| SS34 | 40V | 3A | 0.55V | SMA | MT3608, 中电流 |
| SS54 | 40V | 5A | 0.55V | SMC | TPS61088 |
| 1N5822 | 40V | 3A | 0.5V | DO-201AD | LM2577 |
| SSB43L | 30V | 3A | 0.35V | SMC | 低 Vf 应用 |

### 3.5 输出电容选型

Boost 电路输出电容承受脉冲放电电流，纹波较大：

```
Cout >= Iout * D / (fsw * Vout_ripple)
```

示例（Iout=500mA, D=0.334, fsw=1.2MHz, Vout_ripple=50mV）：

```
Cout >= 0.5 * 0.334 / (1.2e6 * 0.05) = 2.78uF
取标准值: Cout = 22uF (留余量 + 陶瓷电容)
```

ESR 纹波：

```
Vripple_esr = Iout * ESR_Cout
```

选择低 ESR MLCC（ESR < 5m），确保 ESR 纹波 < 2.5mV。

### 3.6 输入电容选型

Boost 电路输入电流连续（CCM 模式），输入电容主要滤除电感纹波电流：

```
Cin >= dI_L / (8 * fsw * Vin_ripple)
```

典型值 10uF~22uF 陶瓷电容。

## 4. 电流限制

### 4.1 峰值电流限制

Boost IC 内部有逐周期峰值电流限制，防止电感饱和：

```
Ipeak_limit = Iin_avg + dI_L/2
```

设计时需确保 IC 的峰值电流限制值 > 实际峰值电流 + 20% 余量：

```
Ipeak_limit_IC >= 1.2 * (Iin_avg + dI_L/2)
```

### 4.2 电感饱和电流校验

当输入电压最低时，电感峰值电流最大：

```
Iin_avg_max = Iout * Vout / (Vin_min * eta_min)
Ipeak_max = Iin_avg_max + dI_L/2
```

确保电感饱和电流 I_sat > Ipeak_max。

示例（Vin_min=3.0V, Vout=5V, Iout=500mA, eta=0.85）：

```
Iin_avg_max = 0.5 * 5 / (3.0 * 0.85) = 0.98A
dI_L = 0.4 * 0.98 = 0.392A
Ipeak_max = 0.98 + 0.196 = 1.176A
I_sat >= 1.2 * 1.176 = 1.41A -> 选 I_sat >= 1.5A 电感
```

## 5. 反馈网络设计

### 5.1 输出电压计算

```
Vout = Vref * (1 + Rtop / Rbottom)
```

Vref 典型值：MT3608 = 0.6V, TPS61088 = 1.2V, LM2577 = 1.23V

示例（MT3608: Vref=0.6V, Vout=5V）：

```
Rtop / Rbottom = 5 / 0.6 - 1 = 7.33

取 Rbottom = 10k ohm
则 Rtop = 10k * 7.33 = 73.3k -> 取标准值 73.2k

验算: Vout = 0.6 * (1 + 73.2/10) = 0.6 * 8.32 = 4.992V (误差 0.16%)
```

### 5.2 分压电阻取值

- 总阻值 50k~500k，平衡功耗与噪声
- Rbottom 取 10k 为常用值
- 使用 1% 精度电阻

## 6. 典型应用电路

### 6.1 MT3608 锂电池 3.7V 升 5V/500mA 电路

```
            L(4.7uH)
   Vin ──────[]()──────┬── D1(SS34) ──┬── Vout(5V)
    │                   │              │
   Cin(10uF)           SW             Cout(22uF)
    │                   │              │
    │              ┌───┴────┐         │
    │              │ MT3608 │         │
    │              │        │         │
    │              │ IN   SW │         │
    │              │        │         │
    │              │ EN  GND │         │
    │              └───┬────┘         │
    │                  │              │
    │            ┌─────┘              │
    │            │ Rtop 73.2k         │
    │            └──┬─────────────────┘
    │               │ FB
    │            Rbot 10k
    │               │
   GND             GND
```

外围参数：
- Cin = 10uF / 16V X5R MLCC
- Cout = 22uF / 10V X5R MLCC
- L = 4.7uH / 饱和 >= 1.5A（如 NR4018T4R7）
- D1 = SS34 (SMA)
- Rtop = 73.2k, Rbot = 10k (1%)

### 6.2 TPS61088 5V 升 12V/2A 电路

外围参数：
- Cin = 22uF / 16V X5R MLCC（输入端）
- Cout = 22uF + 22uF / 25V X5R MLCC（输出端并联）
- L = 2.2uH / 饱和 >= 10A
- D1 = 内置同步整流（无需外部二极管）
- Rtop = 1M, Rbot = 120k (Vref=1.2V, Vout=11.2V)

## 7. PCB 布局指南

### 7.1 布局核心原则

Boost 电路的功率路径包含输入→电感→开关管→二极管→输出电容，高频大电流回路为：

```
Vin → Cin → L → SW → D → Cout → GND → Cin（回路1，Q 关断时）
Vin → Cin → L → SW → Q → GND → Cin（回路2，Q 导通时）
```

### 7.2 元件布局顺序

1. Cin 紧靠 IC 的 VIN/GND 引脚
2. L 紧靠 SW 引脚，缩短 SW 走线
3. D 靠近 SW 和 Cout，缩短续流路径
4. Cout 紧靠 D 的输出端
5. 反馈走线从 Vout 端引出，远离 SW

### 7.3 布局示例

```
┌───────────────────────────────────┐
│  Cin    L          D       Cout    │
│ Vin ─┤├──[]()───┬──>|───┤├── Vout  │
│          │      │      │          │
│       ┌──┴──┐   │      │          │
│       │ IC  │  SW     │          │
│       │ IN  │        │           │
│       │ EN  │   ┌────┘           │
│       │ GND │   │  Rtop           │
│       │ FB  │   └──┬──────────────┘
│       └─────┘      │
│              Rbot   │
│                │    │
│               GND  GND
└───────────────────────────────────┘
```

### 7.4 SW 节点处理

SW 节点是 Boost 电路中 EMI 最严重的节点（高频高 dv/dt）：

- SW 走线尽量短而宽，减小寄生电感
- SW 铜皮面积不宜过大（减少辐射），但需满足载流能力
- SW 走线下方保持完整 GND 平面
- SW 附近避免走敏感信号线

## 8. 同步整流 Boost

### 8.1 同步 vs 非同步

大电流 Boost（如 TPS61088）采用内置 MOSFET 替代肖特基二极管：

| 特性 | 非同步（外接二极管） | 同步（内置 MOS） |
|------|-------------------|-----------------|
| 效率（低压差时） | 低（Vf 损耗） | 高 |
| 成本 | 低 | 高 |
| 外围元件 | 需要二极管 | 不需要 |
| 适用电流 | < 3A | > 3A |

### 8.2 低压差时效率对比

```
非同步: P_diode = Vf * Iout * (1-D) = 0.55 * 2 * 0.666 = 0.73W
同步:   P_mos  = Iout^2 * Rds_on * (1-D) = 4 * 0.01 * 0.666 = 0.027W
效率提升: (0.73 - 0.027) / 12 = 5.9% (Vin=5V, Vout=12V, Iout=2A)
```

## 9. 常见设计陷阱与解决方案

### 9.1 电感饱和导致电流尖峰

**现象**：SW 节点波形出现尖峰，效率下降，IC 过热

**原因**：电感饱和电流不足，输入电压最低时峰值电流超饱和点

**解决**：
- 计算 Vin_min 时的最大峰值电流
- 选择饱和电流 >= 1.2 倍峰值电流的电感
- 使用铁硅铝或合金粉芯电感（饱和特性软）

### 9.2 输出电压无法达到设定值

**原因**：占空比限制、电感饱和、IC 电流限制

**解决**：
- 检查升压比是否超过 IC 最大占空比支持
- 降低输出电流或增大输入电压
- 检查 IC 电流限制是否触发

### 9.3 输出纹波过大

**原因**：Cout 不足、ESR 大、fsw 低

**解决**：
- 并联多颗 MLCC 降低等效 ESR
- 增大 Cout 电容量
- 选择更高 fsw 的 IC

### 9.4 轻载效率低

**原因**：CCM 模式下静态损耗占比高

**解决**：
- 选择支持 PFM/DCM 轻载模式的 IC
- 增加假负载（> 1mA）避免空载不稳定

## 10. 设计检查清单

| 检查项 | 要求 | 通过标准 |
|--------|------|----------|
| 升压比 | < 5:1（实际） | 满足 |
| 占空比 | D < D_max（IC 规定） | 满足 |
| 电感饱和电流 | >= 1.2 * Ipeak_max | 满足 |
| 二极管耐压 | >= 1.3 * Vout | 满足 |
| Cout 容量 | >= Iout*D/(fsw*Vripple) | 满足 |
| IC 电流限制 | > 1.2 * Ipeak_max | 满足 |
| 输入回路面积 | 最小化 | 满足 |
| SW 走线 | 短而宽，下方铺 GND | 满足 |

## 1. 概述

比较器是一种特殊的运算放大器应用，工作在开环状态，输出在两个逻辑电平之间切换。本模块覆盖基本比较器、施密特触发器（迟滞比较器）和窗口比较器的设计。

### 1.1 比较器 vs 运放

| 特性 | 专用比较器 | 运放作比较器 |
|------|----------|------------|
| 响应速度 | 快（ns~us） | 慢（us~ms） |
| 输出级 | 开漏/推挽/开路集电极 | 推挽 |
| 上升/下降时间 | 快 | 受压摆率限制 |
| 过驱恢复 | 快 | 慢（可能需数 us） |
| 功耗 | 低 | 较高 |
| 闭环稳定性 | 不适用（开环工作） | 适合闭环 |
| 推荐场景 | 专用比较功能 | 临时替代/低速 |

### 1.2 常用比较器器件

| 型号 | 通道数 | 供电电压 | 响应时间 | 输出类型 | 封装 | 典型应用 |
|------|--------|---------|---------|---------|------|---------|
| LM393 | 2 | 2~36V | 1.3us | 开漏 | SOIC-8 | 通用比较器 |
| LM339 | 4 | 2~36V | 1.3us | 开漏 | SOIC-14 | 四路比较 |
| LM311 | 1 | 5~30V | 200ns | 开漏+选通 | DIP-8/SOIC-8 | 高速比较 |
| LMV7239 | 1 | 2.7~5.5V | 75ns | 推挽 | SC70-5 | 高速低压 |
| TLV3201 | 1 | 2.7~5.5V | 40ns | 推挽 | SOT-23-6 | 超高速 |
| MAX9031 | 1 | 2.5~5.5V | 0.6us | 开漏 | SOT-23-5 | 低功耗 |
| ADCMP391 | 1 | 1.7~5.5V | 100ns | 开漏 | SC70-5 | 低压精密 |

## 2. 基本比较器

### 2.1 电路拓扑（反相比较器）

```
              Vcc
               │
              Rpullup
               │
Vin ──┤(-)      │
       │   LM393├── Vout
Vref──┤(+)      │
               │
              GND (开漏输出需上拉)
```

工作原理：
- Vin > Vref 时，输出翻转为低电平
- Vin < Vref 时，输出为高电平（上拉到 Vcc）

### 2.2 同相比较器

```
Vref ──┤(-)
        │   LM393├── Vout
Vin ──┤(+)      │
```

工作原理：
- Vin > Vref 时，输出为高电平
- Vin < Vref 时，输出为低电平

### 2.3 开漏输出上拉电阻

LM393/LM339 为开漏输出，需要外部上拉电阻：

```
Rpullup 选值原则:
  下限: Rpullup >= (Vcc - Vol_max) / Iol_max
       例: Vcc=5V, Vol_max=0.4V, Iol_max=6mA
       Rpullup >= (5-0.4)/6m = 767 ohm -> 取 1k

  上限: Rpullup 受上升时间限制
       tr = 2.2 * Rpullup * C_parasitic
       例: C=10pF, tr_max=1us
       Rpullup <= tr/(2.2*C) = 1us/(2.2*10pF) = 45k -> 取 10k~22k

  推荐值: 4.7k~10k (平衡速度与功耗)
```

### 2.4 参考电压产生

```
方案1: 电阻分压
  Vcc ──┬── R1(10k) ──┬── Vref
        │              │
       R2(10k)       C1(100nF)
        │              │
       GND            GND
  
  Vref = Vcc * R2/(R1+R2) = 5 * 10k/20k = 2.5V

方案2: 基准电压源
  Vcc ──┬── TL431 ──┬── Vref(2.5V)
        │           │
       R1(4.7k)   C1(100nF)
        │           │
       GND         GND

方案3: 运放跟随器缓冲分压（低阻抗输出）
```

## 3. 施密特触发器（迟滞比较器）

### 3.1 为什么需要迟滞

基本比较器在输入信号缓慢经过阈值时，噪声会导致输出频繁翻转（振荡）。施密特触发器引入正反馈产生两个不同的阈值电压（上阈值和下阈值），消除噪声导致的误触发。

```
无迟滞:  信号在 Vref 附近抖动 -> 输出振荡
有迟滞:  上阈值 Vth+ > 下阈值 Vth- -> 滞回区间内输出不变
```

### 3.2 反相施密特触发器

```
         R2
Vref ──/\/\/──┬──┤(-)
               │   │   LM393
              R3   │   ├── Vout
               │   │
Vin ───────────┴──┤(+) (正反馈到同相输入)

         R1
Vout ──/\/\/──┘ (反馈电阻连接输出到正输入端)
```

等效电路（同相输入端为正反馈节点）：

```
           R2
    Vref ──/\/\/──┬──┐
                   │  │
                  R3  R1
                   │  │
    Vout ──────────┘  │
                      │
                     V+ (同相输入)
```

### 3.3 阈值电压计算

正反馈分压网络使同相输入端电压随输出状态变化：

```
上阈值（输出从高变低）:
  Vth+ = Vref + (Voh - Vref) * R_eq / (R2 + R_eq)

下阈值（输出从低变高）:
  Vth- = Vref + (Vol - Vref) * R_eq / (R2 + R_eq)

  其中 R_eq = R1 || R3 (R1 和 R3 的并联)
```

简化公式（当 R3 >> R1, R2 >> R1 时）：

```
Vth+ = Vref + R1 / (R1 + R2) * (Voh - Vref)
Vth- = Vref + R1 / (R1 + R2) * (Vol - Vref)

迟滞宽度:
  Vhys = Vth+ - Vth- = R1 / (R1 + R2) * (Voh - Vol)
```

### 3.4 设计示例

设计目标：Vref=2.5V, Vth+=2.8V, Vth-=2.2V（迟滞宽度 0.6V）

```
已知: Vcc=5V, Voh=5V, Vol=0V (开漏输出, Voh=上拉电压)

Vhys = 2.8 - 2.2 = 0.6V
Vhys = R1/(R1+R2) * (Voh - Vol) = R1/(R1+R2) * 5

R1/(R1+R2) = 0.6/5 = 0.12

取 R1 = 10k
R1+R2 = 10k/0.12 = 83.3k
R2 = 83.3k - 10k = 73.3k -> 取 75k

验算:
  Vth+ = 2.5 + 10k/(10k+75k) * (5-2.5) = 2.5 + 0.294 = 2.794V
  Vth- = 2.5 + 10k/(10k+75k) * (0-2.5) = 2.5 - 0.294 = 2.206V
  Vhys = 2.794 - 2.206 = 0.588V (接近目标 0.6V)
```

### 3.5 同相施密特触发器

输入接同相端，参考电压接反相端：

```
         R1
Vin ──/\/\/──┬──┤(+)
              │   │   LM393
             R2   │   ├── Vout
              │   │
Vref ────────┴──┤(-)

         R3
Vout ──/\/\/──┘ (反馈到正输入端)
```

阈值计算（等效电阻 R1 || R2 || R3）：

```
Vth+ = Vref * (1 + R3/R12) - Vol * R3/R12
Vth- = Vref * (1 + R3/R12) - Voh * R3/R12

R12 = R1 || R2
```

## 4. 窗口比较器

### 4.1 电路拓扑

窗口比较器检测输入是否在指定电压范围内（Vlow < Vin < Vhigh）：

```
              Vcc
               │
              Rpullup
               │
Vhigh─┤(-) U1   ├──┐
       │         │  │
Vin ──┤(+)       │  │
       │         │  ├── Vout (窗口内=高, 窗口外=低)
Vin ──┤(-) U2   │  │
       │         │  │
Vlow ─┤(+)       ├──┘
                    (两路开漏输出线与)
```

工作原理：
- Vin > Vhigh：U1 输出低，U2 输出高 -> Vout = 低（超出上限）
- Vlow < Vin < Vhigh：U1 输出高，U2 输出高 -> Vout = 高（在窗口内）
- Vin < Vlow：U1 输出高，U2 输出低 -> Vout = 低（低于下限）

### 4.2 设计示例

设计目标：窗口范围 2.0V ~ 4.0V（Vcc=5V）

```
Vhigh = 4.0V, Vlow = 2.0V

使用 LM393（双路开漏比较器）:
  U1A: 同相输入接 Vin, 反相输入接 Vhigh(4.0V)
  U1B: 同相输入接 Vlow(2.0V), 反相输入接 Vin
  
  两路开漏输出短接 -> 共用一个上拉电阻 Rpullup = 4.7k

Vref 产生:
  Vhigh(4.0V): 5V * R2b/(R1b+R2b) = 4.0V
    取 R1b = 10k, R2b = 40k -> Vhigh = 5*40k/50k = 4.0V

  Vlow(2.0V): 5V * R2a/(R1a+R2a) = 2.0V
    取 R1a = 10k, R2a = 10k -> Vlow = 5*10k/20k = 2.5V (需调整)
    取 R1a = 20k, R2a = 20k -> Vlow = 5*20k/40k = 2.5V (仍不对)
    取 R1a = 15k, R2a = 10k -> Vlow = 5*10k/25k = 2.0V (正确!)
```

### 4.3 窗口比较器输出逻辑

```
输入条件         U1输出    U2输出    Vout(线与)
Vin > 4.0V       低(0)     高(Z)     低(0)  -> 超上限
2.0V < Vin < 4.0V 高(Z)    高(Z)     高(1)  -> 在窗口内
Vin < 2.0V        高(Z)    低(0)     低(0)  -> 超下限
```

## 5. 输出驱动能力与电平转换

### 5.1 开漏输出电平转换

LM393 的开漏输出可以实现电平转换：

```
比较器供电: Vcc1 = 3.3V
上拉电阻到: Vcc2 = 5V (或任意电压)

         Vcc2(5V)
            │
           Rpullup(4.7k)
            │
            ├── Vout (5V 逻辑电平)
            │
LM393(3.3V供电) 开漏输出

输入超过 Vref -> 输出导通 -> Vout = 0V
输入低于 Vref -> 输出截止 -> Vout = 5V
```

### 5.2 推挽输出驱动

LM311 支持外部输出级驱动（发射极和集电极均引出）：

```
高侧驱动:
  Vcc(12V) ──┬── LM311 集电极
              │
             负载
              │
             LM311 发射极 ── GND

低侧驱动:
  Vcc(12V) ── LM311 发射极
              │
             负载
              │
             LM311 集电极 ── GND
```

## 6. 响应时间分析

### 6.1 传输延迟

比较器的响应延迟由以下因素决定：

```
t_response = t_propagation + t_overdrive_recovery

t_propagation: 器件固有传播延迟 (LM393: 1.3us typ)
t_overdrive_recovery: 过驱恢复时间 (取决于过驱程度)
```

### 6.2 过驱量影响

```
过驱量 = |Vin - Vref| (超出阈值的量)

小过驱 (< 5mV): t_response >> t_propagation (可能 > 10us)
中等过驱 (10~100mV): t_response ~ 2~3 * t_propagation
大过驱 (> 100mV): t_response ~ t_propagation
```

### 6.3 提高响应速度的措施

1. 选择更快的比较器（TLV3201: 40ns vs LM393: 1.3us）
2. 增大过驱量（合理设置 Vref）
3. 减小上拉电阻值（降低 RC 充电时间）
4. 使用推挽输出比较器（消除上拉电阻延迟）

## 7. PCB 布局指南

### 7.1 布局原则

1. **输入走线短**：比较器输入走线尽量短，减少噪声耦合
2. **参考电压稳定**：Vref 旁路电容紧贴分压节点
3. **输出上拉就近**：上拉电阻紧贴比较器输出引脚
4. **正反馈走线短**：施密特触发器反馈电阻紧贴运放

### 7.2 噪声控制

```
高阻抗节点（Vref 分压点）处理:
  Vref ──┬── 100nF ── GND (滤除噪声)
         │
        4.7uF (进一步稳定)
         │
        GND

输入信号滤波:
  Vin ──┬── R(1k) ──┬── 比较器输入
        │           │
       C1(1nF)    C2(100nF) (低通滤波)
        │           │
       GND         GND
```

### 7.3 开漏输出布局

```
Vcc ─── Rpullup ─── 比较器输出引脚 ─── Vout
                       │
                      GND (开漏输出内部连 GND)

上拉电阻到输出引脚走线 < 10mm
输出走线远离输入走线（防止正反馈振荡）
```

## 8. 常见设计陷阱与解决方案

### 8.1 输出振荡

**原因**：无迟滞、输入噪声大、PCB 布局耦合

**解决**：
- 增加施密特触发器正反馈（迟滞设计）
- 输入端增加 RC 低通滤波
- 输入/输出走线分离
- 增加电源去耦

### 8.2 响应慢

**原因**：过驱量不足、上拉电阻过大、比较器速度不够

**解决**：
- 增大过驱量（调整 Vref）
- 减小上拉电阻（4.7k → 1k）
- 更换更快的比较器

### 8.3 阈值偏移

**原因**：参考电压不稳、输入偏置电流影响

**解决**：
- Vref 使用基准电压源（TL431）
- 降低分压电阻阻值（减小偏置电流误差）
- Vref 节点增加旁路电容

### 8.4 误触发

**原因**：电源噪声耦合、输入尖峰干扰

**解决**：
- 电源增加 LC 滤波
- 输入端增加 TVS 或钳位二极管
- 增大迟滞宽度

## 9. 设计检查清单

| 检查项 | 要求 | 通过标准 |
|--------|------|----------|
| 迟滞设计 | 输入噪声 > 5mV 时必须有迟滞 | 满足 |

| Vref 稳定性 | 100nF + 基准源 | 满足 |

# 熔断器/PTC 过流保护电路设计知识库

> 适用范围：保险丝、PTC 自恢复保险丝、过流保护电路设计
> 目标受众：AI 设计辅助 Skill，用于过流保护电路设计咨询与审查
> 版本：v1.0 | 更新日期：2026-08

## 1. 概述

过流保护是电子系统安全设计的核心环节。当电路发生短路或过载时，保护器件能在异常电流下切断或限制电流，防止器件损坏、起火等安全事故。本模块覆盖传统熔断器（Fuse）和自恢复保险丝（PTC）的选型与应用设计。

### 1.1 保护器件分类

| 器件类型 | 响应速度 | 恢复性 | 精度 | 成本 | 适用场景 |
|---------|---------|--------|------|------|---------|
| 快速熔断保险丝 | 快 (ms) | 不可恢复 | 高 | 低 | 一次性精密保护 |
| 慢断保险丝 | 慢 (s) | 不可恢复 | 中 | 低 | 电机/容性负载 |
| PTC 自恢复保险丝 | 慢 (s~min) | 可恢复 | 低 | 中 | 可维护设备 |
| 电子保险丝 (eFuse) | 快 (us) | 可恢复 | 高 | 高 | 精密保护 |
| 断路器 | 中 (ms) | 可恢复 | 中 | 高 | 大功率设备 |
| 电流检测 + MOSFET | 快 (us) | 可恢复 | 高 | 中 | 可编程保护 |

### 1.2 Fuse vs PTC vs eFuse 对比

| 特性 | 传统 Fuse | PTC | eFuse |
|------|----------|-----|-------|
| 动作原理 | 熔体熔断 | 聚合物电阻增大 | 电子开关断开 |
| 响应时间 | ms~s | s~min | us |
| 恢复方式 | 更换器件 | 自动恢复 | 自动/手动 |
| 动作精度 | +/-10% | +/-50% | +/-5% |
| 电阻（正常） | 极低 | 较高 | 极低 |
| 电流容量 | 大 (数十 A) | 中 (数 A) | 小 (~10A) |
| 电压降 | < 100mV | 100~500mV | < 50mV |
| 成本 | 最低 | 中 | 最高 |

## 2. 传统熔断器（Fuse）

### 2.1 熔断特性

```
快断 (Fast-Blow / F-Type):
  1.25 * In -> > 1h 不熔断
  2.0 * In -> < 60s 熔断
  2.5 * In -> < 10s 熔断
  
  特点: 过载立即熔断, 不耐受浪涌电流
  适用: 精密电子、半导体器件保护

慢断 (Time-Delay / T-Type):
  1.25 * In -> > 1h 不熔断
  2.0 * In -> > 10s 熔断
  3.0 * In -> > 0.5s 熔断
  
  特点: 可耐受短时浪涌 (电机启动/电容充电)
  适用: 电机、变压器、大电容输入
```

### 2.2 熔断曲线（I-t 曲线）

```
电流倍数 (x In)
  10 ──────────────────
     │  快断    慢断
  5 ──┤<0.01s    |
     │           |
  3 ──┤<0.1s     |
     │      <10s |
  2 ──┤<1s       |
     │      <60s |
  1.5 ┤<60s      |
     │           |
  1.25┤>1h     >1h
  ────┴──────────────
     时间 (s)
```

### 2.3 选型参数

| 参数 | 符号 | 说明 |
|------|------|------|
| 额定电流 | In | 正常工作电流 |
| 额定电压 | Vn | 最大工作电压 (AC/DC) |
| 熔断特性 | F/T | 快断/慢断 |
| 分断能力 | Ir | 最大可分断电流 (kA) |
| 温度降额 | Kt | 环境温度修正系数 |
| 脉冲耐受 | I2t | 熔断器耐受的浪涌能量 |

### 2.4 额定电流选择

```
In_fuse = In_normal * 1.25 / Kt

其中:
  In_normal: 电路正常工作电流
  1.25: 安全系数 (避免误熔断)
  Kt: 温度降额系数

温度降额系数表:
  环境温度   Kt
  25C       1.00
  40C       0.91
  50C       0.85
  60C       0.78
  70C       0.71
  80C       0.64

示例 (In_normal=2A, Ta=60C):
  In_fuse = 2 * 1.25 / 0.78 = 3.2A -> 选 3.15A 快断保险丝
```

### 2.5 分断能力选择

```
分断能力 >= 可能出现的最大短路电流

低压电路短路电流估算:
  5V/2A 电源: 短路电流可达 50~200A
  220V 市电: 短路电流可达 1.5~10kA

常用保险丝分断能力:
  玻璃管保险丝 (5x20): 35A~100A (低压)
  陶瓷管保险丝 (5x20): 1.5kA
  贴片保险丝 (1206/0603): 50A~100A
  工业保险丝: 10kA~200kA
```

### 2.6 常用贴片保险丝

| 型号 | In | Vn | 分断能力 | 熔断特性 | 封装 | I2t |
|------|-----|-----|---------|---------|------|-----|
| 0603F500T | 500mA | 63V | 50A | 快断 | 0603 | 1.0 |
| 0603F1AT | 1A | 63V | 50A | 快断 | 0603 | 4.0 |
| 0603F2AT | 2A | 63V | 50A | 快断 | 0603 | 16 |
| 0805F500T | 500mA | 63V | 100A | 快断 | 0805 | 1.0 |
| 1206F2AT | 2A | 63V | 100A | 快断 | 1206 | 16 |
| 1206T2A | 2A | 63V | 100A | 慢断 | 1206 | 80 |
| 1206T5A | 5A | 32V | 100A | 慢断 | 1206 | 530 |

### 2.7 I2t 脉冲耐受校验

```
保险丝的 I2t 必须 > 电路浪涌电流的 I2t

浪涌 I2t 计算:
  电容充电浪涌: I2t = C * Vin^2 / 2
  电机启动:     I2t = Iinrush^2 * t_inrush

示例 (输入电容 1000uF, Vin=5V):
  I2t = 1000uF * 5^2 / 2 = 0.0125 A2s

保险丝 I2t (1206F2AT = 16):
  保险丝 I2t (16) >> 浪涌 I2t (0.0125) -> 不会误熔断
```

## 3. PTC 自恢复保险丝

### 3.1 工作原理

PTC（Polymer Positive Temperature Coefficient）聚合物正温度系数器件，在正常温度下阻值极低（< 1 ohm），当过流导致温度升高到居里点时，阻值急剧增大（增大 1000 倍以上），限制电流到极低水平。故障消除后自动恢复到低阻状态。

```
正常状态: R_ptc ~ 0.1~1 ohm, 温度 < 80C
动作状态: R_ptc ~ 1k~100k ohm, 温度 > 120C
恢复条件: 断电冷却到 80C 以下
```

### 3.2 PTC 关键参数

| 参数 | 符号 | 说明 |
|------|------|------|
| 保持电流 | Ihold | PTC 保持不动作的最大持续电流 |
| 动作电流 | Itrip | PTC 必然动作的最小电流 |
| 额定电压 | Vmax | PTC 能承受的最大电压 |
| 额定电流 | Imax | PTC 能承受的最大短路电流 |
| 初始电阻 | Rmin | 动作前的最小电阻 |
| 动作后电阻 | R1max | 动作一次后的最大电阻 |
| 动作时间 | Ttrip | 达到 Itrip 时动作时间 |
| 功耗 | Pd | 动作状态下的功耗 |

### 3.3 保持电流与动作电流

```
Ihold 和 Itrip 的关系:
  Itrip / Ihold ~ 1.7~2.0 (典型)

示例 (1206L050YR):
  Ihold = 500mA (20C)
  Itrip = 1.0A (20C)
  -> 电流在 500mA~1.0A 之间状态不确定
  -> 必须确保正常电流 < Ihold, 故障电流 > Itrip
```

### 3.4 温度降额

PTC 对温度极其敏感，高温下保持电流降低：

| 环境温度 | Ihold 降额系数 |
|---------|---------------|
| -20C | 1.30 |
| 0C | 1.15 |
| 20C | 1.00 |
| 40C | 0.85 |
| 60C | 0.70 |
| 80C | 0.55 |

```
选型公式:
  Ihold_rated >= Inormal / Kt

示例 (Inormal=350mA, Ta=60C):
  Ihold >= 350 / 0.70 = 500mA -> 选 Ihold=500mA PTC
```

### 3.5 常用 PTC 型号

| 型号 | Ihold | Itrip | Vmax | Imax | Rmin | 封装 | 典型应用 |
|------|-------|-------|------|------|------|------|---------|
| 0603L035 | 350mA | 750mA | 15V | 40A | 0.6 ohm | 0603 | USB 供电 |
| 0603L050 | 500mA | 1.0A | 15V | 40A | 0.35 ohm | 0603 | USB 2.0 |
| 0805L075 | 750mA | 1.5A | 30V | 40A | 0.2 ohm | 0805 | 低压接口 |
| 1206L050 | 500mA | 1.0A | 30V | 100A | 0.15 ohm | 1206 | USB 供电 |
| 1206L110 | 1.1A | 2.2A | 30V | 100A | 0.07 ohm | 1206 | 5V 电源 |
| 1206L200 | 2.0A | 4.0A | 30V | 100A | 0.04 ohm | 1206 | 大电流 5V |
| 1210L150 | 1.5A | 3.0A | 30V | 100A | 0.05 ohm | 1210 | 通用 |
| 1812L100 | 1.0A | 2.0A | 30V | 100A | 0.08 ohm | 1812 | USB Hub |

## 4. Fuse + TVS 协调保护

### 4.1 协调设计原则

```
Fuse 和 TVS 协调工作:

Vin ──┬── Fuse ──┬── TVS ──┬── Vout
      │          │          │
     GND        GND        GND

工作时序:
  1. 浪涌到来 -> TVS 快速钳位 (ns 级)
  2. TVS 钳位电压限制峰值 -> 保护下游器件
  3. 浪涌持续 -> 电流持续增大 -> Fuse 熔断 (ms~s)
  4. Fuse 断开 -> 切断浪涌源 -> 保护 TVS 不损坏

协调要求:
  - TVS 必须在 Fuse 熔断前存活 (能量协调)
  - Fuse 必须在 TVS 损坏前熔断 (时限协调)
  - Fuse 的 I2t > TVS 的 I2t 耐受值 (否则误熔断)
```

### 4.2 能量协调计算

```
TVS 能量耐受 (8/20us 波形):
  E_tvs = Vc * Ipp * t_pulse / sqrt(2)
  
  SMAJ5.0A: E = 9.2 * 43 * 20us / 1.414 = 5.6mJ (额定)

Fuse 熔断能量:
  I2t_fuse = 已知 (查数据手册)

协调条件:
  E_surge < E_tvs (单次浪涌, Fuse 不熔断)
  E_surge > E_fuse (持续浪涌, Fuse 熔断保护)
```

### 4.3 PTC + TVS 协调

```
PTC 动作慢 (秒级), TVS 动作快 (纳秒级)
两者配合时 PTC 限制持续电流, TVS 钳位瞬态

Vin ──┬── PTC ──┬── TVS ──┬── Vout
      │          │          │
     GND        GND        GND

注意: PTC 电阻在动作后会增大, 限制电流
     但 TVS 仍需承受浪涌直到 PTC 动作
     PTC 动作时间 (s) >> TVS 承受时间 (us)
     -> 需确保 TVS 能承受 PTC 动作前的全部能量
```

## 5. 电子保险丝（eFuse）

### 5.1 eFuse 优势

| 特性 | 传统 Fuse/PTC | eFuse |
|------|-------------|-------|
| 响应时间 | ms~s | us |
| 恢复方式 | 更换/自恢复 | 电子控制 |
| 限流精度 | 差 (+/-50%) | 好 (+/-5%) |
| 电压降 | 100~500mV | < 50mV |
| 附加功能 | 无 | 过压保护/过温保护/EN控制 |
| 成本 | 低 | 高 |

### 5.2 常用 eFuse IC

| 型号 | Vin | Imax | 限流范围 | 过压保护 | 封装 | 典型应用 |
|------|-----|------|---------|---------|------|---------|
| TPS25940 | 2.7~18V | 5A | 0.5~5A | 可调 | VQFN-22 | USB PD |
| TPS25200 | 2.5~6.5V | 2.6A | 固定 | 6.5V | SOT-23-6 | USB 口 |
| TPS2546 | 4.5~5.5V | 2.5A | 可调 | 有 | VQFN-22 | USB 充电口 |
| LM5069 | 9~65V | 外置MOS | 可调 | 可调 | TSSOP-14 | 工业电源 |
| MAX17523 | 4.5~36V | 6A | 可调 | 有 | TQFN-16 | 工业 |

### 5.3 eFuse 典型应用

```
5V USB 供电保护:

Vin(5V) ──┬── eFuse(TPS25200) ──┬── Vout(5V/2.5A)
           │                      │
          EN                     4.7uF
           │                      │
         MCU GPIO                GND

功能:
  - 限流: 2.5A (固定)
  - 过压保护: 6.5V (自动断开)
  - 热保护: 160C (自动关断)
  - EN 控制: MCU 可以远程开关
```

## 6. PCB 布局指南

### 6.1 保险丝布局

```
布局原则:
  1. 保险丝靠近电源输入端
  2. 保险丝前不接任何器件（除 EMI 滤波）
  3. 保险丝后接 TVS 和旁路电容

Vin ──┬── Fuse ──┬── TVS ──┬── 旁路电容 ── Vout
      │          │          │
     GND        GND        GND
```

### 6.2 PTC 布局

```
PTC 布局考虑:
  1. PTC 发热大, 周围留散热空间 (> 2mm)
  2. PTC 不与其他发热器件靠近
  3. PTC 焊盘足够大以散热
  4. PTC 到连接器距离 < 20mm

┌────────────────────────────────┐
│  连接器 ── PTC ── TVS ── 电容   │
│          │     │               │
│         留空间  GND            │
│         >2mm                   │
└────────────────────────────────┘
```

### 6.3 eFuse 布局

```
eFuse IC 布局:
  1. 输入/输出电容紧贴 IC 引脚
  2. 走线短而宽 (承载大电流)
  3. GND 焊盘增加过孔散热
  4. 限流电阻紧贴 ILIM 引脚

  Vin ──┬── Cin(10uF) ── eFuse ── Cout(22uF) ── Vout
        │                 │
       GND              GND pad + 过孔阵列
```

## 7. 常见设计陷阱与解决方案

### 7.1 保险丝频繁误熔断

**原因**：浪涌电流过大、额定电流选小、温度降额不足

**解决**：
- 改用慢断保险丝（耐受浪涌）
- 增大额定电流（1.25~1.5 倍正常电流）
- 考虑温度降额系数
- 验证 I2t 脉冲耐受

### 7.2 PTC 动作过慢

**原因**：PTC 固有特性（秒级响应），环境温度低

**解决**：
- PTC 仅用于过载保护，不能替代短路保护
- 短路保护用快断 Fuse 或 eFuse
- 增加电子保护电路作为快速响应补充

### 7.3 PTC 电阻增大导致压降

**原因**：PTC 正常电阻较高（0.1~1 ohm），大电流时压降显著

**解决**：
- 选择低阻 PTC（如 1206L200: Rmin=0.04 ohm）
- 降低工作电流余量
- 改用 eFuse（电压降 < 50mV）

### 7.4 PTC 不恢复

**原因**：故障未消除时反复上电，PTC 温度维持高位

**解决**：
- 断电后等待 PTC 冷却（> 30s）
- 检查并消除故障源
- 设计故障指示灯提醒用户

## 8. 设计检查清单

| 检查项 | 要求 | 通过标准 |
|--------|------|----------|
| 额定电流 | >= 1.25 * Inormal / Kt | 满足 |
| 额定电压 | >= 工作电压 * 1.2 | 满足 |
| 分断能力 | >= 最大短路电流 | 满足 |
| 熔断特性 | 容性负载选慢断, 精密选快断 | 满足 |
| I2t 校验 | Fuse I2t > 浪涌 I2t | 满足 |
| PTC Ihold | >= Inormal / Kt | 满足 |
| PTC Vmax | >= 最大工作电压 | 满足 |
| TVS 协调 | TVV 承受 Fuse 熔断前能量 | 滀足 |
| 散热空间 | PTC 周围 > 2mm | 满足 |

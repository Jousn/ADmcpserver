# SPI/I2C 接口电路设计知识库

> 适用范围：SPI/I2C 通信接口电路设计（电平转换、隔离、上拉计算）
> 目标受众：AI 设计辅助 Skill，用于 SPI/I2C 总线电路设计咨询与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

SPI 和 I2C 是嵌入式系统中最常用的芯片级串行通信总线。SPI 采用 4 线全双工同步通信，适合高速数据传输（如 Flash、ADC、LCD）；I2C 采用 2 线半双工同步通信，适合多器件低速通信（如传感器、EEPROM、RTC）。本模块覆盖两种接口的电路设计要点。

### 1.1 SPI 与 I2C 对比

| 特性 | SPI | I2C |
|------|-----|-----|
| 信号线数 | 4 (SCLK/MOSI/MISO/CS) | 2 (SDA/SCL) |
| 通信方式 | 全双工 | 半双工 |
| 最大速率 | 几十 Mbps | 100kHz/400kHz/3.4MHz |
| 拓扑 | 主从（星型，每从各需 CS） | 多主多从（总线，地址区分） |
| 应答机制 | 无（硬件确认） | 有（ACK/NACK） |
| 距离 | 短（< 30cm） | 短（< 1m，取决于电容） |
| 复杂度 | 高（多线） | 低（2 线） |
| 典型器件 | Flash/ADC/LCD | EEPROM/Sensor/RTC |

## 2. SPI 接口设计

### 2.1 SPI 信号定义

| 信号 | 方向（主->从） | 功能 |
|------|--------------|------|
| SCLK | 主->从 | 串行时钟 |
| MOSI | 主->从 | 主输出从输入 |
| MISO | 从->主 | 主输入从输出 |
| CS (NSS) | 主->从 | 片选（低有效） |
| GND | — | 公共地 |

### 2.2 SPI 时钟模式

| 模式 | CPOL | CPHA | 时钟空闲 | 采样沿 |
|------|------|------|---------|--------|
| 0 | 0 | 0 | 低电平 | 上升沿采样 |
| 1 | 0 | 1 | 低电平 | 下降沿采样 |
| 2 | 1 | 0 | 高电平 | 下降沿采样 |
| 3 | 1 | 1 | 高电平 | 上升沿采样 |

### 2.3 CS 片选处理

CS 线必须上拉或下拉确保空闲时不选中从器件：

```
方案1: MCU GPIO 直接驱动 CS（推荐）
  MCU CS_PIN ──── 从器件 CS
  (MCU 上电默认输出高，确保不选中)

方案2: 外部上拉电阻
  Vcc ── R(10k) ──┬── 从器件 CS
                   │
                  MCU CS_PIN
  (上电时 MCU 为高阻，靠上拉确保 CS=高)

方案3: 多从器件使用译码器
  MCU ── 3-8译码器 ── 8 个从器件 CS
  (节省 MCU GPIO)
```

### 2.4 SPI 电平转换

当主从器件电压不同时需要电平转换：

```
方案1: 专用电平转换 IC（推荐高速 SPI）
  TXS0108E (8通道双向, 24Mbps, 自动方向)
  或 TXB0108 (8通道, 单向可选)
  
  MCU(3.3V) ── TXS0108E ── 从器件(1.8V/2.5V/5V)

方案2: MOSFET 电平转换（低成本，低速适用）
  仅适用于 SCLK/MOSI/CS（单向）
  MISO 需要反向 MOSFET 电路

方案3: 电阻分压（仅 5V->3.3V 单向）
  5V 信号 ── R1(1k) ──┬── 3.3V 输入
                        │
                       R2(2k)
                        │
                       GND
```

### 2.5 SPI 信号完整性

高速 SPI（> 10MHz）需要考虑信号完整性：

```
串联匹配电阻:
  MCU SCLK ── R(22~33 ohm) ── 从器件 SCLK
  MCU MOSI ── R(22~33 ohm) ── 从器件 MOSI

  作用: 抑制反射和振铃
  阻值: 根据走线阻抗和驱动能力调整 (22~100 ohm)

走线等长:
  SCLK/MOSI/MISO/CS 走线长度差 < 50mil (高速时)
  信号回流路径完整 (GND 参考平面)
```

## 3. I2C 接口设计

### 3.1 I2C 信号定义

| 信号 | 功能 | 电气特性 |
|------|------|---------|
| SDA | 串行数据 | 开漏，需上拉 |
| SCL | 串行时钟 | 开漏，需上拉 |
| GND | 公共地 | — |

### 3.2 I2C 速率等级

| 模式 | 速率 | 最大电容 | 典型应用 |
|------|------|---------|---------|
| Standard | 100kHz | 400pF | 通用传感器 |
| Fast Mode | 400kHz | 400pF | EEPROM/Sensor |
| Fast Mode+ | 1MHz | 550pF | 高速传感器 |
| High Speed | 3.4MHz | 100pF | 特殊高速 |

### 3.3 I2C 上拉电阻计算

I2C 为开漏总线，必须外接上拉电阻。阻值选取至关重要：

```
上拉电阻取值范围:
  下限: Rp_min = (Vcc - Vol_max) / Iol_max
  上限: Rp_max = tr / (0.8473 * Cb)

  Vcc: 供电电压
  Vol_max: 低电平最大电压 (0.4V)
  Iol_max: 灌电流能力 (3mA for Standard, 20mA for Fast+)
  tr: 上升时间 (1000ns for 100kHz, 300ns for 400kHz)
  Cb: 总线电容 (pF)
```

示例计算（Vcc=3.3V, 400kHz Fast Mode, Cb=100pF）：

```
Rp_min = (3.3 - 0.4) / 0.003 = 967 ohm -> 取 >= 1k
Rp_max = 300ns / (0.8473 * 100pF) = 3.54k ohm -> 取 <= 3.3k

推荐: Rp = 2.2k ohm (在 1k~3.3k 范围内)
```

### 3.4 总线电容计算

I2C 总线总电容不能超过标准限制（400pF for Standard/Fast Mode）：

```
Cb = C_wire + N * C_device

  C_wire: 走线寄生电容 (~1pF/cm for 6mil 线宽)
  C_device: 每个器件输入电容 (5~10pF, 查数据手册)
  N: 器件数量

示例: 走线 20cm + 4 个器件 (8pF each)
  Cb = 20*1 + 4*8 = 52pF (远小于 400pF 限制)
```

### 3.5 上拉电阻选型表

| Vcc | 100kHz | 400kHz | 1MHz |
|-----|--------|--------|------|
| 3.3V | 4.7k~10k | 2.2k~4.7k | 1k~2.2k |
| 5V | 4.7k~10k | 2.2k~4.7k | 1k~2.2k |
| 1.8V | 2.2k~4.7k | 1k~2.2k | 470~1k |

### 3.6 I2C 电平转换

```
方案1: MOSFET 双向电平转换（推荐，经典电路）

  Vcc_A(1.8V)                    Vcc_B(3.3V)
     │                               │
    Ra(10k)                        Rb(10k)
     │                               │
SDA_A ──┬──── BSS138 ────┬── SDA_B
         │    (D  G  S)   │
         └────────────────┘

  BSS138: NMOS, 低 Vth (< 1.3V)
  Ra, Rb: 两个域各自的上拉电阻
  
  工作原理:
  - 两端都空闲: SDA_A 和 SDA_B 都被上拉到各自 Vcc
  - A 端拉低: MOSFET 导通, B 端也拉低
  - B 端拉低: MOSFET 体二极管导通, A 端也拉低

方案2: 专用 I2C 电平转换 IC
  PCA9306 (双向, 2 通道, 1MHz)
  TXS0102 (双向, 2 通道, 24Mbps)
  LSF0108 (8 通道, 多电压)
```

## 4. I2C 隔离设计

### 4.1 数字隔离器方案

```
MCU 侧                    I2C 总线侧
                  ┌──────────┐
MCU SDA ──────────┤ADuM1251  ├─ SDA_iso
MCU SCL ──────────┤          ├─ SCL_iso
                  │          │
MCU Vcc ──────────┤Vcc1  Vcc2├─ ISO_Vcc
MCU GND ──────────┤GND1  GND2├─ ISO_GND
                  └──────────┘

ADuM1251 特点:
  - 双通道 I2C 专用隔离器
  - 2.5kV rms 隔离耐压
  - 支持 1MHz I2C
  - 自动方向检测（无需方向控制）

隔离电源:
  B0505S-1W (5V -> 5V 隔离 DC-DC)
  或 LDO + 隔离 DC-DC 组合
```

### 4.2 光耦隔离方案（低速适用）

```
MCU SDA ── R(1k) ── LED ──┤光耦├── R(4.7k) ── ISO_SDA
                          (6N137 或 PC817)
                           ↑
                     隔离电源供电

注意: 光耦方案需要方向控制（I2C 是双向的）
需要额外的方向逻辑电路，设计复杂
推荐使用专用 I2C 数字隔离器替代
```

## 5. 多器件总线设计

### 5.1 I2C 多器件地址管理

```
I2C 器件地址格式:
  [7位地址] [R/W]
  
  常用器件地址:
    EEPROM 24C02: 0x50~0x57 (A0/A1/A2 设定)
    BMP280: 0x76 或 0x77 (SDO 引脚设定)
    MPU6050: 0x68 或 0x69 (AD0 引脚设定)
    DS3231: 0x68 (固定)
    PCA9685: 0x40~0x7F (A0~A5 设定)

  地址冲突解决:
  1. 使用带地址引脚的器件（A0/A1/A2 设定不同地址）
  2. 使用 I2C 多路复用器（PCA9548A, 8 通道）
  3. 使用 I2C 开关（PCA9540B, 2 通道）
```

### 5.2 SPI 多器件片选

```
方案1: 独立 CS 线
  MCU CS0 ──── 器件1 CS
  MCU CS1 ──── 器件2 CS
  MCU CS2 ──── 器件3 CS
  (SCLK/MOSI/MISO 共享)

方案2: 译码器节省 GPIO
  MCU GPIO0/1/2 ── 3-8译码器 ── 8 路 CS

方案3: SPI 总线级联（菊花链）
  MCU MOSI ── 器件1 DIN ── 器件1 DOUT ── 器件2 DIN ── ...
  (所有器件共享一个 CS)
  (适用于移位寄存器/DAC 链式器件)
```

## 6. PCB 布局指南

### 6.1 I2C 布局

```
┌─────────────────────────────────────┐
│  MCU                                │
│  ┌──┐  SDA ──┬──┬──┬──┬──┬──┬──┐  │
│  │  │        │  │  │  │  │  │  │  │
│  │  │  SCL ──┼──┼──┼──┼──┼──┼──┤  │
│  └──┘        │  │  │  │  │  │  │  │
│           Dev1 Dev2 Dev3 ...  Rp   │
│                                     │
│  █████ GND 平面 ████████████████      │
└─────────────────────────────────────┘

布局原则:
  1. SDA/SCL 平行走线, 间距 >= 3x 线宽
  2. 上拉电阻放在总线末端（最后一个器件处）
  3. 器件沿总线顺序排列，避免分支
  4. 总线长度尽量短（< 200mm）
  5. 走线下方保持完整 GND 平面
```

### 6.2 SPI 布局

```
┌─────────────────────────────────────┐
│  MCU                                │
│  ┌──┐  SCLK ──┬──┬──┬──┐           │
│  │  │  MOSI ──┬──┬──┬──┐           │
│  │  │  MISO ──┼──┼──┼──┤           │
│  │  │  CS0  ──┤  │  │  │           │
│  │  │  CS1  ──┼──┤  │  │           │
│  │  │  CS2  ──┼──┼──┤  │           │
│  └──┘          │  │  │             │
│              Dev1 Dev2 Dev3         │
│                                     │
│  串联电阻 22~33 ohm 靠近 MCU 输出端  │
└─────────────────────────────────────┘
```

### 6.3 信号完整性规则

| 规则 | 要求 |
|------|------|
| 走线长度 | I2C < 200mm, SPI < 100mm |
| 线宽 | 6~8mil (0.15~0.2mm) |
| 线距 | >= 3x 线宽（串扰控制） |
| 过孔数 | 尽量少（< 2 个） |
| 参考平面 | 完整 GND |
| 分支长度 | I2C < 50mm, SPI < 30mm |

## 7. 常见设计陷阱与解决方案

### 7.1 I2C 无应答

**原因**：上拉电阻缺失、地址错误、电压不匹配

**解决**：
- 确认 SDA/SCL 有上拉电阻到 Vcc
- 用示波器检查 SDA/SCL 波形（上升时间是否过慢）
- 确认器件地址（7 位 vs 8 位写法差异）
- 确认主从器件电压一致

### 7.2 I2C 总线死锁

**原因**：从器件在 ACK 阶段被复位，SDA 被拉低不释放

**解决**：
- MCU 产生 9 个额外 SCL 时钟脉冲释放总线
- 然后发送 STOP 条件
- 硬件方案：增加 I2C 总线恢复 IC（如 MAX7359）

### 7.3 SPI 通信误码

**原因**：时钟模式错误、走线反射、交叉接错

**解决**：
- 确认 CPOL/CPHA 与从器件数据手册一致
- SCLK 串联 33 ohm 匹配电阻
- 检查 MOSI/MISO 是否交叉连接正确
- 降低 SCLK 频率验证

### 7.4 SPI 多器件干扰

**原因**：未选中的器件 MISO 干扰总线

**解决**：
- 确认从器件在 CS=高时 MISO 为高阻
- 检查 CS 信号是否稳定（无毛刺）
- MISO 线串联电阻隔离

### 7.5 电平转换速度不足

**原因**：MOSFET 电平转换上升时间慢、寄生电容大

**解决**：
- 高速 I2C/SPI 使用专用电平转换 IC（TXS0108E）
- 减小上拉电阻值加速上升沿
- 降低总线电容（缩短走线）

## 8. 设计检查清单

| 检查项 | 要求 | 通过标准 |
|--------|------|----------|
| I2C 上拉电阻 | Vcc=3.3V: 2.2k~4.7k | 满足 |
| I2C 总线电容 | < 400pF | 满足 |
| I2C 地址冲突 | 无冲突或多路复用 | 满足 |

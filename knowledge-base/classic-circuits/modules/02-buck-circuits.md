## 1. 概述

Buck（降压型）DC-DC 变换器是电子系统中最常用的非隔离降压开关电源拓扑。相比 LDO 线性稳压器，Buck DC-DC 具有效率高（85%~95%）、散热需求低、支持大电流输出等优势，广泛用于 5V 转 3.3V、12V 转 5V/3.3V、24V 转 5V 等板级电源转换场景。

### 1.1 Buck 与 LDO 选型对比

| 条件 | 推荐 LDO | 推荐 Buck DC-DC |
|------|---------|----------------|
| 输出电流 < 300mA | 优先 | 不必要 |
| 压差 < 0.5V | 优先 | 不适用 |
| 输出电流 > 500mA | 不推荐 | 优先 |
| 压差 > 3V | 效率低 | 优先 |
| 噪声敏感（射频/ADC） | 优先 | 后级加 LDO |
| 效率优先 | 不推荐 | 优先 |

### 1.2 Buck 工作原理

Buck 电路通过高频开关控制电感储能与释放，实现降压转换：

```
    ┌── Q (MOSFET) ──┐
Vin │           │    │
    └── D (Diode)    L (电感) ──┬── Vout
         │                      │
        GND                    Cout
                                │
                               GND
```

开关周期内：
- Q 导通：Vin 向电感 L 充电，电感电流线性上升
- Q 关断：电感 L 通过续流二极管 D 放电，电感电流线性下降

## 3. 关键参数计算

### 3.1 占空比

Buck 电路工作于 CCM（连续电流模式）时的占空比：

```
D = Vout / (Vin * eta)
```

其中 eta 为转换效率（通常 0.85~0.95），简化计算时取 D ≈ Vout / Vin。

示例：

```
Vin=12V, Vout=3.3V, eta=0.9
D = 3.3 / (12 * 0.9) = 0.306 (30.6%)
```

### 3.2 电感选型

电感值决定输出纹波电流大小，计算公式：

```
L = (Vin - Vout) * Vout / (Vin * dI_L * fsw)
```

其中 dI_L 为电感纹波电流，一般取输出电流的 20%~40%：

```
dI_L = 0.2~0.4 * Iout (典型取 0.3)
```

示例计算（MP1584: Vin=12V, Vout=3.3V, Iout=2A, fsw=1.5MHz）：

```
dI_L = 0.3 * 2 = 0.6A
L = (12 - 3.3) * 3.3 / (12 * 0.6 * 1.5e6) = 2.66e-6 H = 2.66uH

取标准值: L = 2.2uH (或 3.3uH)
```

电感额定电流要求：

```
I_sat >= Iout + dI_L / 2 = 2 + 0.3 = 2.3A (饱和电流)
Irms >= Iout = 2A (温升电流)
```

### 3.3 输出电容选型

输出电容决定输出纹波电压，计算公式：

```
Vout_ripple = dI_L / (8 * fsw * Cout) + dI_L * ESR_Cout
```

前一项为电容充放电纹波，后一项为 ESR 纹波。

示例（Cout = 22uF MLCC, ESR = 5m, dI_L = 0.6A, fsw = 1.5MHz）：

```
Vripple_cap = 0.6 / (8 * 1.5e6 * 22e-6) = 2.27mV
Vripple_esr = 0.6 * 0.005 = 3mV
Vout_ripple = 2.27 + 3 = 5.27mV (可接受)
```

### 3.4 输入电容选型

输入电容承受开关频率的脉冲电流，需满足 RMS 电流要求：

```
Iin_rms = Iout * sqrt(D * (1 - D))
```

示例：

```
D = 0.306, Iout = 2A
Iin_rms = 2 * sqrt(0.306 * 0.694) = 2 * 0.461 = 0.92A
```

选择 Cin 时确保其 RMS 电流额定值 > 0.92A，推荐使用低 ESR 陶瓷电容，典型值 10uF~47uF。

### 3.5 反馈分压网络

输出电压通过分压电阻反馈到 FB 引脚：

```
Vout = Vref * (1 + Rtop / Rbottom)
```

其中 Vref 为 IC 内部基准电压（MP1584 为 0.8V, TPS5430 为 0.8V, SY8120 为 0.6V）。

示例（MP1584: Vref=0.8V, Vout=3.3V）：

```
Rtop / Rbottom = Vout / Vref - 1 = 3.3 / 0.8 - 1 = 3.125

取 Rbottom = 10k ohm
则 Rtop = 10k * 3.125 = 31.25k -> 取标准值 30k + 1k 串联 = 31k

验算: Vout = 0.8 * (1 + 31/10) = 0.8 * 4.1 = 3.28V (误差 0.6%)
```

## 4. 续流二极管选型

对于非同步整流 Buck（如 MP1584, TPS5430），需要外接续流二极管。

### 4.1 选型要求

| 参数 | 要求 | 说明 |
|------|------|------|
| 反向耐压 Vr | >= 1.3 * Vin | 留余量 |
| 正向电流 If | >= Iout | 满足负载电流 |
| 正向压降 Vf | < 0.5V | 低损耗，优先肖特基 |
| 反向恢复时间 trr | < 10ns | 快速恢复 |
| 封装热阻 | 满足功耗 | Pd = Vf * Iout * (1-D) |

### 4.2 常用肖特基二极管

| 型号 | Vr | If | Vf@If | 封装 | 适用 IC |
|------|-----|-----|-------|------|---------|
| SS34 | 40V | 3A | 0.55V | SMA | MP1584, SY8120 |
| SS54 | 40V | 5A | 0.55V | SMC | TPS5430 大电流 |
| B340 | 40V | 3A | 0.5V | SMC | MP1584 |
| MBRS340 | 40V | 3A | 0.45V | SMC | 低损耗应用 |
| SS24 | 40V | 2A | 0.5V | SMB | 小电流应用 |

## 5. 同步整流 Buck

同步整流 Buck 用低导通电阻 MOSFET 替代续流二极管，消除二极管正向压降损耗，提高效率。

### 5.1 同步 vs 非同步对比

| 特性 | 非同步整流 | 同步整流 |
|------|----------|---------|
| 下管 | 肖特基二极管 | NMOS |
| 效率（低压差时） | 较低 | 高（+3~5%） |
| 成本 | 低 | 高（需驱动 IC） |
| 轻载效率 | 较好（DCM 自然续流） | 较差（需特殊控制） |
| 适用场景 | < 3A, 成本敏感 | > 3A, 效率优先 |

### 5.2 同步 Buck 控制器

| 型号 | 特点 | 典型应用 |
|------|------|---------|
| TPS53353 | 5.5~18V, 15A, 集成 MOS | 服务器 |
| MP2940 | 4.5~18V, 12A, 集成 MOS | 消费电子 |
| LM5117 | 外置 MOS, 仿真电流模式 | 大电流工业 |

## 6. 典型应用电路

### 6.1 MP1584 12V 转 3.3V/2A 电路

```
               Cin           MP1584
   Vin(12V) ──┤├──┬── VIN   │  SW ──┬── L ──┬── Vout(3.3V)
              10uF │    ┌────┤      │  2.2uH │
                   │    │ IN │ SW   │        │
                   │    │    │      │       Cout 22uF
                   │    │ EN │ BST  │        │
                   │    │    │      │       GND
                   │    │ GND│      │
                   │    │    │  FB  │
                   │    └────┤      │
                   │         │      │
                   │    ┌────┘      │
                   │    │           │
                   │   D1 SS34     │
                   │    │           │
                  GND  GND          │
                                  Rtop 31k
                                   │
                                  Rbot 10k
                                   │
                                  GND
```

外围参数：
- Cin = 10uF / 25V X5R MLCC
- Cout = 22uF / 10V X5R MLCC
- L = 2.2uH / 3A 饱和（如 NR4018T2R2）
- D1 = SS34 (SMA)
- Rtop = 31k, Rbot = 10k (1% 精度)
- Cff = 22pF (前馈电容，改善瞬态响应)

### 6.2 TPS5430 24V 转 5V/3A 电路

外围参数：
- Cin = 10uF / 50V X7R MLCC
- Cout = 47uF / 10V POSCAP
- L = 15uH / 5A 饱和（如 MSS7341-152)
- D1 = SS54 (SMC)
- Rtop = 10k, Rbot = 1.74k (Vref=0.8V, Vout=5.39V)
- fsw = 500kHz (内部固定)

## 7. 补偿网络设计

电流模式控制的 Buck IC（如 TPS5430, MP1584）通常需要 Type II 补偿网络。

### 7.1 Type II 补偿网络

```
         Rcomp
   FB ──/\/\/──┬── COMP
               │
              Ccomp
               │
              GND
```

补偿参数计算步骤：

1. 确定功率级双零点频率和极点频率：

```
fz_power = 1 / (2*pi*sqrt(L*Cout))  (LC 谐振频率)
fp_power = 1 / (2*pi*Rload*Cout)    (负载极点)
```

2. 设置补偿零点抵消负载极点：

```
fz_comp = 1 / (2*pi*Rcomp*Ccomp) = fp_power / 10
```

3. 设置补偿极点抵消 ESR 零点：

```
fp_comp = 1 / (2*pi*Rcomp*Cff) = fsw / 2 (或 ESR 零点频率)
```

### 7.2 简化设计方法

多数 IC 数据手册提供按 Cout 查表法选取补偿参数：

| Cout | Rcomp | Ccomp | Cff |
|------|-------|-------|-----|
| 22uF | 100k | 150pF | 22pF |
| 47uF | 68k | 220pF | 22pF |
| 100uF | 47k | 470pF | 47pF |

## 8. PCB 布局指南

### 8.1 布局核心原则

Buck DC-DC 的 PCB 布局直接影响 EMI 表现和稳定性，核心原则是**最小化高频电流回路面积**。

### 8.2 关键回路

```
高频率大电流回路1（开关回路）:
  Cin+ → Vin → SW → L → Vout → Cout → GND → Cin-

高频率大电流回路2（续流回路）:
  SW → D1(阳极) → D1(阴极) → GND → Cin- → Cin+ → Vin → SW
```

### 8.3 元件布局顺序

```
1. Cin 尽可能靠近 IC 的 VIN 和 GND 引脚
2. D1 靠近 SW 引脚，阳极连接 GND
3. L 靠近 SW 引脚，缩短开关节点走线
4. Cout 靠近 L 输出端
5. 反馈走线从 Vout 端引出，远离 SW 和 L
```

### 8.4 布局示例

```
┌───────────────────────────────────┐
│   Cin    ┌────────┐     L     Cout │
│ Vin ─┤├──│VIN   SW├───[]()──┤├── Vout
│         │  IC    │          │       │
│    ┌────│GND   FB│          │       │
│    │ D1  │   COMP │          │      GND
│    │  │  └────────┘          │
│    │  └─ GND                 │
│   GND                  Rtop──┘
│                          │
│                        Rbot
│                          │
│                         GND
└───────────────────────────────────┘
```

### 8.5 布局注意事项

1. **输入电容回路最小化**：Cin 到 IC 的 VIN/GND 走线尽量短而宽，回路面积 < 10mm^2
2. **开关节点面积控制**：SW 走线尽量短，避免大面积铜皮辐射 EMI
3. **反馈走线保护**：FB 走线远离 SW 和电感，必要时走内层并两侧铺 GND
4. **GND 处理**：功率 GND 与信号 GND 单点连接，避免地环路
5. **过孔散热**：IC 底部 GND pad 增加过孔连接到内层 GND 平面

## 9. 常见设计陷阱与解决方案

### 9.1 输出纹波过大

**原因**：Cout 不足、ESR 过大、L 过小、布局差

**解决**：
- 增大 Cout（并联多颗 MLCC）
- 确认 Cout ESR < 10m
- 检查 L 值是否过小导致纹波电流大
- 优化 PCB 布局减小寄生电感

### 9.2 效率偏低

**原因**：续流二极管 Vf 大、fsw 过高、电感 DCR 大、轻载模式不当

**解决**：
- 换用更低 Vf 的肖特基（或同步整流）
- 选择合适 fsw（大电流用低频，小电流用高频）
- 选用低 DCR 电感
- 启用 PSM 轻载模式

### 9.3 环路不稳定

**原因**：补偿网络参数不当、Cout ESR 变化、布局引入寄生

**解决**：
- 按数据手册重新计算补偿参数
- 检查 Cout 是否更换为低 ESR 类型后需重新补偿
- 用示波器测量 SW 波形，确认无次谐波振荡

### 9.4 EMI 超标

**原因**：SW 节点辐射、输入回路面积大、地噪声

**解决**：
- 缩小输入回路面积（Cin 紧贴 IC）
- SW 走线下方铺完整 GND 平面
- 输入端增加 pi 型 LC 滤波器
- 减缓开关管开通/关断边沿（增加栅极电阻）

## 10. 设计检查清单

| 检查项 | 要求 | 通过标准 |
|--------|------|----------|
| 电感饱和电流 | >= Iout + dI_L/2 | 满足 |
| Cout RMS 电流 | >= dI_L / sqrt(12) | 满足 |
| 二极管耐压 | >= 1.3 * Vin | 满足 |
| Cin RMS 电流 | >= Iout*sqrt(D*(1-D)) | 满足 |
| 散热设计 | Tj < 125C | 满足 |
| 输入回路面积 | < 10mm^2 | 满足 |
| 反馈走线 | 远离 SW/L | 满足 |
| 补偿网络 | 按 Cout 匹配 | 满足 |

## 1. 概述

MCU 最小系统是使微控制器能正常工作的最基本电路集合，包含电源系统、时钟系统、复位电路、启动配置和调试接口五大核心部分。最小系统设计的稳定性直接决定整个嵌入式系统的可靠性。本模块以 STM32F1/F4 系列为例，覆盖最小系统设计的全部关键环节。

### 1.1 最小系统组成

```
┌────────────────────────────────────────────────┐
│                  MCU 最小系统                    │
│  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐ │
│  │ 电源  │  │ 时钟  │  │ 复位  │  │ 启动  │  │ 调试  │ │
│  │ 系统  │  │ 系统  │  │ 电路  │  │ 配置  │  │ 接口  │ │
│  └──────┘  └──────┘  └──────┘  └──────┘  └──────┘ │
└────────────────────────────────────────────────┘
```

## 2. 电源系统设计

### 2.1 STM32 电源引脚分类

| 引脚类型 | 引脚名称 | 供电对象 | 典型电压 | 去耦要求 |
|---------|---------|---------|---------|---------|
| 数字电源 | VDD / VSS | 数字逻辑核心与 IO | 3.3V | 100nF/引脚 + 4.7uF |
| 模拟电源 | VDDA / VSSA | ADC/DAC/比较器 | 3.3V | 100nF + 1uF + 铁氧体 |
| 电池域 | VBAT | RTC 和备份寄存器 | 3.0~3.6V | 100nF + 电池 |
| 内部核心 | Vcore（内部） | 内部稳压器 | 1.2~1.8V | 无需外部供电 |

### 2.2 VDD 去耦电容设计

每个 VDD 引脚必须就近放置去耦电容：

```
去耦规则:
  每个 VDD 引脚: 100nF (X7R MLCC)
  全芯片共用:    4.7uF (X5R MLCC) 作为储能电容
  
布局原则:
  100nF 电容距 VDD 引脚 < 5mm
  4.7uF 电容距芯片 < 20mm
  电容 GND 端直接连接到完整 GND 平面
```

STM32F103C8T6 去耦电容示例（LQFP-48 封装，3 对 VDD/VSS）：

```
VDD1 ──┤├── 100nF ── GND
VDD2 ──┤├── 100nF ── GND
VDD3 ──┤├── 100nF ── GND
全局   ──┤├── 4.7uF ── GND
```

### 2.3 VDDA 模拟电源设计

VDDA 为 ADC/DAC 等模拟外设供电，需要低噪声隔离：

```
3.3V ──┬── 铁氧体磁珠(BLM18PG121) ──┬── VDDA
       │                            │
      4.7uF                       1uF
       │                            │
      GND            100nF ────────┤
                     │             │
                    GND           VSSA
                                  (单点连接到 GND)
```

铁氧体磁珠选型：
- 阻抗：100~1000 ohm @ 100MHz
- 直流电阻：< 0.1 ohm
- 额定电流：> 200mA
- 推荐型号：BLM18PG121SN1 (120 ohm @ 100MHz)

### 2.4 VBAT 电池供电

VBAT 为 RTC 和备份寄存器提供备用电源：

```
方案1: 纽扣电池供电
  CR2032(3V) ──┬── D1(肖特基) ── VBAT
                │
               100nF
                │
               GND

方案2: 超级电容供电
  3.3V ──┬── D1 ──┬── VBAT
         │         │
        D2      1F/3.3V
         │     超级电容
        VBAT      │
                 GND

方案3: 无电池（VDD 供电）
  3.3V ──┬── 0 ohm 电阻 ── VBAT
         │
        100nF
         │
        GND
```

## 3. 时钟系统设计

### 3.1 时钟源分类

| 时钟源 | 名称 | 频率 | 精度 | 用途 | 启动时间 |
|--------|------|------|------|------|---------|
| HSE | 外部高速晶振 | 4~26MHz | +/-10~20ppm | 主时钟 | < 2ms |
| HSI | 内部高速 RC | 8/16MHz | +/-1~5% | 备用/HSE 故障 | < 2us |
| LSE | 外部低速晶振 | 32.768kHz | +/-20ppm | RTC | < 1s |
| LSI | 内部低速 RC | 32~40kHz | +/-10% | IWDG/RTC 备用 | < 0.1ms |

### 3.2 HSE 高速外部晶振

STM32 主时钟使用外部无源晶振（HSE），典型频率 8MHz（F1系列）或 25MHz（F4系列）。

```
        Y1 (8MHz)
    ┌─────[]()──────┐
    │    Crystal    │
OSC_IN ──┤        ├── OSC_OUT
    │   22pF    │   22pF
    │     │     │     │
    │    GND   │    GND
    │           │
   └── R(1M) ──┘ (反馈电阻，部分 MCU 内置)
```

晶振选型：
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 频率 | 8MHz (F1) / 25MHz (F4) | 匹配 MCU 要求 |
| 负载电容 CL | 9pF~12pF | 匹配晶振规格 |
| 等效串联电阻 ESR | < 100 ohm | 确保起振 |
| 精度 | +/-10ppm (通用), +/-20ppm (成本优先) | |
| 封装 | 3215 / 5032 | 贴片晶振 |

负载电容计算：

```
CL = (C1 * C2) / (C1 + C2) + Cstray
```

其中 Cstray 为 PCB 杂散电容（典型 3~5pF）。

示例（CL=10pF, Cstray=3pF）：

```
C1 = C2 = 2 * (CL - Cstray) = 2 * (10 - 3) = 14pF -> 取标准值 15pF
```

### 3.3 LSE 低速晶振（RTC）

```
        Y2 (32.768kHz)
    ┌─────[]()──────┐
    │  Watch Crystal│
OSC32_IN ─┤       ├── OSC32_OUT
    │   10pF    │   10pF
    │     │     │     │
   GND       GND
```

选型：
- 频率：32.768kHz
- 负载电容：12.5pF（常用）
- ESR：< 50k ohm
- 封装：3215 贴片（SMD）或 DIP 圆柱

负载电容计算（CL=12.5pF, Cstray=2.5pF）：

```
C1 = C2 = 2 * (12.5 - 2.5) = 20pF -> 取标准值 20pF 或 22pF
```

### 3.4 时钟布局注意事项

- 晶振尽量靠近 MCU 的 OSC 引脚（< 5mm）
- 晶振走线两侧铺 GND 保护环
- 晶振下方禁止走其他信号线
- 负载电容 GND 端直接连接到 GND 平面
- 晶振区域禁止过孔穿线

## 4. 复位电路设计

### 4.1 复位电路原理

STM32 的 NRST 引脚为低电平有效复位，需要上电延时复位和手动复位功能。

### 4.2 标准复位电路

```
3.3V                    NRST
  │                       │
  R(10k)              ┌──┤
  │                  │  │
  ├──┬──────────┐    │  │ (复位按钮)
  │  │       C3  │   │  │
  │ 100nF   100nF │  └──┘
  │  │        │   │
  GND        NRST─┘
              │
             GND
```

元件参数：
- R1 = 10k ohm 上拉电阻（MCU 内部已有弱上拉，外部 10k 增强驱动）
- C1 = 100nF 延时电容（上电时产生约 1ms 复位脉冲）
- C2 = 100nF 滤波电容（滤除噪声毛刺）
- 复位按钮：6mm 轻触开关

### 4.3 复位时序计算

上电复位延时时间：

```
t_reset = R1 * C1 * ln(Vdd / (Vdd - V_IL_NRST))
```

示例（R1=10k, C1=100nF, Vdd=3.3V, V_IL=0.8V）：

```
t_reset = 10k * 100nF * ln(3.3 / (3.3 - 0.8)) = 1ms * ln(1.32) = 0.28ms
```

若需要更长的复位延时（确保电源稳定），增大 C1 至 1uF：

```
t_reset = 10k * 1uF * 0.28 = 2.8ms
```

### 4.4 复位电路设计要点

1. NRST 走线尽量短，远离干扰源
2. 必须有滤波电容（100nF）防止误触发
3. 外部看门狗（如 MAX823）的 RST 输出连接到 NRST
4. 调试器（ST-Link）的 NRST 信号通过串联电阻（100 ohm）连接

## 5. 启动模式配置

### 5.1 BOOT 配置引脚

STM32 通过 BOOT0 和 BOOT1 引脚选择启动模式：

| BOOT0 | BOOT1 | 启动区域 | 典型用途 |
|-------|-------|---------|---------|
| 0 | X | Flash 用户程序 | 正常运行 |
| 1 | 0 | 系统存储器 | ISP 串口下载 |
| 1 | 1 | 内置 SRAM | 调试 |

### 5.2 BOOT 电路设计

```
3.3V                          3.3V
  │                             │
 10k                           10k
  │                             │
  ├──── BOOT0    BOOT1 ─────────┤
  │                             │
 0 ohm                        0 ohm
 (默认拉低)                   (默认拉低)
  │                             │
 GND                           GND

或使用排针/拨码开关:

3.3V ──┬──[R10k]── BOOT0
       │
    ┌──┴──┐
    │ JP1 │ (跳线)
    └──┬──┘
       │
      GND
```

设计要点：
- BOOT0 默认下拉到 GND（正常运行 Flash 程序）
- BOOT0 通过跳线/拨码开关可切换到 3.3V（进入 ISP 模式）
- BOOT1 在正常使用中固定拉低（不需要切换）
- BOOT 引脚旁加 100nF 滤波电容防误触发

## 6. 调试接口设计

### 6.1 SWD 调试接口

SWD（Serial Wire Debug）是 ARM 推荐的调试接口，仅需 2 根信号线：

| 信号 | 名称 | 方向 | 功能 |
|------|------|------|------|
| SWDIO | 串行数据 | 双向 | 调试数据传输 |
| SWCLK | 串行时钟 | 输入 | 调试时钟 |
| SWO | 串行线观测 | 输出 | ITM 跟踪（可选） |
| NRST | 复位 | 输入 | 复位目标 MCU |
| GND | 地 | — | 参考地 |
| VDD | 电源 | 输入 | 目标供电（可选） |

### 6.2 SWD 接口电路

标准 2.54mm 排针 SWD 接口（6 引脚）：

```
┌─────────────┐
│ 1  VDD  │ ─── 3.3V
│ 2  SWDIO│ ─── MCU PA13
│ 3  GND  │ ─── GND
│ 4  SWCLK│ ─── MCU PA14
│ 5  GND  │ ─── GND
│ 6  NRST │ ─── MCU NRST
└─────────────┘
```

SWDIO 和 SWCLK 信号处理：

```
MCU PA13(SWDIO) ──┬── 排针 SWDIO
                   │
                  100 ohm (串联电阻，防 ESD/干扰)
                   
MCU PA14(SWCLK) ──┬── 排针 SWCLK
                   │
                  100 ohm (串联电阻)
                  10k    (下拉电阻，确保无调试器时稳定)
```

### 6.3 JTAG 接口（可选）

20 引脚 JTAG 接口引脚定义：

```
┌──────────────────────────────────────────┐
│ 1  VDD    2  VDD                        │
│ 3  TRST   4  GND                        │
│ 5  TDI    6  GND                        │
│ 7  TMS    8  GND                        │
│ 9  TCK    10 GND                        │
│ 11 TDO    12 GND                        │
│ 13 NRST   14 GND                        │
│ 15 N/U    16 GND                        │
│ 17 N/U    18 GND                        │
│ 19 VDD    20 GND                        │
└──────────────────────────────────────────┘
```

JTAG 信号连接（STM32F1）：
- TMS → PA13（与 SWDIO 复用）
- TCK → PA14（与 SWCLK 复用）
- TDI → PA15
- TDO → PB3
- TRST → PB4

### 6.4 调试接口设计要点

1. 优先使用 SWD（节省 IO 资源，仅需 2 根线 + 复位 + 电源）
2. SWDIO/SWCLK 串联 100 ohm 电阻保护
3. NRST 串联 100 ohm 电阻隔离调试器与复位电路
4. 调试排针靠近 PCB 边缘，方便连接
5. 调试接口附近预留足够操作空间

## 7. 未使用 IO 处理

### 7.1 IO 配置原则

| IO 状态 | 配置 | 处理方式 |
|---------|------|---------|
| 输入悬空 | 下拉输入 | 内部下拉 + 不外接 |
| 输出用 | 推挽输出 | 初始化为已知状态 |
| 模拟用 | 模拟输入 | 不外接数字电路 |
| 调试用 | AF 复用 | SWD/JTAG 引脚不随意使用 |

### 7.2 防止浮空

未使用的 GPIO 引脚必须配置为非浮空状态，否则可能导致漏电流增大或内部振荡：

```
方案1: 配置为模拟输入（最低功耗）
方案2: 配置为推挽输出低电平
方案3: 配置为输入 + 内部上拉/下拉
方案4: 外部 10k 下拉电阻（最可靠）
```

## 8. PCB 布局指南

### 8.1 电源布局

1. 去耦电容紧贴 VDD 引脚（< 5mm）
2. 4.7uF 储能电容放在芯片附近
3. VDDA 走线通过铁氧体磁珠隔离
4. GND 引脚直接连接到完整 GND 平面

### 8.2 晶振布局

```
┌──────────────────────┐
│    ┌── OSC_IN        │
│ Y1 │                 │
│    └── OSC_OUT        │
│  C1    C2            │
│  │     │             │
│  GND   GND           │
│                      │
│ GND 保护环 ████████████ │
└──────────────────────┘
```

- 晶振距 MCU < 5mm
- 负载电容紧贴晶振
- 晶振周围铺 GND 保护环
- 晶振下方（所有层）禁止走线

### 8.3 复位布局

- NRST 走线短而直
- 复位按钮靠近 PCB 边缘
- NRST 滤波电容紧贴 NRST 引脚

### 8.4 调试接口布局

- SWD 排针靠近 PCB 边缘
- SWDIO/SWCLK 走线避免与高速信号并行走线
- 调试接口 GND 连接到 GND 平面

## 9. 常见设计陷阱与解决方案

### 9.1 晶振不起振

**原因**：负载电容不匹配、PCB 杂散电容大、晶振质量差

**解决**：
- 重新计算负载电容，考虑 PCB 杂散电容
- 检查晶振 ESR 是否满足 MCU 驱动能力
- 晶振下方禁止走线和过孔
- 更换晶振品牌验证

### 9.2 复位不稳定

**原因**：NRST 引脚噪声、复位电容不足、复位按钮抖动

**解决**：
- NRST 引脚加 100nF 滤波电容
- NRST 走线远离开关电源和晶振
- 复位按钮并联 100nF 消抖电容

### 9.3 ADC 精度差

**原因**：VDDA 噪声大、参考电压不稳、GND 噪声

**解决**：
- VDDA 通过铁氧体磁珠 + 电容滤波
- VSSA 单点连接到 GND 平面
- ADC 输入走线远离数字信号
- 使用内部参考通道校准

### 9.4 SWD 无法连接

**原因**：SWDIO/SWCLK 被复用为其他功能、IO 被锁死

**解决**：
- 确认 BOOT0=1（从系统存储器启动 ISP 模式）后连接
- 在代码中不要在初始化时禁用 SWD 引脚
- SWDIO/SWCLK 串联电阻不要过大（< 470 ohm）

## 10. 设计检查清单

| 检查项 | 要求 | 通过标准 |
|--------|------|----------|
| VDD 去耦 | 每个 VDD 引脚有 100nF | 满足 |
| VDD 储能电容 | 4.7uF 全局储能 | 满足 |
| VDDA 滤波 | 铁氧体 + 1uF + 100nF | 满足 |

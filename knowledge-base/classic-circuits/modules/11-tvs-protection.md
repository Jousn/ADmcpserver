# TVS 瞬态电压抑制电路设计知识库

> 适用范围：TVS 瞬态电压抑制二极管电路设计（ESD/浪涌保护）
> 目标受众：AI 设计辅助 Skill，用于 TVS 保护电路设计咨询与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

TVS（Transient Voltage Suppressor）瞬态电压抑制二极管是电子设备中最重要的保护器件之一。当电路遭受静电放电（ESD）、雷击浪涌（Surge）或电源瞬变时，TVS 能在纳秒级时间内将电压钳位到安全水平，保护下游器件。本模块覆盖 TVS 选型、电路设计和 PCB 布局规范。

### 1.1 瞬态威胁分类

| 威胁类型 | 来源 | 峰值电压 | 峰值电流 | 持续时间 | 标准 |
|---------|------|---------|---------|---------|------|
| ESD (静电) | 人体接触 | +/-15kV | 30A | < 1us | IEC 61000-4-2 |
| EFT (电快速瞬变) | 继电器/接触器 | +/-4kV | 数十 A | ns 级脉冲群 | IEC 61000-4-4 |
| Surge (浪涌) | 雷击/电源切换 | +/-4kV | 数百 A | us~ms 级 | IEC 61000-4-5 |
| 过压 | 电源异常 | 1.5~2x Vnom | — | ms~s 级 | — |

### 1.2 保护器件对比

| 器件类型 | 响应速度 | 钳位精度 | 功率能力 | 电容 | 成本 | 适用 |
|---------|---------|---------|---------|------|------|------|
| TVS 二极管 | 极快 (ps~ns) | 好 | 中 | 低~中 | 中 | 通用 ESD/浪涌 |
| 压敏电阻 (MOV) | 慢 (ns~us) | 差 | 高 | 高 | 低 | 电源浪涌 |
| 气体放电管 (GDT) | 最慢 (us) | 差 | 最高 | 极低 | 中 | 大能量浪涌 |
| TVS 阵列 | 极快 | 好 | 中 | 极低 | 中 | 多线 ESD |
| 聚合物 PTC | 慢 (ms) | 无钳位 | — | 极低 | 低 | 过流保护 |
| ESD 抑制器 (聚合物) | 极快 (ns) | 差 | 低 | 极低 | 低 | 高速 ESD |

## 2. TVS 关键参数

### 2.1 参数定义

| 参数 | 符号 | 说明 |
|------|------|------|
| 反向工作电压 | Vwm (VRWM) | TVS 正常工作时的最大反向电压（不导通） |
| 击穿电压 | Vbr | TVS 开始导通的电压（测试电流 1mA） |
| 钳位电压 | Vc | 通过额定峰值电流时的最大钳位电压 |
| 峰值脉冲功率 | Ppp | 8/20us 或 10/1000us 波形下的最大耗散功率 |
| 峰值脉冲电流 | Ipp | 最大浪涌电流 |
| 结电容 | Cj | TVS 的寄生电容（影响高速信号） |
| 漏电流 | Ir | Vwm 下的反向漏电流 |

### 2.2 参数关系

```
Vwm < Vbr < Vc

典型关系:
  Vbr = 1.1~1.2 * Vwm
  Vc = 1.3~1.6 * Vwm (钳位比 = Vc/Vwm)

示例 (SMAJ5.0A):
  Vwm = 5.0V
  Vbr = 6.4V (1mA 测试)
  Vc = 9.2V (@ Ipp=8.1A)
  Ppp = 400W
  Ipp = 8.1A
```

### 2.3 单向 vs 双向

```
单向 TVS (Unidirectional):
  正向: 二极管正向导通 (~0.7V)
  反向: 雪崩击穿 (Vbr)
  
  符号: ──├|── 或 ──├<──
  适用: 直流电源、单向信号

双向 TVS (Bidirectional):
  正向和反向均雪崩击出
  
  符号: ──├├── 或 ──├><──
  适用: 交流信号、差分信号、RS485/RS232

命名区分:
  SMAJ5.0A -> 单向 (A 后缀)
  SMAJ5.0CA -> 双向 (CA 后缀)
```

## 3. TVS 选型方法

### 3.1 选型步骤

```
Step 1: 确定工作电压 Vwm
  Vwm >= 被保护电路的最大正常工作电压 * 1.2

Step 2: 确定钳位电压 Vc
  Vc < 被保护器件的最大耐受电压 * 0.8

Step 3: 确定峰值功率 Ppp
  Ppp >= Vsurge * Isurge (浪涌电压 * 浪涌电流)
  或按标准等级: 400W / 600W / 1500W / 5000W

Step 4: 确定电容要求
  高速信号 (< 480Mbps): Cj < 5pF
  低速信号: Cj < 100pF
  电源线: Cj 不限

Step 5: 确定封装
  低功率: SMA/SMB
  中功率: SMC/SMCJ
  大功率: DPAK/D2PAK
```

### 3.2 选型计算示例

设计目标：保护 5V 电源线，IEC 61000-4-2 Level 4 (8kV 接触放电)

```
Step 1: Vwm >= 5V * 1.2 = 6V -> 选 Vwm = 5V 的 TVS (留余量)
Step 2: 下游器件耐压 7V -> Vc < 7 * 0.8 = 5.6V
         (但 SMAJ5.0A 的 Vc=9.2V > 5.6V, 不满足!)
         -> 改用更低 Vc 的 TVS 或增加保护级数
         -> 或选 Vwm=5V, Vc=7V 的精密 TVS (如 ESD9B5.0)

Step 3: IEC 61000-4-2 Level 4 (8kV 接触)
         峰值电流约 30A
         Ppp = Vc * Ipp = 9.2 * 8.1 = 74.5W (SMAJ 400W 足够)

Step 4: 电源线不需低电容
Step 5: 选 SMA 封装 (400W)

结论: SMAJ5.0A (单向, 5V, 400W, SMA)
```

## 5. 保护电路设计

### 5.1 电源线保护

```
Vin(5V) ──┬── PTC(500mA) ──┬── TVS(SMAJ5.0A) ──┬── 系统 VCC
            │                │                    │
           Fuse            TVS1               4.7uF
            │                │                    │
           GND              GND                  GND

两级保护:
  PTC: 过流保护（缓慢响应，限制持续电流）
  TVS: 过压保护（快速响应，钳位瞬态）
  4.7uF: 吸收残余能量

能量协调:
  PTC 限流 -> TVS 钳位 -> 电容吸收
  PTC 必须在 TVS 钳位时间内不熔断
```

### 5.2 信号线 ESD 保护

```
外部信号 ──┬── TVS ──┬── 内部电路
            │         │
         ESD保护   串联电阻(可选, 22~100 ohm)
            │         │
           GND       内部 IC

TVS 选型:
  信号电压 <= 3.3V: Vwm=3.3V (如 ESDA3.3)
  信号电压 <= 5V:   Vwm=5V (如 USBLC6-2SC6)
  高速信号: Cj < 5pF
  低速信号: Cj < 50pF
```

### 5.3 差分信号保护

```
RS485 差分对保护:

  A ──┬── TVS1(SMAJ6.5CA, 对地) ──┬── 内部 A
       │                            │
      TVS3(对A-B差分)               │
       │                            │
  B ──┼── TVS2(SMAJ6.5CA, 对地) ──┬── 内部 B
       │                            │
      GND                         内部

差分 TVS 选型:
  Vwm >= 最大共模电压 (RS485: -7~+12V -> Vwm >= 12V)
  双向 TVS (信号可能正负)
  常用: SMAJ12CA, SMBJ12CA
```

### 5.4 多级保护设计

大功率浪涌保护需要多级设计：

```
外部输入 ──┬── GDT ──┬── MOV ──┬── TVS ──┬── 内部电路
            │         │         │         │
           GND       GND       GND      4.7uF

第一级 GDT (气体放电管):
  泄放大部分浪涌能量 (kA 级)
  响应慢 (us 级)
  钳位电压高 (几百 V)

第二级 MOV (压敏电阻):
  吸收中等能量 (百 A 级)
  响应中等 (ns~us)
  钳位电压中等 (几十~百 V)

第三级 TVS:
  精确钳位到安全电压
  响应快 (ps~ns)
  吸收残余能量 (A 级)

级间退耦:
  R(1~10 ohm) 或 L(电感) 串联在各级之间
  确保前级先导通
```

## 6. IEC 61000-4-2 ESD 标准

### 6.1 测试等级

| 等级 | 接触放电电压 | 空气放电电压 | 适用环境 |
|------|------------|------------|---------|
| 1 | 2kV | 2kV | 受控环境 |
| 2 | 4kV | 4kV | 办公环境 |
| 3 | 6kV | 8kV | 工业环境 |
| 4 | 8kV | 15kV | 恶劣环境 |

### 6.2 ESD 电流波形

```
IEC 61000-4-2 8kV 接触放电电流波形:

  峰值电流: ~30A
  上升时间: < 1ns
  30ns 电流: ~16A
  60ns 电流: ~8A

能量计算:
  E ≈ Vc * I * t = 9V * 30A * 60ns = 16.2mJ
  SMAJ5.0A (400W, 1us) -> E_max = 400 * 1us = 0.4mJ
  
  结论: 单次 8kV ESD 能量在 TVS 承受范围内
  但需验证 TVS 在多次冲击后的退化
```

## 7. PCB 布局指南

### 7.1 放置位置

```
核心原则: TVS 尽可能靠近外部接口/连接器

┌─────────────────────────────────────┐
│  连接器                              │
│  ┌──┐                                │
│  │  │────── TVS ──── 串联电阻 ──── IC │
│  │  │        <5mm     <20mm         │
│  └──┘                                │
│  GND                                  │
│  │                                    │
│  GND 平面 ─────────────────────────────│
└─────────────────────────────────────┘

TVS 到连接器距离: < 5mm (最佳), < 10mm (可接受)
TVS 到被保护 IC: > TVS 到连接器的距离 (确保 TVS 先动作)
```

### 7.2 GND 路径

```
TVS 的 GND 引脚直接连接到完整 GND 平面:

  信号线 ──┬── TVS
            │     │
           GND   GND 引脚
                  │
            █████GND 平面█████

禁止:
  - TVS GND 通过长走线连接到 GND
  - TVS GND 通过过孔穿过多个层
  - TVS GND 连接到分割 GND 区域
```

### 7.3 电源线 TVS 布局

```
Vin ──┬──────────────────────┬── Vout
      │                      │
    TVS                    旁路电容
      │                      │
     GND                    GND

TVS 在旁路电容之前（靠近输入端）
旁路电容在 TVS 之后（靠近负载）
两者之间走线尽量短
```

### 7.4 多线 TVS 布局

```
多线 ESD 保护 IC (如 USBLC6-2SC6):

┌────────────────┐
│  USB 连接器     │
│  D+ ───────┬────┤ USBLC6-2SC6 ┌── D+ (IC)
│  D- ───────┤    │              ├── D- (IC)
│  VBUS ─────┤    │              ├── VBUS
│  GND ──────┤    │              ├── GND
└────────────┘    └──────────────┘

ESD IC 紧贴连接器 (< 5mm)
各信号线直接进入 ESD IC (最短路径)
ESD IC GND 直接连接 GND 平面
```

## 8. 常见设计陷阱与解决方案

### 8.1 TVS 钳位电压过高

**原因**：TVS 选型 Vc 大于下游器件耐压

**解决**：
- 重新选型：选择更低 Vc 的精密 TVS
- 使用多级保护：前级大功率 TVS + 后级精密 TVS
- 串联电阻分压降低下游电压

### 8.2 TVS 频繁损坏

**原因**：功率不足、反复浪涌冲击

**解决**：
- 升级封装功率（SMA -> SMB -> SMC）
- 增加前级保护（GDT/MOV 吸收大能量）
- 检查浪涌源是否为持续异常

### 8.3 高速信号完整性下降

**原因**：TVS 结电容过大

**解决**：
- 选择低电容 TVS（Cj < 1pF）
- 使用专用 ESD 保护 IC（如 TPD4E05U6, 0.5pF）
- 仅在必要信号线上放置 TVS

### 8.4 TVS 漏电影响精度

**原因**：高阻抗信号线上 TVS 漏电流引起误差

**解决**：
- 选择低漏电流 TVS（Ir < 1nA）
- 降低信号线阻抗（增加负载电阻）
- 在敏感信号线避免使用 TVS，改用钳位二极管

## 1. 概述

分立晶体管电路是原理图设计中最基础也最容易出错的领域：元件少但每个元件的参数角色差异极大，**同一类元件（如电阻）在不同支路中的典型值相差可达两个数量级**。本模块提供无稳态多谐振荡器（LED 闪烁电路）的完整典型参数表、LED 限流电阻计算表，以及高频错误清单。

### 1.1 无稳态多谐振荡器（LED 闪烁）典型参数表 ⭐

**标准拓扑**：VCC → Rc1 → Q1.C；Q1.E → GND；C1 耦合 Q1.C 至 Q2.B；对称的另一侧同构（交叉耦合）。LED 通常串在集电极电阻支路或经独立限流电阻由集电极驱动。

| 元件 | 电路角色 | 典型值（VCC=5V） | 取值依据 | 常见错误 |
|------|---------|------------------|---------|---------|
| Rc（集电极电阻，R1/R2） | 决定集电极电流 / LED 亮度 / 输出摆幅 | **470Ω ~ 1kΩ** | 需提供 LED 电流（1~20mA）+ 晶体管饱和电流 | ❌ 设为 100k → LED 电流仅 ~30µA，不可见 |
| Rb（基极偏置电阻，R3/R4） | 与定时电容共同决定振荡频率 | **47k ~ 100k** | 需提供足够基极电流使晶体管饱和：Ib ≈ VCC/Rb ≥ Ic/β（×5 余量） | ❌ 设为 470Ω → 基极电流过大、深饱和难翻转 |
| C（定时电容，C1/C2） | 与 Rb 决定充放电周期 | **1µF ~ 100µF**（电解，注意极性） | T = 0.693·Rb·C（单侧半周期） | ❌ 用 100pF → 频率 MHz 级，看起来常亮 |
| Q（晶体管，Q1/Q2） | 开关管 | 8050 / 9013 / 2N3904 | Ic_max > LED 电流 × 2，β > 100 | — |
| R_LED（LED 限流电阻） | 限制 LED 正向电流 | 见 §3 计算表 | (VCC − Vf − Vce_sat) / I_LED | ❌ 遗忘 → LED 过流 |

**振荡频率**：

```
T_half = ln2 × Rb × C ≈ 0.693 × Rb × C     （单侧半周期）
f = 1 / (2 × T_half) = 1 / (1.386 × Rb × C)  （对称电路）

示例：Rb = 100k, C = 10µF
T_half = 0.693 × 100000 × 10e-6 ≈ 0.69 s
f ≈ 0.72 Hz  （周期约 1.4 s，人眼可见闪烁）
```

**设计校验清单**：
- [ ] 饱和条件：VCC / Rb ≥ (VCC / Rc) × 5 / β（基极电流裕量 5 倍）
- [ ] LED 电流：(VCC − Vf − Vce_sat) / (Rc + R_LED) 落在 2~20mA
- [ ] 振荡频率：f = 1/(1.386·Rb·C) 在目标范围（可见闪烁 0.5~5Hz）
- [ ] 定时电容耐压 ≥ VCC，电解电容极性方向正确（正极接基极侧）
- [ ] Rb 上端必须接 VCC（基极直流偏置路径）——**悬空的 Rb = 电路不振荡**

### 1.2 晶体管开关电路（驱动 LED / 继电器）典型参数表

| 元件 | 电路角色 | 典型值（VCC=5V） | 取值依据 |
|------|---------|------------------|---------|
| Rb（基极电阻） | 限制 MCU 引脚输出电流，提供饱和基极电流 | **1k ~ 10k** | (V_IO − Vbe) / Rb ≥ Ic / β × 3 |
| Rc / R_LED（负载电阻） | 负载本身或限流电阻 | 见 §3 | 按负载电流计算 |
| Rpulldown（可选下拉） | 防止输入悬空误导通 | **10k** | 与 Rb 分压后 Vbe < 0.3V |
| Q（晶体管） | 低压侧开关 | 8050 / 2N3904（NPN 低边） | Ic_max > 负载电流 × 2 |
| 继电器应用 | 感性负载 | 续流二极管 1N4148/1N4007 反并联在线圈两端 | 必须，否则关断尖峰损坏晶体管 |

## 2. 无稳态多谐振荡器电路拓扑

```
        VCC                              VCC
         │                                 │
    ┌────┴────┐                      ┌────┴────┐
    │  Rc1    │                      │  Rc2    │      Rc: 470Ω~1k
    │         │                      │         │
    ├─────────●── C1 ──┐   ┌── C2 ──●─────────┤
    │         │         │   │        │         │
   LED1      Q1.C      Q2.B │       LED2     Q2.C
    │        Q1.B ←────┘   └──────→ Q2.E...  │
    │         │                             │
   GND       GND                           GND

    Q1.B ── C2 ── Q2.C   （交叉耦合：C1 接 Q1.C→Q2.B，C2 接 Q2.C→Q1.B）
    Q1.B ── Rb1 ── VCC   （基极偏置：Rb 上端必须接 VCC）
    Q1.E ── GND，Q2.E ── GND
```

**交叉耦合核对规则**（画原理图时逐项检查）：
1. C1 一端接 Q1 集电极，另一端接 Q2 基极
2. C2 一端接 Q2 集电极，另一端接 Q1 基极
3. Rb1 上端接 VCC、下端接 Q1 基极（Rb2 同理）——**这是最常被遗漏的支路**
4. Q1.E、Q2.E 接 GND
5. 每个元件的每个引脚都必须在网络表中有归属（pin-coverage）

## 3. LED 限流电阻计算表

`R_LED = (VCC − Vf − Vce_sat) / I_LED`（Vce_sat ≈ 0.2V，可忽略）

### 3.1 红色 LED（Vf ≈ 2.0V）

| VCC | I_LED = 2mA（指示） | I_LED = 5mA | I_LED = 10mA（常规） | I_LED = 20mA（高亮） |
|-----|------|------|------|------|
| 3.3V | 650Ω → **680Ω** | 260Ω → **270Ω** | 130Ω → **150Ω** | 65Ω → **68Ω** |
| 5V | 1.65k → **1.6k** | 600Ω → **620Ω** | 300Ω → **300Ω** | 150Ω → **150Ω** |
| 12V | 5k → **5.1k** | 2k → **2k** | 1k → **1k** | 500Ω → **510Ω** |

### 3.2 蓝/白/绿 LED（Vf ≈ 3.0~3.2V）

| VCC | I_LED = 2mA | I_LED = 5mA | I_LED = 10mA | I_LED = 20mA |
|-----|------|------|------|------|
| 3.3V | 150Ω → **150Ω** | 60Ω → **62Ω** | 30Ω → **33Ω** | 建议升压驱动 |
| 5V | 1k → **1k** | 400Ω → **390Ω** | 200Ω → **200Ω** | 100Ω → **100Ω** |
| 12V | 4.5k → **4.7k** | 1.8k → **1.8k** | 900Ω → **910Ω** | 450Ω → **470Ω** |

> 表中"→"表示取 E24 标准系列就近值。3.3V 直接驱动蓝光 LED 余量不足，建议用升压或恒流驱动。

### 3.3 多谐振荡器 + LED 组合电流校验

LED 串在集电极支路时：`I_LED ≈ (VCC − Vf − Vce_sat) / (Rc + R_LED)`。
**必须代入 Rc 一起算**——Rc=100k 时即使 R_LED=0，I_LED 也只有 ~30µA（本次实测暴露的典型错误）。

## 4. 高频错误清单（画图与选型审查必查）

| # | 错误模式 | 后果 | 检查方法 |
|---|---------|------|---------|
| E1 | **集电极电阻用了基极电阻的典型值（如 100k）** | LED 电流 µA 级，不可见 | 代入 I=(VCC−Vf)/(Rc+R_LED) 校验 |
| E2 | **基极偏置电阻支路整体漏画**（放了 Rb 却没布线） | 无直流偏置，电容永不充电，不振荡 | pin-coverage：每个引脚必须有网络 |
| E3 | 定时电容两引脚接在同一晶体管上（未交叉耦合） | 电路变成两个独立放大器，不振荡 | 核对 §2 交叉耦合规则 1/2 |
| E4 | 电解电容极性接反 | 上电漏电流大、鼓包 | 正极接基极侧（正电压侧） |
| E5 | LED 阴阳极接反 | 不亮，且反向击穿风险 | LED1 符号 A(阳极)/K(阴极)：K 接低电位 |
| E6 | 晶体管 C/E 接反 | β 骤降（<10），不饱和不开关 | NPN 符号箭头在 E 极，E 接 GND（低边） |
| E7 | 感性负载（继电器/蜂鸣器）无续流二极管 | 关断尖峰击穿晶体管 | 1N4148 反并联在线圈两端 |
| E8 | β 按标称最大值计算无余量 | 低温下不完全饱和，LED 闪烁暗淡 | 基极电流按 β_min × 3~5 裕量设计 |

## 5. PCB 布局要点

- 定时电容 C1/C2 尽量靠近对应晶体管基极，缩短高阻抗节点走线（易拾取干扰）
- LED 电流回路（VCC→Rc→LED→Q→GND）面积最小化
- 双侧对称布局：Q1/C1/Rb1 与 Q2/C2/Rb2 镜像放置，减少参数失配引起的占空比偏差
- 大电流 LED（>50mA）改用 MOSFET（AO3400 等）驱动，栅极电阻 100Ω + 下拉 10k

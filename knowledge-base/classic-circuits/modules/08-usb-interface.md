# USB 接口电路设计知识库

> 适用范围：USB2.0/USB3.0 接口电路设计（ESD 保护、电源、差分信号）
> 目标受众：AI 设计辅助 Skill，用于 USB 接口电路设计咨询与审查
> 版本：v1.0 | 更新日期：2026-08

## 1. 概述

USB（Universal Serial Bus）是消费电子和工业设备中最常用的通信接口之一。USB 接口设计涉及差分信号完整性、ESD 防护、电源管理和协议兼容性等多个方面。本模块覆盖 USB2.0 和 USB3.0 的硬件电路设计要点。

### 1.1 USB 版本对比

| 版本 | 速率 | 差分对 | 供电 | 典型应用 |
|------|------|--------|------|---------|
| USB 1.1 | 1.5/12 Mbps | D+/D- | 5V/500mA | 低速外设 |
| USB 2.0 | 480 Mbps | D+/D- | 5V/500mA | 通用外设 |
| USB 3.0 (3.2 Gen1) | 5 Gbps | D+/D- + TX+/TX- + RX+/RX- | 5V/900mA | 高速外设 |
| USB 3.1 (3.2 Gen2) | 10 Gbps | 同上 | 5V/900mA~3A | 高速存储 |
| USB Type-C | 正反插 | 同上 + CC1/CC2 | 5V/3A~20V/5A | 通用接口 |

### 1.2 USB 连接器引脚定义

USB2.0 Type-A 连接器：

| 引脚 | 信号 | 说明 |
|------|------|------|
| 1 | VBUS | +5V 电源 |
| 2 | D- | 差分负信号 |
| 3 | D+ | 差分正信号 |
| 4 | GND | 地 |

USB3.0 Type-A 连接器（兼容 USB2.0）：

| 引脚 | 信号 | 说明 |
|------|------|------|
| 1 | VBUS | +5V 电源 |
| 2 | D- | USB2.0 差分负 |
| 3 | D+ | USB2.0 差分正 |
| 4 | GND | 地 |
| 5 | SSRX- | 超速接收负 |
| 6 | SSRX+ | 超速接收正 |
| 7 | GND_DRAIN | 信号地 |
| 8 | SSTX- | 超速发送负 |
| 9 | SSTX+ | 超速发送正 |

## 2. USB2.0 差分信号设计

### 2.1 差分阻抗要求

```
USB2.0 差分对阻抗要求:
  高速(480Mbps): 90 ohm +/- 15% (差分阻抗)
  全速(12Mbps):  90 ohm +/- 30%
  低速(1.5Mbps): 90 ohm +/- 30%

单端阻抗: 45 ohm +/- 15%
```

### 2.2 差分对走线规则

```
线宽/线距计算 (以 FR4 4 层板为例):

层叠: TOP(信号) / GND / VCC / BOTTOM
  线宽 W = 0.18mm (7mil)
  线距 S = 0.12mm (5mil)
  介质厚度 H = 0.2mm (TOP 到 GND)
  -> 差分阻抗 Zdiff ≈ 90 ohm

计算公式(微带线差分阻抗):
  Zdiff = 2 * Z0 * (1 - 0.48 * exp(-0.96 * S/H))
  Z0 = 87 / sqrt(eps_r + 1.41) * ln(5.98 * H / (0.8 * W + T))
```

### 2.3 等长控制

```
等长要求:
  D+ 和 D- 差分对长度差 < 5mil (0.13mm)
  
  补偿方法:
  - 靠近连接器处添加蛇形走线补偿长度差
  - 补偿位置在差分对末端（靠近接收端）
```

### 2.4 走线层数

```
推荐: D+/D- 走顶层或底层，下方有完整 GND 参考平面
禁止: D+/D- 走内层信号层（除非有完整参考平面）
禁止: D+/D- 跨越平面分割区
```

## 3. ESD 保护设计

### 3.1 ESD 威胁分析

USB 连接器是外部接口，直接暴露在静电环境中。需满足 IEC 61000-4-2 标准：

| 等级 | 接触放电 | 空气放电 | 适用场景 |
|------|---------|---------|---------|
| Level 1 | 2kV | 2kV | 受控环境 |
| Level 2 | 4kV | 4kV | 办公环境 |
| Level 3 | 6kV | 8kV | 工业环境 |
| Level 4 | 8kV | 15kV | 恶劣环境 |

### 3.2 ESD 保护器件选型

| 器件型号 | 通道数 | 工作电压 | 钳位电压 | 电容 | 封装 | 适用 |
|---------|--------|---------|---------|------|------|------|
| USBLC6-2SC6 | 2 | 5V | 17V | 5pF | SOT-23-6 | USB2.0 高速 |
| USBLC6-4SC6 | 4 | 5V | 17V | 5pF | SOT-23-6L | USB2.0 双通道 |
| ESDA6V1-5P6 | 5 | 5V | 12V | 9pF | SOT-23-6 | USB+VBUS |
| SRV05-4 | 4 | 5V | 6.5V | 5pF | SOT-23-6 | 低电容 USB |
| USBLC6-2P6 | 2 | 5V | 17V | 2.5pF | DFN | 高速 USB3.0 |
| TPD2E2U7 | 2 | 3.6V | 6.5V | 1.5pF | DSBGA | 超低电容 |

### 3.3 ESD 保护电路

```
USB 连接器               ESD 保护器件           MCU/PHY
                  
VBUS ──────┬────────────┬───────────────── VBUS
            │            │
           Fuse      TPD2E2U7 (TVS)
            │        ┌───┴───┐
D+ ─────────┼────────┤  D+   │────── D+
            │        │       │
D- ─────────┼────────┤  D-   │────── D-
            │        └───────┘
GND ────────┴────────────┴────────────── GND

ESD 保护器件放置: 紧靠 USB 连接器 (< 5mm)
```

### 3.4 VBUS 保护

```
VBUS(5V) ──┬── PTC(500mA) ──┬── TVS(5V) ──┬── 系统 VBUS
            │                │             │
           Fuse          SMAJ5.0A       4.7uF
            │                │             │
           GND              GND           GND

PTC 选型: hold current >= 200mA, trip current <= 500mA
TVS 选型: Vwm=5V, Vc < 12V (保护下游器件)
```

## 4. USB PHY 晶振设计

### 5.1 USB PHY 晶振需求

USB2.0 PHY 需要精确的参考时钟，通常使用外部晶振：

```
参考时钟要求:
  频率: 12MHz 或 24MHz 或 48MHz (取决于 PHY)
  精度: +/- 100ppm (USB2.0 规范)
  抖动: < 1ps rms (高速模式)
  
常用晶振:
  12MHz: 用于大多数 USB PHY
  24MHz: 用于部分集成 PHY 的 MCU
  48MHz: 用于独立 USB PHY
```

### 5.2 晶振电路

```
         Y1 (12MHz)
    ┌─────[]()──────┐
    │    Crystal    │
XTAL_IN ─┤        ├── XTAL_OUT
    │   22pF    │   22pF
    │     │     │     │
    │    GND   │    GND
```

## 5. VBUS 电源管理

### 5.1 USB 主机端供电

USB 主机需要向下游设备提供 5V 电源，电流能力取决于 USB 版本：

| USB 版本 | 最大电流 | 功率 |
|---------|---------|------|
| USB 2.0 | 500mA (1 单位负载=100mA) | 2.5W |
| USB 3.0 | 900mA | 4.5W |
| USB BC 1.2 | 1.5A | 7.5W |
| USB Type-C (5V/3A) | 3A | 15W |
| USB PD (20V/5A) | 5A | 100W |

### 5.2 电源开关设计

```
5V 电源输入 ──┬── EN ────┐ (控制信号)
              │          │
           电源开关 IC   (如 AP2156, TPS2051)
              │          │
VBUS 输出 ────┴──────────┘
              │
         电流检测
              │
           USB 连接器 VBUS
```

推荐电源开关 IC：

| 型号 | 电压 | 电流 | 限流 | 标志 | 封装 |
|------|------|------|------|------|------|
| AP2156 | 2.7~5.5V | 500mA | 1A | 有 | SOT-23-5 |
| TPS2051 | 2.7~5.5V | 500mA | 可调 | 有 | SOIC-8 |
| TPS2065 | 2.7~5.5V | 1A | 1.5A | 有 | SOIC-8 |
| LM3526 | 3.0~5.5V | 500mA*2 | 可调 | 有 | SOIC-8 |
| FP6717 | 2.5~5.5V | 1.5A | 2A | 有 | SOT-23-5 |

### 5.3 USB 设备端 VBUS 检测

USB 设备需要检测 VBUS 是否存在，以实现连接/断开管理：

```
VBUS(5V) ──┬── R1(100k) ──┬── VBUS_DETECT (MCU GPIO)
            │              │
           R2(47k)      C1(1nF)
            │              │
           GND            GND

分压后电压: 5 * 47k/(100k+47k) = 1.6V (3.3V MCU 可检测)
```

## 6. USB Type-C 设计

### 6.1 Type-C 引脚定义

| 引脚 | 信号 | 说明 |
|------|------|------|
| A1, B12 | GND | 地 |
| A4, B9 | VBUS | 电源（默认 5V，PD 可达 20V） |
| A5, B5 | CC1/CC2 | 配置通道 |
| A6, B6 | D+ | USB2.0 差分正 |
| A7, B7 | D- | USB2.0 差分负 |
| A2, A3 | TX1+/TX1- | USB3.0 超速发送 |
| A10, A11 | RX1+/RX1- | USB3.0 超速接收 |
| B2, B3 | TX2+/TX2- | USB3.0 超速发送（正反插冗余） |
| B10, B11 | RX2+/RX2- | USB3.0 超速接收 |

### 6.2 CC 通道配置

```
下拉模式（UFP/设备端）:
  CC1 ── R(5.1k) ── GND
  CC2 ── R(5.1k) ── GND

上拉模式（DFP/主机端）:
  VBUS ──┬── R(56k) ── CC1
         │
         └── R(56k) ── CC2
```

CC 电阻值表：

| 角色 | CC 电阻 | 电流能力 |
|------|---------|---------|
| UFP (设备) | 5.1k 下拉 | 默认 |
| DFP (主机) | 56k 上拉 | 500mA (USB2.0) |
| DFP (主机) | 22k 上拉 | 1.5A |
| DFP (主机) | 10k 上拉 | 3A |

### 6.3 Type-C ESD 保护

```
Type-C 连接器 → ESD 阵列 → PHY/MCU

推荐 ESD 器件:
  USB3.0 高速通道: TPD4E05U6 (4通道, 0.5pF)
  D+/D-: USBLC6-2SC6 (2通道, 5pF)
  CC1/CC2: TPD2E2U7 (2通道, 1.5pF)
  VBUS: SMAJ5.0A (TVS)
```

## 7. 共模电感设计

### 7.1 共模电感作用

USB 差分信号线上常放置共模电感（CMC）抑制共模噪声：

```
D+ ──┬──╔═╗──┬── D+
     │  ║ ║  │
     └──║CMC║──┘ (共模扼流圈)
        ║ ║
D- ──┬──╚═╝──┬── D-
     │       │
     └───────┘
```

### 7.2 共模电感选型

| 参数 | 要求 | 典型值 |
|------|------|--------|
| 共模阻抗 | 90~500 ohm @ 100MHz | 90 ohm (USB2.0) |
| 差模阻抗 | < 1 ohm @ 100MHz | 0.5 ohm |
| 直流电阻 | < 0.5 ohm | 0.1 ohm |
| 额定电流 | > 100mA | 500mA |
| 工作频率 | DC~1GHz | — |

常用型号：
- ACM2520-901-2P (90 ohm, 2520 封装)
- BLM15HD102SN1 (差模, 替代方案)
- TCM45-600-2P (600 ohm, 高抑制)

## 8. PCB 布局指南

### 8.1 USB2.0 差分对布局

```
┌─────────────────────────────────────┐
│  USB 连接器                           │
│  ┌──┐                                │
│  │D+│──┬──[ESD]──┬──[CMC]──┬── D+   │
│  │  │  │          │          │       │
│  │D-│──┴──[ESD]──┴──[CMC]──┴── D-   │
│  └──┘                                │
│        <5mm  │           │           │
│              │           │           │
│          ESD就近     CMC           PHY │
└─────────────────────────────────────┘
```

### 8.2 布线规则汇总

| 规则 | 要求 |
|------|------|
| 差分阻抗 | 90 ohm +/- 15% |
| 单端阻抗 | 45 ohm +/- 15% |
| 等长误差 | < 5mil (0.13mm) |
| 线宽 | 7~9mil (0.18~0.23mm) |
| 线距 | 5~6mil (0.13~0.15mm) |
| 过孔数 | 差分对过孔数相同 |
| 参考平面 | 完整 GND 平面（无分割） |
| ESD 位置 | 距连接器 < 5mm |
| CMC 位置 | ESD 与 PHY 之间 |
| 串扰间距 | > 3x 线宽 |

### 8.3 USB3.0 高速差分对

USB3.0 超速差分对（SSTX, SSRX）要求更严格：

```
差分阻抗: 90 ohm +/- 10%
等长误差: < 3mil
最大长度: < 4 inch (100mm)
AC 耦合电容: 100nF (仅 TX 端, 靠近发送端)
线宽: 7mil, 线距: 5mil (微带线)
参考平面: 完整 GND
```

### 8.4 VBUS 布局

```
VBUS 走线宽: >= 30mil (0.75mm) (满足 500mA 载流)
VBUS 过孔: >= 0.3mm 孔径
VBUS 旁路电容: 4.7uF + 100nF (靠近连接器)
```

## 9. 常见设计陷阱与解决方案

### 9.1 USB 枚举失败

**原因**：差分阻抗不匹配、等长差过大、晶振频率不准

**解决**：
- 检查差分对阻抗（用阻抗计算器或 TDR 测量）
- 确认等长误差 < 5mil
- 检查晶振频率精度 < +/-100ppm
- 确保 D+/D- 下方参考平面完整

### 9.2 ESD 测试失败

**原因**：ESD 器件选型不当、放置位置远、GND 路径差

**解决**：
- 选择低电容 ESD 器件（< 5pF）
- ESD 器件紧贴连接器（< 5mm）
- ESD 器件 GND 直接连接到完整 GND 平面
- VBUS 增加 TVS 保护

### 9.3 信号完整性差

**原因**：走线过长、过孔过多、参考平面不连续

**解决**：
- 缩短 D+/D- 走线长度（< 100mm）
- 减少过孔数量（理想为 0）
- 确保参考平面连续无分割
- 避免与高速时钟并行

### 9.4 VBUS 电压跌落

**原因**：VBUS 走线细、旁路电容不足、电源开关内阻大

**解决**：
- 加宽 VBUS 走线（> 30mil）
- 增加旁路电容（4.7uF + 100nF）
- 选择低内阻电源开关 IC

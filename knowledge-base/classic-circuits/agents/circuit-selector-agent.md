# 电路拓扑选型 Agent

> 功能：根据用户需求（输入/输出电压、电流、功率、隔离要求、噪声要求）推荐最合适的电路拓扑和具体器件方案
> 版本：v1.0 | 更新日期：2026-09

---

## 1. Agent 工作流程

```
用户输入需求
    │
    ▼
┌──────────────────┐
│ Step 1: 需求解析  │  提取：Vin/Vout/Iout/Pout/隔离/噪声/成本/尺寸
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ Step 2: 知识库检索│  search_knowledge_base("<电路类型> topology selection")
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ Step 3: 拓扑筛选  │  按功率/电压/隔离/效率/成本排序
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ Step 4: 器件选型  │  search_knowledge_base(category="component-selection")
└──────┬───────────┘
       │
       ▼
┌──────────────────┐
│ Step 5: 方案输出  │  拓扑图 + BOM + 设计要点 + 审查清单
└──────────────────┘
```

## 2. 电源拓扑选择矩阵

### 2.1 非隔离 DC-DC

| Vin→Vout | 功率 | 推荐拓扑 | 控制IC示例 | 关键考量 |
|----------|------|----------|-----------|----------|
| 降压 2:1~10:1 | <3W | Buck | MP2359 (SOT-23) | 低成本/小封装 |
| 降压 2:1~10:1 | 3~50W | Buck | TPS5430/LM2675 | 效率/集成度 |
| 降压 2:1~10:1 | 50~200W | 同步Buck | TPS40322 | 同步整流降损耗 |
| 升压 1:2~1:10 | <3W | Boost | MT3608 (SOT-23) | 低成本 |
| 升压 1:2~1:10 | 3~50W | Boost | TPS61088/LM2577 | 效率/功率 |
| 升降压 | <30W | SEPIC | LM3478 | 输入可高于或低于输出 |
| 升降压 | <30W | Flyback(非隔离) | LM3481 | 简单隔离可选 |
| 反极性 | <30W | Cuk/Inverting | LM2596-ADJ | 负压输出 |

### 2.2 隔离 DC-DC

| 功率范围 | 推荐拓扑 | 控制IC | 隔离方式 | 典型应用 |
|----------|----------|-------|----------|----------|
| <5W | Flyback | TNY278/TNY280 | 变压器 | 适配器/辅助电源 |
| 5~25W | Flyback | NCP12700/LM3481 | 变压器 | 通信/工业 |
| 25~100W | Forward(单管) | LM5020 | 变压器 | 工业/医疗 |
| 50~200W | Active Clamp Forward | LM5025 | 变压器 | 高效率/小体积 |
| 100~500W | LLC半桥 | L6599/NCP1399 | 变压器 | 高效率/低EMI |
| 200~1000W | LLC全桥 | UCC25600 | 变压器 | 服务器/大功率 |
| 200~1000W | PSFB(移相全桥) | UCC28950 | 变压器 | 高效率/ZVS |
| >500W | 交错LLC | NCP1399×2 | 变压器 | 高功率/均流 |

## 5. 保护电路选型矩阵

| 保护类型 | 威胁等级 | 推荐方案 | 响应时间 | 恢复方式 |
|----------|----------|----------|----------|----------|
| ESD (接触8kV/空气15kV) | 高 | TVS阵列(USBLC6) | <1ns | 自恢复 |
| 浪涌 (IEC 61000-4-5) | 高 | GDT+TVS两级 | <1us | 自恢复 |
| 过流 | 中 | PTC/保险丝/eFuse | 1ms~10s | PTC自恢复/丝不可 |
| 过压 | 中 | TVS/稳压管/OVP IC | <1us | TVS自恢复 |
| 反接 | 中 | 肖特基/理想二极管 | <1us | 自恢复 |
| 过温 | 中 | 热敏电阻/温度开关 | 1~10s | 手动/自恢复 |

## 6. 输出格式

Agent 输出一份结构化方案文档：

```
# 电路方案: <需求摘要>

## 推荐拓扑: <拓扑名>
- 选型理由: <为什么选这个拓扑>
- 替代方案: <备选拓扑>

## 核心器件
| 位号 | 型号 | 参数 | 封装 | 数量 |
|------|------|------|------|------|

## 关键设计参数
- 工作频率: XXX kHz
- 效率预估: XX%
- 输出纹波: <XXmV
- 热功耗: XXW

## 审查要点
- [ ] 去耦电容已按知识库规则放置
- [ ] 反馈环路已用网络标签
- [ ] 保护电路已配合 (Fuse + TVS)
- [ ] 接地策略已确定 (单点/星型)
```

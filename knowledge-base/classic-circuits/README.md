## 4. 按设计阶段的推荐检索路径

### 4.1 电源设计阶段

```
确定电源需求（输入/输出电压/电流/效率）
    │
    ├─▶ [模块 01] LDO → 低噪声/小电流(<500mA)/低压差场景
    ├─▶ [模块 02] Buck → 大电流/高效率降压场景
    ├─▶ [模块 03] Boost → 升压场景（电池/LED驱动）
    └─▶ 检查: [审查 PI-01~PI-12] 电源完整性
```

### 4.2 MCU 系统设计阶段

```
选定 MCU 型号后
    │
    ├─▶ [模块 04] MCU 最小系统 → 电源/时钟/复位/BOOT/调试
    │      ├─▶ 电源设计 → [模块 01/02] LDO 或 Buck 供电
    │      ├─▶ 时钟设计 → HSE(8MHz) + LSE(32.768kHz)
    │      ├─▶ 复位设计 → 10k 上拉 + 100nF 延时
    │      └─▶ 调试接口 → SWD (2线 + NRST + GND)
    │
    └─▶ 检查: [审查 MC-01~MC-08] MCU 系统审查
```

### 4.3 模拟电路设计阶段

```
确定模拟功能需求
    │
    ├─▶ 信号放大 → [模块 05] OpAmp 放大器
    │      ├─▶ 反相/同相/差分/仪表放大器选型
    │      ├─▶ 增益计算 → Av = -Rf/Rin (反相)
    │      ├─▶ GBW 校验 → GBW > Av * f * 10
    │      └─▶ 运放选型 → LM358/TL084/OPA2333/AD620
    │
    ├─▶ 信号滤波 → [模块 06] OpAmp 滤波器
    │      ├─▶ Sallen-Key / MFB 拓扑选型
    │      ├─▶ 截止频率计算 → fc = 1/(2*pi*sqrt(R1*R2*C1*C2))
    │      └─▶ 元件精度 → 0.1% 电阻 + C0G 电容
    │
    ├─▶ 信号比较 → [模块 07] OpAmp 比较器
    │      ├─▶ LM393/LM311 选型
    │      ├─▶ 施密特触发器 → 迟滞设计
    │      └─▶ 窗口比较器 → 双比较器线与
    │
    └─▶ 检查: [审查 AN-01~AN-10] 模拟电路审查
```

### 4.4 接口电路设计阶段

```
确定通信接口需求
    │
    ├─▶ USB 接口 → [模块 08]
    │      ├─▶ USB2.0/3.0/Type-C 选型
    │      ├─▶ 差分对设计 → 90 ohm 阻抗/等长控制
    │      ├─▶ ESD 保护 → USBLC6-2SC6
    │      └─▶ 电源管理 → PTC + TVS + 电源开关
    │
    ├─▶ UART/RS232/RS485 → [模块 09]
    │      ├─▶ RS232 → MAX3232 电平转换
    │      ├─▶ RS485 → MAX485 + 终端匹配 + 偏置
    │      └─▶ 隔离 → ADuM1201 + B0505S
    │
    ├─▶ SPI/I2C → [模块 10]
    │      ├─▶ I2C 上拉计算 → Rp = (Vcc-0.4V)/3mA
    │      ├─▶ 电平转换 → TXS0108E / MOSFET
    │      └─▶ 隔离 → ADuM1251
    │
    └─▶ 检查: [审查 IF-01~IF-10/SI-05~SI-08] 接口与信号完整性
```

### 4.5 保护电路设计阶段

```
确定保护需求
    │
    ├─▶ 过压保护 → [模块 11] TVS
    │      ├─▶ ESD 保护 → USBLC6/TPD 系列（< 5pF）
    │      ├─▶ 浪涌保护 → SMAJ/SMBJ/SMCJ 系列
    │      ├─▶ 多级保护 → GDT + MOV + TVS
    │      └─▶ 放置位置 → 紧贴连接器 (< 5mm)
    │
    ├─▶ 过流保护 → [模块 12] Fuse/PTC
    │      ├─▶ 快断 → 精密电子保护
    │      ├─▶ 慢断 → 容性负载/电机
    │      ├─▶ PTC → 可恢复保护
    │      ├─▶ eFuse → 精密可编程保护
    │      └─▶ Fuse + TVS 协调 → 能量/时限协调
    │
    └─▶ 检查: [审查 SF-01~SF-10] 安全与保护审查
```

### 4.6 审查与验证阶段

```
设计完成后
    │
    ├─▶ [审查: circuit-design-checklist] → 87 项全面审查
    │      ├─▶ P0 阻断性审查（电源/安全/MCU 核心）
    │      ├─▶ P1 重要审查（信号/EMC/热/模拟）
    │      └─▶ P2 改进性审查（接口/制造）
    │
    └─▶ 样机验证 → ESD测试/浪涌测试/温升测试
```

### 6.2 设计公式速查

| 公式 | 用途 | 模块 |
|------|------|------|
| `Vout = Vref * (1 + R2/R1)` | LDO/Boost 输出电压 | 01, 03 |
| `Pd = (Vin - Vout) * Iout` | LDO 功耗 | 01 |
| `L = (Vin-Vout)*Vout / (Vin*dI_L*fsw)` | Buck 电感值 | 02 |
| `D = Vout / (Vin * eta)` | Buck 占空比 | 02 |
| `D = 1 - Vin*eta/Vout` | Boost 占空比 | 03 |
| `Av = -Rf/Rin` | 反相放大器增益 | 05 |
| `Av = 1 + Rf/Rin` | 同相放大器增益 | 05 |
| `fc = 1/(2*pi*sqrt(R1*R2*C1*C2))` | 滤波器截止频率 | 06 |
| `GBW > Av * f * 10` | 运放带宽校验 | 05, 06 |
| `Vth+ = Vref + R1/(R1+R2)*(Voh-Vref)` | 施密特上阈值 | 07 |
| `Rp = (Vcc - 0.4V) / 3mA` | I2C 上拉电阻 | 10 |
| `Vhys = R1/(R1+R2)*(Voh-Vol)` | 施密特迟滞宽度 | 07 |
| `In_fuse = Inormal * 1.25 / Kt` | 保险丝额定电流 | 12 |
| `I2t = C * Vin^2 / 2` | 电容充电浪涌能量 | 12 |
| `f = 1 / (1.386 * Rb * C)` | 多谐振荡器振荡频率 | 13 |
| `R_LED = (VCC - Vf - Vce_sat) / I_LED` | LED 限流电阻 | 13 |

## 9. 知识库使用指南

### 9.1 AI Skills 检索建议

1. **关键词检索优先**：每个文件头部均包含主题摘要，支持关键词快速定位
2. **公式驱动设计**：第 6.2 节提供设计公式速查表，支持参数计算
3. **器件型号检索**：第 7 节提供关键器件速查表，支持器件选型
4. **阶段化检索**：按设计阶段（电源→MCU→模拟→接口→保护→审查）选择对应路径
5. **场景化检索**：按应用场景（消费/工业/电池供电/通信扩展）选择对应路径

### 9.2 Altium Designer 集成建议

1. **原理图设计阶段**：检索对应模块获取电路拓扑和器件型号
2. **参数计算阶段**：使用设计公式速查表进行元件值计算
3. **PCB 布局阶段**：每个模块的 PCB 布局指南提供具体走线规则
4. **设计审查阶段**：使用 87 项审查清单进行逐项核查

### 9.3 知识库维护

- 新增模块文件按 `NN-topic-name.md` 编号规则命名
- 审查清单新增项需分配唯一编号（如 PI-13, SI-13 等）
- 器件速查表更新需同步更新对应模块文件
- 公式速查表更新需同步更新对应模块的公式章节

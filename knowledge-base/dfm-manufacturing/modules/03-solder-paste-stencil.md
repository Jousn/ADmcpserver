## 1. 钢网规格

### 1.1 钢网厚度选择

| 钢网厚度 | 适用封装 | 最小开孔 | 典型应用 |
|----------|----------|----------|----------|
| 0.08mm | 0201/0402 | 8mil | 高密度/小元件 |
| 0.10mm | 0402~0805 | 10mil | 通用 SMT |
| 0.12mm | 0603~1206 | 12mil | 大元件/通孔回流 |
| 0.15mm | 通孔/大焊盘 | 15mil | 锡量大的场景 |
| 0.15mm+台阶 | 混合 | - | 台阶钢网 |

### 1.2 钢网材料

| 材料 | 特性 | 适用 |
|------|------|------|
| 不锈钢(SS304) | 通用, 成本低 | 标准SMT |
| 电铸镍 | 精度高, 壁光滑 | 高精度/0201 |
| 聚合物 | 低摩擦, 适合粘性锡膏 | 特殊锡膏 |
| 涂层钢网 | 表面纳米涂层 | 减少清洗频次 |

## 2. 开孔设计规则

### 2.1 开孔面积比/宽厚比

```
面积比 (Area Ratio):
  AR = 开孔面积 / 开孔孔壁面积
     = (W × L) / (2×(W+L)×T)
  
  规则: AR ≥ 0.66 (IPC-7525)
  
宽厚比 (Aspect Ratio):
  AS = 开孔宽度 / 钢网厚度
  
  规则: AS ≥ 1.5 (标准)
  推荐: AS ≥ 1.7 (稳定)

示例:
  0.1mm钢网, 0402焊盘 (22×25mil=0.56×0.635mm):
    AR = (0.56×0.635) / (2×(0.56+0.635)×0.1) = 0.295 < 0.66 → 不达标
    → 需要台阶钢网或减小钢网厚度
```

### 2.2 开孔尺寸

| 元件 | 钢网厚度 | 开孔尺寸(相对焊盘) | 备注 |
|------|----------|-------------------|------|
| 0201 | 0.08mm | 80%~85% | 减少桥连 |
| 0402 | 0.10mm | 85%~90% | 减少锡珠 |
| 0603 | 0.10mm | 90%~100% | 标准 |
| 0805 | 0.12mm | 100% | 标准 |
| 1206 | 0.12mm | 100% | 标准 |
| QFP 0.5mm | 0.10mm | 80%~90% | 减少桥连 |
| QFP 0.4mm | 0.08mm | 70%~80% | 内移0.05~0.1mm |
| BGA 0.5mm | 0.10mm | 90%~100% | 圆形开孔 |
| BGA 0.4mm | 0.08mm | 80%~90% | 圆形 |

### 2.3 特殊开孔

```
 CHIP元件(0402/0603)防锡珠开孔:
  ┌──────────┐
  │ ┌──────┐ │  ← 外框 = 焊盘尺寸
  │ │██████│ │  ← 内框 = 开孔(缩小20%)
  │ │██████│ │
  │ └──────┘ │
  └──────────┘
  开孔内移 0.05~0.1mm, 避免元件侧面锡珠

 QFP防桥连开孔:
  ┌──┐ ┌──┐ ┌──┐  ← 骨架型开孔
  │██│ │██│ │██│  ← 减少引脚间锡量
  └──┘ └──┘ └──┘
  开孔间留 0.05~0.1mm 间隔, 减少桥连

 BGA 开孔:
  圆形开孔, 直径 = 焊盘直径 × 0.9~1.0
  0.5mm pitch: 0.28~0.32mm 直径
  0.4mm pitch: 0.22~0.25mm 直径

 转进IC (QFN/LGA):
  ┌──────────┐
  │████████│ ← 中心散热焊盘, 开孔网格化
  │█┌──┐█┌──┐│  (避免锡量过多导致翘起)
  │█└──┘█└──┘│
  │████████│
  └──────────┘
  开孔分为 4~9 个小方块, 每块 0.5~1.0mm
```

## 3. 台阶钢网 (Step Stencil)

```
台阶钢网用途:
  1. 大焊盘(连接器/屏蔽罩)需更多锡量 → 凸台阶(+0.03~0.05mm)
  2. 小元件(0201/QFP)需更少锡量 → 凹台阶(-0.03~0.05mm)
  3. 混合封装板需要差异化锡量

  剖面:
    ┌─┐     ┌─┐     ┌──────┐
    │ │     │ │     │凸台  │ ← 大焊盘区
    │ │     │ │     ├──┬───┤
    │ │     │ │     │  │   │
    └─┘     └─┘     └──┴───┘
    标准    标准     增加0.05mm
```

## 4. 锡膏选择

| 锡膏类型 | 合金 | 熔点 | 颗粒度 | 适用 |
|----------|------|------|--------|------|
| Sn-37Pb | 有铅 | 183°C | T3/T4 | 通用 |
| SAC305 | 无铅 | 217°C | T3/T4 | RoHS |
| SAC0307 | 无铅 | 217°C | T4 | 高可靠性 |
| Sn-42Bi | 低温 | 138°C | T4 | 敏感元件 |
| Sn-3.5Ag | 无铅 | 221°C | T3 | 高温场景 |

```
颗粒度选择:
  T3(25-45um): 通用, 0.5mm pitch 以上
  T4(20-38um): 高密度, 0.4mm pitch
  T5(15-25um): 超高密度, 0.3mm pitch
```

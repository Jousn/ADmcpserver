# 组装工艺与可焊性

> 版本：v1.0 | 更新日期：2026-09

## 1. 组装工艺选择

### 1.1 工艺路线

| 工艺路线 | 适用场景 | 流程 |
|----------|----------|------|
| 单面SMT | 单面元件 | 锡膏→贴片→回流焊 |
| 双面SMT | 双面元件 | A面→翻板→B面→回流焊 |
| 混合(SMT+THT) | 有插件 | A面SMT→B面胶→波峰焊 |
| 通孔回流(PIH) | 少量通孔 | 锡膏→插件→回流焊 |
| 双面混合 | 双面+插件 | A面SMT→B面SMT→B面波峰焊 |

## 2. 元件间距规则

### 2.1 SMT 元件间距

| 元件类型 | 间距(同类型) | 间距(异类型) | 说明 |
|----------|-------------|-------------|------|
| 0201 | 0.3mm | 0.4mm | 最小 |
| 0402 | 0.4mm | 0.5mm | 标准 |
| 0603 | 0.5mm | 0.6mm | 标准 |
| 0805+ | 0.6mm | 0.8mm | 大元件 |
| QFP 0.5mm | 0.5mm | 0.8mm | 引脚间距 |
| QFP 0.4mm | 0.4mm | 0.6mm | 高密度 |
| BGA 1.0mm | 1.0mm | 1.5mm | 球间距+检修 |
| BGA 0.8mm | 0.8mm | 1.2mm | 高密度BGA |
| IC(SOIC) | 1.0mm | 1.5mm | 标准 |

### 2.2 检修间距

```
检修间距 (保证可返修):
  - 烙铁可接触: 0.5mm
  - 热风枪可拆: 3mm (小IC) ~5mm (大IC)
  - BGA 返修: 5mm 周边

  BGA 检修区:
    ┌──────┐
    │ BGA  │ ←── 周边5mm内无其他元件
    │      │     (避免返修热损伤)
    └──────┘
```

## 3. 回流焊曲线

### 3.1 标准回流焊曲线

| 阶段 | 温度 | 时间 | 目的 |
|------|------|------|------|
| 预热 | 25→150°C | 60~90s | 缓升温, 防热冲击 |
| 保温 | 150~200°C | 60~120s | 活化助焊剂 |
| 回流 | 峰温(无铅245°C, 有铅220°C) | 30~60s | 熔化合金 |
| 冷却 | 峰温→100°C | 快冷 | 形成焊点结晶 |

### 3.2 温度敏感元件

| 元件 | 最高温度 | 时间 | 说明 |
|------|----------|------|------|
| 标准 IC | 260°C | 10s | IPC 标准 |
| LED | 250°C | 10s | 部分敏感 |
| 铝电解电容 | 245°C | 5s | 温度敏感 |
| 晶振 | 250°C | 10s | 密封性 |
| 电池 | 180°C | 0s | 不能回流焊 |
| 连接器 | 250°C | 10s | 塑料件检查 |
| 光耦 | 245°C | 10s | 密封性 |

## 4. 可焊性设计

### 4.1 焊盘设计

```
标准焊盘尺寸 (IPC-7351):
  CHIP 0603:
    焊盘宽 = 元件宽 + 0.1mm
    焊盘长 = 元件端头宽 + 0.3mm (每端)
    间距 = 元件长 - 0.3mm

  QFP 0.5mm pitch:
    焊盘宽 = 0.3mm (引脚宽-0.1)
    焊盘长 = 1.8mm (引脚长+0.5)
    外延 = 0.6mm (引脚外侧)

  BGA 0.5mm pitch:
    焊盘 = 0.28mm (圆形)
    阻焊 = 0.35mm (比焊盘大0.07)
```

### 4.2 阻焊设计

| 参数 | 规格 | 说明 |
|------|------|------|
| 阻焊开窗 | 焊盘+0.05mm(每侧) | 暴露焊盘 |
| 阻焊桥宽 | 3mil (0.075mm) | 最小 |
| 阻焊到铜 | 3mil | 最小 |
| 阻焊颜色 | 绿/黑/白 | 标准 |
| 阻焊厚度 | 10~20um | 标准 |

## 5. 丝印设计

| 参数 | 规格 | 说明 |
|------|------|------|
| 丝印线宽 | 0.15mm (6mil) | 最小 |
| 字号 | 0.8~1.5mm | 标准字高 |
| 字线宽 | 0.15~0.2mm | 与字号匹配 |
| 丝印到焊盘 | 0.15mm | 避免上焊盘 |
| 丝印方向 | 一致(左到右/底到顶) | 阅读方便 |
| 极性标记 | +/● | 必须清晰 |
| 位号方向 | 一致 | 检查方便 |

## 6. 常见 DFM 问题

| 问题 | 后果 | 预防 |
|------|------|------|
| 元件间距不足 | 贴片机精度不够 | 遵守间距规则 |
| 焊盘尺寸错误 | 焊点质量差 | 用 IPC-7351 标准 |
| 阻焊桥太窄 | 桥连 | 最小3mil |
| 元件重叠 | 不可制造 | 检查封装 |
| 测试点不足 | 无法ICT测试 | DFT设计 |
| BGA无丝印 | 检修困难 | 加丝印框 |
| 元件方向不一致 | 贴片效率低 | 统一方向 |
| 板厚无支撑 | ICT 翘曲 | 测试点均匀分布 |

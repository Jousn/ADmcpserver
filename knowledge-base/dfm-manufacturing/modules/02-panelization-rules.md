# 拼板与 V-Cut/桥连规则

> 适用范围：PCB 拼板设计、V-Cut、桥连、工艺边、定位孔
> 版本：v1.0 | 更新日期：2026-09

---

## 1. 拼板设计原则

### 1.1 拼板尺寸限制

| 参数 | 范围 | 说明 |
|------|------|------|
| 最小拼板尺寸 | 50×50mm | 小于此尺寸需拼板 |
| 最大拼板尺寸 | 250×350mm | 受贴片机限制 |
| 标准拼板尺寸 | 150×150~200×250mm | 最通用 |
| 工艺边宽度 | 5~10mm | 两侧各一条 |

### 1.2 拼板方向

```
单板排列:
  1×1: 单板足够大
  1×2: 长条形单板
  2×2: 小型单板
  2×N: 通用排列
  3×3/4×4: 小板/模组

方向选择:
  1. 单板长边与贴片机传送方向一致
  2. 短边走V-Cut/桥连
  3. 便于分板后使用
```

## 2. V-Cut

### 2.1 V-Cut 参数

| 参数 | 规格 | 说明 |
|------|------|------|
| V-Cut 角度 | 30°/45°/60° | 45° 最常用 |
| V-Cut 深度 | 板厚的1/3 (每侧) | 剩余1/3 |
| 最小板厚 | 0.6mm | 薄板不适合 |
| 最大板厚 | 3.2mm | 厚板V-Cut困难 |
| 最小单板尺寸 | 75×75mm | 太小不便V-Cut |
| 最小间距 | 0.0mm | V-Cut不带间距 |
| V-Cut 线到元件 | >0.5mm | 避免分板损伤 |

### 2.2 V-Cut 限制

```
不适合V-Cut的情况:
  1. 板厚 < 0.6mm → 用桥连
  2. 单板尺寸 < 75×75mm → 用桥连
  3. 元件伸入V-Cut线 > 0.5mm → 用桥连
  4. 需要圆角单板 → 用桥连
  5. 单板有通孔/槽靠近V-Cut → 用桥连
```

## 3. 桥连 (Tab Routing)

### 3.1 桥连类型

| 类型 | 结构 | 适用 | 分板方式 |
|------|------|------|----------|
| 直线桥连 | 两圆孔间留直桥 | 通用 | 手工/刀 |
| V-Cut+桥连 | V-Cut线+两端桥 | 大板 | V-Cut+手工 |
|邮票孔桥连 | 排孔(5~10个0.3mm孔) | 小板 | 手工掰开 |
| 鼠咬桥连 | 连续小齿 | 超小板 | 手工掰开 |

### 3.2 邮票孔设计

```
邮票孔参数:
  - 孔径: 0.3~0.5mm (NPTH 非金属化)
  - 孔数: 5~10个/桥
  - 孔间距: 0.5~0.8mm
  - 桥宽: 2~3mm
  - 每边桥数: 2 (两端)

布局:
          ┌───┐  ┌───┐
          │●●●│  │●●●│  ← 邮票孔(每端5~10孔)
          └─┬─┘  └─┬─┘
            │      │
    单板A ──┘      └── 单板B
```

## 4. 工艺边

### 4.1 工艺边设计

```
工艺边:
  1. 宽度: 5~10mm (标准 5mm)
  2. 位置: 拼板两侧 (传送方向)
  3. 上方: 无需工艺边 (贴片机单侧传送)
  4. 工艺边内容: Mark点 + 定位孔 + 基准孔

  示意图:
    ┌──────────────────────────────────┐
    │Mark  Mark  Mark  Mark  Mark  Mark│ ← 上工艺边(可选)
    ├──────────────────────────────────┤
    │  ┌──┐ ┌──┐ ┌──┐ ┌──┐           │
    │  │板│ │板│ │板│ │板│           │
    │  │A │ │B │ │A │ │B │           │
    │  └──┘ └──┘ └──┘ └──┘           │
    ├──────────────────────────────────┤
    │Mark  Mark  Mark  Mark  Mark  Mark│ ← 下工艺边
    └──────────────────────────────────┘
     ←─── 工艺边 ───→
```

## 5. Mark 点 (Fiducial Marks)

### 5.1 Mark 点规格

| 参数 | 规格 | 说明 |
|------|------|------|
| 形状 | 圆形 | 最常用 |
| 直径 | 1.0~2.0mm | 标准1.0/1.5mm |
| 铜箔 | 裸铜 | 不涂阻焊 |
| 阻焊开窗 | 直径+2×直径 | 环绕暴露 |
| 表面处理 | 与板面一致 | HASL/ENIG等 |
| 数量 | 3个/面 | 对角2个+1个 |
| 位置 | 拼板对角线 | 距离越远越好 |

### 5.2 Mark 点层级

```
Mark点分三个层级:
  1. 拼板Mark: 拼板对角, 用于整板定位
  2. 单板Mark: 每块单板对角, 用于单板定位
  3. 元件Mark: 大IC(BGA/QFP)旁, 用于元件贴装

  数量:
    - 拼板Mark: 每面 3个 (对角2 + 辅助1)
    - 单板Mark: 每块 3个 (同上)
    - IC Mark: BGA/QFP > 20mm 时必须
```

## 6. 定位孔

| 参数 | 规格 |
|------|------|
| 孔径 | 4.0mm (标准) |
| 位置 | 拼板对角 |
| 数量 | 2个 |
| 孔距 | 距拼板角 5mm |
| 类型 | NPTH (非金属化) |
| 公差 | ±0.1mm |

# 测试焊盘与可测试性设计

> 适用范围：PCB 可测试性设计（DFT）、ICT/FCT/飞针测试、测试焊盘规则
> 版本：v1.0 | 更新日期：2026-09

## 1. 测试方法对比

| 测试方法 | 覆盖率 | 速度 | 成本 | 适用阶段 |
|----------|--------|------|------|----------|
| ICT(在线测试) | 80~90% | 快 | 高(夹具) | 量产 |
| FCT(功能测试) | 70~85% | 中 | 中 | 量产 |
| 飞针测试 | 60~80% | 慢 | 低(无夹具) | 样品/小批量 |
| AOI(自动光学) | 外观 | 快 | 中 | 量产 |
| X-Ray | 焊点 | 快 | 高 | BGA/通孔 |
| 边界扫描 | 逻辑 | 快 | 低 | 高密度 |

## 2. 测试焊盘设计

### 2.1 ICT 测试焊盘

| 参数 | 规格 | 说明 |
|------|------|------|
| 焊盘直径 | 0.9~1.0mm | 标准 |
| 焊盘间距 | 2.54mm (100mil) | 标准 |
| 最小间距 | 1.27mm (50mil) | 高密度 |
| 位置 | 底面(Bot) | ICT 探针接触面 |
| 表面 | 裸铜或ENIG | 避免HASL(不平整) |
| 阻焊 | 开窗 = 焊盘 | 不缩小 |

### 2.2 测试点布局规则

```
测试点布局 5 条规则:

1. 每个网络至少一个测试点
   - 优先在信号源端和负载端各一个
   - 高速信号可不加测试点(避免阻抗不连续)

2. 间距:
   - 标准 ICT: 2.54mm (100mil)
   - 高密度 ICT: 1.27mm (50mil)
   - 测试点间距 > 1.5mm (避免探针碰)

3. 远离元件:
   - 测试点距元件 > 2mm
   - 测试点距板边 > 3mm
   - 测试点距通孔 > 1mm

4. 均匀分布:
   - 测试点间距 < 100mm
   - 避免大范围无测试点区域
   - ICT 夹具支撑需均匀

5. 高度限制:
   - 测试面元件高度 < 6mm (ICT 探针行程)
   - 背面元件高度 < 15mm
```

## 3. 需要测试点的信号

### 3.1 必须有测试点

| 信号类型 | 原因 | 测试点位置 |
|----------|------|-----------|
| 电源轨 | 验证供电 | 每个IC电源引脚附近 |
| 地轨 | 参考基准 | 每50mm一个 |
| 关键控制信号 | 功能验证 | 源端和负载端 |
| 总线(SPI/I2C/UART) | 通信验证 | 每根信号线 |
| 复位信号 | 启动验证 | 复位线 |
| 时钟信号 | 时序验证 | 源端(避免负载影响) |
| 模拟信号 | 精度验证 | 运放输入/输出 |

### 3.2 可不加测试点

| 信号类型 | 原因 |
|----------|------|
| 高速差分对 | 测试点引入阻抗不连续 |
| DDR DQ/DQS | 太密, 用边界扫描替代 |
| BGA 引脚 | 不可接触, 用边界扫描 |
| ESD 保护节点 | 加测试点降低保护效果 |

## 4. 边界扫描（JTAG）

### 4.1 JTAG 测试

```
边界扫描优势:
  - 不需要物理接触每个网络
  - 通过 TCK/TMS/TDI/TDO 4 线测试
  - 覆盖率取决于 IC 支持的边界扫描单元数

JTAG 链:
  TDI → IC1 → IC2 → ... → ICn → TDO
  TCK, TMS 并联所有 IC
  TRST 可选(并联或独立)

JTAG 测试焊盘:
  - TDI, TDO, TCK, TMS, TRST 各一个
  - 焊盘间距 2.54mm
  - 放在板边缘, 便于探针
```

## 5. DFT 设计流程

```
DFT 检查流程:
  1. 原理图阶段:
     - 确定测试策略 (ICT/FCT/飞针)
     - 标注测试点网络
     - 确定 JTAG 链
  
  2. PCB 布局阶段:
     - 放置测试点焊盘
     - 确保间距/位置规则
     - 避免高速信号加测试点
  
  3. PCB 验证:
     - DRC: 测试点间距检查
     - 测试覆盖率分析
     - 生成测试夹具坐标文件
  
  4. 制造阶段:
     - 生成测试程序
     - 制作 ICT 夹具
     - 首件测试验证
```

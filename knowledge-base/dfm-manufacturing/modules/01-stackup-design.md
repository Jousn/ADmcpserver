# PCB 叠层设计规范

> 适用范围：多层 PCB 叠层结构设计、阻抗控制与材料选择
> 版本：v1.0 | 更新日期：2026-09

---

## 1. 层数选择

### 1.1 层数决策矩阵

| 信号复杂度 | 电源/地需求 | 推荐层数 | 典型应用 |
|-----------|------------|----------|----------|
| 简单(单面) | 1 电源 | 1层 | 玩具/简单控制 |
| 低速双面 | 1~2 电源 | 2层 | MCU最小系统/传感器 |
| 中速多电源 | 2~3 电源 | 4层 | STM32+简单外设 |
| 高速+混合信号 | 3+ 电源 | 6层 | DDR3/以太网/USB3 |
| 高速多DDR | 4+ 电源 | 8层 | DDR4/SoC/PCIe |
| 超高速/高密度 | 5+ 电源 | 10层+ | DDR5/服务器/HDI |

### 1.2 层数估算

```
估算步骤:
  1. 信号层 = ceil(走线密度 / 1.2)
     - 低密度(<1.5 inch/inch²) → 1~2 层
     - 中密度(1.5~3) → 2~3 层
     - 高密度(3~6) → 3~5 层
     - 超高密度(>6) → HDI

  2. 电源/地层:
     - 每 2 个信号层需 1 个 GND 层
     - 多电压域需 1~2 个 PWR 层
     - 高速设计: 每个信号层配 GND 层

  3. 总层数 = 信号层 + 电源层 + 地层
     - 偶数优先 (对称结构)
     - 芯板对称 (避免翘曲)
```

## 2. 推荐叠层结构

### 2.1 4 层板

```
L1 (Top)   Signal + Component
L2         GND    ←── 完整地平面
L3         PWR    ←── 电源平面
L4 (Bot)   Signal + Component

阻抗控制(微带线): L1 对 L2 参考
阻抗控制(微带线): L4 对 L3 参考
```

### 2.2 6 层板

```
方案A (常规, 推荐):
  L1 (Top)  Signal
  L2        GND   ←── 完整地
  L3        PWR   ←── 电源 (紧邻L2, 平面电容)
  L4        GND   ←── 完整地
  L5        Signal
  L6 (Bot)  Signal

方案B (高速优先):
  L1 (Top)  Signal
  L2        GND
  L3        Signal ←── 带状线 (高速)
  L4        PWR
  L5        GND
  L6 (Bot)  Signal
```

### 2.3 8 层板

```
L1 (Top)  Signal
L2        GND
L3        Signal ←── 带状线 (高速)
L4        GND
L5        PWR
L6        Signal ←── 带状线 (高速)
L7        GND
L8 (Bot)  Signal
```

## 4. 对称性与翘曲控制

```
对称设计原则:
  1. 以板中心为对称轴, 两侧铜厚对称
  2. 介质厚度对称
  3. 走线密度尽量对称 (避免一侧过密)
  4. 大面积铜箔对称分布

  不对称 → 翘曲:
    - PCB 翘曲 > 0.75% (IPC-2221) → 不合格
    - SMT 要求 < 0.5%
    - BGA 要求 < 0.3%

  翘曲计算: 翘曲% = (翘曲高度/对角线长度) × 100%
```

| 铜厚 | 厚度 | 最小线宽 | 最小线距 | 适用 |

| 0.5oz | 18um | 4mil | 4mil | 信号层/高密度 |

## 6. 介质厚度

### 6.1 阻抗控制介质厚度

| 层间 | 厚度范围 | 用途 |
|------|----------|------|
| L1-L2 | 3~6mil | 微带线阻抗控制 |
| L2-L3 | 3~5mil | 平面电容(低Z PDN) |
| 内层间 | 8~20mil | 带状线阻抗控制 |
| 芯板 | 10~40mil | 结构支撑 |

## 7. Altium 中的叠层管理

| 操作 | 说明 |
|------|------|
| Design » Layer Stack Manager | 打开叠层管理器 |
| Layer → Material | 设置每层材料 (FR-4/Rogers) |
| Layer → Thickness | 设置铜厚/介质厚 |
| Layer → Dielectric Constant | 设置介电常数 |
| Impedance Calculation | 自动计算阻抗 |
| Design » Rules → Routing Layers | 控制信号层使用 |

# 混合信号设计 DRC 规则模板

> 适用范围：MCU + 模拟前端、ADC/DAC 系统、混合信号数据采集板
> 目标受众：AI设计辅助Skill，用于混合信号 PCB DRC 规则配置与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

混合信号系统同时包含模拟电路（运放、传感器、ADC/DAC）和数字电路（MCU、FPGA、时钟），是 PCB 设计中最具挑战的类型。核心难点在于防止数字噪声耦合到模拟信号中，同时保证模拟和数字电路各有完整的接地和供电。本模板提供混合信号设计的单点接地、区域分割、返回路径和布局工作流的完整 DRC 规则集。

---

## 2. 设计类型与核心挑战

### 2.1 典型混合信号系统

| 系统类型 | 模拟部分 | 数字部分 | 关键器件 |
|----------|---------|---------|---------|
| MCU + ADC 数据采集 | 运放前端、RC 滤波 | MCU、晶振 | MCU 内置 ADC |
| 独立 ADC/DAC 板 | 运放驱动、基准源 | 控制逻辑、数据接口 | 高精度 ADC（如 ADS1256） |
| 传感器采集系统 | 信号调理、电平转换 | MCU、通信接口 | 24bit ADC + MCU |
| 音频系统 | 音频运放、DAC | DSP、I2S 接口 | 音频 DAC + DSP |
| 电力测量 | 电流互感器前端 | MCU、计量算法 | 计量 ADC + MCU |

### 2.2 核心设计挑战

| 挑战 | 机理 | 影响 |
|------|------|------|
| 数字噪声耦合到模拟 | 数字开关电流通过地阻抗产生压降 | ADC 精度下降，噪声增大 |
| 时钟干扰模拟 | 时钟谐波耦合到敏感信号 | 信号失真，混频干扰 |
| 地环路噪声 | 模拟/数字地形成环路 | 共模噪声增大 |
| 电源串扰 | 数字/模拟共用电源 | 纹波耦合到模拟部分 |
| 返回路径不连续 | 信号跨越地分割 | EMI 增大，信号完整性下降 |

## 3. 接地策略

### 3.1 单点接地原则

混合信号系统的核心接地原则：模拟地（AGND）和数字地（DGND）在唯一一点连接。

```
单点接地结构：

  ┌──────────────────────────────────┐
  │         模拟区域          数字区域   │
  │                                    │
  │   AGND ──────────┐   ┌─── DGND    │
  │                   │   │            │
  │   [运放]  [ADC]   │   │  [MCU]     │
  │                   │   │            │
  │        ← 单点连接→ │ ← │           │
  │   AGND ──────── ● ─── ● ── DGND  │
  │                (桥接点)             │
  └──────────────────────────────────┘

原则：
1. AGND 和 DGND 仅在一个点连接
2. 连接点位于 ADC/DAC 下方（桥接区域）
3. 桥接走线短而宽
4. 桥接点无其他网络通过
```

### 3.2 分割平面策略

```
分割平面策略对比：

方案A：分割 GND 平面（不推荐，高风险）
  ┌──────────┬──────────┐
  │   AGND   │   DGND   │ ← 平面被分割
  │          │          │
  │   ●──────┘   ←─────● │ ← 仅在桥接点连接
  └──────────┴──────────┘
  风险：任何信号跨越分割线 → 返回路径中断 → EMI 暴增

方案B：统一 GND 平面（推荐，低风险）
  ┌──────────────────────┐
  │     统一 GND 平面     │ ← 完整无分割
  │                       │
  │  模拟区  │  数字区     │ ← 仅器件分区，平面不分割
  └──────────────────────┘
  原理：依靠器件物理分区和布线约束实现隔离
  返回路径始终连续，EMI 最优
```

### 3.3 ADC/DAC 桥接区设计

```
ADC/DAC 桥接区设计（方案A：分割平面，适用于高精度系统）：

  ┌──────────────────────────────┐
  │  模拟区           数字区      │
  │                               │
  │         ┌──ADC──┐            │
  │  AGND ──┤        ├── DGND    │
  │         │ 桥接区  │           │
  │  AGND ──┤        ├── DGND    │
  │         └────────┘            │
  │            │                   │
  │         单点桥接                │
  │     (0Ω 电阻 或 铜皮)           │
  └──────────────────────────────┘

桥接区规则：
1. 桥接宽度 ≥ 40mil（宽桥减少阻抗）
2. 桥接位置在 ADC/DAC 正下方
3. 桥接处使用 0Ω 电阻或铜皮直连
4. 桥接处不允许其他走线穿过
5. 高精度系统可用单点连接 + 多过孔降低阻抗
```

## 4. 信号布线约束

### 4.1 返回路径连续性

```
返回路径不连续问题：

  错误（信号跨越分割线）：
  ┌──────────┬──────────┐
  │   AGND   │   DGND   │
  │          │          │
  │   ───信号──→──跨分割──→ │ ← 返回路径中断！
  │          │          │
  └──────────┴──────────┘
  问题：返回电流被迫绕大圈 → 增大环路面积 → EMI 暴增

  正确（信号不跨越分割线）：
  ┌──────────────────────┐
  │     统一 GND 平面     │ ← 完整地平面
  │   ───信号──→           │ ← 返回路径连续
  └──────────────────────┘
```

### 4.2 区域穿越约束

| 约束 | 要求 | 说明 |
|------|------|------|
| 数字走线不进入模拟区 | 绝对禁止 | 数字噪声耦合 |
| 模拟走线不进入数字区 | 绝对禁止 | 信号被干扰 |
| 跨区域走线 | 仅通过桥接区 | 保证返回路径连续 |
| 时钟走线 | 不穿越模拟区 | 最强干扰源 |
| 电源走线 | 各走各区 | AVDD/DVDD 分离 |

## 5. 元件布局分区

### 5.1 物理分区原则

```
混合信号板布局分区：

  ┌──────────────────────────────────────────┐
  │                                          │
  │    ┌─────────┐      ┌─────────┐         │
  │    │ 模拟区  │      │ 模拟区  │         │
  │    │ 运放前端 │      │ 基准源  │         │
  │    │ RC 滤波 │      │ LDO    │         │
  │    └────┬───┘      └────┬───┘         │
  │         │   ┌─────────┐  │              │
  │         └───┤ ADC/DAC ├──┘              │
  │             │ (桥接区) │                 │
  │         ┌───┤         ├──┐              │
  │    ┌────┘   └─────────┘  └────┐        │
  │    │ 数字区      数字区       │        │
  │    │ MCU         晶振         │        │
  │    │ 逻辑        通信接口     │        │
  │    └─────────────────────────┘        │
  │                                          │
  │         ┌───────────────┐                │
  │         │ 电源区        │                │
  │         │ DC-DC + LDO   │                │
  │         └───────────────┘                │
  └──────────────────────────────────────────┘

分区原则：
1. 模拟区在最左边，靠近模拟输入连接器
2. ADC/DAC 在模拟/数字交界处（桥接区）
3. 数字区在右边，靠近数字接口连接器
4. 电源区在底部（或独立区域）
5. 晶振/时钟在数字区内侧
```

### 5.2 分区间距

| 区域间 | 最小间距 (mil) | 说明 |
|--------|---------------|------|
| 模拟 - 数字 | 40 | 器件物理隔离 |
| 模拟 - 电源 | 30 | 电源噪声隔离 |
| 数字 - 电源 | 20 | 一般间距 |
| 时钟 - 模拟 | 80 | 最强隔离 |
| 模拟 - 板边 | 20 | 制造安全 |
| ADC/DAC - 其他 | 20 | 桥接区清晰 |

## 6. 电源策略

### 6.1 独立 LDO 供电

```
混合信号电源架构：

  DC-DC (开关电源)
    │
    ├─▶ LDO_DVDD → DVDD (数字电源) → MCU/逻辑
    │
    ├─▶ LDO_AVDD → AVDD (模拟电源) → 运放/ADC
    │
    └─▶ LDO_VREF → VREF (基准电源) → ADC/DAC 基准

原则：
1. AVDD 和 DVDD 使用独立 LDO
2. 开关电源不直接供给敏感模拟电路
3. VREF 使用超低噪声 LDO 或专用基准源
4. AVDD 平面和 DVDD 平面不重叠（区域分割）
```

### 6.2 去耦策略

| 器件类型 | 去耦方案 | 说明 |
|----------|---------|------|
| 运放（模拟） | 0.1μF X7R + 1μF X7R | 每电源引脚 |
| ADC/DAC | 0.1μF + 1μF + 10μF | 多级去耦 |
| MCU（数字） | 0.1μF × 每对电源 + 10μF | 多引脚去耦 |
| VREF | 1μF X7R + 0.1μF C0G | 基准专用低噪声 |
| LDO 输入 | 10μF + 0.1μF | 输入侧储能 |
| LDO 输出 | 10μF X7R（按 ESR） | 按 IC 稳定性要求 |

### 6.3 模拟 vs 数字去耦差异

| 参数 | 模拟去耦 | 数字去耦 |
|------|---------|---------|
| 电容类型 | X7R/C0G MLCC | X5R/X7R MLCC |
| 主要目标 | 低噪声、低纹波 | 瞬态电流供应 |
| 容量 | 精确（按 IC 要求） | 充裕（大容量） |
| ESR 要求 | 低且稳定 | 超低 ESR |
| 布局 | 紧邻每器件 | 每对电源引脚一组 |

## 7. 时钟布线规则

### 7.1 时钟隔离

```
时钟布线原则：

1. 晶振/时钟在数字区内侧，远离模拟区
2. 时钟走线不穿越模拟区域（≥ 80mil 隔离）
3. 时钟走线两侧布保护走线（GND Guard Trace）
4. 时钟层转换时旁打地过孔（返回路径连续）

时钟保护走线：
  GND ── GND_Via ── GND
   │                 │
  CLK ──────────────
   │                 │
  GND ── GND_Via ── GND
```

### 7.2 时钟 EMI 控制

| 措施 | 说明 |
|------|------|
| 时钟走线内层布线 | 减少 EMI 辐射 |
| 时钟线两侧 GND 保护 | 屏蔽耦合 |
| 时钟远离板边/连接器 | 减少辐射 |
| 扩频时钟（SSC） | 降低峰值辐射 |
| 串接匹配电阻 | 减少反射和过冲 |

## 8. ADC/DAC 放置规则

### 8.1 ADC/DAC 放置位置

```
ADC/DAC 放置原则：

1. 位于模拟区和数字区交界处（桥接区）
2. 模拟引脚朝向模拟区，数字引脚朝向数字区
3. AGND 引脚连接模拟地，DGND 引脚连接数字地
4. AVDD 引脚连接模拟电源，DVDD 引脚连接数字电源
5. 芯片正下方为单点接地桥接区

ADC 封装方向示例（QFP 封装）：

  模拟区                数字区
  │                       │
  │  ┌─────────────────┐  │
  │  │ AIN0  AIN1  AIN2│  │
  │  │ AIN3  AIN4  AIN5│  │
  │  │ AVDD  AGND  VREF│  │
  │  │      [ADC]      │  │
  │  │ DVDD  DGND  DOUT│  │
  │  │ SCLK  CS    DRDY│  │
  │  └─────────────────┘  │
  │                       │
  模拟引脚 ←──→ 数字引脚

布局原则：模拟引脚侧朝模拟区，数字引脚侧朝数字区
```

### 8.2 ADC 输入保护

| 措施 | 说明 |
|------|------|
| RC 低通滤波 | ADC 输入前端，截止频率按采样率 |
| 运放驱动 | 降低源阻抗，提高采样精度 |
| 过压保护 | 钳位二极管防 ESD |
| 输入走线短 | 减少噪声拾取 |
| 差分走线 | 差分输入对抗共模噪声 |

## 10. 布局工作流

### 10.1 推荐布局顺序

```
混合信号 PCB 布局工作流：

Step 1: 模拟区布局
  ├─ 放置模拟输入连接器（板边）
  ├─ 放置运放前端（紧邻连接器）
  ├─ 放置 RC 滤波（运放和 ADC 之间）
  ├─ 放置模拟 LDO（模拟区内侧）
  └─ 放置基准源（ADC 旁）

Step 2: 数字区布局
  ├─ 放置 MCU/FPGA（数字区中心）
  ├─ 放置晶振（MCU 旁，远离模拟区）
  ├─ 放置数字接口连接器（板边）
  ├─ 放置数字 LDO（数字区内侧）
  └─ 放置数字去耦电容（每 MCU 电源引脚旁）

Step 3: 桥接区布局
  ├─ 放置 ADC/DAC（模拟/数字交界）
  ├─ ADC 模拟引脚朝向模拟区
  ├─ ADC 数字引脚朝向数字区
  └─ 确定桥接点和桥接走线

Step 4: 电源区布局
  ├─ 放置 DC-DC 变换器（独立区域）
  ├─ 放置 LDO（AVDD/DVDD/VREF 分别）
  ├─ 电源走线分区布线
  └─ 去耦电容就位

Step 5: 连接器布局
  ├─ 模拟输入连接器（板边靠模拟区）
  ├─ 数字接口连接器（板边靠数字区）
  ├─ 电源输入连接器（板边靠电源区）
  └─ ESD 保护（连接器旁）
```

### 10.2 布线顺序

```
混合信号布线顺序：

1. 地平面 → 先布地，保证完整性
2. 模拟信号 → 模拟区内布线，不越界
3. 数字信号 → 数字区内布线，不越界
4. 时钟 → 内层布线，两侧保护走线
5. 电源 → AVDD/DVDD 分区布线
6. 反馈/控制 → 最后布线，最短路径
7. 去耦电容 → 布线后放置在信号旁
8. 连接器走线 → 最后连接外部接口
```

## 11. 设计审查要点清单

| 序号 | 审查项 | 合格判据 | 优先级 |
|-----|--------|---------|--------|
| 1 | AGND/DGND 单点连接 | 仅在 ADC/DAC 桥接点连接 | 高 |
| 2 | 统一地平面完整性 | 无开槽/分割（推荐方案B） | 高 |
| 3 | 模拟/数字区域分离 | 器件物理分区，间距 ≥ 40mil | 高 |
| 4 | 模拟走线不进数字区 | 布线约束验证 | 高 |
| 5 | 数字走线不进模拟区 | 布线约束验证 | 高 |
| 6 | 时钟远离模拟区 | ≥ 80mil | 高 |
| 7 | AVDD/DVDD 独立 LDO | 各自供电，不共平面 | 高 |
| 8 | ADC/DAC 桥接位置 | 位于交界处 | 高 |
| 9 | 返回路径连续 | 无信号跨越分割 | 高 |
| 10 | 去耦策略差异化 | 模拟和数字分别配置 | 中 |
| 11 | 时钟保护走线 | 两侧 GND 保护 | 中 |

核心规则速查：

穿越约束：模拟走线不进数字区，数字走线不进模拟区
时钟：内层布线，两侧 GND 保护，远离模拟 ≥ 80mil
电源：AVDD/DVDD/VREF 独立 LDO，不共平面
ADC/DAC：位于交界（桥接区），模拟侧朝模拟，数字侧朝数字
去耦：模拟用 X7R/C0G，数字用 X5R/X7R，分别配置
返回路径：统一地平面无分割，不跨越分割
布局工作流：模拟→数字→桥接→电源→连接器

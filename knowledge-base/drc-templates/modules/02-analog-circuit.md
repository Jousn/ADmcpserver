# 模拟电路 DRC 规则模板

> 适用范围：信号频率 DC~10MHz 的模拟电路（运放电路、传感器调理、滤波器、精密测量）
> 目标受众：AI设计辅助Skill，用于模拟电路 PCB DRC 规则配置与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

模拟电路对噪声极其敏感，PCB 设计的核心目标是降低噪声、防止干扰、保证精度。与高速数字电路追求阻抗控制和高速开关不同，模拟电路更关注低噪声布线、保护环、星形接地和热对称布局。不当的布线会引入漏电流、热电偶效应、共模噪声和串扰，导致测量误差或信号失真。

---

## 2. 信号频率与噪声控制

### 2.1 信号频率范围

| 频段 | 典型应用 | 噪声关注点 |
|------|---------|-----------|
| DC~100Hz | 传感器、热电偶、应变片 | 1/f 噪声、漏电流、热电势 |
| 100Hz~10kHz | 生物电（ECG/EEG）、音频低频 | 工频干扰（50/60Hz）、共模噪声 |
| 10kHz~100kHz | 音频、超声波 | 热噪声、运放噪声 |
| 100kHz~10MHz | 视频滤波、高速运放 | 串扰、EMI、阻抗匹配 |

### 2.2 噪声来源与抑制

| 噪声类型 | 来源 | 抑制方法 |
|----------|------|---------|
| 电阻热噪声 | 信号路径电阻 | 降低源阻抗，缩短走线 |
| 1/f 噪声 | 运放输入级 | 选低噪声运放，斩波稳零型 |
| 工频干扰 | 电源线/变压器 | 屏蔽、差分输入、陷波滤波 |
| 共模噪声 | 地环路、寄生耦合 | 仪表放大器、隔离、单点接地 |
| 串扰 | 相邻走线耦合 | 3W 规则、保护走线 |
| 漏电流 | PCB 基材（FR-4 ~10^9 Ω·cm） | 保护环、特氟龙基材 |

## 3. 保护环（Guard Ring）规则

### 3.1 保护环设计

高阻抗节点（如 pH 传感器、静电计、运放输入）需使用保护环防止 PCB 漏电流：

```
保护环结构（俯视图）：

         ┌─────────────────────┐
         │  ┌───────────────┐  │
         │  │  保护环走线    │  │ ← 接低阻抗等电位
         │  │  ┌────────┐  │  │
         │  │  │ 输入   │  │  │
  信号 ──┤  │  │ 焊盘   │  │  │
         │  │  └────────┘  │  │
         │  └───────────────┘  │
         └─────────────────────┘
```

### 3.2 保护环连接原则

| 保护环类型 | 连接电位 | 适用电路 |
|-----------|---------|---------|
| 反相运放保护环 | 运放反相输入电位（虚地） | 反相放大器、积分器 |
| 同相运放保护环 | 运放同相输入电位（信号源） | 跟随器、同相放大器 |
| 公共保护环 | 地（GND） | 通用低阻抗参考 |

### 3.3 DRC 规则

| 规则 | 值 | 说明 |
|------|-----|------|
| 保护环宽度 | ≥ 15mil | 确保等电位覆盖 |
| 保护环与信号间距 | 8~12mil | 足够间距避免寄生电容 |
| 保护环过孔间距 | 100mil | 均匀分布确保等电位 |
| 保护环层 | 信号层 + 地层（双面） | 上下层通过过孔连接 |

## 4. 星形接地（Star Grounding）规则

### 4.1 星形接地原则

```
星形接地结构：

              ┌─ GND（单点参考）
              │
     ┌────────┼────────┐
     │        │        │
  模拟1    模拟2    模拟3
  返回     返回     返回
     │        │        │
  [电路1]  [电路2]  [电路3]

原则：所有模拟电路的地返回走线汇聚到单点
目的：消除地环路电流引起的共模噪声
```

### 4.2 DRC 规则

| 规则 | 要求 | 说明 |
|------|------|------|
| 星形接地点 | 每个独立模拟模块有唯一接地汇聚点 | 消除环路 |
| 地走线宽度 | ≥ 20mil | 降低地阻抗 |
| 地平面完整性 | 模拟区域下方完整地平面 | 不允许分割/开槽 |
| 地过孔数量 | 模拟区域多点接地 | 降低地阻抗 |

## 5. 元件布局规则

### 5.1 布局分区

| 区域 | 布局位置 | 说明 |
|------|---------|------|
| 模拟前端 | 远离数字/电源区 | 噪声隔离 |
| 运放/精密器件 | 远离热源 | 防止热梯度 |
| 高阻抗节点 | 远离数字走线 | 防止漏电流/耦合 |
| 传感器接口 | 板边靠近输入连接器 | 最短信号路径 |
| LDO/基准源 | 模拟区内侧 | 就近供电，低纹波 |

### 5.2 热对称布局

精密运放电路中，差分输入对需保持对称的热环境：

```
热对称布局原则：

  [热源：功率器件]
         ↓ 热梯度方向
  ┌──────────────┐
  │  ┌─运放─┐    │
  │  │IN+ IN-│   │ → IN+ 和 IN- 在同一等温线上
  │  └──────┘    │
  └──────────────┘

违规：IN+ 靠近热源，IN- 远离热源 → 热电偶效应产生失调

修正：使 IN+ 和 IN- 等距于热源，位于同一等温线
```

## 6. 走线规则

### 6.1 线宽规则

| 信号类型 | 最小 (mil) | 推荐 (mil) | 说明 |
|----------|-----------|-----------|------|
| 模拟信号 | 8 | 12 | 降低噪声（非追求低电感） |
| 高阻抗节点 | 8 | 10 | 较细走线减小面积防漏电 |
| 低阻抗信号 | 12 | 15 | 降低电阻和噪声 |
| 电源（模拟 LDO） | 15 | 20 | 按电流计算 |
| 地走线 | 20 | 30 | 降低地阻抗 |

### 6.2 间距规则

| 网络分类间 | 间距 (mil) | 说明 |
|-----------|-----------|------|
| 模拟信号 - 模拟信号 | 10 | 标准间距 |
| 高阻抗节点 - 任何信号 | 20 | 防漏电流/耦合 |
| 模拟信号 - 数字信号 | 30 | 噪声隔离 |
| 模拟信号 - 电源 | 20 | 防止耦合 |
| 模拟信号 - 时钟 | 50 | 最强隔离 |

### 6.3 布线层规则

| 规则 | 要求 | 说明 |
|------|------|------|
| 布线层优先级 | 顶层优先 | 最短路径，最少过孔 |
| 层转换 | 最小化 | 每个过孔增加寄生电容/电阻 |
| 差分走线 | 等长、等宽、紧耦合 | 对称走线 |
| 拐角 | 45° 或圆角 | 避免 90° 拐角引入反射 |
| 走线长度 | 最短化 | 降低电阻和噪声拾取 |

## 7. 接地规则

### 7.1 地平面完整性

| 规则 | 要求 | 说明 |
|------|------|------|
| 模拟地平面 | 完整，不分割 | 模拟区域下方全覆盖 |
| 地平面过孔 | 密集分布 | 降低地阻抗 |
| 地平面开槽 | 禁止 | 开槽阻断返回电流路径 |
| 地平面分割 | 仅在 ADC/DAC 边界 | 单点连接 |

### 7.2 地平面与电源平面

```
模拟电路叠层推荐：

L1: SIG（模拟信号布线，元件面）
L2: GND（完整模拟地平面）
L3: PWR（模拟电源平面）
L4: SIG（模拟信号布线，底层）

关键原则：
- L2 必须为完整 GND 平面，模拟区域下方无任何分割
- 电源平面不与地平面重叠（除非作为去耦电容）
- L1 和 L4 布线方向正交（减少层间耦合）
```

## 8. 屏蔽规则

### 8.1 保护走线（Guard Trace）

```
保护走线用于敏感模拟信号两侧：

  GND ── GND_Via ── GND ── GND_Via ── GND
   │                              │
  Analog_Signal ──────────────────
   │                              │
  GND ── GND_Via ── GND ── GND_Via ── GND

间距：保护走线与信号间距 10~15mil
过孔：每 100~200mil 一个接地过孔
效果：屏蔽噪声耦合，提供低阻抗返回路径
```

### 8.2 过孔围栏（Via Fencing）

高速/高频噪声敏感区域使用过孔围栏形成法拉第笼：

```
过孔围栏结构：

  GND_Via  GND_Via  GND_Via  GND_Via
    │        │        │        │
    │  ┌─────────────────┐   │
    │  │  敏感信号区域    │   │
    │  │  (模拟前端)     │   │
    │  └─────────────────┘   │
    │        │        │        │
  GND_Via  GND_Via  GND_Via  GND_Via

间距：过孔间距 100~200mil
层：贯穿所有信号层
效果：屏蔽外部 EMI，减少共模噪声
```

## 9. 电源规则

### 9.1 电源选择

| 电源类型 | 噪声水平 | 适用模拟电路 | 说明 |
|----------|---------|------------|------|
| LDO 线性稳压器 | 低（< 100μVrms） | 精密模拟前端 | 噪声最低 |
| 开关电源 | 高（> 10mVrms） | 不推荐直接供电 | 需后级 LDO 滤波 |
| 基准电压源 | 极低（< 10μV） | ADC/DAC 基准 | 超精密 |

### 9.2 模拟/数字电源分离

```
电源分离原则：

1. 模拟电源（AVDD）和数字电源（DVDD）使用独立 LDO
2. AVDD 专供运放/ADC/传感器模拟部分
3. DVDD 专供 MCU/逻辑/数字部分
4. AVDD 和 DVDD 不共平面（区域分割）
5. 模拟电源去耦：每器件 0.1μF + 10μF（MLCC X7R）

电源区划分：
  ┌─────────┬─────────┐
  │ AVDD    │ DVDD    │
  │ 模拟电源 │ 数字电源 │
  │ LDO     │ LDO     │
  └─────────┴─────────┘
```

### 9.3 去耦电容配置

| 器件类型 | 去耦方案 | 布局要求 |
|----------|---------|---------|
| 运放电源 | 0.1μF X7R + 10μF X7R | 每个电源引脚就近放置 |
| ADC/DAC | 0.1μF + 1μF + 10μF | 多级去耦，基准引脚加 1μF |
| LDO 输入 | 10μF + 0.1μF | 输入侧大容量 |
| LDO 输出 | 10μF X7R（按 IC 要求） | 按 ESR 稳定性要求选型 |
| 基准电压 | 1μF + 0.1μF | 基准输出端 |

## 11. 热设计规则

### 11.1 温度梯度控制

| 规则 | 要求 | 说明 |
|------|------|------|
| 精密器件远离热源 | ≥ 10mm 间距 | 防止热电偶效应 |
| 差分对热对称 | IN+ 和 IN- 等温线对称 | 消除热失调 |
| LDO 散热铜皮 | ≥ 100mm²（1oz） | 降低 LDO 热阻 |
| 热敏器件远离功率 | ≥ 15mm | 防止温度漂移 |

### 11.2 常见热相关问题

| 问题 | 机理 | 影响 | 预防 |
|------|------|------|------|
| 热电偶效应 | 不同金属接合处温差产生热电势 | 运放输入失调漂移 | 热对称布局、零漂移运放 |
| 漏电流温度依赖 | FR-4 绝缘电阻随温度降低（10 倍/25°C） | 高阻抗节点误差 | 保护环、降低环境温度 |
| 热失控（LDO） | 温度升高→电流增大→温度更高 | 器件烧毁 | 充分散热、热关断保护 |

## 附录A：模拟电路 DRC 规则快速配置

```
Altium 模拟 DRC 配置步骤：

1. Design » Classes → 创建网络分类
   - Analog_Signal, High_Z_Node
   - Analog_Power, Analog_GND
   - Digital_Signal, Clock

2. Design » Rules → 逐项配置规则
   - Electrical » Clearance：按 10.1 表
   - Routing » Width：按 10.2 表
   - Routing » Routing Layers：按 10.3 表
   - Manufacturing：按 10.5 表

3. 手动检查保护环和星形接地（DRC 无法自动检测）

4. Tools » Design Rule Check → 运行 DRC

5. Design » Rules » File » Export Rules → 导出规则
```

核心规则速查：

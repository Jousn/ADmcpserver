# 电源系统 DRC 规则模板

> 适用范围：功率等级 1W~100W+ 的电源系统（DC-DC 变换器、LDO、开关电源、线性稳压）
> 目标受众：AI设计辅助Skill，用于电源 PCB DRC 规则配置与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

电源系统的 PCB 设计核心目标是承载大电流、降低功率回路面积、控制温升和保证安规间距。与高速数字电路追求信号完整性不同，电源设计更关注电流承载能力、热管理和电磁兼容。不当的布线会导致效率下降、器件过热、EMI 超标甚至安规失效。本模板覆盖功率回路、电流承载、爬电距离、热铺铜和安全隔离的完整 DRC 规则集。

## 2. 功率等级与电流承载

### 2.1 功率等级分类

| 功率等级 | 电流范围 | 典型应用 | PCB 关注点 |
|----------|---------|---------|-----------|
| 低功率（1~10W） | < 2A | LDO、小功率 DC-DC | 常规线宽，一般散热 |
| 中功率（10~50W） | 2~10A | Buck/Boost DC-DC | 铜皮加宽，热铺铜 |
| 高功率（50~100W） | 10~30A | 多相 DC-DC、模块电源 | 大面积铺铜，热过孔 |
| 超高功率（100W+） | 30A+ | 服务器电源、工业电源 | 2oz 铜，独立散热层 |

### 2.2 IPC-2152 线宽电流承载表

**1oz 铜（35μm），温升 10°C，外部走线：**

| 电流 (A) | 最小线宽 (mil) | 最小线宽 (mm) | 截面积 (mil²) |
|----------|---------------|-------------|-------------|
| 0.5 | 5 | 0.13 | 5 |
| 1.0 | 10 | 0.25 | 10 |
| 2.0 | 15 | 0.38 | 30 |
| 3.0 | 20 | 0.51 | 60 |
| 5.0 | 50 | 1.27 | 175 |
| 8.0 | 100 | 2.54 | 400 |
| 10.0 | 150 | 3.81 | 600 |
| 15.0 | 300 | 7.62 | 1200 |
| 20.0 | 500 | 12.7 | 2000 |

**2oz 铜（70μm），温升 10°C，外部走线：**

| 电流 (A) | 最小线宽 (mil) | 最小线宽 (mm) |
|----------|---------------|-------------|
| 1.0 | 5 | 0.13 |
| 3.0 | 10 | 0.25 |
| 5.0 | 25 | 0.64 |
| 10.0 | 75 | 1.91 |
| 15.0 | 150 | 3.81 |
| 20.0 | 250 | 6.35 |

```
选型原则：
- 1oz 铜用于 < 5A 低/中功率
- 2oz 铜用于 5~20A 高功率
- > 20A 使用大面积铺铜 + 热过孔阵列
- 内层走线承载能力约为外层的 50~70%
- 降额原则：实际设计取表中值 × 1.3~1.5 倍安全裕量
```

## 3. 铜厚与铺铜规则

### 3.1 铜厚选择

| 铜厚 | 厚度 (μm) | 适用电流 | 适用场景 |
|------|---------|---------|---------|
| 0.5oz | 18 | < 1A | 信号层、低成本 |
| 1oz | 35 | 1~5A | 通用，标准 |
| 2oz | 70 | 5~20A | 大功率走线/平面 |
| 3oz | 105 | 10~40A | 超大功率，特殊制程 |
| 4oz+ | 140+ | > 20A | 超大功率，定制 |

### 3.2 铺铜规则

| 网络类型 | 铺铜方式 | 说明 |
|----------|---------|------|
| 功率输入/输出 | 大面积实心铺铜 | 最大散热和载流 |
| 开关节点（SW） | 实心铺铜 + 缩小面积 | 降低 EMI，平衡散热 |
| 地（GND/PGND） | 完整地平面 | 低阻抗返回路径 |
| 反馈/控制信号 | 细走线（8~10mil） | 远离功率区 |

### 3.3 热风焊盘（Thermal Relief）

```
热风焊盘用于大焊盘焊接，防止散热过快：

  正常连接              热风焊盘
  ┌────────┐        ┌────────┐
  │████████│        │██ ── ██│
  │████████│        │██ ── ██│  ← 4 条热风辐条
  │████████│        │██ ── ██│
  │████████│        │██ ── ██│
  └────────┘        └────────┘

  全连接（载流最优）    热风焊盘（焊接友好）

选型原则：
- 功率焊盘（MOSFET 漏极、电感焊盘）：全连接（最大化载流和散热）
- 小信号焊盘（电阻电容）：热风焊盘（焊接方便）
- GND 过孔焊盘：全连接（降低地阻抗）
```

## 4. 功率回路规则

### 4.1 功率回路面积最小化

```
开关电源功率回路（Buck 变换器示例）：

  ┌─── VIN ──────────┬──────┐
  │                  │      │
  │              ┌───┤ Q1   │
  │              │   │(HS)  │
  │              │   └──┬───┘
  │              │      │ SW（开关节点）
  │              │   ┌──┴───┐
  │              │   │ Q2   │
  │              │   │(LS) │
  │              │   └──┬───┘
  │              │      │
  └─── L_out ────┴──────┘
                    │
              ──────┬───── PGND

功率回路 = VIN → HS_FET → LS_FET → PGND → VIN

回路面积最小化原则：
1. HS MOSFET 和 LS MOSFET 尽量靠近放置
2. 输入电容紧邻 MOSFET 对放置
3. PGND 走线最短、最宽
4. SW 节点走线宽而短（降低 EMI）
5. 回路包围面积 < 1cm²（目标值）
```

### 4.2 输入电容布局

| 规则 | 要求 | 说明 |
|------|------|------|
| 输入电容位置 | 紧邻 MOSFET 对（< 5mm） | 最小化回路面积 |
| 输入电容类型 | MLCC（低 ESR/ESL）优先 | 高频去耦 |
| 大容量电容 | 稍远放置 | 低频储能 |
| 输入电容走线 | 宽铜皮直连 | 降低寄生电感 |

### 4.3 开关节点（SW）规则

| 规则 | 值 | 说明 |
|------|-----|------|
| SW 铺铜面积 | 最小化但兼顾散热 | EMI vs 热量权衡 |
| SW 走线远离敏感信号 | ≥ 30mil | 高 dv/dt 噪声耦合 |
| SW 走线远离板边 | ≥ 40mil | 辐射 EMI |
| SW 不穿越其他层 | 保持单层 | 减少层间耦合 |

## 5. 热管理规则

### 5.1 热铺铜

| 器件 | 散热方式 | 铜皮面积 | 说明 |
|------|---------|---------|------|
| MOSFET（SOT-23） | 顶层铺铜 | 50~100mm² | 小功率 |
| MOSFET（DPAK） | 顶层铺铜 + 热过孔 | 100~300mm² | 中功率 |
| MOSFET（D2PAK） | 顶层 + 底层铺铜 + 热过孔 | 300~600mm² | 大功率 |
| MOSFET（TO-220） | 外置散热器 | — | 独立散热 |
| 电感 | 顶层铺铜（避免下方） | — | 电感下方不布敏感信号 |
| LDO | 顶层铺铜 + 热过孔 | 按功耗计算 | 结温控制 |

### 5.2 热过孔阵列

```
热过孔阵列设计：

  MOSFET 焊盘（散热焊盘）
  ┌────────────────────────┐
  │ ○  ○  ○  ○  ○  ○  ○  │ ← 热过孔阵列
  │ ○  ○  ○  ○  ○  ○  ○  │
  │ ○  ○  ○  ○  ○  ○  ○  │
  │ ○  ○  ○  ○  ○  ○  ○  │
  │ ○  ○  ○  ○  ○  ○  ○  │
  └────────────────────────┘
        ↓ 导热到背面铜皮
  ┌────────────────────────┐
  │  背面散热铺铜           │
  └────────────────────────┘

参数：
- 过孔孔径：0.3mm（12mil）
- 过孔间距：1~2mm（40~80mil）
- 过孔数量：按功耗计算（每过孔约 1~3°C/W 热阻降低）
- 铜厚：≥ 1oz（2oz 优先）
```

### 5.3 温升控制目标

| 应用场景 | 最大允许温升 | 环境温度 | 目标结温 |
|----------|------------|---------|---------|
| 商用 | 40°C | 25°C | < 105°C |
| 工业 | 35°C | 50°C | < 125°C |
| 军用 | 30°C | 70°C | < 150°C |

## 6. 元件间距与爬电距离

### 6.1 电压相关间距（IEC 60950/62368）

| 工作电压 (V) | 最小电气间隙 (mm) | 最小爬电距离 (mm) | 说明 |
|-------------|-----------------|-----------------|------|
| < 60 | 0.4 | 0.4 | 安全电压 |
| 60~150 | 0.5~1.0 | 0.8~1.2 | 一般应用 |
| 150~300 | 1.5~2.0 | 1.5~2.5 | AC 220V |
| 300~600 | 3.0~5.0 | 3.0~5.0 | AC 380V |
| 600~1000 | 5.0~8.0 | 5.0~8.0 | 高压 |

```
爬电距离 vs 电气间隙：
- 爬电距离：沿绝缘表面的最短距离
- 电气间隙：空气中直线距离
- 爬电距离 ≥ 电气间隙（表面可能受污染）

污染等级影响：
- 等级 1（无污染）：间距最小
- 等级 2（一般污染）：标准值
- 等级 3（严重污染）：间距 × 1.5~2 倍
```

### 6.2 高低压隔离

```
隔离电源一次-二次间距要求：

  ┌─────────────────────────┐
  │  一次侧（高压区）        │
  │  AC 220V 整流/PFC        │
  │                          │
  │        ║ 隔离带 ║         │ ← 最小 6.4mm（加强绝缘）
  │        ║        ║         │
  │                          │
  │  二次侧（低压区）         │
  │  DC-DC 输出              │
  └─────────────────────────┘

加强绝缘：≥ 6.4mm（IEC 60950/62368）
基本绝缘：≥ 3.2mm
```

## 7. 电感/磁性元件布局规则

### 7.1 磁性元件间距

| 规则 | 要求 | 说明 |
|------|------|------|
| 电感间互感 | ≥ 5mm 间距 | 防止磁性耦合 |
| 电感方向 | 互相垂直排列 | 减少耦合 |
| 电感与敏感信号 | ≥ 5mm | 磁场干扰 |
| 电感下方 | 不布反馈/控制信号 | 磁场耦合噪声 |
| 变压器绕组 | 最短线段 | 降低漏感 |

### 7.2 电感布局原则

```
电感布局：

  错误：                      正确：
  ┌──────────────┐           ┌──────────────┐
  │              │           │              │
  │ [电感1] [电感2]│           │ [电感1]      │ ← 间距 ≥ 5mm
  │   平行排列    │           │              │
  │              │           │      [电感2] │ ← 方向垂直
  │              │           │              │
  └──────────────┘           └──────────────┘

原则：
1. 相邻电感方向垂直（减少互感）
2. 电感下方不布任何信号走线
3. 大电流电感远离反馈/控制电路
4. 开关电源电感和 MOSFET 尽量靠近
```

## 8. 输入/输出分离规则

### 8.1 输入输出隔离

| 规则 | 要求 | 说明 |
|------|------|------|
| 输入输出走线不交叉 | 物理分离 | 防止反馈振荡 |
| 输入输出电容分区 | 各自区域 | 降低耦合 |
| 反馈走线 | 独立路径 | 远离功率 SW 节点 |
| 输出采样点 | 在输出电容端 | 准确检测输出电压 |

### 8.2 反馈走线规则

```
反馈走线设计原则：

1. 反馈走线尽量短且直
2. 反馈走线远离 SW 节点（≥ 30mil）
3. 反馈走线布在内层（GND 参考层上方）
4. 反馈分压电阻靠近 IC 反馈引脚
5. 反馈走线使用 Kelvin 连接（在输出端采样）

Kelvin 连接：
  ┌── 输出 ──┬── 负载 ──┐
  │          │           │
  │     ┌────┘           │
  │     │ ← Kelvin 采样点（在输出电容正端）
  │     │
  └─────┴── 反馈走线 ── IC_FB
```

## 10. 安全规则

### 10.1 保险丝放置

| 规则 | 要求 | 说明 |
|------|------|------|
| 保险丝位置 | 输入端最前（连接器后第一器件） | 保护全部后级电路 |
| 保险丝间距 | 与周边器件 ≥ 2mm | 防止保险丝熔断时引燃 |
| 保险丝额定 | ≥ 最大工作电流 × 1.25~1.5 倍 | 避免误熔断 |

### 10.2 安规间距（IEC 60950/62368）

| 间距类型 | 基本绝缘 (mm) | 加强绝缘 (mm) | 辅助绝缘 (mm) |
|----------|-------------|-------------|-------------|
| 电气间隙（≤ 250V） | 1.5 | 3.0 | 1.0 |
| 爬电距离（≤ 250V） | 2.0 | 4.0 | 1.5 |
| 绝缘穿透距离 | — | 1.0 | 0.4 |

### 10.3 隔离要求

```
电源隔离要求：

1. 一次侧-二次侧隔离距离 ≥ 6.4mm（加强绝缘，250V）
2. 变压器满足隔离要求（三层绝缘线/骨架）
3. 光耦/磁耦跨隔离带，满足爬电距离
4. Y 电容跨隔离带时满足安规等级
5. PCB 开槽增加爬电距离（V 型槽）

隔离带开槽示例：
  ┌────────────┬──┬────────────┐
  │  一次侧     │槽│  二次侧     │
  │            │  │            │
  │  AC 输入   │  │  DC 输出   │
  │            │  │            │
  └────────────┴──┴────────────┘
       ← 6.4mm →
```

## 附录A：电源 DRC 规则快速配置

```
Altium 电源 DRC 配置步骤：

1. Design » Classes → 创建网络分类
   - Power_In, Power_Switch, Power_Out, Power_GND
   - Signal_GND, Control, Feedback

2. Design » Rules → 逐项配置规则
   - Electrical » Clearance：按 9.2 表
   - Routing » Width：按 9.3 表
   - Plane » Polygon Connect：按 9.4 表
   - Routing » Routing Via Style：按 9.5 表

3. 手动检查功率回路和隔离带（DRC 无法自动检测）

4. Tools » Design Rule Check → 运行 DRC

5. Design » Rules » File » Export Rules → 导出规则
```

## 附录B：电源系统 DRC 速查

```
核心规则速查：

间距：20mil（功率级），30mil（SW/反馈），60mil+（高压）
线宽：40mil+（功率，按电流），10mil（控制/反馈），30mil（地）
铜厚：1oz（< 5A），2oz（> 5A）
回路面积：最小化（< 1cm²）
热设计：铺铜 + 热过孔阵列（0.3mm 孔，1~2mm 间距）
```

> 适用范围：Xilinx/Altera FPGA Bank 供电、PLL/MMCM 时钟管理
> 版本：v1.0 | 更新日期：2026-09

## 1. Bank 供电设计

### 1.1 Bank 分组原则

```
Bank 分组策略:
  1. 按 IO 电压分组:
     - 3.3V IO → 同一 Bank
     - 1.8V IO → 同一 Bank
     - 1.2V IO → 同一 Bank

  2. 按功能分组:
     - DDR3 接口 → 独立 Bank (VCCO=1.5V)
     - SPI Flash → 独立 Bank
     - 高速收发器 → GTX Bank (专用VCC)
     - 调试LED/按钮 → 任意Bank

  3. Bank 间隔离:
     - 不同电压的Bank之间留间距
     - 避免跨越Bank区域的布线
     - 必要时在Bank边界加地过孔
```

### 1.2 VCCO 去耦

```
每个 Bank 的 VCCO 去耦:
  - 100nF × 2 (0402, 每Bank两个)
  - 4.7uF × 1 (0603, 每Bank一个)
  - 22uF × 1 (0805, 每2个Bank共享)

  电容位置:
    ┌──────────Bank 0──────────┐┌────Bank 34────┐
    │  100nF       4.7uF       ││ 100nF  4.7uF │
    │  100nF       22uF        ││               │
    └─────────────────────────┘└──────────────┘
```

## 2. 时钟管理

### 2.1 Xilinx 7系列时钟资源

| 资源 | 数量 | 功能 | 频率范围 |
|------|------|------|----------|
| BUFG | 32 | 全局时钟缓冲 | <7系列频率上限 |
| BUFR | 区域时钟 | 最多12 | 同上 |
| BUFIO | I/O时钟 | 每Bank对 | 高速IO |
| BUFH | 水平时钟 | 每行2个 | - |
| MMCM | 混合模式时钟管理 | 最多12 | 10~1600MHz |
| PLL | 锁相环 | 2~4 | 10~1600MHz |

### 2.2 MMCM 配置

```
MMCM (混合模式时钟管理器) 功能:
  1. 频率合成: 输入×M/D = 输出 (0.001~0.999精度)
  2. 相移: 0~360°, 步进 1/(8×M) × T_in
  3. 占空比: 50%/25%/75%等
  4. 时钟切换: 双输入冗余
  5. 抖动滤波: 可选带宽

  框图:
    CLKIN1 ─┐
            ├─→ /M ─→ VCO ─→ /D ─→ CLKOUT0..6
    CLKIN2 ─┘              │
            CLKINSEL        └→ CLKOUTFB ─→ /M (反馈)

  典型应用:
    输入: 50MHz 单端
    输出0: 100MHz (系统时钟)
    输出1: 200MHz (DDR参考)
    输出2: 25MHz (以太网)
    输出3: 10MHz (UART)
```

### 2.3 全局时钟网络

```
全局时钟 (BUFG) 特点:
  - 到达所有逻辑单元 (CLB/BRAM/DSP)
  - 偏斜 < 100ps (同器件内)
  - 抖动 < 50ps
  - 驱动能力强
  - 每7系列约32个BUFG

使用原则:
  1. 所有同步逻辑用全局时钟
  2. 高扇出时钟必须用BUFG
  3. 内部生成的时钟(分频等)过BUFG再使用
  4. 外部时钟输入首选CCIO引脚→BUFG
  5. BUFG资源有限, 合理分配
```

### 2.4 时钟布线规则

```
时钟信号 PCB 布线:
  1. 外部时钟走在内层(带状线)
  2. 差分时钟对称走线
  3. 远离开关电源和高速数据线
  4. 最短路径到FPGA时钟引脚
  5. 参考平面完整(无开窗/分割)
  6. 过孔处加地回流过孔

时钟引脚分配:
  ┌────────FPGA────────────┐
  │                        │
  │  CCIO_P ←── 50MHz OSC  │  ← 单端时钟
  │                        │
  │  MRCC_P ←── 100MHz Diff│  ← 差分时钟(跨区域)
  │  MRCC_N                │
  │                        │
  │  SRCC_P ←── 内部BUFG   │  ← 区域时钟
  │  SRCC_N                │
  └────────────────────────┘
```

## 3. PLL 设计要点

### 3.1 PLL vs MMCM

| 特性 | PLL | MMCM |
|------|-----|------|
| 频率合成 | ✓ | ✓ |
| 相移 | 有限 | 精细 |
| 占空比调节 | 50% | 可调 |
| 抖动滤波 | ✓ | ✓(更好) |
| 动态相位 | ✗ | ✓ |
| 动态重新配置 | ✗ | ✓(DRP) |

```
选择原则:
  - 简单倍频/分频 → PLL (省资源)
  - 精细相移/占空比/动态配置 → MMCM
```

### 3.2 PLL 锁定检测

```
PLL LOCK 信号:
  - LOCK 高: PLL 输出稳定
  - LOCK 低: PLL 未锁定(输出不稳定)

  使用方式:
    1. LOCK → MCU/LED (状态指示)
    2. LOCK → 复位逻辑 (等PLL锁定后释放复位)
    3. LOCK → 时钟切换 (多PLL冗余切换)

  电路:
    ┌─── PLL ────┐
    │  CLKIN →   │
    │  CLKOUT    │
    │  LOCK ──────┘──→ AND ──→ FPGA内部复位释放
    └────────────┘
```

## 4. 时钟冗余设计

### 4.1 双时钟冗余

```
双时钟方案:
  主时钟: TCXO 100MHz (±0.5ppm)
  备用时钟: 普通 OSC 100MHz (±50ppm)

  ┌── TCXO ──→ CLKIN1 ─┐
  │                     ├─→ MMCM ─→ 系统时钟
  └── OSC  ──→ CLKIN2 ─┘
                     │
                CLKINSEL (MCU控制)

  正常: 用TCXO (低抖动)
  TCXO故障: MCU切换到OSC
```

### 4.2 时钟监控

```
时钟监控电路 (FPGA内部):
  1. 频率检测: 计数器+参考时钟
     - 主时钟频率 = 预期值 ± 5%
     - 超出范围 → 报警/切换

  2. 丢失检测: 边沿检测
     - 时钟停止 → 报警/切换备用

  3. 抖动检测: 长期频率平均
     - 累积相位偏差 > 阈值 → 报警
```

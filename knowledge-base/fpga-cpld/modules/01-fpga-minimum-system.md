# FPGA 最小系统设计

> 适用范围：Xilinx/Intel(Altera) FPGA 最小系统硬件设计
> 版本：v1.0 | 更新日期：2026-09

## 1. FPGA 最小系统组成

```
FPGA 最小系统 = 电源 + 时钟 + 配置 + JTAG + IO + 复位

  ┌─────────────────────────────────────────┐
  │                 FPGA                    │
  │  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐   │
  │  │Core │  │IO   │  │PLL  │  │BRAM│   │
  │  │Logic│  │Bank │  │MMCM │  │DSP │   │
  │  └──┬──┘  └──┬──┘  └──┬──┘  └──┬──┘   │
  │     │        │        │        │       │
  │  VCCINT    VCCIO   VCCAUX    GND      │
  │     │        │        │                │
  └─────┴────────┴────────┴────────────────┘
        │          │        │
     电源序列    IO供电   辅助电源
```

## 2. 电源设计

### 2.1 电源域

| 电源域 | Xilinx 名称 | 典型电压 | 电流范围 | 去耦 |
|--------|------------|----------|----------|------|
| Core | VCCINT | 0.95V~1.0V (7系列) | 0.5~10A+ | 大量MLCC |
| IO Bank | VCCO | 1.2V~3.3V | 0.1~2A/bank | 每bank去耦 |
| Auxiliary | VCCAUX | 1.8V~2.5V | 10~200mA | 低噪声 |
| Analog Aux | VCCAUX_IO | 1.8V | 10~50mA | 极低噪声 |
| MGT (GTX) | VCCINT_IO | 0.95V~1.2V | 100~500mA | 低噪声 |
| MGT Analog | AVTT/AVCC | 1.2V/0.95V | 100mA | 极低噪声 |

### 2.2 去耦电容方案

```
Xilinx Artix-7 (XC7A35T) 去耦方案:

VCCINT (1.0V, 峰值电流~1A):
  100nF × 8  (0402, 均匀分布)
  1uF × 4    (0603, 均匀分布)
  10uF × 2   (0805, 近IC)
  47uF × 1   (钽电容, IC附近)

VCCO (每个Bank, 如3.3V):
  100nF × 2  (每bank)
  4.7uF × 1  (每bank)

VCCAUX (1.8V):
  100nF × 2
  4.7uF × 1
  磁珠隔离 (600Ω@100MHz)

VCCAUX_IO (1.8V):
  100nF × 2
  磁珠+铁氧体隔离
```

## 3. 时钟设计

### 3.1 系统时钟

```
FPGA 系统时钟方案:
  1. 单端时钟 (LVECMOS):
     - 50MHz~200MHz
     - 走线短, 单点
     - 适合一般逻辑

  2. 差分时钟 (LVDS/LVPECL):
     - 100MHz~700MHz
     - 低抖动 (<1ps)
     - 长距离传输
     - 时钟分配器输出

  3. 外部有源振荡器:
     - TCXO (±0.5ppm) → 精密时钟
     - 普通OSC (±50ppm) → 通用
     - 差分OSC → 高速
```

### 3.2 时钟引脚

| Xilinx 7系列 | 引脚类型 | 功能 |
|-------------|----------|------|
| MRCC | 多区域时钟 | 跨区域, 不进BUFG |
| SRCC | 单区域时钟 | 区域内, 不进BUFG |
| 全局时钟 | CCIO | 可进BUFG/MCMM |

```
时钟进 FPGA 路径:
  外部时钟 → CCIO 引脚 → IBUFG → BUFG/MMCM → 全局时钟网络
```

## 4. 复位设计

```
复位方案:
  1. 上电复位 (POR):
     - Xilinx 内置 POR 监控 VCCINT/VCCAUX
     - 上电时序完成后自动释放

  2. 外部手动复位:
     - 按钮 + RC 延迟 (10ms~100ms)
     - 施密特触发器 (74LVC1G14)
     - 上拉电阻 10k
     - ESD 保护 TVS

  3. 复位去抖:
     - 硬件: RC + 施密特
     - 软件: FPGA 内部计数器 (4 bit+)

  复位信号:
     ┌───────────┐
     │ FPGA      │
     │ /RST ──────┤ ←── 上拉 10k + 按钮/电源监控
     │           │     + 去抖电路
     └───────────┘
```

## 5. IO 设计

### 5.1 IO 标准

| IO 标准 | VCCO | 输入参考 | 差分 | 典型应用 |
|---------|------|----------|------|----------|
| LVCMOS33 | 3.3V | - | - | 通用 |
| LVCMOS18 | 1.8V | - | - | 低压通用 |
| LVCMOS12 | 1.2V | - | - | 超低压 |
| LVTTL | 3.3V | - | - | 兼容5V |
| LVDS | 2.5V | - | Yes | 高速差分 |
| LVPECL | 2.5V | - | Yes | 高速差分 |
| SSTL15 | 1.5V | VREF | - | DDR3 |
| SSTL18 | 1.8V | VREF | - | DDR2 |
| TMDS | 3.3V | - | Yes | HDMI/DVI |

### 5.2 IO 注意事项

```
1. IO 电压匹配:
   - 外部器件电压必须 = FPGA VCCO
   - 3.3V 器件 → VCCO = 3.3V
   - 1.8V 器件 → VCCO = 1.8V
   - 混合电压 → 用Bank分组

2. Bank 供电:
   - 每个 Bank 独立 VCCO
   - 同一Bank 内所有IO必须同电压
   - 不同Bank 可不同电压

3. 上电时序:
   - VCCINT → VCCAUX → VCCO (推荐)
   - VCCINT 完成后 VCCO 才能稳定

4. 内部上拉/下拉:
   - 未用IO: 设为Input+内部上拉
   - 不悬空 (防静电)
```

## 6. Xilinx 7 系列引脚分配规则

```
7系列引脚类型:
  1. 普通 IO: 可用作通用 IO
  2. 多功能 IO (MIO): 支持 JTAG/配置/普通IO
  3. 配置引脚: 只在配置阶段使用
  4. 专用引脚: GND/VCC/JTAG/时钟/启动
  5. 收发器引脚 (GTX/GTH): 高速串行

分配规则:
  1. 时钟信号 → CCIO 引脚 (低偏斜)
  2. 差分时钟 → MRCC/SRCC 引脚
  3. 控制信号 (复位/使能) → 控制引脚
  4. 高速收发 → GTX/GTH 引脚
  5. 配置 → 专用配置引脚
  6. 通用 → 普通 IO
```

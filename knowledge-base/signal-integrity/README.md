# 信号完整性（Signal Integrity）知识库 — 总索引

> 本知识库面向 AI Skills 和 Agent 的结构化检索，覆盖高速数字电路设计中信号完整性分析与设计全流程（传输线理论 → 阻抗控制 → DDR 路由 → 高速串行 → 时钟分配 → 串扰分析 → 电源完整性），适用于 Altium Designer 环境下的高速数字、混合信号、通信系统设计场景。

## 3. 按设计阶段的推荐检索路径

### 3.1 原理图阶段

```
确定高速接口类型
    │
    ├─▶ [模块 02] DDR → 确定等长匹配/ODT/终端策略
    ├─▶ [模块 03] 高速串行 → 确定预加重/通道规格
    ├─▶ [模块 04] 时钟分配 → 确定时钟拓扑/抖动要求
    └─▶ [模块 06] 电源完整性 → 确定 PDN 去耦方案
```

### 3.2 PCB 布局阶段

```
层叠设计
    │
    ├─▶ [模块 01] 阻抗计算 → 确定线宽/线距/介质厚度
    ├─▶ [模块 05] 串扰防护 → 确定线距/屏蔽策略
    └─▶ [模块 06] PDN 设计 → 确定电源平面/去耦布局
```

### 3.3 PCB 布线阶段

```
路由执行
    │
    ├─▶ [模块 02] DDR → 猫眼路由/写均衡/数据组等长
    ├─▶ [模块 03] 高速串行 → 差分对路由/AC 耦合
    └─▶ [模块 04] 时钟 → 长度匹配/最小化分支
```

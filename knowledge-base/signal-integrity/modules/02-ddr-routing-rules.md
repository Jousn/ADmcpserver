# DDR 存储器路由规则

> 适用范围：DDR3/DDR4/DDR5 PCB 布局布线设计
> 版本：v1.0 | 更新日期：2026-09

---

## 1. DDR 拓扑结构

### 1.1 常见拓扑

| 拓扑 | 适用 | 优点 | 缺点 |
|------|------|------|------|
| 点对点 | 1颗粒 | 最简单/最佳SI | 不可扩展 |
| Fly-by(菊花链) | 多颗粒 | SI最好/反射小 | 布线长/等长难 |
| T-分支 | 2颗粒 | 等长容易 | 反射/振铃 |
| T-Tree | 4颗粒 | 对称 | 分支多/SI差 |
| Balanced-T | 2~4颗粒 | 折中方案 | 复杂 |

### 1.2 DDR4 拓扑推荐

```
DDR4 推荐 Fly-by 拓扑:
  CPU ──[CA/CLK 菊花链]── DDR1 ── DDR2 ── DDR3 ── DDR4
  │                                                    │
  └──[Data 点对点]── 每个 DDR 独立数据组 ──────────────┘

  CA/CLK: Fly-by + ODT 终端
  DATA: 点对点 + DQS 差分 + ODT
  ADDR/CMD: 共享总线 + Fly-by 终端
```

## 2. 布线规则

### 2.1 线宽与阻抗

| 信号类型 | 阻抗 | 线宽(微带) | 线宽(带状) | 层建议 |
|----------|------|-----------|-----------|--------|
| 地址/命令 | 50Ω单端 | 5mil (H=4) | 4mil (H=5) | 内层优先 |
| 时钟 | 100Ω差分 | 5/6mil | 4/5mil | 内层 |
| DQ/DQS | 40Ω单端 | 7mil (H=4) | 6mil (H=5) | 外层优先 |
| DQS差分 | 80Ω差分 | 5/5mil | 4/4mil | 同DQ层 |

### 2.2 等长匹配

| 信号组 | 组内等长 | 组间等长 | 蛇形绕线限制 |
|--------|----------|----------|-------------|
| DQ[7:0]+DQS+DM | ±25mil | - | 蛇形高度<3×W |
| DQ[15:8]+DQS+DM | ±25mil | - | 蛇形间距>3×W |
| ADDR/CMD | ±50mil | - | - |
| CLK差分 | ±10mil(组内) | 对ADDR±100mil | - |
| 各DQ组之间 | - | ±100mil | - |

**DDR4-3200 更严格要求**:

| 信号组 | 组内偏差 | 组间偏差 |
|--------|----------|----------|
| DQ/DQS/DM | ±10mil | - |
| ADDR/CMD | ±25mil | - |
| CLK | ±5mil | 对ADDR±50mil |
| 各DQ组间 | - | ±50mil |

### 2.3 走线层和过孔

```
推荐布线层分配 (6层板):
  L1 (Top):    DQ组1 (点对点短走线)
  L2 (GND):    完整地平面
  L3 (SIG):    ADDR/CMD (带状线)
  L4 (GND):    完整地平面
  L5 (PWR):    电源平面 (VDD/VTT)
  L6 (Bottom): DQ组2 (点对点短走线)

过孔规则:
  - 每个信号转换层用同一过孔类型
  - 时钟差分对过孔对称
  - 过孔残桩 < 10mil (或用背钻/HDI)
  - 信号过孔旁加地过孔 (回流路径)
```

## 3. 电源设计

### 3.1 DDR 电源域

| 电源 | 电压 | 电流(典型) | 去耦方案 | 布线要求 |
|------|------|-----------|----------|----------|
| VDD | 1.5V(DDR3)/1.2V(DDR4) | 2~8A | 100nF×8 + 10uF×4 | 低阻抗平面 |
| VTT | 0.75V(DDR3)/0.6V(DDR4) | 1~4A | 100nF×4 + 10uF×2 | 终端电源 |
| VREF | 0.75V/0.6V | <10mA | 100nF×2 + 1uF | 噪声<±10mV |

### 3.2 VTT 终端

```
VTT 要求:
  - 电压 = VDD/2
  - 必须能吸入和输出电流 (推挽 LDO 或专用 VTT regulator)
  - 噪声 < ±10mV
  - 去耦: 每颗粒旁 100nF + 每8颗 10uF

推荐 VTT IC:
  - DDR3: LP2975 (TI) / RTS8510 (Richtek)
  - DDR4: TPS51206 (TI) / RT7294 (Richtek)
```

## 4. ODT (On-Die Termination)

| DDR 代 | ODT 值 | ODT 控制信号 | 效果 |
|--------|--------|-------------|------|
| DDR2 | 75/150Ω | A0/A1/A2 | 基本终端 |
| DDR3 | 20/30/40/60/120Ω | MR1 | 多档选择 |
| DDR4 | 34/40/48/60/120/240Ω | MR1/MR2 | 精细控制 |
| DDR5 | DQ: 40/48/60/80/120/240Ω | MR3 | 独立DQ控制 |

## 5. 布局建议

```
DDR 布局顺序:
  1. DDR 颗粒紧靠 CPU/MCU (走线尽量短)
  2. 颗粒间距: 每颗间留 50~100mil 间距 (去耦+过孔空间)
  3. VTT 稳压器放在 Fly-by 链末端附近
  4. 去耦电容放在 DDR 颗粒背面 (底面)
  5. 时钟差分对走在内层 (带状线, 参考地平面)

DQ 组布线:
  - 每组 8 bit DQ + 1 DQS + 1 DM 紧密走在一起
  - 组间间距 > 3×线宽
  - DQ 和 DQS 同层走线
  - DQS 差分对始终保持在同层
```

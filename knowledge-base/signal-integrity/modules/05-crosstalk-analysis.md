# 串扰分析与防护

> 适用范围：高速数字 PCB 串扰分析、防护设计与布局布线规则
> 版本：v1.0 | 更新日期：2026-09

---

## 1. 串扰机理

```
攻击线(Aggressor) ←→ 受害线(Victim)

串扰类型:
  近端串扰 (NEXT): 受害端靠近攻击驱动端 → 同方向耦合
  远端串扰 (FEXT): 受害端远离攻击驱动端 → 反方向耦合

耦合机制:
  电容耦合: 线间寄生电容 → 高频耦合为主
  电感耦合: 互感 → 磁场耦合为主

串扰电压:
  V_xtalk ∝ (Cm×dV/dt + Lm×di/dt) × Z0

  其中:
    Cm = 互容 (pF/inch)
    Lm = 互感 (nH/inch)
    Z0 = 受害线阻抗
```

---

## 2. 串扰估算

### 2.1 经验公式

```
微带线串扰 (近似):
  NEXT = 1 / (1 + (D/H)²) (近端)
  FEXT = K × L × (1 / (1 + (D/H)²)) (远端)

其中:
  D = 线距 (mil)
  H = 介质厚度 (mil)
  L = 耦合长度 (inch)
  K = 材料常数 (FR-4 ≈ 0.001~0.005)

典型 FR-4 串扰表 (50Ω 微带线, H=4mil):
  线距D=2W (8mil):  NEXT≈5%,  FEXT≈2%/inch
  线距D=3W (12mil): NEXT≈2%,  FEXT≈1%/inch
  线距D=5W (20mil): NEXT≈0.5%,FEXT≈0.2%/inch
  线距D=10W(40mil): NEXT≈0.1%,FEXT≈0.05%/inch
```

### 2.2 串扰容限

| 受害信号类型 | 容许串扰 | 线距要求 |
|-------------|----------|----------|
| 时钟差分对 | <0.5% | >5W + 包地 |
| DDR DQ/DQS | <1% | >3W |
| PCIe/USB差分 | <0.5% | >5W + 包地 |
| 模拟信号 | <0.1% | >10W 或包地+隔离 |
| 通用数字 | <5% | >2W |
| GPIO/控制 | <10% | >1W |

## 3. 防护规则

### 3.1 3W 规则

```
3W 规则:
  线间距 ≥ 3×线宽 → 串扰 < 2%

推广:
  5W 规则 → 串扰 < 0.5% (时钟/差分)
  10W规则 → 串扰 < 0.1% (模拟/高精度)

应用:
  W=5mil → 3W=15mil, 5W=25mil, 10W=50mil
  W=4mil → 3W=12mil, 5W=20mil, 10W=40mil
```

### 3.2 包地屏蔽

```
包地 (Guard Trace):
  1. 受害线两侧各一根地线 (W_guard = 0.5~1×W_signal)
  2. 地线两端接地过孔
  3. 地线上每 1/10 波长加一个地过孔
  4. 地线与信号线间距 = 1~2W

效果:
  包地 + 过孔 → 串扰降低 50~90%
  适用于: 模拟/时钟/高速差分
```

### 3.3 层间隔离

```
层间串扰防护:
  1. 信号层之间必须有完整参考平面 (GND)
  2. 相邻信号层走线方向垂直 (L3 水平, L4 垂直)
  3. 高速信号层下方/上方必须为 GND 平面
  4. 电源平面不可作为高速信号的参考平面

推荐层叠:
  L1(Top)  信号 ←── 微带线, 短走线
  L2       GND  ←── 完整地平面
  L3       信号 ←── 带状线, 高速信号
  L4       GND  ←── 完整地平面
  L5       PWR  ←── 电源平面
  L6(Bot)  信号 ←── 微带线, 短走线
```

### 3.4 过孔串扰

```
过孔串扰防护:
  1. 信号过孔旁加地过孔 (提供回流路径)
  2. 地过孔距信号过孔 < 30mil
  3. 每个信号过孔至少 1 个地过孔
  4. 差分对过孔对称 (2 个地过孔在两侧)

  示例:
    差分对过孔布局:
      GND  via     GND  via
        \           /
    SIG_P via ── SIG_N via
        /           \
      GND  via     GND  via
```

## 4. 关键串扰场景

### 4.1 模拟-数字隔离

```
混合信号板串扰防护:
  1. 模拟区和数字区物理隔离 (>50mil 间距)
  2. AGND/DGND 平面分割, 单点连接
  3. 模拟信号不跨越数字区
  4. 数字信号不跨越模拟区
  5. ADC/DAC 芯片跨越 AGND/DGND 边界

  布局:
    ┌──────────────┐┌──────────────┐
    │  模拟区      ││  数字区      │
    │  (AGND)      ││  (DGND)      │
    │  运放/ADC    ││  MCU/DDR     │
    │              ││              │
    └──────┬───────┘└──────┬───────┘
           │  单点连接(0Ω/磁珠)│
           └──────────────────┘
```

### 4.2 高速差分对间串扰

```
差分对间串扰:
  1. 同组差分对间距 > 3W
  2. 不同组差分对间距 > 5W
  3. 平行走线长度最小化
  4. 必要时在差分对间加地屏蔽线

  示例 (USB3 差分对):
    ┌─TX+──TX-─┐  ← 对内线距 1S
    │          │
    │  地线    │  ← 对间屏蔽
    │          │
    └─RX+──RX-─┘  ← 对内线距 1S
    ←───对间距 5W───→
```

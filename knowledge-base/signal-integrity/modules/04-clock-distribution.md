## 2. 时钟信号类型

### 2.1 单端 vs 差分

| 信号类型 | 电平 | 抖动 | 频率上限 | 应用 |
|----------|------|------|----------|------|
| LVCMOS | 1.8V/3.3V | 基准+50fs | <200MHz | MCU通用 |
| LVTTL | 3.3V | 基准+80fs | <100MHz | 通用 |
| LVPECL | 800mV | 基准+30fs | <3GHz | 高速/低抖动 |
| CML | 400mV | 基准+20fs | <10GHz | 高速串行 |
| LVDS | 350mV | 基准+40fs | <2GHz | 通信/DDR |
| HCSL | 700mV | 基准+30fs | <2GHz | PCIe |

### 2.2 PCIe 时钟要求

```
PCIe 参考时钟 (100MHz, HCSL):
  - 频率: 100MHz ±300ppm (Gen3)
  - 抖动: <3ps RMS (12kHz~20MHz 积分)
  - 占空比: 50% ±5%
  - 上升时间: 0.4~1.5ns (20%~80%)
  - 差分电压: 700mV ±10%
  - 共模电压: 300mV

布线:
  - 差分对 100Ω 差分阻抗
  - 线长 < 6 inch (推荐 < 3 inch)
  - 源端串阻 33Ω (减小过冲)
```

## 3. 抖动分析

### 3.1 抖动类型

| 类型 | 来源 | 频率范围 | 可消除 |
|------|------|----------|--------|
| RJ(随机抖动) | 热噪声/散粒噪声 | 无界 | 不可 |
| PJ(周期抖动) | 电源纹波/EMI | 有界 | 部分 |
| DDJ(数据相关) | ISI/反射 | 依赖数据 | 可(均衡) |
| BUJ(有界不相关) | 串扰 | 有界 | 可(隔离) |

### 3.2 抖动预算

```
总抖动(TJ) = DJ + 14.069×RJ (BER=1e-12)

PCIe Gen3 时钟抖动预算:
  TJ_budget = 3.0ps (12kHz~20MHz)
  分配:
    DJ: 2.0ps
    RJ: 0.071ps RMS (→14.07×0.071=1.0ps)
  
  实际测量:
    时钟IC RJ: 0.05ps RMS → 0.7ps
    PCB 贡献 DJ: 0.3ps
    串扰 BUJ: 0.2ps
    总计: 0.7+0.5 = 1.2ps < 3.0ps ✓
```

### 3.3 相位噪声

```
相位噪声到抖动的转换:
  RJ(rms) = sqrt(2) / (2πf) × 10^(L/20) × sqrt(Δf)

  其中:
    f = 时钟频率
    L = 相位噪声 (dBc/Hz)
    Δf = 积分带宽

典型 100MHz 时钟 IC 相位噪声:
    100Hz:  -70 dBc/Hz
    1kHz:   -100 dBc/Hz
    10kHz:  -120 dBc/Hz
    100kHz: -130 dBc/Hz
    1MHz:   -140 dBc/Hz
    10MHz:  -150 dBc/Hz
```

## 4. 时钟布线规则

```
时钟信号布线 5 条黄金法则:

1. 最短路径:
   - 时钟源到负载尽量短 (< 6 inch)
   - 避免90度弯折, 用圆弧或45度

2. 内层优先:
   - 时钟走在带状线层 (两个参考平面之间)
   - 避免走在外层 (暴露在 EMI 源中)

3. 远离干扰:
   - 与其他信号间距 > 5×线宽
   - 远离开关电源/DC-DC 电感
   - 不与时钟差分对交叉

4. 参考平面完整:
   - 时钟线下方参考平面无开窗/分割
   - 过孔处加地回流过孔

5. 终端匹配:
   - 源端串联: Rs = Z0 - R_driver
   - 差分终端: 100Ω 跨接
   - HCSL: 50Ω 到地 (每端)
```

## 5. DDR 时钟特殊规则

```
DDR 时钟路由 (Fly-by 拓扑):
  1. CLK/CLK# 差分对走在内层 (L3 或 L4)
  2. Fly-by 顺序: CPU → DDR1 → DDR2 → ... → 终端
  3. 每颗 DDR 处不产生分支 (T 型连接 = 短柱 <50mil)
  4. 差分对等长: < 5mil 偏差
  5. 终端: 100Ω 差分跨接在链末端
  6. CLK 与 ADDR/CMD 同层同区域走线
  7. CLK 与 ADDR/CMD 长度差 < 100mil
```

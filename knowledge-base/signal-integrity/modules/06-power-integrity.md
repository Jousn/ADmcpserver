# 电源完整性设计

> 适用范围：高速数字 PCB 电源分配网络（PDN）设计、去耦优化与平面规划
> 版本：v1.0 | 更新日期：2026-09

---

## 1. PDN 基础

### 1.1 电源分配网络组成

```
电源路径:
  VRM → PCB 电源平面 → 去耦电容 → IC 电源引脚 → 芯片内电容

PDN 阻抗目标:
  Z_target = (V_ripple × 0.5) / (I_transient × 0.5)
  
  其中:
    V_ripple = 允许纹波 (典型 VDD×5%)
    I_transient = 瞬态电流 (典型 I_max×0.5)

  示例:
    VDD=1.2V, 纹波=60mV, I_trans=3A
    Z_target = 0.06/3 = 20mΩ → PDN 阻抗 < 20mΩ
```

### 1.2 频率域分析

| 频率范围 | PDN 贡献者 | 阻抗特性 |
|----------|-----------|----------|
| DC~1kHz | VRM | 低阻抗 (<10mΩ) |
| 1kHz~100kHz | 大容量电容 (钽/电解) | 中阻抗 |
| 100kHz~10MHz | MLCC 去耦电容 | 低阻抗 |
| 10MHz~100MHz | 电源平面电容 | 中低阻抗 |
| >100MHz | 芯片内电容 + 封装 | 封装依赖 |

## 2. 去耦电容策略

### 2.1 去耦网络设计

```
去耦电容网络设计步骤:
  1. 确定 Z_target (见 1.1)
  2. 确定 IC 瞬态电流谱 (从数据手册或仿真)
  3. 从高频到低频逐步添加电容:
    a. 芯片内/封装电容 (无法控制, IC厂商已固定)
    b. MLCC 0402 100nF (高频, 最近IC)
    c. MLCC 0402/0603 10nF (更高频)
    d. MLCC 0603 1uF (中频)
    e. MLCC 0805 10uF (低频)
    f. 钽/铝 100uF~1000uF (DC~低频)
  4. 每步检查 PDN 阻抗 < Z_target
  5. 优化数量/位置使阻抗曲线平坦
```

### 2.2 MLCC 直流偏压降额

```
MLCC 实际容值 = 标称容值 × (1 - DC偏压降额)

典型降额 (X5R/X7R):
  额定电压 10V, 1uF 0603:
    0V → 1.0uF
    5V → 0.7uF (70%)
    10V → 0.4uF (40%)

  额定电压 16V, 10uF 0805:
    0V → 10uF
    5V → 7uF (70%)
    12V → 4uF (40%)

设计原则:
  1. 工作电压 < 50% 额定电压 (留 50% 裕量)
  2. 使用降额后容值计算阻抗
  3. 高频段用多个 0402 100nF 而非一个大电容
```

### 2.3 去耦电容数量计算

```
计算公式 (近似):
  N = (I_trans × ΔT) / (C × ΔV × 0.5)
  
  其中:
    I_trans = 瞬态电流
    ΔT = 电流上升时间
    C = 单个电容容值
    ΔV = 允许纹波

示例 (DDR4 VDD 1.2V, I_trans=3A, ΔT=1ns, ΔV=60mV):
  100nF 0402: N = (3×1ns) / (0.1uF×60mV×0.5) = 1
  但需考虑 ESL/ESR 和频率特性 → 实际放 4~8 个

  总去耦方案:
    4 × 100nF 0402 (最近IC)
    2 × 10nF 0402 (更近IC)
    2 × 1uF 0603 (中间)
    1 × 10uF 0805 (远端)
    1 × 100uF 钽 (大容量)
```

## 3. 电源平面设计

### 3.1 平面阻抗

```
电源平面阻抗 (平板电容):
  C_plane = ε0 × εr × A / H
  
  其中:
    A = 重叠面积 (mm²)
    H = 介质厚度 (mm)
    εr = 介电常数 (FR-4 ≈ 4.2)

  示例:
    A=50×50mm, H=0.1mm (4mil)
    C = 8.85e-12 × 4.2 × 2500 / 0.0001 = 0.93uF
    这是天然的高频去耦电容

设计原则:
  1. 电源平面紧邻地平面 (间距 < 5mil)
  2. 平面面积尽量大
  3. 不在平面下方/上方走高速信号
  4. 避免平面分割/开窗
```

### 3.2 平面谐振

```
平面谐振频率:
  f_res = c / (2×L×sqrt(εr))
  
  示例 (50×50mm平面):
    f_res = 3e8 / (2×0.05×2.05) = 1.46GHz
    
    谐振频率附近阻抗激增 → 需去耦电容压低

防护方法:
  1. 在平面谐振频率附近放 MLCC
  2. 平面边缘放 EBG (电磁带隙) 结构
  3. 避免谐振频率与 IC 开关频率重合
```

## 4. 电源层叠设计

### 4.1 推荐层叠

```
6层板 (常用):
  L1 (Top)  Signal ←── 元件/短走线
  L2        GND   ←── 完整地平面
  L3        PWR   ←── 电源平面 (紧邻L2, 平面电容)
  L4        GND   ←── 完整地平面
  L5        Signal ←── 内层信号
  L6 (Bot)  Signal ←── 元件/短走线

8层板 (高速优化):
  L1 (Top)  Signal
  L2        GND   ←── 参考平面
  L3        Signal ←── 高速信号 (带状线)
  L4        PWR   ←── 电源平面
  L5        GND   ←── 参考平面
  L6        Signal ←── 高速信号 (带状线)
  L7        GND   ←── 参考平面
  L8 (Bot)  Signal

10层板 (DDR4/5 优化):
  L1 (Top)  Signal (DQ组1)
  L2        GND
  L3        Signal (ADDR/CMD)
  L4        GND
  L5        PWR (VDD/VTT)
  L6        GND
  L7        Signal (CLK差分)
  L8        GND
  L9        Signal (DQ组2)
  L10(Bot)  Signal
```

### 4.2 电源平面分割

```
分割原则:
  1. 不同电压平面可同层但物理分离
  2. 分割线宽度 > 20mil (避免边缘场串扰)
  3. 分割线不与高速信号线平行
  4. 跨越分割区的信号必须有桥接电容(0Ω或0.1uF)
  
  示例:
    +3V3 ─────┬──────────┐
              │          │
              │  桥接0Ω  │
              │          │
    +1V2 ─────┴──────────┘
```

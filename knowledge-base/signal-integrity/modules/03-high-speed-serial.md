# 高速串行接口设计

> 适用范围：PCIe/USB3/SATA/MIPI CSI-2 等高速串行链路设计
> 版本：v1.0 | 更新日期：2026-09

---

## 1. 高速串行链路组成

```
TX(发送端) ──┬── Pre-emphasis/De-emphasis ──┬── Channel(PCB+连接器+线缆) ──┬── EQ(CTLE/DFE) ── RX(接收端)
             │                                │                              │
          预加重                          AC耦合电容                    均衡器
          去加重                                                       自适应
```

### 1.1 关键参数

| 接口 | 速率 | 上升时间 | 差分阻抗 | AC耦合 | 预加重 | RX EQ |
|------|------|----------|----------|--------|--------|-------|
| PCIe Gen1 | 2.5 Gbps | ~100ps | 100Ω | 100nF | -3.5dB | 无 |
| PCIe Gen2 | 5 Gbps | ~50ps | 100Ω | 100nF | -6dB | CTLE |
| PCIe Gen3 | 8 Gbps | ~30ps | 85Ω | 100nF | -6.5~9.5dB | CTLE+DFE |
| PCIe Gen4 | 16 Gbps | ~20ps | 85Ω | 100nF | -9.5dB | CTLE+DFE |
| USB 3.0 | 5 Gbps | ~50ps | 90Ω | 100nF | -3.5dB | CTLE |
| USB 3.1 | 10 Gbps | ~30ps | 90Ω | 100nF | -6dB | CTLE+DFE |
| SATA 3.0 | 6 Gbps | ~40ps | 100Ω | 100nF | -3.5dB | CTLE |
| MIPI CSI | 1~2.5 Gbps/lane | ~100ps | 100Ω | 无 | 可选 | 可选 |

## 2. PCB 布线规则

### 2.1 差分对走线

```
规则:
  1. 差分对两线等宽等距
  2. 线宽/线距按阻抗计算 (见 01-transmission-line-basics)
  3. 最少过孔: 0~2个 (每对)
  4. 过孔对称: 差分对两线过孔在同一位置镜像
  5. 回流过孔: 每对差分信号旁2个地过孔
  6. 线长匹配: 差分对内长度差 < 5mil
  7. 线距: 同组差分对间 > 3×线宽 (串扰隔离)
  8. 包地: 高速差分对两侧加地屏蔽过孔
```

### 2.2 AC 耦合电容

```
AC耦合电容放置:
  - 靠近 TX 端 (PCIe/SATA) 或靠近 RX 端 (USB3)
  - 焊盘间距: 不应引入阻抗不连续
    - 0402封装: 焊盘间距 ≥ 20mil, 焊盘宽 ≤ 10mil
    - 0201封装: 焊盘间距 ≥ 12mil (推荐, 更小不连续)
  - 两侧走线宽度 = 差分线宽

推荐封装: 0201 (0.4×0.6mm) 优于 0402, 阻抗不连续更小
```

### 2.3 连接器区域

```
高速连接器区布线:
  1. 连接器焊盘的焊盘较大, 引入电容不连续
  2. 补偿方法: 焊盘下挖空参考层 (减小对地电容)
  3. 挖空范围: 焊盘尺寸 + 10mil 两侧
  4. 挖空深度: 隔一层参考平面

  示例: 焊盘 30×15mil → 挖空 40×25mil (到L3, L1信号在Top)
```

## 3. 预加重与均衡

### 3.1 TX 预加重/去加重

```
原理:
  高频分量在通道中衰减更大, TX 预先增强高频分量补偿
  去加重: 降低低频分量 (等效增强高频)
  预加重: 增强高频分量 (额外功率)

设置方法:
  - 主板 BIOS/驱动配置
  - 链路训练自动协商 (PCIe Gen3+)
  - 默认值通常够用, 仅在长通道时调整

典型设置:
  PCIe Gen3: De-emphasis = -6.5dB (短通道) 或 -9.5dB (长通道)
  USB 3.0: Pre-emphasis = -3.5dB (默认)
```

### 3.2 RX 均衡

| 均衡类型 | 功能 | 适用 |
|----------|------|------|
| CTLE | 高通滤波器 (补偿通道低通) | Gen2~Gen4 |
| DFE | 判决反馈 (消除码间干扰/反射) | Gen3~Gen4 |
| FFE | 前馈均衡 (多抽头) | 高速背板 |

## 4. 通道预算

### 4.1 PCIe Gen3 通道预算

```
总预算: 23dB @ 4GHz (Nyquist)

分配:
  TX 抖动/偏差: 3.5dB
  PCB 走线 (8in): 7dB
  连接器: 1.5dB
  线缆: 2.5dB
  接收端: 1.5dB
  裕量: 7dB

计算: 总衰减 = 3.5+7+1.5+2.5+1.5 = 16dB < 23dB ✓
```

### 4.2 眼图裕量

| 接口 | 速率 | 最小眼高 | 最小眼宽 | 合格标准 |
|------|------|----------|----------|----------|

## 5. ESD 保护

```
高速差分对 ESD 保护:
  1. 选择低电容 TVS (<0.8pF for 5Gbps, <0.5pF for 10Gbps)
  2. TVS 放置在连接器入口, 靠近差分对
  3. TVS 到差分对的走线尽量短 (<50mil)
  4. 优先使用集成式 TVS 阵列 (ESD9L 系列)
  5. 保持差分对称: TVS 焊盘对称

推荐器件:
  USB 3.0: USBLC6-4SC6 (0.6pF)
  PCIe Gen3: ESD9L5.0 (0.5pF)
  USB 3.1: TPD4E05U06 (0.3pF)
  HDMI 2.1: TPD12S016 (0.15pF)
```

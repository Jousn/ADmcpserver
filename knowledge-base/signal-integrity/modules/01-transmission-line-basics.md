# 传输线理论与阻抗控制

> 适用范围：高速数字电路 PCB 传输线设计（>100MHz 或上升沿 <1ns）
> 版本：v1.0 | 更新日期：2026-09

---

## 1. 何时需要考虑传输线效应

```
判断标准:
  线长 > 上升沿长度的 1/6 → 需要传输线分析

  上升沿长度 = 上升时间 × 信号传播速度
  传播速度(微带线) ≈ c / sqrt(Eff) ≈ 150~180 ps/mm (FR-4)
  传播速度(带状线) ≈ c / sqrt(Er) ≈ 140~150 ps/mm (FR-4)

  典型:
    信号上升时间 1ns → 上升沿长度 ≈ 150~180mm → 线长 >25~30mm 时需考虑
    信号上升时间 100ps → 上升沿长度 ≈ 15~18mm → 线长 >2.5~3mm 时需考虑
```

| 信号 | 上升时间 | 阈值线长 | 是否需要传输线分析 |
|------|----------|----------|-------------------|
| 10MHz 方波 | ~10ns | >1500mm | 一般不需要 |
| 50MHz 方波 | ~2ns | >300mm | 通常需要 |
| 100MHz 方波 | ~1ns | >150mm | 需要 |
| 500MHz 方波 | ~200ps | >30mm | 必须分析 |
| 1GHz 方波 | ~100ps | >15mm | 必须分析 |
| DDR4-3200 | ~50ps | >7mm | 必须分析 |

## 2. 阻抗计算

### 2.1 微带线（Surface, Top/Bottom 层）

```
Z0 = 87 / sqrt(Er + 1.41) × ln(5.98×H / (0.8×W + T))

简化公式 (Er=4.2, T=0):
  Z0 ≈ 87 / sqrt(5.61) × ln(7.47×H / W) ≈ 36.7 × ln(7.47×H/W)

其中:
  Er = 介质介电常数 (FR-4 ≈ 4.2~4.5)
  H = 介质厚度 (mil)
  W = 线宽 (mil)
  T = 铜厚 (mil, 1oz ≈ 1.4mil)
```

**FR-4 (Er=4.2) 微带线 50Ω 快速查表**:

| 铜厚 | H=4mil | H=6mil | H=8mil | H=10mil | H=12mil |
|------|--------|--------|--------|---------|----------|
| 1oz (1.4mil) | W=7.6 | W=11.4 | W=15.2 | W=19.0 | W=22.8 |
| 0.5oz (0.7mil) | W=7.2 | W=10.8 | W=14.4 | W=18.0 | W=21.6 |

### 2.2 带状线（内层，两个参考平面之间）

```
Z0 = 60 / sqrt(Er) × ln(4×H / (0.67×π×(0.8×W + T)))

简化公式 (Er=4.2):
  Z0 ≈ 29.3 × ln(1.91×H / W)
```

**FR-4 带状线 50Ω 快速查表**:

| H (介质半厚) | 线宽 W |
|-------------|--------|
| 3mil | W=2.5 |
| 4mil | W=3.3 |
| 5mil | W=4.1 |
| 6mil | W=5.0 |
| 8mil | W=6.6 |

### 2.3 差分阻抗

```
Zdiff = 2 × Z0 × (1 - 0.48×exp(-2.9×S/H))

其中:
  Z0 = 单端阻抗
  S = 差分对线距
  H = 介质厚度

100Ω 差分对设计（微带线, FR-4, H=4mil, 1oz）:
  S=5mil → Z0=65Ω → Zdiff≈100Ω
  S=6mil → Z0=67Ω → Zdiff≈103Ω
```

| 差分阻抗 | H=4mil | H=6mil | H=8mil | 应用 |
|----------|--------|--------|--------|------|
| 100Ω | W=5.5/S=5 | W=8/S=7 | W=10.5/S=9 | USB3/SATA/以太网 |
| 90Ω | W=6/S=4 | W=9/S=5.5 | W=12/S=7 | USB2.0 |
| 85Ω | W=6.5/S=3.5 | W=10/S=4.5 | W=13/S=6 | PCIe Gen3/4 |

## 3. 终端匹配

### 3.1 匹配策略选择

| 拓扑 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| 源端串联 | 点对点/低速 | 低功耗/无反射 | 信号延迟半周期 |
| 终端并联 | 多负载/双向 | 信号完整/快 | 高功耗 |
| 戴维南 | DDR 地址/控制 | 平衡上下拉 | 功耗较高 |
| RC 终端 | 多负载/单向 | 低功耗 | RC 时间常数限制 |
| 二极管 | ESD 双重保护 | 限幅 | 非线性阻抗 |

### 3.2 源端串联匹配

```
Rs = Z0 - R_driver

典型:
  线阻抗 50Ω, 驱动内阻 10Ω → Rs = 40Ω
  线阻抗 50Ω, 驱动内阻 20Ω → Rs = 30Ω

布线: Rs 尽量靠近驱动端, < 100mil
```

### 3.3 DDR 终端策略

| 信号类型 | 匹配方式 | 终端位置 | 阻值 |
|----------|----------|----------|------|
| 地址/命令 | 戴维南 | 线末端 | 50Ω 到 VTT |
| 时钟 | 并联 | 线末端 | 100Ω 差分 |
| 数据 (ODT) | 片上 | DDR 颗粒内部 | 40/60/120Ω |
| 控制信号 | 戴维南 | 线末端 | 50Ω 到 VTT |

## 4. Altium Designer 中的阻抗控制

| 操作 | 菜单路径 | 说明 |
|------|----------|------|
| 层叠管理 | Design » Layer Stack Manager | 设置 Er/H/T/铜厚 |
| 阻抗计算 | Layer Stack Manager » Impedance | 自动计算 Z0/Zdiff |
| 规则设置 | Design » Rules » Routing » Routing Width | 按网络类设置线宽 |
| 差分对设置 | Design » Rules » Routing » Differential Pairs Routing | 设置线宽/线距 |
| 阻抗规则 | Design » Rules » High Speed » Max/Min Impedance | 限制阻抗范围 |
| 信号仿真 | Signal Integrity (SI) Analysis | 预布线/后布线 SI 仿真 |

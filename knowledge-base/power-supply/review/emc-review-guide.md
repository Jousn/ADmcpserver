# EMC 设计审查指南

> 本文档为电源产品电磁兼容（EMC）设计审查专项指南，覆盖传导/辐射发射与敏感度、EMI 滤波器、屏蔽、接地、线缆走线，以及军用 GJB151B 与民用 IEC61000 标准差异。面向 AI Skills 在 EMC 审查阶段的结构化检索与整改建议生成。

---

## 1. 传导发射（CE）审查要点

传导发射审查关注电源通过输入电源线向电网传导的噪声干扰，频率范围通常为 150kHz~30MHz。

| 检查项 | 审查要点 | 通过标准 | 风险等级 |
|--------|----------|----------|----------|
| 开关频率谐波 | 主开关频率及谐波在频谱图中的峰值 | 峰值低于限值 6dB 余量 | 高 |
| 差模噪声 | 开关管开关动作产生的高频差模噪声 | 差模滤波器衰减量满足要求 | 高 |
| 共模噪声 | 开关节点对地寄生电容引起的共模噪声 | 共模电感与 Y 电容组合有效 | 高 |
| 滤波器截止频率 | LC 滤波器截止频率低于最低干扰频率 | 截止频率 < 150kHz 或最低开关频率 | 中 |
| 滤波器布局 | 滤波器靠近输入端口，输入输出不交叉 | 输入走线不与开关节点平行耦合 | 高 |
| 接地处理 | 滤波器共模电容接地路径短而粗 | 接地阻抗 < 10mΩ | 高 |
| 频段余量 | 全频段扫描 150kHz~30MHz | 所有频点低于限值至少 6dB | 高 |

### CE 整改速查

| 超标频段 | 可能原因 | 整改方案 |
|----------|----------|----------|
| 150kHz~1MHz | 差模噪声过大，X 电容不足 | 增大 X 电容，优化差模电感 |
| 1MHz~10MHz | 共模噪声为主，Y 电容/共模电感不足 | 增大共模电感量，增加 Y 电容 |
| 10MHz~30MHz | 开关边沿过快，寄生振荡 | 增加驱动电阻，RC 吸收电路 |

## 2. 辐射发射（RE）审查要点

辐射发射审查关注电源通过空间辐射的电磁干扰，频率范围通常为 30MHz~1GHz。

| 检查项 | 审查要点 | 通过标准 | 风险等级 |
|--------|----------|----------|----------|
| 开关节点面积 | MOS/二极管开关节点铜皮面积 | 面积最小化，减少天线效应 | 高 |
| 开关边沿速率 | dv/dt 与 di/dt 控制合理性 | 边沿时间在损耗与 EMI 间平衡 | 高 |
| 时钟谐波 | 控制芯片时钟及高频谐振谐波 | 谐波峰值低于限值 6dB 余量 | 中 |
| 屏蔽体完整性 | 机壳缝隙、孔洞尺寸 | 最大缝隙尺寸 < λ/20（最高频率） | 高 |
| 线缆辐射 | 输入/输出线缆作为辐射天线 | 线缆滤波/磁环抑制共模电流 | 高 |
| PCB 层叠 | 关键信号层与参考地平面距离 | 信号层紧邻完整地平面 | 中 |
| 返回路径 | 高频信号返回电流路径连续 | 无跨分割地平面走线 | 高 |

## 3. 传导敏感度（CS）审查要点

传导敏感度审查确保电源在电网注入干扰条件下仍能正常工作。

| 检查项 | 审查要点 | 通过标准 | 风险等级 |
|--------|----------|----------|----------|
| CS101 注入 | 150kHz~50MHz 正弦注入，电源线 | 性能不降级，输出纹波无异常增量 | 高 |
| CS114 注入 | 10kHz~200MHz 集束电流注入 | 信号端口功能正常 | 中 |
| CS115 注入 | 脉冲激励注入 | 快速瞬态下无误触发 | 中 |
| CS106 注入 | 电源线尖峰信号注入 | 无复位、无损坏 | 高 |
| 输入滤波器抗扰 | 滤波器对注入干扰的衰减能力 | 滤波后干扰不影响后级电路 | 高 |
| 控制电路去耦 | 控制芯片电源去耦电容充足 | 注入干扰下控制环路不抖动 | 中 |

---

## 4. 辐射敏感度（RS）审查要点

辐射敏感度审查确保电源在强电磁场环境下功能正常。

| 检查项 | 审查要点 | 通过标准 | 风险等级 |
|--------|----------|----------|----------|
| RS103 场强 | 10kHz~40GHz 连续波辐射场 | 在规定场强下功能正常 | 高 |
| 屏蔽效能 | 机壳对辐射场的屏蔽能力 | 屏蔽效能 ≥ 40dB（1GHz 处） | 高 |
| 线缆屏蔽 | 外部线缆屏蔽层 360° 搭接 | 线缆耦合干扰不影响功能 | 高 |
| 敏感电路保护 | 反馈/采样电路防干扰设计 | 输出精度在场强下不超差 | 中 |
| 接口滤波 | 信号接口加装 TVS/滤波器 | 瞬态干扰不损坏接口器件 | 中 |

## 5. EMI 滤波器审查清单

EMI 滤波器是抑制传导发射与传导敏感度的核心环节。

| 检查项 | 审查要点 | 通过标准 | 风险等级 |
|--------|----------|----------|----------|
| 拓扑完整性 | 共模 + 差模两级滤波 | 覆盖 150kHz~30MHz 全频段 | 高 |
| 共模电感量 | 按共模噪声频段选择磁芯与匝数 | 插入损耗在目标频段 ≥ 40dB | 高 |
| X 电容选择 | 差模电容容量满足低频衰减 | 截止频率计算后验证衰减量 | 中 |
| Y 电容选择 | 共模电容容量与漏电流平衡 | 漏电流 < 0.5mA（医用 < 0.1mA） | 高 |
| 磁芯饱和 | 共模电感在最大电流下不饱和 | 电感量下降 < 10% @ Imax | 高 |
| 滤波器布局 | 元件紧凑，输入输出端隔离 | 无空间耦合导致滤波器旁路 | 高 |
| 放电电阻 | X 电容并联放电电阻 | 断电后 1s 内电压降至 34V 以下 | 中 |
| 安规认证 | X/Y 电容具有相应认证 | 认证齐全（CQC/UL/VDE） | 高 |

## 6. 屏蔽设计审查

屏蔽设计审查关注机壳与关键器件的电磁屏蔽效果。

| 检查项 | 审查要点 | 通过标准 | 风险等级 |
|--------|----------|----------|----------|
| 屏蔽材料 | 材料电导率/磁导率满足目标频段 | 屏蔽效能计算 ≥ 目标值 | 高 |
| 缝隙处理 | 接缝处导电衬垫或簧片搭接 | 搭接阻抗 < 2.5mΩ | 高 |
| 通风孔 | 孔径 < λ/20，优先蜂窝状 | 最高频率下屏蔽效能达标 | 中 |
| 穿墙滤波 | 线缆穿越屏蔽体使用穿墙电容/滤波连接器 | 无线缆旁路屏蔽体 | 高 |
| 屏蔽接地 | 屏蔽体低阻抗接地 | 360° 环接，阻抗最小化 | 高 |
| 变压器屏蔽 | 变压器初次级间屏蔽绕组 | 共模噪声降低 ≥ 10dB | 中 |

## 7. 接地设计审查

接地设计是 EMC 的基础，良好的接地策略可大幅降低干扰。

| 检查项 | 审查要点 | 通过标准 | 风险等级 |
|--------|----------|----------|----------|
| 接地策略 | 低频单点接地，高频多点接地 | 接地策略与频段匹配 | 高 |
| 地平面完整性 | 参考地平面无大面积分割 | 分割区域不阻断返回路径 | 高 |
| 混合地处理 | 模拟地与数字地单点连接 | 连接点位于噪声最小处 | 中 |
| 地阻抗 | 高频返回路径阻抗最小化 | 关键频段地阻抗 < 设计值 | 高 |
| 保护地与信号地 | 保护地在单点与信号地连接 | 无地环路引入共模干扰 | 高 |
| 接地铜排 | 大功率电源使用接地铜排 | 直流电阻 < 5mΩ | 中 |

---

## 8. 线缆走线审查

线缆是电磁干扰的重要耦合与辐射路径，合理布线至关重要。

| 检查项 | 审查要点 | 通过标准 | 风险等级 |
|--------|----------|----------|----------|
| 线缆分类 | 功率线、信号线、敏感线分离布线 | 间距 ≥ 50mm 或物理隔离 | 高 |
| 双绞线使用 | 差分信号与低压信号使用双绞线 | 双绞节距满足抗扰要求 | 中 |
| 屏蔽线接地 | 屏蔽层两端 360° 搭接或单端接地 | 按频段选择接地策略 | 高 |
| 线缆长度 | 线缆尽量短，避免谐振长度 | 无线缆长度接近 λ/4 谐振点 | 中 |
| 线缆捆扎 | 功率与信号线不混扎 | 独立走线槽/走线管 | 中 |
| 线缆出/入口 | 集中于一侧出线，便于滤波 | 出入口靠近 EMI 滤波器 | 中 |

## 9. 军用 GJB151B vs 民用 IEC61000 审查差异

| 对比维度 | 军用 GJB151B | 民用 IEC61000 |
|----------|--------------|---------------|
| CE 频段范围 | 10kHz~10MHz（CE102） | 150kHz~30MHz |
| CE 限值严苛度 | 60~70 dBμV（窄带） | 56~73 dBμV（准峰值） |
| RE 频段范围 | 10kHz~40GHz（RE102） | 30MHz~1GHz（部分到 6GHz） |
| RS 场强等级 | 200V/m（RS103，舰船平台可达 200V/m 以上） | 3~10V/m（IEC61000-4-3） |
| CS 注入方式 | 集束电流注入、尖峰注入 | 传导抗扰度、电快速瞬变 |
| 测试项目数量 | 19 项（含 CE/RE/CS/RS 全覆盖） | 5~8 项（按产品类别选取） |
| 安全裕量要求 | 敏感度测试余量 ≥ 6dB | 无统一余量要求 |
| 脉冲干扰 | CS106 尖峰、CS115 脉冲激励 | EFT/Burst、Surge |
| 设计导向 | 以抗扰为主，强调战场电磁环境 | 以发射控制为主，兼顾抗扰 |

## 10. 常见 EMC 问题与整改方案

| 问题现象 | 根因分析 | 整改方案 | 验证方法 |
|----------|----------|----------|----------|
| CE 低频超标（150kHz~1MHz） | 差模噪声大，X 电容不足 | 增大 X 电容，加差模电感 | 频谱仪复测 |
| CE 高频超标（>5MHz） | 共模噪声大，Y 电容不足 | 增大共模电感，加 Y 电容 | 频谱仪复测 |
| RE 超标（30~200MHz） | 开关节点辐射，线缆天线 | 减小节点面积，加磁环 | 半电波暗室复测 |
| RE 超标（>200MHz） | 时钟谐波，屏蔽缝隙 | 时钟扩频，改善屏蔽搭接 | 暗室复测 |
| EFT 抗扰失败 | 控制电路误触发 | 增加 TVS，去耦电容，光耦隔离 | EFT 发生器复测 |
| Surge 抗扰失败 | 输入端保护不足 | 加大 MOV，GDT，TVS 组合 | 浪涌发生器复测 |
| RS 功能异常 | 敏感电路耦合干扰 | 屏蔽机壳，接口滤波，线缆屏蔽 | GTEM/暗室复测 |
| 输出纹波异常增大 | 输出滤波不足或寄生振荡 | 增大输出 LC，加 RC 吸收 | 示波器测量 |

## 审查报告输出模板

```yaml
emc_review_report:
  project_id: <项目编号>
  standard: "GJB151B"  # 或 "IEC61000"
  review_stage: "设计阶段"  # 设计阶段/样机阶段/认证阶段
  ce_review:
    status: pass
    margin_db: 8
    worst_case: "250kHz 共模噪声 62dBuV（限值 68dBuV）"
  re_review:
    status: fail
    worst_case: "120MHz 谐波超标 4dB"
    root_cause: "开关节点面积过大"
    rectification: "缩小开关节点铜皮，增加屏蔽罩"
  cs_review:
    status: pass
    notes: "CS101/CS106 均通过"
  rs_review:
    status: conditional_pass
    notes: "RS103 10V/m 通过，50V/m 需验证"
  shielding_grounding:
    status: pass
  recommendations:
    - "增加共模电感量至 10mH"
    - "开关节点增加 RC 吸收电路"
    - "输出线缆增加磁环"
```

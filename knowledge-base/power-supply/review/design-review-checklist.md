# 电源设计审查总清单

> 本文档为电源设计全流程审查总清单，覆盖电气安全、拓扑选型、元器件、保护功能、控制环路、热设计、EMC、可制造性、可维修性及军用专项要求。面向 AI Skills 在设计审查阶段的结构化检索与自动核查。

---

## 1. 电气安全审查

电气安全审查确保电源在正常及单一故障条件下不危及人身与设备安全，核心关注安规间距、绝缘耐压与接地连续性。

| 检查项 | 要求 | 通过标准 | 风险等级 |
|--------|------|----------|----------|
| 一次/二次电气间隙 | 按工作电压查 GB4943/IEC62368 表，最小 3.2mm@250V | 实际值 ≥ 查表值，留 20% 余量 | 高 |
| 爬电距离 | 按污染等级查表，CTI≥175 时材料组别 IIIa | 实际值 ≥ 查表值 | 高 |
| 绝缘耐压（Hi-Pot） | 一次-二次 1500VAC/1min 或 2121VDC/1min | 无击穿、无飞弧，漏电流 < 2mA | 高 |
| 接地连续性 | 保护地阻抗 ≤ 0.1Ω（25A 测试电流） | 所有可触及金属件至接地点阻抗达标 | 高 |
| 变压器绝缘 | 骨架槽宽 ≥ 6.4mm，三层绝缘线或挡墙 ≥ 3 层 | 耐压测试通过，绝缘等级满足加强绝缘 | 高 |
| Y 电容选择 | 额定电压 ≥ 峰值工作电压 1.6 倍，Y1/Y2 认证 | 安规认证齐全，漏电流在限值内 | 中 |
| 保护地走线 | 独立走线，不与信号地共线，宽度 ≥ 2.5mm | 直流电阻 < 25mΩ，无单点失效 | 高 |
| 输入保险丝 | 额定电流 1.25~1.5 倍最大输入电流，安规认证 | 熔断特性曲线匹配，分断能力 ≥ 额定值 | 中 |

## 2. 拓扑选型审查

拓扑选型直接决定效率、成本与体积，需根据功率等级、隔离要求与应用场景综合判定。

| 检查项 | 要求 | 通过标准 | 风险等级 |
|--------|------|----------|----------|
| 功率等级匹配 | < 50W 优先反激；50~250W 正激/双管正激；> 250W 桥式/LLC | 拓扑功率范围覆盖设计需求 | 高 |
| 隔离要求 | 非隔离仅用于板级电源；隔离用于一次到二次 | 隔离等级与应用场景一致 | 高 |
| 效率目标 | 同步整流、ZVS/ZCS 软开关满足能效等级 | 满载效率 ≥ 目标值，半载效率 ≥ 目标值-2% | 中 |
| 成本约束 | BOM 成本在预算范围内，避免高成本拓扑 | 成本估算偏差 < 10% | 中 |
| 输入电压范围 | 拓扑支持输入电压全范围（如 85~264VAC） | 最高/最低输入下拓扑可正常工作 | 高 |
| 输出路数 | 单路用简单拓扑，多路用耦合电感或独立模块 | 交叉调整率满足 ±5% | 中 |
| 控制方式 | 简单拓扑用电压型/电流型，复杂用数字控制 | 环路稳定，动态响应满足要求 | 中 |
| 功率器件类型 | 宽禁带器件（GaN/SiC）用于高频高效场景 | 开关损耗与成本平衡，驱动设计匹配 | 中 |

## 3. 元器件选型审查

元器件选型审查聚焦降额设计、生命周期管理与供应链风险，确保长期可靠性。

| 检查项 | 要求 | 通过标准 | 风险等级 |
|--------|------|----------|----------|
| 电压降额 | 电容电压降额 ≥ 20%，MOS管 Vds 降额 ≥ 30% | 工作电压 ≤ 额定值 × 0.7~0.8 | 高 |
| 电流降额 | 功率器件电流降额 ≥ 30%，二极管 ≥ 50% | 峰值电流 ≤ 额定值 × 0.5~0.7 | 高 |
| 功率/热降额 | 电阻功率降额 ≥ 50%，MOS 管结温 < 125℃ | 稳态损耗 ≤ 额定值 × 0.5 | 高 |
| 生命周期状态 | 元件生命周期状态 Active，无 NRND/EOL | 供货周期 < 16 周，至少 2 年连续供应 | 高 |
| 单一来源 | 关键器件至少 2 家供应商或 pin-to-pin 替代 | 单一来源器件占比 < 15% | 高 |
| 温度系数 | 关键电阻/电容温度系数满足精度要求 | 全温区精度漂移在设计公差内 | 中 |
| 电容寿命 | 电解电容 105℃/设计寿命 ≥ 2000h | 折算到工作温度后寿命 ≥ 设计要求年限 | 高 |
| 安规认证 | X/Y 电容、光耦、变压器具有安规认证 | 认证证书齐全且在有效期内 | 高 |

---

## 4. 保护功能审查

保护功能审查确保电源在异常工况下自我保护，避免级联损坏。

| 检查项 | 要求 | 通过标准 | 风险等级 |
|--------|------|----------|----------|
| 过压保护（OVP） | 输出过压阈值 = 标称值 × 1.1~1.2 | 触发后切断输出，恢复后需复位 | 高 |
| 过流保护（OCP） | 逐周期限流，阈值 = 额定值 × 1.1~1.3 | 恒流后自动恢复或锁死保护 | 高 |
| 过温保护（OTP） | 温度传感器置于热点，阈值 85~105℃ | 触发降功率或关断，滞后 ≥ 10℃ | 高 |
| 短路保护（SCP） | 输出短路耐受持续短路且自动恢复 | 打嗝模式工作，平均功率受限 | 高 |
| 输入欠压保护 | UVLO 阈值高于最低工作电压 | 启停无振荡，阈值有 5~10V 滞后 | 中 |
| 输入过压保护 | OVP 阈值低于器件耐压的 90% | 触发后可靠切断输入 | 中 |
| 反接保护 | 输入反接时保险丝熔断或 MOS 反向截止 | 反接时无损坏，恢复后正常工作 | 中 |
| 浪涌保护 | 输入端 MOV + GDT 组合防护 | 通过雷击浪涌测试（4kV 差模/共模） | 高 |

---

## 5. 控制环路稳定性审查

控制环路稳定性决定电源的动态性能与稳定性，需通过 Bode 图与负载阶跃响应验证。

| 检查项 | 要求 | 通过标准 | 风险等级 |
|--------|------|----------|----------|
| 穿越频率 | fc = (1/5~1/10) × fsw | 穿越频率远低于开关频率 | 高 |
| 相位裕度 | PM ≥ 45°，推荐 45°~60° | 全输入/全负载范围内满足 | 高 |
| 增益裕度 | GM ≥ 8dB，推荐 ≥ 10dB | 全工作条件下满足 | 高 |
| 补偿网络类型 | Type II 用于电流型，Type III 用于电压型 | 补偿零极点正确放置 | 中 |
| 负载阶跃响应 | 25%~75%~25% 负载阶跃 | 过冲 < 5%，恢复时间 < 200μs | 中 |
| 线电压阶跃响应 | 输入电压阶跃 ±10% | 输出偏离 < 3%，恢复时间 < 1ms | 中 |
| 右半平面零点（RHPZ） | 反激/Boost 需限制带宽在 RHPZ 的 1/3 以内 | fc < fRHPZ/3 | 高 |
| 仿真验证 | 用 SIMPLIS/PSpice 仿真环路 Bode 图 | 仿真与实测一致，偏差 < 10° | 中 |

---

## 6. 热设计审查

热设计审查保证所有功率器件在最恶劣工况下结温不超过降额限制。

| 检查项 | 要求 | 通过标准 | 风险等级 |
|--------|------|----------|----------|
| 结温降额 | Si 器件 Tj < 125℃，宽禁带 < 150℃ | 最恶劣工况下热点结温满足降额 | 高 |
| 环境温度 | 设计环境温度覆盖最高工况温度 | Ta_max 下所有器件温度达标 | 高 |
| 散热器选型 | Rth ≤ (Tj_max - Ta) / Pdiss | 散热器热阻计算正确，留 20% 余量 | 高 |
| 风道设计 | 气流路径覆盖主要热源，无死角 | 进出风口温差 < 15℃，风速均匀 | 中 |
| 热仿真 | CFD/FEA 仿真验证温度分布 | 仿真与实测偏差 < 10℃ | 中 |
| PCB 散热 | 功率器件铺铜散热，过孔阵列导热 | 热阻实测或仿真达标 | 中 |
| 变压器温升 | 磁芯与绕组温升 < 40K（A级绝缘） | 红外热像仪实测温升满足要求 | 高 |
| 热保护冗余 | OTP 传感器覆盖 1 个以上热点 | 多点监控，任意热点超温均触发保护 | 中 |

## 7. EMC 设计审查

EMC 设计审查的详细内容参见 `emc-review-guide.md`，此处列出概要检查项。

| 检查项 | 要求 | 通过标准 | 风险等级 |
|--------|------|----------|----------|
| EMI 滤波器 | 共模 + 差模滤波器设计完整 | 传导发射低于限值 6dB 余量 | 高 |
| 屏蔽设计 | 关键噪声源屏蔽，缝隙搭接良好 | 辐射发射低于限值 6dB 余量 | 高 |
| 布局分区 | 强噪声区与敏感区物理隔离 | 噪声耦合路径最小化 | 中 |
| 接地设计 | 单点接地/多点接地策略合理 | 无地环路，地阻抗最小 | 高 |
| 线缆处理 | 信号线与功率线分离，双绞/屏蔽 | 线缆辐射在限值内 | 中 |

## 8. 可制造性审查（DFM/DFA）

可制造性审查确保设计可高效、低缺陷率地批量生产。

| 检查项 | 要求 | 通过标准 | 风险等级 |
|--------|------|----------|----------|
| 元件间距 | 最小间距 ≥ 0.15mm（波峰焊）或 0.1mm（回流焊） | 贴片机/焊接工艺可接受 | 中 |
| 器件封装 | 避免异形封装，优选标准封装 | 标准封装占比 > 90% | 低 |
| 焊盘设计 | 焊盘尺寸按 IPC-7351 规范 | 无立碑、桥连风险 | 中 |
| 波峰焊适配 | SMD 排列方向利于波峰焊，避免阴影 | 底面元件无焊接缺陷 | 中 |
| 插件方向 | 所有插件方向一致，便于自动插装 | 插装效率高，错插风险低 | 低 |
| 测试点覆盖 | 关键节点设置测试点，覆盖率 > 95% | ICT/FCT 可自动测试 | 中 |
| BOM 标准化 | 同规格元件合并，减少料号 | 料号数量 < 预算值 | 低 |
| 装配顺序 | 装配层级清晰，无干涉 | DFA 评分达 B 级以上 | 低 |

---

## 9. 可维修性审查

可维修性审查关注故障定位便捷性与现场维修可行性。

| 检查项 | 要求 | 通过标准 | 风险等级 |
|--------|------|----------|----------|
| 故障指示 | LED/通信接口指示故障类型 | 故障代码覆盖主要故障模式 | 中 |
| 模块化设计 | 关键模块可独立更换 | 更换时间 < 15min | 中 |
| 测试点可达 | 维修测试点在拆盖后可触及 | 探针可达率 > 90% | 中 |
| 紧固件标准化 | 螺丝种类 < 3 种 | 维修工具通用化 | 低 |
| 防呆设计 | 接插件有防反插设计 | 误插率 < 0.1% | 中 |
| 可调电位器 | 调试电位器可达且锁定 | 调试后可锁定防漂移 | 低 |

## 10. 军用专项审查

军用电源需满足严苛的环境适应性与可靠性要求，以下为专项检查项。

| 检查项 | 要求 | 通过标准 | 风险等级 |
|--------|------|----------|----------|
| 工作温度范围 | -55℃~+85℃（军用宽温） | 全温区内电气性能达标 | 高 |
| 振动适应性 | 按 GJB150.18A 随机振动谱测试 | 无机械松动、无性能降级 | 高 |
| 冲击适应性 | 按 GJB150.18A 冲击试验 30g/11ms | 无结构损坏、功能正常 | 高 |
| 湿热适应性 | 按 GJB150.9A 交变湿热 10 周期 | 绝缘电阻 > 10MΩ，功能正常 | 高 |
| 三防处理 | PCB 喷涂三防漆，元器件符合防护等级 | 通过盐雾试验 48h/96h | 高 |
| 电磁兼容 | 按 GJB151B 全项目测试 | 所有适用项目通过 | 高 |
| 可靠性预计 | 按 GJB/Z 299C 进行应力分析预计 | MTBF ≥ 目标值（如 20000h） | 高 |
| 元器件等级 | 军用级/宇航级，JANTXV 以上 | 降额满足 GJB/Z 35 I 级要求 | 高 |
| 供应链安全 | 国产化率满足要求，关键器件自主可控 | 国产化率 ≥ 80%，无禁运风险 | 高 |
| 质量一致性 | 按 GJB 909A 关键件管控 | 每批质量一致性检验通过 | 中 |

## 审查风险分级与处置原则

| 风险等级 | 含义 | 处置要求 |
|----------|------|----------|
| 高 | 涉及安全/法规/核心功能 | 必须通过，不通过则设计冻结 |
| 中 | 影响性能/可靠性/制造 | 限期整改，评审通过后放行 |
| 低 | 优化建议/可制造性提升 | 记录在案，后续版本优化 |

## 审查报告输出模板

每次审查完成后应输出结构化报告，供 AI Agent 自动归档与跟踪：

```yaml
report:
  project_id: <项目编号>
  review_date: <审查日期>
  reviewer: <审查人/Agent>
  checklist_version: "1.0"
  summary:
    total_items: <总检查项数>
    passed: <通过数>
    failed: <不通过数>
    high_risk_fail: <高风险不通过数>
  items:
    - id: "ELEC-001"
      category: 电气安全
      check_item: 一次/二次电气间隙
      result: pass
      actual_value: "4.0mm"
      required_value: "≥3.2mm"
      risk: high
      comment: "余量充足"
    - id: "PROT-003"
      category: 保护功能
      check_item: 过温保护
      result: fail
      actual_value: "无温度传感器"
      required_value: "阈值85~105℃"
      risk: high
      action: "需增加NTC热敏电阻并设置OTP阈值"
      due_date: <整改截止日期>
```

# 电源测试与鉴定指南

> 适用范围：军用及民用中高功率电源（200W~50kW+）全流程测试与鉴定
> 目标受众：AI设计辅助Skill，用于测试方案规划咨询与鉴定审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 电源测试体系总览

电源测试贯穿产品全生命周期，从研发到量产各阶段测试目标和方法不同，需建立分层递进的测试体系。

### 1.1 测试阶段划分

```
研发测试 → 型式试验 → 可靠性鉴定 → 生产筛选
   │           │           │            │
   ├─功能验证   ├─安全合规   ├─寿命验证    ├─工艺缺陷筛查
   ├─性能调试   ├─EMC合规    ├─环境适应性  ├─早期失效剔除
   └─环境预测试 └─环境定型   └─MTBF验证    └─出厂质量保证

测试递进关系：
  研发测试（发现问题）→ 型式试验（证明合规）→ 可靠性鉴定（证明耐用）→ 生产筛选（保证一致）
```

### 1.2 各阶段测试目标

| 阶段 | 目标 | 时机 | 样本数 | 通过判据 |
|------|------|------|--------|---------|
| 研发测试 | 验证设计、发现问题、优化参数 | 原型/工程样机 | 1~3台 | 设计指标达标 |
| 型式试验 | 证明产品满足标准和法规 | 设计定型 | 1~2台 | 全项目通过 |
| 可靠性鉴定 | 验证MTBF和环境耐久性 | 设计定型/定型后 | 3~10台 | 无失效或失效数≤方案允许 |
| 生产筛选 | 剔除早期失效，保证出厂质量 | 量产阶段 | 100%（或抽样） | 无失效 |

## 2. 研发测试

### 2.1 功能测试清单

| 测试项 | 测试方法 | 合格判据 | 测试设备 |
|--------|---------|---------|---------|
| 稳压精度 | 全输入×全负载矩阵测V_out | 民用±3%，军用±1% | 电子负载+数字万用表 |
| 负载调整率 | 空载→满载阶跃，测ΔV_out | < 1%（军用）/ < 3%（民用） | 电子负载+示波器 |
| 电网调整率 | 输入电压±10%阶跃，测ΔV_out | < 1%（军用）/ < 2%（民用） | 可调交流源+示波器 |
| 输出纹波 | 20MHz带宽示波器测V_out纹波 | < 1%（军用）/ < 3%（民用） | 示波器+电压探头 |
| 满载效率 | P_in/P_out全输入×全负载矩阵 | 满载≥97%（军用）/ ≥96%（民用） | 功率分析仪 |
| 轻载效率 | 10%/25%/50%负载效率 | 半载≥96%，10%载>85% | 功率分析仪 |
| 瞬态响应 | 25%~75%~25%负载阶跃 | 过冲<5%，恢复<200μs | 电子负载（快沿）+示波器 |
| 启动时序 | 上电监测V_out上升沿 | 单调上升，无过冲>10% | 示波器 |
| 保持时间 | 断电后V_out保持时间 | ≥20ms（民用）/ ≥50ms（军用） | 示波器+交流源 |
| 开关频率 | 测开关管栅极信号频率 | 与设计值偏差<5% | 示波器 |
| 功率因数 | PFC级输入PF全负载扫描 | 满载≥0.99（军用）/ ≥0.95（民用） | 功率分析仪 |
| 输入谐波 | FFT分析输入电流谐波 | 满足IEC61000-3-2/GJB要求 | 功率分析仪/EMI接收机 |

### 2.2 环境预测试

```
温度扫描（研发阶段快速筛查）：
  - 工作温度范围扫描：-40°C → +85°C（步进10°C）
  - 每个温度点稳态运行30min + 功能测试
  - 记录关键参数温度漂移（V_out, f_sw, 效率）
  - 识别温度敏感点（低温启动、高温降额）

振动筛查（研发阶段）：
  - 正弦扫频振动：5~500Hz, 0.5g
  - 随机振动筛查：5~2000Hz, 1g, 30min/轴
  - 通电运行检测振动引起的间歇故障
  - 重点检查磁性元件、连接器、大质量器件

热分布测试：
  - 红外热像仪满载温度分布
  - 热点标记：器件结温估算
  - 验证散热设计和降额裕度
```

  - CS101（GJB151B）：30Hz~150kHz，电源线传导敏感度

  - RS103（GJB151B）：2MHz~40GHz，电场辐射敏感度

其他EMC项目：
  - EFT（电快速瞬变）：IEC61000-4-4，±2kV（信号）/ ±4kV（电源）

  - 静电放电（ESD）：IEC61000-4-2，±8kV接触/±15kV空气
```

### 3.4 HALT（高加速寿命试验）

```
HALT目的：在研发阶段快速发现设计薄弱环节（非用于计算MTBF）

HALT四步法：

步骤1：温度步进（Cold/Hot Step Stress）
  - 低温步进：+20°C → 降10°C步进至-80°C（或更低）
  - 高温步进：+20°C → 升10°C步进至+120°C（或更高）
  - 每步保持15min + 功能测试
  - 记录首次失效温度（工作极限/破坏极限）

步骤2：快速温变（Thermal Transition）
  - 温变率：≥15°C/min（液氮辅助）
  - -60°C↔+120°C，每端停留15min
  - 循环数：10~50次
  - 发现热应力疲劳缺陷（焊点/连接器）

步骤3：振动步进（Vibration Step Stress）
  - 6自由度气动振动台
  - 5grms起步，5grms步进至50grms+（或破坏）
  - 每步保持10min + 功能测试
  - 发现机械应力缺陷

步骤4：综合应力（Combined Stress）
  - 快速温变 + 随机振动同时施加
  - 温度：-50°C↔+100°C，15°C/min
  - 振动：5~30grms
  - 循环5~20次
  - 暴露温度+振动耦合失效

HALT原则：
  - 不设固定通过判据（目标是找到极限）
  - 发现失效即分析改进（Root Cause Analysis）
  - 改进后重新测试验证
  - 最终目标：破坏极限远超规格要求
```

## 4. 可靠性鉴定试验

### 4.1 MTBF验证试验（GJB 899A）

```
GJB 899A可靠性鉴定试验方案：

定时截尾试验（最常用）：
  - 规定试验时间T和允许失效数r
  - 在T时间内若失效数≤r → 通过
  - 若失效数>r → 不通过

序贯试验（节省样本）：
  - 根据每次失效累计时间判断接收/拒收/继续
  - 适合样本数有限时

参数选择：
  θ0 = 鉴定上限（MTBF目标值，如20000h）
  θ1 = 鉴定下限（最低可接受MTBF，如10000h）
  d = θ0/θ1 = 鉴别比（通常取1.5~3.0）
  α = 生产方风险（通常10~20%）
  β = 使用方风险（通常10~20%）

示例（GJB899A 方案21-7, 定时截尾）：
  d=3.0, α=β=10%
  T = 9.27 × θ1 = 9.27 × 10000 = 92700台时
  r = 5（允许5次失效）

若样本n=10台，每台需试验 92700/10 = 9270h
→ 可用加速条件缩短试验时间（见4.3）
```

### 4.2 温度循环试验

```
温度循环鉴定（验证热疲劳寿命）：

条件：
  - 温度范围：-55°C ~ +85°C（军用）
  - 变温率：5~15°C/min
  - 保持时间：每端≥15min（达到热平衡）
  - 循环数：200~1000次（取决于寿命要求）

失效判据：
  - 功能失效（输出异常/保护动作）
  - 参数超差（V_out/效率漂移>5%）
  - 目视检查（焊点裂纹/器件损伤）

加速因子：
  N_field = N_test × AF_TC
  AF_TC = (ΔT_test/ΔT_field)^m
  m = 4~6（焊点疲劳Coffin-M Manson指数）
```

### 4.3 加速寿命试验

```
加速寿命模型：

1. Arrhenius模型（热加速，恒定温度）：
   AF = exp(Ea/k × (1/T_use - 1/T_test))
   
   Ea = 激活能（0.5~1.0eV，半导体典型0.7eV）
   k = 玻尔兹曼常数 8.617e-5 eV/K
   T_use = 使用温度（K）
   T_test = 测试温度（K）

   示例：
   T_use=85°C(358K), T_test=125°C(398K), Ea=0.7eV
   AF = exp(0.7/8.617e-5 × (1/358 - 1/398)) = exp(2.29) = 9.9倍
   → 1000h@125°C 等效于 9900h@85°C

2. Coffin-Manson模型（热循环疲劳）：
   AF = (ΔT_test/ΔT_field)^m × (f_test/f_field)^n
   
   ΔT = 温度变化幅度
   f = 循环频率
   m = 4~6（焊点），2~3（塑封器件）
   n = 1/3（频率因子，通常忽略）

3. 综合模型（温度+电压+湿度）：
   AF = AF_thermal × AF_voltage × AF_humidity
   AF_voltage = exp(β × (V_test - V_use))
   AF_humidity = (RH_test/RH_use)^γ

加速试验设计原则：
  - 加速条件不超过材料/器件的物理极限
  - 确保加速条件下失效机理与使用条件一致
  - 多应力综合加速时各因子独立验证
```

## 5. 生产筛选

### 5.1 HASS（高加速应力筛选）

```
HASS目的：100%筛选生产批次中的工艺缺陷（早期失效）

HASS剖面设计（基于HALT结果）：
  - 工作极限OL和破坏极限DL由HALT确定
  - 筛选应力 = 0.5~0.8 × OL（低于工作极限，不损耗正常产品寿命）
  - 典型组合：快速温变 + 振动 + 通电运行

HASS剖面示例：
  - 温度：-30°C↔+80°C, 15°C/min
  - 振动：10~15grms
  - 循环数：2~3次（每台约30~60min）
  - 全程通电+功能监测

筛选有效性验证：
  - 嵌入已知缺陷样本（植缺陷种子）验证检出率
  - 筛选覆盖率 ≥ 95%
  - 无损验证：连续HASS循环5~10次确认不损伤良品

HASS vs HALT对比：
| 特性 | HALT（研发） | HASS（生产） |
|------|-------------|-------------|
| 目的 | 发现设计缺陷 | 筛选工艺缺陷 |
| 应力水平 | 极限（到破坏） | 适中（0.5~0.8×OL） |
| 样本 | 1~5台原型 | 100%产品 |
| 时长 | 数天~数周 | 30~60min/台 |
| 结果 | 改进设计 | 剔除缺陷品 |
```

### 5.2 Burn-in（老化测试）

```
Burn-in目的：消除早期失效（浴盆曲线左端），稳定产品参数

老化条件：
  - 温度：+50°C~+70°C（高于工作温度，加速老化）
  - 负载：满载或额定80%负载
  - 通电方式：连续通电/周期通断
  - 持续时间：民用24~72h，军用48~168h

失效判据：
  - 功能失效（输出异常/保护动作）
  - 参数漂移超差（V_out变化>1%，效率下降>1%）
  - 热异常（局部过热/异响）

军用老化特殊要求：
  - 高温老化：+70°C，满载，≥48h（GJB要求）
  - 温度循环老化：-40°C↔+70°C，≥5循环
  - 老化后复测：全功能测试确认参数稳定

老化设备：
  - 老化房/老化箱（温度可控）
  - 老化测试架（多台并行，独立监测）
  - 电子负载（恒流/恒功率模式）
  - 数据记录系统（自动监测V_out/I_out/温度）
```

### 5.3 ESS（环境应力筛选）

```
ESS目的：剔除制造过程引入的环境敏感缺陷（焊点/连接/器件）

ESS剖面：
  - 温度循环：-40°C↔+70°C, 10~20°C/min
  - 循环数：10~24次（典型）
  - 通电监测：全程或部分循环通电
  - 振动（可选）：随机振动5~10grms，10min/轴

ESS分级：
  | 筛选等级 | 温度范围 | 变温率 | 循环数 | 适用 |
  |---------|---------|--------|--------|------|
  | 轻度 | 0~+60°C | 5°C/min | 8次 | 民用低成本 |
  | 标准 | -40~+70°C | 10°C/min | 12次 | 民用标准 |
  | 严格 | -55~+85°C | 15°C/min | 24次 | 军用高可靠 |

ESS有效性和经济性平衡：
  - 过度筛选：成本高，可能损耗良品寿命
  - 不足筛选：缺陷逃逸率高
  - 推荐：基于现场失效数据反馈持续优化筛选剖面
```

  - 定时截尾/序贯试验方案

GJB/Z 299C（可靠性预计）：
  - 元器件应力分析法预计MTBF

GJB/Z 35（降额设计）：
  - 元器件降额准则（I/II/III级）
```

### 6.2 军用鉴定流程

```
军用电源鉴定典型流程：

1. 方案评审 → 确定鉴定试验矩阵
2. 研制试验 → 内部验证设计达标
3. 鉴定试验大纲评审 → 确认试验项目和判据
4. 环境试验（GJB150A全套） → 第三方实验室
5. EMC试验（GJB151B全套） → 认可实验室
6. 可靠性鉴定试验（GJB899A） → 专用试验场
7. 鉴定试验报告评审 → 专家组评审
8. 定型审查 → 军代表参与
9. 设计定型 → 批准定型
10. 生产定型 → 批生产工艺验证

关键节点：
  - 每阶段试验需独立报告
  - 失效需Root Cause Analysis + 改进 + 复测
  - 定型审查需军代表签字
```

# 军用电源标准知识库

> 适用范围：军用中高功率电源（100W~50kW）
> 目标受众：AI设计辅助Skill，用于军用电源标准查询、设计指导与评审
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

军用电源设计需满足一系列国家军用标准（GJB），涵盖电磁兼容性、环境适应性、可靠性预计、元器件降额和试验验证等方面。与民用标准相比，军用标准对温度范围、振动冲击、EMC限值和可靠性指标要求更为严格。本知识库汇总了军用电源设计的核心标准及其实际应用要点。

## 2. GJB 151B-2013 电磁兼容性要求

### 2.1 适用范围

GJB 151B-2013《军用设备和分系统电磁发射和敏感度要求与测量》是军用设备EMC设计和测试的核心标准，对应美军标MIL-STD-461G。

### 2.2 关键测试项目与限值

| 测试项目 | 类别 | 频率范围 | 适用平台 | 限值/要求 |
|---------|------|---------|---------|---------|
| CE102 | 传导发射（电源线） | 10kHz~10MHz | 所有平台 | 10kHz: 94~76dBμV；500kHz: 60~50dBμV；10MHz: 60~50dBμV |
| CE106 | 传导发射（天线端口） | 10kHz~40GHz | 带天线设备 | 取决于设备类型 |
| CS101 | 传导敏感度（电源线） | 30Hz~150kHz | 所有平台 | 注入电压3~10Vrms（视电源电压） |
| CS114 | 传导敏感度（集束注入） | 10kHz~200MHz | 所有平台 | 注入电流40~109dBμA（视平台） |
| CS115 | 传导敏感度（脉冲激励） | 脉冲信号 | 所有平台 | 5A脉冲，30ns脉宽 |
| CS116 | 传导敏感度（阻尼正弦） | 10kHz~100MHz | 所有平台 | 10~200mA峰值电流 |
| RE102 | 辐射发射（电场） | 10kHz~18GHz | 所有平台 | 2MHz: 62~24dBμV/m；200MHz: 56~30dBμV/m |
| RS103 | 辐射敏感度（电场） | 2MHz~40GHz | 所有平台 | 10~200V/m（视平台） |
| RS105 | 辐射敏感度（瞬态电磁场） | 脉冲场 | 所有平台 | 50kV/m峰值场强 |

### 2.3 CE102限值曲线（典型）

```
CE102限值（海军/陆军/空军，内部平台）：

频率        限值（dBμV）
10kHz       94
50kHz       84
100kHz      78
500kHz      60
1MHz        56
10MHz       56

注：
- 限值在500kHz以下按 10kHz为基准，每十倍频下降
- 不同平台（水面舰艇/潜艇/陆军/空军）限值有差异
- 电源线传导发射通常需要EMI滤波器设计保证达标
```

## 3. GJB 150A-2009 环境适应性要求

### 3.1 环境试验项目

| 试验项目 | GJB 150A编号 | 条件概要 | 军用电源关键考核点 |
|---------|-------------|---------|------------------|
| 高温试验 | Part 3 | 工作温度+65°C~+85°C，存储+70°C~+125°C | 散热设计、电容寿命、磁性元件温升 |
| 低温试验 | Part 4 | 工作温度-40°C~-55°C，存储-55°C~-65°C | 电容容值下降、启动能力、材料脆化 |
| 温度冲击 | Part 5 | -65°C~+125°C，转换时间<1min | 焊点疲劳、PCB分层、器件开裂 |
| 湿热试验 | Part 9 | 40°C/95%RH，10天或60°C/95%RH | 三防涂覆、绝缘电阻、腐蚀 |
| 盐雾试验 | Part 11 | 35°C/5%NaCl溶液，48~96h | 外壳防腐、连接器密封 |
| 振动试验 | Part 16 | 正弦扫频/随机振动，5~2000Hz | 结构强度、焊点疲劳、紧固件松脱 |
| 冲击试验 | Part 18 | 半正弦脉冲，15~100g | 结构完整性、器件脱落 |
| 加速度试验 | Part 15 | 离心加速度，10~50g | 机械应力、器件固定 |
| 低气压试验 | Part 2 | 相当于15km高度，12kPa | 绝缘间隙修正、散热效率下降 |

### 3.2 温度等级分类

```
军用电源工作温度等级：
- 陆军地面设备：-40°C ~ +55°C（一般），-55°C ~ +70°C（严酷）
- 舰船设备：-10°C ~ +50°C（舱内），-40°C ~ +65°C（露天）
- 航空设备：-55°C ~ +70°C（短时+85°C）
- 弹载设备：-55°C ~ +85°C（部分+125°C）

设计准则：
- 元器件结温降额：Tj < Tj_max - 25°C（I级降额）
- 电容寿命计算：基于最高工作温度+10°C余量
- PCB基材Tg：≥ 170°C（军标最低要求）
- 低温启动：电容容值可能下降30%~50%，需在设计时预留裕量
```

## 4. GJB/Z 299C-2006 可靠性预计手册

### 4.1 失效率预计方法

```
元器件工作失效率模型（应力分析法）：
λp = λb * πE * πQ * πA * πS * πR * πC

其中：
λp = 工作失效率（10⁻⁶/h）
λb = 基本失效率（由器件类型和工作温度决定）
πE = 环境系数（地面固定GF=1，舰船舱内NSI=6，航空AUF=15）
πQ = 质量系数（军级A=0.25，B级=0.5，C级=1.0）
πA = 应用系数
πS = 应力比系数（实际应力/额定应力）
πR = 额定值系数
πC = 结构系数

系统失效率：
λ_system = Σ λp_i（串联模型）

MTBF = 1 / λ_system
```

### 4.2 典型元器件失效率（地面固定环境，军级）

| 元器件类型 | 基本失效率 λb (10⁻⁶/h) | 主要应力因子 | 备注 |
|-----------|----------------------|-------------|------|
| 硅MOSFET | 0.02~0.1 | 温度、电压应力 | SiC失效率数据参考JEDEC |
| 铝电解电容 | 0.05~0.5 | 温度、纹波电流 | 温度每升10°C，λ翻倍 |
| 陶瓷电容 | 0.005~0.05 | 电压应力 | X7R优于Y5V |
| 薄膜电容 | 0.01~0.1 | 温度、电压 | 金属化薄膜自愈性 |
| 功率二极管 | 0.01~0.1 | 温度、电流 | 快恢复优于普通 |
| 变压器/电感 | 0.01~0.05 | 温度 | 绝缘等级决定 |
| 电阻 | 0.001~0.02 | 温度、功率 | 金属膜优于碳膜 |
| IC（线性） | 0.02~0.2 | 温度、引脚数 | |
| 光耦 | 0.05~0.3 | 温度、电流 | CTR退化 |

### 5.2 可靠性设计准则

```
军用电源可靠性设计要求：
1. MTBF指标：一般 ≥ 20000小时，关键装备 ≥ 50000小时
2. 冗余设计：关键链路采用N+1或2N冗余
3. 降额设计：执行GJB/Z 35降额准则（I级降额最严格）
4. 热设计：最恶劣工况下器件结温 ≤ Tj_max - 25°C
5. 简化设计：尽量减少元器件数量和种类
6. 标准化：优先选用军用标准件和通用件
7. FMECA：对所有单点故障进行分析并制定改进措施
```

## 6. GJB 899A 可靠性鉴定和验收试验

### 6.1 试验方案

```
定时截尾试验方案（常用）：
- 风险率：α = β = 20%（生产方和使用方风险）
- 鉴别比：d = θ0/θ1 = 3（θ0为上限MTBF，θ1为下限MTBF）
- 试验时间：T = 4.3 * θ1（总台时数）
- 判决准则：试验期间故障数 r ≤ 2 判为合格

示例：
若要求 MTBF ≥ 20000h（θ1），则：
- 试验总时间 T = 4.3 × 20000 = 86000 台时
- 用2台样机则每台运行 43000 小时（不实际，需增加样机数）
- 用10台样机则每台运行 8600 小时（约1年）

序贯试验方案：
- 每出现一次故障即判决（继续/接收/拒收）
- 试验时间不固定，通常比定时截尾短
- 适用于可靠性增长阶段的快速验证
```

## 7. GJB 239A 军用电源通用规范

### 7.1 主要技术要求

| 要求项 | 内容 | 设计影响 |
|--------|------|---------|
| 输入电压范围 | 直流：额定值±20%；交流：额定值±10% | 宽输入PFC设计、欠压保护 |
| 输出电压精度 | 稳态±1%~3%；瞬态±5%~10% | 高精度反馈、快瞬态响应 |
| 纹波与噪声 | ≤ 1%~3% 额定输出（峰峰值） | 滤波器设计、布局优化 |
| 效率 | ≥ 80%~92%（视功率等级和拓扑） | 软开关、同步整流、低损耗器件 |
| 负载调整率 | ≤ 1%~2% | 反馈环路设计 |
| 电压调整率 | ≤ 1% | 前馈/反馈补偿 |
| 过流保护 | 110%~150%额定电流，自恢复或锁死 | 电流采样、保护电路 |
| 过压保护 | 110%~120%额定电压，锁死保护 | OVP电路、SCR撬棍 |
| 绝缘电阻 | 输入-输出 ≥ 100MΩ（500V DC） | 变压器绝缘、PCB间距 |
| 绝缘耐压 | 输入-输出 ≥ 1500V AC/1min | 安规设计、Y电容选择 |

## 9. 降额设计标准（GJB/Z 35）

### 9.1 降额等级

```
降额等级定义：
I级降额（最严格）：用于关键/长寿命设备，如航天
II级降额（中等）：用于较高可靠性设备，如军用地面装备
III级降额（基本）：用于一般军用设备
```

## 10. 军用电源设计流程与评审节点

### 10.1 设计流程

```
军用电源设计流程（V模型）：

1. 需求分析阶段
   → 输入：技术规格书、GJB标准清单
   → 输出：研制方案、可靠性工作计划
   → 评审节点：方案评审（SRR）

2. 方案设计阶段
   → 输入：研制方案
   → 输出：系统方案、拓扑选型、可靠性分配
   → 评审节点：系统设计评审（SDR）

3. 工程设计阶段
   → 输入：系统方案
   → 输出：电路设计、PCB设计、软件设计、FMECA
   → 评审节点：初步设计评审（PDR）、关键设计评审（CDR）

4. 样机试制阶段
   → 输入：设计文件
   → 输出：样机、调试报告、环境应力筛选(ESS)
   → 评审节点：试制准备评审（PRR）

5. 验证试验阶段
   → 输入：样机
   → 输出：环境试验报告、EMC试验报告、可靠性鉴定试验
   → 评审节点：功能配置审核（FCA）、物理配置审核（PCA）

6. 定型阶段
   → 输入：验证报告
   → 输出：定型文件、技术资料
   → 评审节点：设计定型评审
```

## 11. 军民标准差异对比表

| 对比维度 | 军用标准 | 民用标准 | 差异说明 |
|---------|---------|---------|---------|
| EMC传导发射 | GJB 151B CE102 (10kHz起) | EN 55032 (150kHz起) | 军标起始频率更低，限值更严 |
| EMC辐射敏感度 | RS103 10~200V/m | IEC 61000-4-3 3~10V/m | 军标场强高10~20倍 |
| 温度范围 | -55°C~+85°C（典型） | 0°C~+40°C（典型） | 军标宽温约3倍 |
| 振动等级 | 5~2000Hz, 20g随机 | IEC 60068 2~500Hz, 2~5g | 军标严苛10倍 |
| MTBF要求 | ≥ 20000~50000h | ≥ 5000~20000h | 军标高3~5倍 |
| 降额等级 | I级降额（最严） | 一般无强制降额 | 军标应力大幅降低 |
| 元器件质量 | 军级/宇航级 | 工业级/消费级 | 军标失效率低5~10倍 |
| 绝缘耐压 | 1500V AC/1min | 1500V AC/1min（相同） | 基本一致 |
| 三防要求 | 强制三防涂覆/灌封 | 无强制要求 | 军标必须防腐 |
| 设计寿命 | ≥ 15年 | 3~5年 | 军标寿命长3~5倍 |
| 审批流程 | 方案/初设/关键/定型多轮 | 认证测试即可 | 军标流程更长 |
| 文件要求 | 完整技术状态管理 | 技术说明书即可 | 军标文件体系庞大 |

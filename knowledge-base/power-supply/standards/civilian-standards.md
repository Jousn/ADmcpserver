# 民用电源标准知识库

> 适用范围：民用中高功率电源（100W~50kW）
> 目标受众：AI设计辅助Skill，用于民用电源标准查询、设计指导与认证审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

民用电源设计需满足IEC/EN/UL/GB等系列标准，涵盖EMC、安全、能效和谐波等方面。相比军用标准，民用标准更注重人身安全、能效法规和市场准入认证。本知识库汇总了民用电源设计的核心标准、限值要求和认证流程，为民用电源设计与审查提供依据。

```

  线-线: ±1kV（标准）/ ±2kV
  线-地: ±2kV（标准）/ ±4kV

辐射抗扰度 (IEC 61000-4-3):
  场强: 3V/m（居民区）/ 10V/m（工业区）

传导抗扰度 (IEC 61000-4-6):
  电压: 3V（居民区）/ 10V（工业区）
```

## 3. EN 55032/55035 信息技术设备EMC要求

### 3.1 EN 55032 传导/辐射发射限值

EN 55032替代了原EN 55022和EN 55013，统一了多媒体设备的EMC发射要求。

#### 传导发射限值（交流电源端口）

| 频率范围 | Class A（工业） | Class B（民用） |
|---------|----------------|----------------|
| 150kHz~500kHz | 79 dBμV (QP) / 66 dBμV (AV) | 66~56 dBμV (QP) / 56~46 dBμV (AV) |
| 500kHz~1MHz | 73 dBμV (QP) / 60 dBμV (AV) | 56 dBμV (QP) / 46 dBμV (AV) |
| 1MHz~5MHz | 73 dBμV (QP) / 60 dBμV (AV) | 60 dBμV (QP) / 50 dBμV (AV) |
| 5MHz~30MHz | 73 dBμV (QP) / 60 dBμV (AV) | 60 dBμV (QP) / 50 dBμV (AV) |

#### 辐射发射限值（10米测量距离）

| 频率范围 | Class A（工业） | Class B（民用） |
|---------|----------------|----------------|
| 30MHz~230MHz | 40 dBμV/m (QP) | 30 dBμV/m (QP) |
| 230MHz~1GHz | 47 dBμV/m (QP) | 37 dBμV/m (QP) |
| 1GHz~3GHz | 56 dBμV/m (AV) | 50 dBμV/m (AV) |

```
QP = 准峰值（Quasi-Peak），AV = 平均值（Average）
Class B限值比Class A严格约10dB
3米法测量时限值需加10dB（20log(10/3)≈10）
```

### 3.2 EN 55035 抗扰度要求

EN 55035替代了原EN 55024，规定了多媒体设备的EMC抗扰度要求，试验项目与IEC 61000-4系列对应。

## 4. UL 60950-1/IEC 62368-1 安规标准

### 4.1 标准演进

```
安规标准演进路线：
UL 60950-1 / EN 60950-1 (信息技术设备安全)
    ↓ 逐步替代（2020年底全面废止）
IEC 62368-1 / EN 62368-1 (音视频/信息技术设备安全)
    → 基于危险工程学原理，更现代的安全标准
    → 第二版(2018)成为全球统一标准
    → 第三版(2023)进一步细化要求
```

### 4.2 IEC 62368-1 关键安全要求

| 安全要求 | 内容 | 设计影响 |
|---------|------|---------|
| 电气绝缘 | 基本/补充/加强/双重绝缘 | 变压器绝缘、爬电距离 |
| 安全特低电压(SELV) | ≤ 60V DC / 42.4V AC | 输出隔离设计 |
| 保护接地 | 接地阻抗 ≤ 0.1Ω（25A测试） | PE线截面积、接地连续性 |
| 温度限值 | 可触及部件 ≤ 95°C（金属）/ 75°C（非金属） | 散热设计、外壳材料 |
| 能量危险 | > 240VA电路需防触及 | 内部布线、外壳开孔 |
| 机械强度 | 跌落/冲击试验 | 外壳设计、PCB固定 |
| 防火防护 | V-1/V-0阻燃外壳（VJ级） | 外壳材料选择 |
| 电气间隙 | 见模块10安规间距表 | PCB间距设计 |
| 爬电距离 | 见模块10安规间距表 | PCB间距设计 |

### 4.3 变压器安规要求

```
IEC 62368-1 变压器绝缘要求：
1. 隔离变压器初次级之间需满足加强绝缘
2. 爬电距离：≥ 5.0mm（250V~500V，污染等级2）
3. 电气间隙：≥ 3.0mm（250V~500V）
4. 绝缘厚度：≥ 0.4mm（穿通绝缘，加强绝缘）
5. 漏电流测试：500V DC，绝缘电阻 ≥ 100MΩ
6. 耐压测试：初次级3000V AC/1min，无击穿
7. 温升测试：绕组温升 ≤ 80°C（B级绝缘，热阻法）
```

## 6. GB 17625 谐波电流限值

### 6.1 GB 17625.1-2022（等同IEC 61000-3-2）

```
谐波电流限值分类：
Class A：三相平衡设备及其他（含专业设备）
Class B：便携式工具
Class C：照明设备
Class D：≤ 600W，特殊波形输入设备（含个人电脑、电视等）

Class D 谐波电流限值（每瓦限值，适用75W~600W设备）：

谐波次数  限值(mA/W)    绝对限值(A)
  3       3.4          2.30
  5       1.9          1.14
  7       1.0          0.77
  9       0.5          0.40
  11      0.35         0.33
  13      0.30         0.21
  15~39   3.85/n       0.15 (15次)

注：
- 75W以下设备豁免（部分标准为50W）
- 超过600W按Class A限值（绝对值）
- PFC电路是满足谐波标准的主要手段
```

## 7. GB/T 14714 微型计算机通用规范

### 7.1 主要技术要求

| 要求项 | GB/T 14714规定 | 设计影响 |
|--------|---------------|---------|
| 输入电压 | 220V AC ±10%（198~242V） | 宽输入PFC设计 |
| 输入频率 | 50Hz ±1Hz | 锁相环频率跟踪 |
| 输出电压 | ±5%（典型值） | 反馈精度设计 |
| 输出功率 | 额定功率下连续运行 | 热设计裕量 |
| 效率 | ≥ 80%（台式机电源） | 同步整流、软开关 |
| 功率因数 | ≥ 0.9（>300W） | 主动PFC |

| 保持时间 | ≥ 16ms（满载） | 大容量储能电容 |
| 开机浪涌 | ≤ 额定电流的10倍 | 软启动、NTC/继电器 |
| MTBF | ≥ 25000h | 降额设计、可靠器件 |
| 噪声 | ≤ 38dBA（额定负载） | 风扇选型、风道设计 |

## 8. 民用vs军用标准要求对比

| 对比维度 | 民用标准 | 军用标准 | 差异说明 |
|---------|---------|---------|---------|
| EMC发射 | EN 55032（150kHz~30MHz传导） | GJB 151B CE102（10kHz~10MHz传导） | 军标起始频率低10倍 |
| EMC敏感度 | IEC 61000-4-3（3~10V/m） | GJB 151B RS103（10~200V/m） | 军标场强高10~20倍 |
| 安全标准 | IEC 62368-1 | GJB 239A + 安全要求 | 民用更注重人身安全 |
| 温度范围 | 0~40°C（商用）/ -20~+60°C（工业） | -55~+85°C | 军标宽2~3倍 |
| 振动要求 | IEC 60068（2~5g） | GJB 150A（20g随机） | 军标高4~10倍 |
| 能效要求 | 80 PLUS / DOE / CEC强制 | 无强制能效标准 | 民用有能效法规 |
| 谐波要求 | GB 17625 / IEC 61000-3-2 | GJB 151B（含CE101低频） | 民用有谐波强制限值 |
| 可靠性 | MTBF ≥ 5000~20000h | MTBF ≥ 20000~50000h | 军标高3~5倍 |
| 降额设计 | 无强制（工程实践推荐） | GJB/Z 35强制I/II级降额 | 军标有强制降额 |
| 三防要求 | 无强制 | 强制三防涂覆/灌封 | 军标必须防腐 |
| 认证方式 | 第三方认证（CE/UL/CCC） | 军方定型审批 | 民用走市场认证 |
| 设计寿命 | 3~5年（商用）/ 5~10年（工业） | ≥ 15年 | 军标长3~5倍 |
| 元器件等级 | 商用/工业级 | 军级/宇航级 | 军标失效率低5~10倍 |

## 9. 认证流程与测试项目

### 9.1 主要认证体系

| 认证体系 | 适用市场 | 标志 | 核心标准 | 认证机构 |
|---------|---------|------|---------|---------|
| CE | 欧盟 | CE | EN 55032/35, EN 62368-1 | TUV/SGS/Intertek |
| FCC | 美国 | FCC | FCC Part 15B/18 | FCC认可实验室 |
| UL | 美国（安全） | UL | UL 62368-1 | UL |
| CCC | 中国 | CCC | GB 9254, GB 4943.1 | CQC/CTC |
| EAC | 欧亚经济联盟 | EAC | TR CU 004/020 | EAC认可机构 |
| PSE | 日本 | PSE | J55032, J62368-1 | JET/JQA |
| KC | 韩国 | KC | KS C 9832/9835 | KTL |

### 9.2 CE认证流程（典型）

```
CE认证流程：
1. 确定适用指令（LVD低电压/EMC/ErP能效）
2. 确定适用标准（EN 62368-1, EN 55032/35, EN 61000-3-2/3）
3. 进行EMC测试
   - 传导发射（EN 55032）
   - 辐射发射（EN 55032）
   - 谐波电流（EN 61000-3-2）
   - 电压闪变（EN 61000-3-3）
   - ESD/EFT/Surge/RS/CS抗扰度（EN 55035）
4. 进行安全测试（EN 62368-1）
   - 耐压测试、接地测试、温升测试
   - 机械强度、防火测试
   - 电气间隙/爬电距离检查
5. 进行能效测试（如适用）
   - 平均效率、空载功耗
6. 编制技术构造文件(TCF)
7. 签署DoC符合性声明
8. 加贴CE标志
```

### 9.3 CCC认证流程

```
CCC认证流程（中国强制性产品认证）：
1. 提交认证申请（CQC网站）
2. 型式试验（CQC指定实验室）
   - 安全测试：GB 4943.1
   - EMC测试：GB 9254, GB 17625.1
3. 工厂质量体系审查（初次认证）
4. 获证后监督（每年1~2次工厂检查）
5. 发证：CCC证书有效期5年
6. 标志购买和使用：CCC标志需向CQC购买

关键差异（与CE对比）：
- CCC需工厂审查（CE不需要）
- CCC需年审监督（CE无年审）
- CCC标准为GB系列（CE为EN系列，技术等效但不完全相同）
- CCC认证周期：8~12周（CE约4~8周）
```

### 10.2 能效设计优化要点

```
能效优化策略（民用电源）：

1. 拓扑选择：
   - < 200W：反激（Flyback）
   - 200W~1kW：LLC谐振（高效率首选）
   - 1kW~5kW：移相全桥ZVS（PSFB）
   - > 5kW：交错并联LLC或PSFB

2. 同步整流：输出侧用MOSFET替代二极管整流，效率提升2~5%

3. 软开关技术：ZVS/ZCS减少开关损耗，LLC天然实现ZVS

4. 待机功耗控制：
   - Burst模式降低轻载损耗
   - 高压启动电阻换为JFET启动
   - 辅助电源优化（LDO换为Buck）

5. 器件选择：
   - 低Rds(on) MOSFET（超结/SiC）
   - 低ESR输出电容
   - 低损耗磁性材料（PC95/PC44）
```

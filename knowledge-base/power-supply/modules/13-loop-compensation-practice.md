## 1. 环路稳定性基础

控制环路稳定性是电源设计的核心，直接决定瞬态响应、输出精度和系统可靠性。

### 1.1 Bode图稳定性判据

```
开环传递函数 T(s) = G(s) × H(s)（功率级 × 补偿网络）

稳定性判据（Bode图）：
1. 相位裕度 PM（Phase Margin）= 180° + ∠T(jω_c)
   → PM > 45°（最低要求），推荐 45°~60°
   → PM < 30°：严重振荡风险
   → PM > 75°：响应过慢（过于保守）

2. 增益裕度 GM（Gain Margin）
   → |T(jω_π)| 在相位=-180°处的负增益
   → GM > 6dB（最低要求），推荐 > 10dB

3. 穿越频率 f_c（Crossover Frequency）
   → |T(jω_c)| = 0dB 时的频率
   → f_c = (1/5 ~ 1/10) × f_sw（一般原则）
   → 电压模式：f_c = f_sw / 5
   → 电流模式：f_c = f_sw / 5 ~ f_sw / 4
   → PFC电压环：f_c < f_line / 10（典型5~10Hz）
```

### 1.2 穿越频率选择指南

| 拓扑 | 控制模式 | 推荐穿越频率 | 限制因素 |
|------|---------|------------|---------|
| Buck | 电流模式 | f_sw / 5 | 采样延时 |
| Buck | 电压模式 | f_sw / 10 | LC谐振双极点 |
| Boost | 电流模式 | min(f_sw/5, f_RHPZ/3) | 右半平面零点 |
| 反激 | 电流模式 | min(f_sw/5, f_RHPZ/3) | 右半平面零点 |
| LLC | 变频控制 | f_sw / 10 | 谐振特性 |
| PSFB | 移相控制 | f_sw / 5 | 移相延时 |
| PFC（电压环） | 平均电流 | f_line / 10 | 工频纹波注入 |

### 1.3 稳定性指标与瞬态响应关系

```
相位裕度与过冲关系（二阶近似）：
 overshoot ≈ exp(-ζπ / √(1-ζ²))
其中 ζ ≈ PM(°) / 100（经验换算）

| PM | ζ | 过冲 | 振铃次数 | 评价 |
|----|---|------|---------|------|
| 30° | 0.30 | 38% | 多次 | 危险 |
| 45° | 0.45 | 23% | 2~3次 | 最低要求 |
| 52° | 0.52 | 16% | 1~2次 | 良好 |
| 60° | 0.60 | 10% | 1次 | 最佳 |
| 76° | 0.76 | 3% | 无 | 保守（慢） |
```

## 2. 网络分析仪实测方法

### 2.1 注入变压器选型与连接方式

```
环路测量原理：在反馈回路中注入小幅度扰动信号，测量扰动前后增益比

注入点选择（关键）：
→ 必须在低阻抗输出端和高阻抗反馈端之间
→ 典型注入点：输出电压分压电阻上端串联注入电阻

注入电阻：R_inject = 10~100Ω（远小于反馈阻抗，不影响直流工作点）

注入变压器选型要求：
- 带宽：覆盖 f_c / 10 ~ f_sw × 2（典型1Hz~10MHz）
- 低频响应好（低端 < 1Hz，用于PFC低带宽环路）
- 绝缘耐压满足一次-二次隔离要求（隔离反馈时）
- 推荐型号：Picotest J2100A（1Hz~5MHz）、OMICRON B-WIC（1Hz~10MHz）
```

### 2.2 扫频设置

```
网络分析仪（Bode 100 / FRA5087 / AP310等）设置：

频率范围：
  DC-DC环路：10Hz ~ 2MHz（覆盖f_c两侧各十倍频程）
  PFC电压环：0.1Hz ~ 1kHz（极低频）

注入幅度：
  扫频起始幅值：-30dBm（约7mV，小信号线性区）
  自适应幅度：开启（大信号时自动降低）
  注入电压扰动 < 5% × V_out（保证线性）

扫描速度：
  快速扫描：高速度，低精度（初测定位）
  精细扫描：低速度，高精度（最终验证）
  分辨率带宽RBW：≤ 测试频率/100（如测1kHz，RBW ≤ 10Hz）

测量参数：
  增益 |T|（dB）和相位 ∠T（°）
  输出：Bode图（幅频+相频）
```

### 2.3 隔离探头使用与测量注意事项

```
隔离差分探头使用：
  → 反馈信号测量须用差分探头（避免接地环路短路）
  → 推荐探头：Tektronix TMDP0200（200MHz差分）
  → 探头接地线最短化（减小拾取噪声）

常见测量误差及对策：

| 误差来源 | 现象 | 对策 |
|---------|------|------|
| 地线环路 | 测量波形含工频干扰 | 使用隔离变压器供电仪器 |
| 注入点不当 | Bode图不连续/异常 | 确认注入点在低阻-高阻之间 |
| 注入幅度过大 | 环路非线性，结果失真 | 降低注入幅度至 <5%输出 |
| 开关噪声干扰 | 高频段波形跳动 | 增加平均次数，降低RBW |
| 探头带宽不足 | 高频相位测量误差 | 差分探头带宽 > 10×f_sw |
| 负载电流影响 | 不同负载下环路特性不同 | 在多负载点测试 |

测量条件矩阵：
  → 最低输入电压 × 满载（最恶劣相位裕度）
  → 最高输入电压 × 满载
  → 标称输入 × 轻载（10%~25%）
  → 标称输入 × 满载
  → 全输入全负载扫描确认无条件稳定
```

## 3. Type I/II/III补偿器实际调试步骤

### 3.1 补偿器类型对比

```
Type I：单积分+单极点（原点极点+一个高频极点）
  → 用于电流模式控制内环
  → 提供-90°相位（积分器），带宽受限

Type II：原点极点+一个零点+一个高频极点
  → 用于电流模式控制外环
  → 零点提供+90°相位提升，最大相位提升90°
  → 最常用补偿器类型

Type III：原点极点+两个零点+两个高频极点
  → 用于电压模式控制（LC双极点需双零点补偿）
  → 最大相位提升180°
  → 补偿复杂，参数敏感
```

### 3.2 实际调试步骤

```
步骤1：获取功率级传递函数 G(s)
  ├─ 方法A：解析计算（基于拓扑公式）
  ├─ 方法B：实测（去掉补偿网络，网络分析仪测功率级Bode图）
  └─ 方法C：仿真（SIMPLIS/PSpice AC扫描）

步骤2：确定目标穿越频率 f_c
  → f_c = f_sw / 5（电流模式）或 f_sw / 10（电压模式）
  → 检查 f_c < f_RHPZ / 3（Boost/反激/反激）

步骤3：计算功率级在 f_c 处的增益和相位
  → |G(jω_c)| 和 ∠G(jω_c)

步骤4：选择补偿器类型
  → 电流模式 → Type II
  → 电压模式（LC双极点在f_c附近）→ Type III

步骤5：计算补偿参数
  Type II：
    补偿器增益 K = 1 / |G(jω_c)|
    零点 f_z1 = f_c / 10（提升相位）
    极点 f_p1 = f_sw / 2（滤除开关噪声）
    → R2/R1 = K, C1 = 1/(2π × f_z1 × R2), C2 = 1/(2π × f_p1 × R2)

  Type III：
    零点 f_z1, f_z2 = f_LC × 0.5（补偿LC谐振双极点）
    极点 f_p1 = f_sw / 2, f_p2 = f_sw / 2
    → 参见具体设计公式

步骤6：实测验证与调整
  → 网络分析仪测补偿后环路Bode图
  → 检查 PM > 45°, GM > 6dB, f_c 达标
  → 微调零极点位置优化
```

## 4. 不同拓扑补偿实例

### 4.1 Buck补偿实例

```
=== 电流模式Buck ===
参数：V_in=24V, V_out=5V, L=10μH, C_out=220μF, f_sw=500kHz
目标f_c = 100kHz

功率级在f_c处：
  |G| ≈ V_in/V_sense × R_load / (2π×f_c×L) （需查具体公式）
  ∠G ≈ -90°（电感占主导）

Type II补偿：
  f_z1 = 10kHz, f_p1 = 250kHz
  → PM目标55°

=== 电压模式Buck ===
LC谐振频率：f_LC = 1/(2π√(LC)) = 1/(2π√(10μ×220μ)) = 3.4kHz
  → LC双极点在3.4kHz，相位突降180°
  → 必须用Type III，双零点放置在f_LC附近

Type III零极点配置：
  f_z1 = f_LC / 2 = 1.7kHz
  f_z2 = f_LC × 2 = 6.8kHz  
  f_p1 = f_sw / 2 = 250kHz
  f_p2 = f_sw / 2 = 250kHz
  目标f_c = 50kHz, PM > 45°
```

### 4.2 Boost补偿实例（注意RHPZ）

```
右半平面零点频率：
f_RHPZ = R_load × (1-D)² / (2π × L)

参数：V_in=12V, V_out=24V, L=15μH, R_load=4.8Ω, D=0.5, f_sw=200kHz

f_RHPZ = 4.8 × 0.25 / (2π × 15e-6) = 12.7kHz

关键约束：f_c < f_RHPZ / 3 = 4.2kHz
→ 穿越频率限制在4kHz以下（Boost动态响应天生较慢）

Type II补偿：
  f_c = 3kHz
  f_z1 = 300Hz, f_p1 = 100kHz
  → PM目标50°（RHPZ造成相位损失，裕度需更大）

宽输入时RHPZ变化：
  V_in_min=8V → D_max=0.67 → f_RHPZ_min大幅下降
  → 需在最恶劣工况（最低输入、满载）下设计
```

### 4.3 LLC补偿实例

```
LLC为变频控制（PFM），控制变量为开关频率f_sw

谐振增益曲线特性：
  - f_sw > f_r（谐振频率）：降压模式，增益随频率升高而下降
  - f_sw < f_r：升压模式，增益随频率降低而先升后降
  - 工作点在f_r附近时灵敏度最高

补偿特点：
  - 功率级传递函数含谐振峰（高Q双极点）
  - 变频控制引入非线性（增益随工作点变化）
  - 推荐在最高增益灵敏度点设计补偿

设计步骤：
  1. 在最低输入电压（最高增益需求）工况下分析
  2. 小信号模型获取功率级传递函数
  3. Type II补偿，f_c = f_sw_nominal / 10
  4. 零点放置在f_c / 5，极点在f_sw / 2
  5. 全输入范围验证稳定性（不同工作点增益不同）
```

### 4.4 PSFB补偿实例（移相控制）

```
移相全桥特点：
  - 变频等效（移相角对应有效占空比）
  - 漏感导致有效占空比损失（D_eff = D - D_loss）
  - ZVS范围受负载影响（轻载ZVS丢失）

补偿策略：
  - 峰值电流模式控制（内环）→ Type I/II
  - 电压外环 → Type II
  - D_loss补偿：前馈补偿有效占空比损失

关键参数：
  f_c_inner = f_sw / 5（电流环）
  f_c_outer = f_sw / 10（电压环）
  → 注意变压器漏感对动态响应的影响
```

## 5. TL431+光耦反馈环路设计

### 5.1 光耦带宽限制与极点

```
光耦小信号模型：
  - 电流传输比 CTR（随温度/老化退化30~50%）
  - 寄生极点：f_p_opto ≈ 50kHz~500kHz（取决于负载电阻和Cce）

光耦极点频率：
f_p = 1 / (2π × R_pullup × C_ce)

其中：
  R_pullup = 次侧上拉电阻（通常1~10kΩ）
  C_ce = 光耦输出电容（典型3~10pF）

示例：R=4.7kΩ, C=5pF
f_p = 1/(2π × 4700 × 5e-12) = 6.8MHz（通常不是瓶颈）

但CTR低频滚降（受三极管特性限制）：
  - 实际有效带宽 ≈ 10~100kHz
  - CTR变化影响环路增益（需在设计裕度中考虑）
```

### 5.2 TL431补偿网络配置

```
TL431+光耦反馈典型配置（Type II补偿）：

        V_out
         │
    ┌────┤
    │    │ R_top（分压上臂）
    │    ┤
    │    ├──── REF (TL431)
    │    │
    │    │ R_bottom
    │    │
    │   GND
    
补偿网络：
  - R_z, C_z 串联在TL431阴极与REF之间（零点）
  - C_p 并联在R_z两端（高频极点，含光耦极点）

零点：f_z = 1 / (2π × R_z × C_z)
极点：f_p = 1 / (2π × R_z × C_p) （含光耦寄生极点）

TL431偏置电流要求：
  I_bias > 1mA（TL431正常工作最低电流）
  → 须保证空载时光耦LED电流回路能提供TL431偏置
  → 常加假负载或专用偏置电阻
```

### 5.3 隔离反馈环路稳定性要点

```
关键设计考量：

1. CTR容差影响：
   - CTR范围：50%~600%（器件差异+温度+老化）
   - 环路增益变化 = CTR变化
   → 必须在CTR_min下验证PM > 45°
   → 在CTR_max下验证GM > 6dB

2. 光耦响应速度：
   - 慢速光耦（如PC817）：带宽~80kHz
   - 高速光耦（如HCPL-0601）：带宽>1MHz
   → 高带宽环路需选高速光耦

3. TL431动态电阻：
   - TL431阴极动态阻抗影响补偿零点
   → R_z 须 >> TL431动态阻抗（约1~10Ω）

4. 隔离寄生电容：
   - 光耦输入-输出寄生电容（0.5~5pF）
   → 高dv/dt时共模噪声注入，可能引起误触发
```

## 6. 常见环路问题诊断

### 6.1 问题诊断表

| 现象 | 可能原因 | 诊断方法 | 解决方案 |
|------|---------|---------|---------|
| 输出持续振荡 | PM不足或GM不足 | Bode图检查PM/GM | 降低f_c或增加相位提升 |
| 负载阶跃振铃 | PM偏低（30~45°） | 阶跃响应+Bode图 | 增大补偿零点（提升相位） |
| 负载阶跃过冲大 | PM偏低或f_c过高 | 阶跃响应 | 降低f_c，增大PM |
| 瞬态响应慢 | PM过大（>70°）或f_c过低 | Bode图检查f_c | 提高f_c，减少补偿裕度 |
| 条件稳定 | 某工况PM为负但未振荡 | 全工况Bode扫描 | 重新设计补偿消除条件稳定 |
| 低频纹波大 | f_c过低或直流增益不足 | 输出纹波频谱 | 提高直流增益（增大积分系数） |
| 开机过冲 | 软启动与环路启动冲突 | 开机波形 | 优化软启动斜率，补偿初始状态 |

### 6.2 条件稳定风险

```
条件稳定（Conditional Stability）：
  某些工况下环路在f_c附近PM为正，但在其他频率PM为负
  → 虽然Nyquist未包围(-1,j0)，但工作点漂移可能进入不稳定区

风险：
  - 负载突变导致工作点变化 → 瞬间进入不稳定区
  - 温度变化改变器件参数 → 增益曲线偏移
  - 启动过程中穿越不稳定区

识别方法：
  - Bode图在某频率段相位接近-180°但增益>0dB
  - Nyquist图接近(-1,j0)

解决方案：
  - 重新设计补偿网络，确保全工况PM > 45°
  - 避免在f_c附近放置过多零极点
```

### 6.3 负载阶跃响应优化

```
阶跃响应指标：
  - 过冲量：< 5%（军用），< 10%（民用）
  - 恢复时间：< 200μs（高频环路），< 2ms（低频PFC）
  - 稳态误差：趋近于零（积分器保证）

优化方向：

| 目标 | 调整方向 | 副作用 |
|------|---------|--------|
| 减小过冲 | 增大PM（降低f_c或增加相位提升） | 响应变慢 |
| 加快响应 | 提高f_c | 过冲增大，PM降低 |
| 减小振铃 | 增大阻尼（零点靠近f_c） | 可能降低响应速度 |
| 减小稳态误差 | 增大直流增益（积分时间常数） | 可能影响PM |

负载阶跃测试条件：
  - 阶跃幅度：25%~75%~25%额定负载
  - 阶跃速率：0.1~1A/μs（模拟实际负载变化）
  - 测试点：输出端子（非PCB测试点，含连线阻抗）
```

## 7. 数字控制环路调试

### 7.1 数字补偿器实现

```
数字补偿器（PID/Type II/Type III）离散化：

连续域 Type II 传递函数：
G_c(s) = K × (1 + s/ω_z) / (s/ω_z × (1 + s/ω_p))

离散化方法（Tustin双线性变换）：
s = (2/T_s) × (z-1)/(z+1)

→ 转换为差分方程：
y[n] = b0×x[n] + b1×x[n-1] + b2×x[n-2] - a1×y[n-1] - a2×y[n-2]

系数计算：
b0 = K × (1 + T_s×ω_z/2) / (T_s×ω_z/2 × (1 + T_s×ω_p/2))
... （完整公式见数字控制参考文献）
```

### 7.2 采样延时补偿

```
数字控制引入额外延时（采样+计算+PWM更新）：
  T_delay = T_sample + T_compute + T_PWM_update

延时相位损失：
  Δφ = 360° × f_c × T_delay

示例：
  T_delay = 1.5 × T_sw（1.5个开关周期延时）
  f_c = f_sw / 5
  Δφ = 360° × (1/5) × 1.5 = 108°（巨大相位损失！）

补偿策略：
1. 减小延时：
   → 采样在PWM周期中间（避开开关瞬态）
   → 快速ISR（中断响应<500ns）
   → 双更新模式（每周期更新两次PWM）

2. 延时补偿器：
   → 预测控制（Smith预估器）
   → 增加相位超前补偿

3. 降低f_c：
   → f_c = f_sw / 8 ~ f_sw / 10（数字控制比模拟保守）

推荐数字控制器：
  - TI C2000（TMS320F28004x）：50~100MHz，专用PWM ePWM
  - ST STM32G4：170MHz，HRTIM（高分辨率定时器）
```

## 8. 设计审查要点清单

| 序号 | 审查项 | 合格判据 | 优先级 |
|-----|--------|---------|--------|
| 1 | 相位裕度（全工况） | PM > 45°，全输入全负载范围 | 高 |
| 2 | 增益裕度 | GM > 6dB（推荐>10dB），全工况 | 高 |
| 3 | 穿越频率 | f_c = f_sw/5~f_sw/10，且 < f_RHPZ/3 | 高 |

| 7 | 条件稳定排查 | 全工况无PM为负频段，Nyquist安全 | 高 |
| 8 | RHPZ约束（Boost/反激） | f_c < f_RHPZ_min/3（最低输入满载） | 高 |

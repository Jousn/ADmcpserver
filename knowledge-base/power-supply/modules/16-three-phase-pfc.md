# 三相PFC设计知识库（>10kW大功率应用）

> 适用范围：军用及民用大功率电源（10kW~100kW+）
> 目标受众：AI设计辅助Skill，用于三相PFC电路设计咨询与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 三相PFC需求分析

### 1.1 为何>10kW需要三相PFC

```
单相PFC受限因素：
1. 单相电流过大：10kW/230V = 43.5A（超出常规插座16~32A限制）
2. 电网不平衡：大功率单相负载导致三相不平衡
3. 中线电流：单相大功率使中线过载
4. 输入功率限制：单相市电实际可用功率通常 < 7kW

三相PFC优势：
- 功率分配到三相，每相电流降低为1/√3
- 自然平衡三相负载
- 无中线电流（三相平衡时）
- 功率密度高，适合大功率应用

适用场景：
- 工业大功率电源（>10kW）
- 军用地面/舰船电源
- 充电桩（直流快充）
- 数据中心UPS
- 大功率激光器/雷达电源
```

### 1.2 三相PFC设计目标

| 指标 | 民用目标 | 军用目标 |
|------|---------|---------|
| 功率因数 PF | ≥0.98（满载） | ≥0.99（满载） |
| 总谐波失真 THD | <5% | <3% |
| 效率（满载） | ≥97% | ≥98% |
| 输入电压 | AC 380V/400V/480V三相 | AC 115V/220V三相（航空/舰船） |
| 输出电压 | 650~800VDC | 600~800VDC |
| 中点平衡 | ±2% | ±1% |
| 功率范围 | 10~100kW | 10~200kW+ |

## 2. 拓扑类型对比

### 2.1 三相PFC主要拓扑

| 拓扑 | 器件数 | 器件电压应力 | 控制复杂度 | 效率 | 适用功率 | 特点 |
|------|--------|------------|-----------|------|---------|------|
| 三相Boost（六开关全桥） | 6 MOSFET + 6 Diode | V_out | 高 | 96~97% | 10~50kW | 全可控，双向功率流 |
| Vienna整流器 | 3 MOSFET + 18 Diode | V_out/2 | 中 | 97~98% | 10~30kW | 三电平，器件应力低 |
| 三电平NPC PFC | 8~12 MOSFET + Diode | V_out/2 | 高 | 97~98% | 20~100kW | 模块化，高功率 |
| 矩阵变换器 | 9双向开关 | 输入电压 | 极高 | 95~96% | <20kW | 无直流环节，研究阶段 |
| 两相/三相Interleaved PFC | 2~3×单相PFC | V_out | 中 | 96~97% | 10~30kW | 单相并联，无三相整流 |

### 2.2 选型决策矩阵

```
10~30kW, 高效率优先 → Vienna整流器（SiC）
20~100kW, 高功率/模块化 → 三电平NPC PFC
10~50kW, 需双向功率流 → 三相Boost全桥
10~30kW, 成本优先 → 三相Interleaved PFC（单相并联）
军用高可靠（宽输入） → 三电平NPC（器件应力低，冗余设计）
航空（115VAC/400Hz） → Vienna整流器（高功率密度）
```

## 3. Vienna整流器详细设计

### 3.1 拓扑结构

```
三电平Vienna整流器（每相2个开关管 + 2个二极管）：

     Va ── L_a ──┬──────────┬──────────┬── V_out(+) 
                 │          │          │
               D_a1       D_a2       ─┴─ C1
                 │          │          │
              ─┤├─ Q_a   ─┤├─          ─┬─ (中点M)
                 │          │          │
                 M          M          ─┴─ C2
                 │          │          │
     Vb ── L_b ──┼──────────┼──────────┼── V_out(-)  
                 │          │          │
               D_b1       D_b2        (结构类似a相)
              ─┤├─ Q_b   ─┤├─
                 │          │
     Vc ── L_c ──┼──────────┼──────────┘
               D_c1       D_c2
              ─┤├─ Q_c   ─┤├─

特点：
- 每相仅1个开关管（共3个），控制简单
- 三电平输出：器件电压应力 = V_out/2
- 二极管钳位实现中点连接
- 输入电流连续（ Boost电感在输入侧）
```

### 3.2 工作原理与开关状态

```
每相工作状态（以a相为例）：

状态1：Q_a导通
  → 电流路径：Va → L_a → Q_a → 中点M
  → 电感储能（类似Boost导通阶段）
  → 输出由C1/C2供电

状态2：Q_a关断，电流为正
  → 电流路径：Va → L_a → D_a1 → V_out(+)
  → 电感释放能量到上电容C1

状态3：Q_a关断，电流为负
  → 电流路径：V_out(-) → D_a2 → L_a → Va
  → 电感释放能量到下电容C2

关键特性：
- 每相开关独立控制（不需相间协调）
- 中点电流由各相电流方向决定
- 开关频率固定，PWM调制
- 器件电压应力 = V_out/2（三电平优势）
```

### 3.3 SVPWM控制策略

```
空间矢量脉宽调制（SVPWM）用于三相Vienna整流器：

1. 坐标变换：
   abc三相 → αβ静止坐标 → dq旋转坐标
   （Park变换，d轴对齐电压矢量）

2. 电压参考生成：
   V_d_ref = 控制d轴电流（有功功率）
   V_q_ref = 控制q轴电流（无功功率，PFC时q=0）

3. SVPWM调制：
   - 将dq参考电压合成空间矢量
   - 在六边形空间矢量图中选择最近三个矢量
   - 计算各矢量占空比
   - 生成三相PWM信号

4. 中点平衡控制：
   - 监测C1/C2电压差 ΔV = V_C1 - V_C2
   - 调整冗余矢量占空比平衡中点
   - 小矢量对中点电流方向可控

调制比限制：
m = V_peak_phase / (V_out/2) < 1.15（线性调制区）
→ 需保证 V_out > √2 × V_line-line / √3 × 1.15
→ 典型V_out = 700~800VDC（输入380VAC时）
```

### 3.4 SiC器件应用优势

```
Vienna整流器采用SiC器件的优势：

| 对比项 | Si器件方案 | SiC器件方案 | 改善 |
|--------|-----------|------------|------|
| 开关频率 | 20~40kHz | 60~100kHz | 2~3倍 |
| 开关损耗 | 高（IGBT尾流） | 低（MOSFET无尾流） | 降低50~70% |
| 二极管损耗 | 高（反向恢复） | 极低（SiC肖特基无trr） | 消除反向恢复 |
| 效率（满载） | 96~97% | 98~99% | +1~2% |
| 功率密度 | 基准 | 提升1.5~2倍 | 高频化减小磁性元件 |
| 热管理 | 大散热器 | 小散热器 | 热阻降低 |

推荐SiC器件（Vienna整流器）：
- 开关管：C3M0030090K（900V/45A，Wolfspeed）
- 钳位二极管：C3D10170H（1700V/15A SiC SBD）
- 适用功率：单模块10~30kW
```

### 3.5 输出电容中点平衡

```
中点不平衡问题：
- C1和C2电压不等 → 器件应力不均 → 失效风险
- 中点偏移 → 输入电流THD恶化

中点平衡控制方法：

1. 硬件平衡（被动）：
   - C1 = C2（严格匹配，±1%）
   - 均压电阻并联（消耗式，低效）

2. 软件平衡（主动，推荐）：
   - 检测 ΔV = V_C1 - V_C2
   - PI控制器输出补偿量 Δd
   - 注入零序分量调整中点电流
   - 或调整SVPWM冗余矢量分配

3. 中点平衡环路设计：
   f_c_balance = f_sw / 100 ~ f_sw / 50（低带宽）
   PM > 60°（中点平衡须高稳定）

设计要求：
| ΔV / V_out | < 1%（军用） / < 2%（民用）
```

### 3.6 典型功率范围与设计参数

```
Vienna整流器设计示例（30kW, 380VAC输入）：

| 参数 | 值 |
|-----|---|
| 输入电压 | 380VAC三相（线电压） |
| 输出电压 | 700VDC |
| 输出功率 | 30kW |
| 开关频率 | 70kHz（SiC） |
| 每相电感 | 150μH |
| 输出电容 C1=C2 | 680μF/450V（各2颗并联） |
| SiC MOSFET | C3M0030090K ×3 |
| SiC二极管 | C3D10170H ×6 |
| 满载效率 | 98.2%（SiC方案） |
| 满载PF | 0.998 |
| 满载THD | 2.5% |

电感设计：
L = V_phase_peak / (2 × f_sw × ΔI × k)
k = 纹波系数（0.2~0.3）
V_phase_peak = 380 × √2 / √3 = 310V
L = 310 / (2 × 70000 × 0.25 × 60) ≈ 148μH → 选150μH
```

## 4. 三电平NPC PFC设计

### 4.1 拓扑结构

```
中性点钳位（NPC）三电平三相PFC：

每相4个开关管 + 2个钳位二极管：

V_out(+) ──┬─────────────────────────────────
           │
         ─┤├─ Q1（上臂上管）
           │
         D1 ─→ 中点M（上钳位二极管）
           │
         ─┤├─ Q2（上臂下管）
           │───── L_a ── Va
         ─┤├─ Q3（下臂上管）
           │
         D2 ─→ 中点M（下钳位二极管）
           │
         ─┤├─ Q4（下臂下管）
           │
V_out(-) ──┴─────────────────────────────────

三相对称，共12个开关管 + 6个钳位二极管

电平状态：
P1：Q1+Q2导通 → 输出接V_out(+)     [+V_out/2]
P2：Q2+Q3导通 → 输出接中点M         [0]
P3：Q3+Q4导通 → 输出接V_out(-)     [-V_out/2]
```

### 4.2 器件电压应力减半优势

```
三电平NPC核心优势：器件电压应力 = V_out/2

| 参数 | 两电平（六开关全桥） | 三电平NPC |
|------|-------------------|----------|
| 器件电压应力 | V_out（全压） | V_out/2（半压） |
| 器件耐压选型 | 1200V（V_out=800V） | 650V（V_out=800V） |
| 器件成本 | 高（1200V SiC贵） | 低（650V SiC成熟） |
| 开关损耗 | 高（高压开关） | 低（低压开关） |
| EMI | dv/dt大 | dv/dt减半 |
| 中点平衡 | 无需 | 需要控制 |

选型建议：
- V_out = 800VDC → 选650V SiC MOSFET（NPC）
- V_out = 800VDC → 两电平需1200V SiC（成本高2~3倍）
- 大功率(>30kW) NPC可扩展为五电平（ANPC/T-Type）
```

### 4.3 控制策略

```
NPC PFC控制策略与Vienna类似，但开关管更多：

1. dq旋转坐标系电流控制（同Vienna）
2. SVPWM调制（三电平空间矢量图，更多矢量选择）
3. 中点平衡控制（NPC中点电流可控性优于Vienna）
4. 开关损耗平衡（ANPC：交替使用上下管路分担损耗）

ANPC（Active NPC）改进：
- 将钳位二极管替换为有源开关管
- 优化损耗分配，均衡热应力
- 适合高开关频率SiC应用

三电平SVPWM特点：
- 27个电压矢量（大/中/小/零矢量）
- 中矢量影响中点电位（不可控）
- 小矢量对中点可控（冗余矢量选择）
- 调制比 m < 1.15（线性区）
```

## 5. 三相PFC控制策略

### 5.1 dq旋转坐标系控制

```
控制框架：

abc → Clarke → αβ → Park → dq（旋转坐标系）

电压外环：
  V_d_ref = PI(V_out_ref - V_out) → I_d_ref（有功电流参考）
  I_q_ref = 0（单位功率因数，无功=0）

电流内环：
  V_d = PI(I_d_ref - I_d) + 解耦补偿
  V_q = PI(I_q_ref - I_q) + 解耦补偿

解耦补偿：
  V_d_comp = -ω × L × I_q
  V_q_comp = +ω × L × I_d
  （消除d/q轴交叉耦合）

逆变换：
  dq → Park逆 → αβ → Clarke逆 → abc → PWM占空比

带宽设计：
  电流内环 f_c = f_sw / 5 ~ f_sw / 8
  电压外环 f_c = 10~50Hz（PFC电压环须低带宽，避免工频注入）
  中点平衡环 f_c = f_sw / 100
```

### 5.2 PR控制器（比例谐振）

```
PR控制器（替代dq坐标系，在静止αβ坐标实现）：

G_PR(s) = Kp + Kr × s / (s² + ω₀²)

其中 ω₀ = 2π × f_line（工频角频率）

优势：
- 在基频处增益无穷大 → 稳态无差跟踪正弦参考
- 无需旋转坐标变换 → 计算量小
- 无需锁相环（PLL可选）

适用：电网频率固定的三相PFC
劣势：对电网频率偏移敏感（可加阻尼项改进）

改进型：准PR控制器（加阻尼）
G_QPR(s) = Kp + 2×Kr×ω_c×s / (s² + 2×ω_c×s + ω₀²)
ω_c = 5~15 rad/s（带宽，容忍频率偏移）
```

### 5.3 SVPWM调制

```
三相PFC的SVPWM实现：

1. 采样三相电流和电压
2. Clarke变换：abc → αβ
3. 计算参考电压矢量 V_ref（αβ分量）
4. 扇区判断（6扇区，三电平为24扇区）
5. 矢量作用时间计算（T1, T2, T0）
6. 占空比分配（对称7段式或5段式）
7. 生成PWM比较值

SVPWM vs SPWM：
| 特性 | SPWM | SVPWM |
|------|------|-------|
| 直流利用率 | 0.866 × V_dc | 1.0 × V_dc（+15%） |
| 谐波 | 较多 | 较少（最优） |
| 实现复杂度 | 低 | 中 |
| 中点可控性 | 无 | 有（冗余矢量） |

→ 三相PFC优先选用SVPWM
```

### 5.4 中点平衡控制

```
中点平衡控制方法对比：

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 冗余矢量法 | 调整小矢量正/负对占空比 | 不影响输出波形 | 调节范围有限 |
| 零序注入法 | 注入零序电压偏置 | 实现简单 | 增加谐波 |
| 滞环比较法 | ΔV超阈值切换矢量 | 响应快 | 可能引入低频振荡 |
| PI闭环法 | ΔV经PI输出补偿 | 平滑稳定 | 需调参 |

推荐：PI闭环 + 冗余矢量法（组合方案）

控制目标：
  |V_C1 - V_C2| / V_out < 1%（军用）
  |V_C1 - V_C2| / V_out < 2%（民用）
```

## 6. 三相PFC vs 单相Interleaved PFC选型（>10kW）

### 6.1 方案对比

| 对比项 | 三相Vienna PFC | 三相NPC PFC | 三相Interleaved单相PFC |
|--------|---------------|-------------|----------------------|
| 输入 | 三相无整流桥 | 三相无整流桥 | 3×单相PFC并联 |
| 器件数 | 少（3开关+18二极管） | 多（12开关+6二极管） | 中（3×(2开关+2二极管)） |
| 器件应力 | V_out/2 | V_out/2 | V_out（全压） |
| 控制复杂度 | 中 | 高 | 低（每相独立控制） |
| 三相平衡 | 天然平衡 | 天然平衡 | 需功率分配控制 |
| 中线电流 | 零（平衡时） | 零（平衡时） | 有（各相独立） |
| 效率 | 98%（SiC） | 98%（SiC） | 97%（含整流桥损耗） |
| 功率密度 | 高 | 高 | 中 |
| 成本 | 中 | 高 | 低（单相方案成熟） |
| 适用场景 | 工业标准方案 | 超大功率/高性能 | 成本敏感/现有单相平台扩展 |

### 6.2 选型决策流程

```
>10kW三相PFC选型：

是否需要三相平衡负载？
├─ 是 → 三相整流拓扑（Vienna / NPC）
│   ├─ 功率 10~30kW → Vienna整流器（SiC，效率最优）
│   ├─ 功率 30~100kW → 三电平NPC PFC（模块化扩展）
│   └─ 需双向功率流 → 三相Boost全桥
└─ 否（可接受中线电流） → 3×单相Interleaved PFC
    ├─ 成本优先 → 3×单相CCM Boost PFC
    └─ 效率优先 → 3×单相Totem-Pole PFC（SiC）

军用特殊考量：
├─ 宽输入（115VAC航空）→ Vienna（三电平应力低）
├─ 高可靠冗余 → NPC（可降额运行/冗余相）
└─ 400Hz航空电源 → Vienna（高频SiC，减小磁性元件体积）
```

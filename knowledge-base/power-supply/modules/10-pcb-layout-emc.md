# PCB布局与EMC设计知识库

> 适用范围：军用及民用中高功率电源（100W~50kW）
> 目标受众：AI设计辅助Skill，用于PCB布局设计与EMC审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

PCB布局是电源设计的核心环节，直接决定了电源的EMC性能、热性能、可靠性和功率密度。在大功率电源中，高di/dt回路产生的磁场辐射、高dv/dt节点产生的电场辐射、以及接地系统的完整性是三大核心挑战。军用电源还需满足三防涂覆、金属芯板、加固等特殊要求。

## 2. 大功率电源PCB叠层设计

### 2.1 推荐叠层结构

| 层数 | 典型叠层（6层板） | 典型叠层（8层板） | 用途 |
|------|------------------|------------------|------|
| L1 | 信号/元件面 | 元件面 | 元件布局、低速信号 |
| L2 | GND（完整地平面） | GND | 信号回流参考面 |
| L3 | 功率/信号 | 功率层 | 功率走线、大电流通路 |
| L4 | 功率/信号 | GND | 功率回路参考面 |
| L5 | GND | 功率层 | 辅助功率走线 |
| L6 | 信号/元件面 | GND | 信号参考面 |
| L7 | - | 信号层 | 控制信号 |
| L8 | - | 元件面 | 底面元件 |

### 2.2 叠层设计准则

```
关键原则：
1. 每个信号层都应紧邻一个完整参考面（GND或PWR）
2. 功率层与对应的地平面紧邻，形成低阻抗回路
3. 电源层和地平面间距尽量小（< 0.2mm），增大平面电容
4. 避免信号层跨分割平面走线（返回路径中断）
5. 高频信号尽量走在内层（两地面之间），减少辐射

铜厚选择：
- 控制/信号层：1oz（35μm）
- 功率层：2~4oz（70~140μm），根据电流密度
- 军用大功率：3~6oz（105~210μm），考虑载流和散热

载流能力估算（IPC-2152）：
I = K * ΔT^0.44 * W^1.0 * T^0.625

其中：
I = 允许电流（A）
ΔT = 允许温升（°C，通常10~20°C）
W = 铜箔宽度（mil）
T = 铜箔厚度（mil）
K = 系数（外层0.048，内层0.024）
```

## 3. 功率回路最小化原则

### 3.1 功率回路面积的影响

```
回路寄生电感估算：
L_loop ≈ μ0 * μr * A_loop / (2 * π * d)

其中：
μ0 = 4π × 10⁻⁷ H/m
A_loop = 回路面积（m²）
d = 回路等效直径（m）

回路面积引起的电压尖峰：
V_spike = L_loop * di/dt

设计目标：
- 回路面积越小越好
- Buck变换器：输入电容-上管-下管回路最小化
- Boost变换器：开关管-二极管-输出电容回路最小化
- 全桥/半桥：桥臂中点-变压器-母线电容回路最小化
```

### 3.2 回路优化布局策略

| 拓扑 | 关键回路 | 优化方法 |
|------|---------|---------|
| Buck | Cin-MOSFET-二极管 | 输入电容紧靠开关管，并联陶瓷电容 |
| Boost | MOSFET-二极管-Cout | 输出电容紧靠二极管，缩短开关节点走线 |
| 正激 | MOSFET-变压器-整流管 | 变压器初级回路和次级回路分别最小化 |
| 全桥 | 母线电容-桥臂-变压器 | 母线电容跨接全桥，低ESL电容并联 |
| LLC | 谐振电容-变压器-开关管 | 谐振回路紧凑布局，减小寄生参数对谐振频率影响 |

## 4. 接地策略

### 4.1 单点接地 vs 多点接地

| 接地方式 | 适用频率 | 优点 | 缺点 | 适用场景 |
|---------|---------|------|------|---------|
| 单点接地 | < 1MHz | 无地环路干扰 | 高频时地线阻抗大 | 低频模拟电路 |
| 多点接地 | > 10MHz | 低高频阻抗 | 可能形成地环路 | 数字/高频电路 |
| 混合接地 | 宽频段 | 兼顾高低频 | 设计复杂 | 电源系统（推荐） |

### 4.2 PGND vs SGND分离与汇接

```
电源PCB接地系统设计：

PGND（功率地）：
- 承载大电流回路（开关管、整流管、滤波电容）
- 噪声大，di/dt高
- 使用大面积铜箔，多过孔连接

SGND（信号地）：
- 控制电路、反馈电路的参考地
- 噪声敏感，需保持干净
- 与PGND在唯一一点汇接

汇接原则：
1. PGND与SGND在电源输出端单点汇接（星形接地）
2. 汇接点选择在输出滤波电容的负极
3. 汇接路径为单点连接（0Ω电阻或铜箔窄带）
4. 隔离电源的原副边地需通过Y电容连接（满足EMC）
5. 军用电源的汇接点需进行防腐处理
```

### 4.3 地平面分割规则

- 信号地与功率地物理分离，仅在输出端单点汇接
- A/D转换器跨接模拟地和数字地，地分割线在芯片下方
- 模拟地与数字地在A/D芯片引脚处汇接
- 禁止信号走线跨越地分割线（会导致返回路径中断和EMI恶化）

## 5. 高频走线设计

### 5.1 凯文接法（Kelvin Connection）

```
电流采样的凯文接法：
- 采样电阻的功率电流路径和电压检测路径独立
- 检测走线从采样电阻焊盘内侧引出（非电流流入端）
- 检测走线应平行且紧靠（差分布线），抵消共模干扰
- 检测走线宽度：0.2~0.3mm（减小电容耦合）

电压采样的凯文接法：
- 输出电压检测线从负载端引回（非输出电容端）
- 检测线和回流线平行布线（差分对）
- 检测线远离功率走线（间距 > 3倍线宽）
```

### 5.2 并联去耦设计

| 去耦电容 | 容值 | 谐振频率 | 作用 | 布局位置 |
|---------|------|---------|------|---------|
| 大电解 | 10~470μF | < 100kHz | 低频储能 | 输入/输出端 |
| 钽电容 | 1~22μF | 100kHz~1MHz | 中频去耦 | IC电源引脚 |
| 陶瓷X7R | 0.1~1μF | 1~10MHz | 高频去耦 | 紧贴IC VCC引脚 |
| 陶瓷COG | 1~10nF | 10~100MHz | 超高频去耦 | 紧贴IC VCC引脚 |
| 陶瓷COG | 100~470pF | > 100MHz | 射频去耦 | 最靠近噪声源 |

```
去耦电容并联原则：
1. 多个不同容值并联，覆盖宽频段
2. 小电容最靠近IC引脚，大电容稍远
3. 电容到IC引脚的走线尽量短（< 5mm）
4. 每个去耦电容应有过孔直接连接到地平面
5. 大功率开关管的去耦电容（陶瓷）应紧贴漏极/源极
```

## 6. 功率器件布局热均衡

### 6.1 热分布设计

```
热均衡布局原则：
1. 发热器件（MOSFET/IGBT/二极管）均匀分布在PCB上
2. 避免热源集中在一侧（导致局部热斑）
3. 热敏元件（NTC/温度传感器）远离热源
4. 电解电容远离热源（温度每升10°C，寿命减半）
5. 变压器/电感周围留散热空间（间距 > 5mm）

PCB热阻估算：
Rth(pcb) = t / (k * A)

其中：
t = PCB厚度（m）
k = FR4热导率 ≈ 0.3 W/(m·K)
A = 散热面积（m²）

散热优化：
- 发热器件下方铺满散热铜箔（非信号区）
- 散热焊盘使用多过孔阵列连接到内部地平面
- 过孔热阻约 50~100°C/W（单个），阵列可降至 5~10°C/W
```

## 7. 安规间距要求

### 7.1 爬电距离与电气间隙

| 工作电压 | 电气间隙（mm） | 爬电距离（mm） | 适用标准 |
|---------|--------------|--------------|---------|
| ≤ 60V (SELV) | 1.2 | 1.2 | IEC 62368-1 |
| 60~250V | 1.5 | 2.5 | IEC 62368-1 |
| 250~500V | 3.0 | 5.0 | IEC 62368-1 |
| 500~1000V | 5.5 | 8.0 | IEC 62368-1 |
| 1000~1500V | 8.0 | 12.0 | IEC 62368-1 |

```
爬电距离 vs 电气间隙：
- 爬电距离（Creepage）：沿绝缘表面的最短距离
- 电气间隙（Clearance）：空气中两导体间最短距离

污染等级修正：
- 污染等级1（无污染）：基准值
- 污染等级2（非导电性污染）：爬电距离 × 1.2
- 污染等级3（导电性污染）：爬电距离 × 1.5
- 军用/户外：按污染等级3设计，留额外裕量

过电压类别修正：
- 类别I（信号级）：基准 × 0.5
- 类别II（设备级）：基准值
- 类别III（配电级）：基准 × 1.25
- 类别IV（电源入口）：基准 × 1.5
```

## 8. EMC布局关键规则

### 8.1 EMI滤波器布局

```
EMI滤波器布局黄金法则：
1. 滤波器紧靠电源入口放置（入口到滤波器走线 < 20mm）
2. 滤波器输入与输出走线严格分离（不交叉、不平行走）
3. 共模电感下方禁止走信号线（磁场耦合）
4. X/Y电容的引线尽量短（减小寄生电感）
5. 滤波器地独立连接到机壳地（单点）
6. 滤波器元件集中布局，形成独立功能区
```

### 8.2 EMC布局检查规则

| 规则编号 | 内容 | 优先级 |
|---------|------|--------|
| EMC-01 | EMI滤波器输入输出线禁止平行走线 | 高 |
| EMC-02 | 开关节点（高dv/dt）铜箔面积最小化 | 高 |
| EMC-03 | 高di/dt回路面积最小化 | 高 |
| EMC-04 | 敏感信号远离开关管和变压器（间距>5mm） | 高 |
| EMC-05 | Y电容引线总长度 < 10mm | 高 |
| EMC-06 | 变压器下方禁止布控制信号 | 中 |
| EMC-07 | 散热器接大地（PE），减小共模耦合 | 高 |
| EMC-08 | 高速时钟/数字信号走在两地层之间 | 中 |
| EMC-09 | 输出功率线与反馈线分离布线 | 高 |
| EMC-10 | 连接器处加TVS/滤波，防止外部干扰注入 | 高 |

## 9. 军用PCB特殊要求

### 9.1 三防涂覆

```
三防涂覆要求：
- 涂覆材料：丙烯酸树脂（AR）、聚氨酯（UR）、硅树脂（SR）
- 涂覆厚度：25~75μm（常规），75~130μm（恶劣环境）
- 涂覆区域：所有PCB裸露导电部分（除连接器和指定不涂区域）
- 军标要求：GJB 150A 湿热试验后绝缘电阻 > 100MΩ
- 施工方式：浸涂、喷涂、选择性涂覆（推荐选择性涂覆，精度高）

不涂覆区域：
- 连接器触点
- 可调电位器
- 散热焊盘（如需直接接触散热器）
- 测试点
- 指定维修更换区域
```

### 9.2 金属芯板与加固

| 加固方式 | 适用场景 | 特点 | 成本影响 |
|---------|---------|------|---------|
| 金属芯板（铝基/铜基） | 大功率LED/高功率密度 | 导热性优，单层/双层为主 | 中 |
| 刚性加固框架 | 振动/冲击环境 | 增加机械强度 | 中 |
| 灌封处理 | 恶劣环境/防潮 | 全封装，散热好但维修困难 | 高 |
| 底部填充胶 | BGA/QFN器件 | 防焊点疲劳 | 低 |
| 锚定孔/压铆螺柱 | 模块固定 | 机械固定可靠 | 低 |

### 9.3 军用PCB材料选择

```
基材选择：
- 常规军用：FR-4 High-Tg（Tg ≥ 170°C），如生益S1000-2
- 高频/高速：Rogers RO4350B / Megtron 6
- 高温环境：聚酰亚胺（PI），Tg ≥ 260°C
- 高可靠性：BT环氧树脂，低CTE

军用PCB特殊要求清单：
1. 基材Tg ≥ 170°C（军标GJB要求）
2. 阻燃等级 94V-0
3. 阻焊油墨耐温 ≥ 150°C
4. 铜箔附着力满足GJB 360A要求
5. 过孔可靠性：100次温度循环（-65~+125°C）无失效
6. 表面处理：ENIG（金厚 ≥ 0.05μm），抗氧化耐腐蚀
7. 线宽/间距公差 ±10%（军标），比民用 ±20% 更严格
```

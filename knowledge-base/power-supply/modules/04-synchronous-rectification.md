# 同步整流设计知识库

> 适用范围：军用及民用中高功率电源（50W~10kW级）
> 目标读者：AI设计辅助技能（用于设计建议与设计审查）
> 版本：v1.0

---

## 1. 概述

同步整流（Synchronous Rectification, SR）是用功率MOSFET替代整流二极管以降低导通损耗的技术。在低压大电流输出（Vout < 12V，Iout > 5A）的电源中，同步整流可显著提升效率，典型效率提升幅度为3%~8%。

### 1.1 适用场景判断

| 判据 | 条件 | 推荐方案 |
|------|------|----------|
| 输出电压 | Vout < 5V | 强烈推荐同步整流 |
| 输出电压 | 5V ≤ Vout < 12V | 推荐同步整流 |
| 输出电压 | 12V ≤ Vout < 24V | 视电流大小决定 |
| 输出电压 | Vout ≥ 24V | 肖特基或硅二极管即可 |
| 输出电流 | Iout > 10A | 推荐同步整流 |
| 效率要求 | η > 92% | 必须使用同步整流 |

## 2. 同步整流 vs 肖特基二极管整流对比

### 2.1 核心对比表

| 对比项 | 肖特基二极管整流 | 同步整流（MOSFET） |
|--------|------------------|---------------------|
| 导通压降 | 0.3V~0.6V（固定） | I × Rds_on（随电流变化） |
| 导通损耗 | P = Vf × Io | P = Io² × Rds_on |
| 反向恢复 | 无（少数载流子存储少） | 体二极管有反向恢复问题 |
| 驱动复杂度 | 无需驱动 | 需要栅极驱动电路 |
| 成本 | 低 | 较高（MOSFET+驱动IC） |
| 效率（低压大电流） | 较低 | 显著提升 |
| 可靠性 | 高（无直通风险） | 需防交叉导通 |
| 适用频率 | 无限制 | 受驱动延迟限制 |
| 电压范围 | 高低压均可 | 低压大电流优势明显 |

### 2.2 损耗对比计算

肖特基二极管整流损耗：

```
P_schottky = Vf × Io
```

同步整流MOSFET导通损耗：

```
P_sr = Io² × Rds_on × D
```

其中 D 为占空比。

**临界电流**（两者损耗相等时的电流）：

```
I_critical = Vf / Rds_on
```

当实际输出电流大于 I_critical 时，同步整流才有优势。

**示例**：Vf = 0.45V，Rds_on = 5mΩ，则 I_critical = 90A。但在典型 Buck 变换器中，同步整流MOSFET的占空比 D ≈ (1 - Vin/Vout_relation)，需结合具体拓扑计算。

## 3. 自驱动 vs 外驱动同步整流

### 3.1 对比表

| 特性 | 自驱动同步整流 | 外驱动同步整流 |
|------|----------------|----------------|
| 驱动信号来源 | 变压器绕组或开关节点 | 专用驱动IC |
| 电路复杂度 | 低 | 较高 |
| 驱动时序精度 | 差（依赖电路拓扑） | 高（精确控制死区） |
| 适用拓扑 | 正激、反激 | 所有拓扑 |
| 轻载效率 | 较差（可能反向导通） | 好（可切换为二极管模式） |
| 瞬态响应 | 可能丢失驱动 | 稳定 |
| 成本 | 低 | 较高 |
| 军用推荐 | 不推荐（可靠性差） | 推荐 |

### 3.2 自驱动同步整流电路类型

#### 3.2.1 电压自驱动

- 利用变压器辅助绕组提供栅极驱动电压
- 适用于正激变换器
- **缺点**：轻载时驱动电压不足，可能进入二极管整流模式

#### 3.2.2 电流自驱动

- 通过检测电流方向控制MOSFET开关
- 适用于反激变换器
- **优点**：自然实现零电流关断
- **缺点**：需要电流检测电路，增加复杂度

### 3.3 外驱动同步整流

#### 3.3.1 推荐驱动IC

| 驱动IC型号 | 驱动能力 | 适用拓扑 | 特点 |
|------------|----------|----------|------|
| TI UCC24612 | 4A峰值 | 反激/正激 | 高速、低功耗 |
| TI LM5045 | 1.5A | 正激 | 集成PWM控制器 |
| Infineon IR11682 | 4A | 正激/反激 | 双通道SR驱动 |
| onsemi NCP4305 | 4.5A | 反激/正激 | 可编程关断阈值 |
| Maxim MAX5079 | 3A | 正激 | 低传播延迟 |

#### 3.3.2 外驱动设计要点

- 驱动IC应靠近MOSFET放置，减小驱动回路寄生电感
- 栅极驱动走线应采用开尔文连接
- 驱动电压建议 5V~10V，不应超过MOSFET的 Vgs_max（通常 ±20V）

## 4. MOSFET选型

### 4.1 关键参数

| 参数 | 符号 | 说明 | 选型建议 |
|------|------|------|----------|
| 漏源击穿电压 | Vds | 需留有裕量 | Vds ≥ 1.5 × Vds_max |
| 导通电阻 | Rds_on | 决定导通损耗 | 越低越好，但权衡Qg |
| 栅极电荷 | Qg | 影响驱动损耗和开关速度 | 低Qg优先 |
| 体二极管压降 | Vsd | 影响死区损耗 | 越低越好 |
| 体二极管反向恢复电荷 | Qrr | 影响反向恢复损耗 | 越低越好 |
| 结-壳热阻 | RθJC | 影响散热设计 | 越低越好 |
| 开关时间 | td_on/td_off | 影响死区设置 | 快速开关 |
| 最大结温 | Tj_max | 军用需高裕量 | ≥ 150°C，军用推荐 ≥175°C |

### 4.2 Rds_on 与 Qg 的权衡

低 Rds_on 意味着大芯片面积，从而导致高 Qg。需根据开关频率和工作占空比进行优化。

**品质因数（Figure of Merit, FOM）**：

```
FOM = Rds_on × Qg  [mΩ·nC]
```

FOM 越小，MOSFET综合性能越好。现代低压MOSFET的FOM通常在 10~100 mΩ·nC 范围。

### 4.3 推荐MOSFET型号（低压同步整流）

| 型号 | Vds | Rds_on(max) | Qg(typ) | 封装 | 适用场景 |
|------|-----|-------------|---------|------|----------|
| Infineon BSC014N06NS | 60V | 1.4mΩ | 88nC | SuperSO8 | 大电流输出 |
| Infineon IPB019N08N3 | 80V | 1.9mΩ | 110nC | TO-263 | 高功率 |
| TI CSD18533KCS | 60V | 1.8mΩ | 62nC | TO-220 | 中高功率 |
| onsemi FDBL86361 | 60V | 2.6mΩ | 45nC | TO-252 | 中功率 |
| Vishay SiR626DP | 60V | 4.5mΩ | 25nC | PowerPAK | 高频应用 |

### 4.4 军用MOSFET选型特殊要求

- 工作温度范围：-55°C ~ +125°C（结温可达 +175°C）
- 抗辐射要求：根据轨道高度选择TID（总电离剂量）等级
  - 低轨道（LEO）：≥ 10 krad(Si)
  - 地球同步轨道（GEO）：≥ 100 krad(Si)
- 推荐抗辐射加固型号：IRHNJ67130（Vishay）、IRHLNJ77030（Infineon）
- 需有抗浪涌能力，Vds 需 ≥ 2 × 正常工作电压

## 5. 驱动电路设计

### 5.1 驱动电压选择

```
Vgs_drive 推荐值：
- 逻辑级MOSFET（Vth < 2V）：4.5V ~ 5V
- 标准MOSFET（Vth 2~4V）：8V ~ 10V
- 不应超过 Vgs_max（通常 ±20V），推荐留 50% 裕量
```

### 5.2 死区时间设计

死区时间（Dead Time, tdt）是上下管均关断的时间，用于防止交叉导通。

**死区时间计算**：

```
tdt = td_off(max) - td_on(min) + t_margin

其中：
  td_off(max): 关断延迟最大值（含温度、工艺偏差）
  td_on(min):  开通延迟最小值
  t_margin:   安全裕量（通常 20~50ns）
```

典型死区时间范围：50ns ~ 200ns

**死区时间过大的影响**：
- 死区期间电流通过体二极管导通，增加损耗
- 体二极管压降约 0.7V~1.2V，远高于 Rds_on 压降

**死区时间过小的影响**：
- 交叉导通（直通），造成巨大短路电流
- 可能损坏MOSFET

### 5.3 防止反向导通

在同步整流应用中，MOSFET可能在电流反向时仍被驱动导通，导致能量倒灌。预防措施：

1. **电流方向检测**：使用检流电阻或霍尔传感器检测电流方向，电流过零时关断SR MOSFET
2. **谷底检测关断**：检测 drain-source 电压过零点，提前关断
3. **最小导通时间限制**：设置最小导通时间防止抖动
4. **使用专用SR驱动IC**：内置电流检测和自适应关断功能

### 5.4 驱动损耗计算

```
P_drive = Qg × Vgs × fsw × N

其中：
  Qg:    栅极总电荷
  Vgs:   驱动电压
  fsw:   开关频率
  N:     每周期开关次数（通常为1或2）
```

**示例**：Qg = 60nC, Vgs = 10V, fsw = 100kHz, N = 2

```
P_drive = 60e-9 × 10 × 100e3 × 2 = 0.12W
```

## 6. 交叉导通（Cross Conduction）预防

### 6.1 交叉导通成因

| 成因 | 说明 |
|------|------|
| 死区时间不足 | 上下管切换时存在重叠导通 |
| 驱动延迟不对称 | 上升沿和下降沿延迟差异大 |
| 寄生电感引起振铃 | 栅极驱动回路寄生电感导致误触发 |
| 噪声耦合 | 开关节点dv/dt噪声耦合到栅极 |
| 驱动IC故障 | 驱动IC内部逻辑错误 |

### 6.2 预防措施

1. **硬件死区时间**：使用具有固定硬件死区的驱动IC，不依赖软件
2. **自适应死区时间**：部分高级驱动IC可根据负载自适应调整死区
3. **栅极电阻优化**：
   - 开通电阻 Rg_on 控制开通速度
   - 关断电阻 Rg_off 控制关断速度（通常 Rg_off < Rg_on）
   - 使用二极管+电阻并联实现非对称驱动
4. **负压关断**：关断时施加 -2V ~ -5V 负栅压，提高抗噪声能力
5. **米勒钳位**：使用有源米勒钳位电路防止 Cgd 耦合引起的误开通

### 6.3 交叉导通检测

- 监测开关节点电压波形，检查是否有短路脉冲
- 监测输入电流，异常尖峰可能指示直通
- 在调试阶段使用电流探头检测每个MOSFET的漏极电流

## 7. 大功率同步整流并联均流

### 7.1 并联均流方法

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 被动均流 | 利用Rds_on自然均衡 | 简单 | 均流精度低 |
| 栅极电阻均流 | 调整各管Rg微调开关时序 | 中等复杂 | 温漂影响大 |
| 源极电阻均流 | 检测各管电流反馈调节 | 精度高 | 增加损耗 |
| 专用均流IC | 集成电流采样和均流控制 | 精度最高 | 成本高 |

### 7.2 并联MOSFET设计要点

1. **选型匹配**：并联MOSFET应选同一批次，Rds_on 偏差 < 5%
2. **对称布局**：PCB布局保证各并联支路寄生参数一致
3. **温度耦合**：并联MOSFET应靠近放置，保证温度均衡（防止热失控）
4. **栅极独立电阻**：每个MOSFET的栅极串联独立电阻（3~10Ω），防止振荡
5. **均流降额**：并联后总电流降额 10%~20%，不可直接线性叠加

### 7.3 均流精度要求

```
均流不平衡度 = (Imax - Imin) / Iavg × 100%

要求：
- 民用电源：< 15%
- 军用电源：< 10%
- 高可靠性应用：< 5%
```

## 8. 效率优化策略

### 8.1 损耗分解与优化

| 损耗类型 | 公式 | 优化策略 |
|----------|------|----------|
| 导通损耗 | P_cond = Io² × Rds_on × D | 降低Rds_on、并联 |
| 开关损耗 | P_sw = 0.5 × Vin × Io × (tr+tf) × fsw | 加快开关速度、ZVS/ZCS |
| 驱动损耗 | P_drive = Qg × Vgs × fsw | 选择低Qg器件 |
| 死区损耗 | P_dead = Vsd × Io × tdt × fsw | 优化死区时间 |
| 体二极管反向恢复 | P_rr = Qrr × Vin × fsw | 选择低Qrr器件 |
| 输出电容损耗 | P_coss = 0.5 × Coss × Vin² × fsw | 选择低Coss器件 |

### 8.2 轻载效率优化

1. **二极管仿真模式（DEM）**：轻载时关闭同步整流，让体二极管工作，避免反向电流
2. **脉冲跳跃模式（PSM）**：极轻载时降低开关频率
3. **可变频率控制**：根据负载调整开关频率
4. **栅极驱动自适应**：轻载时降低驱动电压以减少驱动损耗

### 8.3 ZVS/ZCS 软开关配合

- 在LLC谐振变换器中，同步整流天然实现ZCS
- 在移相全桥中，原边ZVS可减少副边整流管电压应力
- 软开关可显著降低开关损耗，允许使用更高开关频率

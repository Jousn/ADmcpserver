# 隔离技术设计知识库

> 适用范围：军用及民用中高功率电源（100W~50kW）
> 目标受众：AI设计辅助Skill，用于隔离方案选型、隔离器件选型与隔离电路审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

隔离技术是电源系统中保障人身安全、提升抗干扰能力、实现地回路分离的关键手段。在中高功率电源中，原副边隔离不仅满足安规要求，还影响反馈环路稳定性、栅极驱动可靠性以及系统EMC性能。军用电源对隔离器件的共模瞬态抗扰度（CMTI）、绝缘耐压、抗辐射能力有更严苛的要求，需在器件选型与PCB布局中重点考虑。

## 2. 隔离需求分析

### 2.1 隔离类型

| 隔离类型 | 定义 | 典型应用 | 安规标准 |
|---------|------|---------|---------|
| 安全隔离（Basic） | 基本绝缘，防电击单重保护 | 一次侧到可触及部分 | IEC 61010/IEC 60950 |
| 加强隔离（Reinforced） | 等效双重绝缘，高可靠性 | 医疗/军用电源一次侧到二次侧 | IEC 60601-1/IEC 62368 |
| 功能隔离 | 仅功能需要，非安全目的 | 数字地与模拟地分离 | — |
| 双重隔离 | 基本绝缘+附加绝缘 | 医疗设备（BF/CF型） | IEC 60601-1 |

### 2.2 工作电压与过电压类别

```
过电压类别（IEC 60664-1）：
- OVC II：便携式设备，瞬时过压 2.5kV（250V系统）
- OVC III：固定安装设备，瞬时过压 4.0kV（250V系统）
- OVC IV：进线设备，瞬时过压 6.0kV（250V系统）

工作电压与隔离耐压关系：
- 基本绝缘：耐压 = 1.5 × 工作电压峰值
- 加强绝缘：耐压 = 2 × 基本绝缘耐压

示例（280VAC输入电源）：
- 峰值工作电压 Vpk = 280 × 1.414 = 396V
- 基本绝缘耐压 ≥ 1.5 × 396 = 594V
- 加强绝缘耐压 ≥ 2 × 594 = 1188V → 按 1500Vrms 设计

军用要求：
- GJB 181A：航空电源28VDC系统，瞬态过压可达 600V
- 绝缘耐压试验：1500VAC/60s 无击穿（常规），军用常按 2500VAC/60s
```

### 3.2 光耦隔离

#### 3.2.1 普通光耦（PC817/PC354）

```
关键参数：
- 电流传输比 CTR（Current Transfer Ratio）：
  CTR = Ic / If × 100%
  PC817典型值：50%~600%（分档）
- CTR温漂：-25°C时下降至常温的50%，+85°C时下降至70%
- CTR老化：10000小时后下降 10%~30%（高温、大电流更严重）

带宽限制：
- PC817 上升/下降时间：3~4us（典型）
- 最大可用频率：< 50kHz
- 适用于：低速反馈、数字信号隔离

设计准则：
- 工作电流 If 取 5~10mA（CTR最佳区间）
- CTR设计降额：按标称值的 50% 设计（温漂+老化）
- 反馈环路中光耦极点：f_p = 1/(2π × R_pullup × C_parasitic)
  典型 f_p = 10~100kHz，需在补偿中考虑
```

#### 3.2.2 高线性光耦（HCNR201/HCPL-7520）

```
HCNR201（高线性模拟光耦）：
- 结构：LED + 两个匹配光敏二极管（PD1反馈，PD2输出）
- 非线性度：< 0.01%
- 带宽：1MHz（典型）
- CTR匹配度：±5%（PD1/PD2）
- 应用：模拟信号隔离采样（电压/电流反馈）

电路结构：
PD1接运放负反馈 → LED电流稳定 → PD2输出跟随
Vout = Vin × (R2/R1) × (K2/K1)
其中 K2/K1 ≈ 1（出厂匹配）

设计准则：
- 运放选低偏置型（< 1nA），减少PD暗电流影响
- 增益由外部电阻设定，避免依赖光耦CTR
- 适用于高精度隔离反馈（0.1级）
```

#### 3.2.3 TL431 + 光耦反馈环路设计

```
TL431+光耦是隔离反激/正激电源最常用的反馈组合：

电路结构：
1) 输出电压经分压电阻 R1/R2 接TL431 REF端
2) TL431阴极接光耦LED，串联限流电阻 R3
3) 光耦三极管接原边控制IC反馈脚，上拉电阻 R4

关键设计公式：
- 输出电压：Vout = Vref × (1 + R1/R2)，Vref = 2.5V
- 光耦LED电流：If = (Vout - Vk_tl431) / R3，Vk_tl431 ≈ 2.5~3V
- 原边反馈电流：Ic = CTR × If
- 反馈电压：Vfb = Vcc - Ic × R4

环路补偿（Type II）：
- 零点：fz = 1/(2π × R3 × Cz)
- 极点：fp = 1/(2π × R3 × Cp)（Cp含寄生电容）
- 光耦极点：fp_opto = 1/(2π × R4 × C_opto)，C_opto ≈ 2~10pF

设计准则：
- TL431阴极电流 ≥ 1mA（保证正常工作，低静态电流型号如TLV431可0.1mA）
- 光耦If设计值 1~5mA，避免大电流加速老化
- R4取值 1~10kΩ，平衡带宽与功耗
- 光耦极点 fp_opto 常在 10~100kHz，对环路相位影响大，需在补偿中计入
```

### 3.3 磁耦隔离

#### 3.3.1 电流互感器（CT）

```
应用：电流采样隔离（如PFC电感电流、变压器原边电流）

关键参数：
- 变比 N：如 1:100（原边1匝，副边100匝）
- 采样电阻 Rs：将副边电流转换为电压
- Is = Ip / N，Vsample = Is × Rs

设计准则：
- 采样电压：1~2V（信噪比与功耗平衡）
- 磁通密度：B < 0.2 × Bsat（避免饱和）
- 单向电流需复位电路（二极管+齐纳）
- 带宽：由磁芯材料决定，通常 10kHz~1MHz

优缺点：
- 优点：无损采样、带宽高、隔离耐压高
- 缺点：无法测量直流、体积大、低频精度差
```

#### 3.3.2 脉冲变压器

```
应用：栅极驱动隔离、信号隔离传输

关键参数：
- 变比：1:1 或 1:2（升压驱动）
- 绝缘耐压：1500~5000VAC
- 伏秒积：V·us（防止饱和）
- 漏感：< 1uH（影响驱动速度）

设计准则：
- 伏秒积裕量 ≥ 2× 最大占空比×周期×电压
- 推荐磁芯：N30/N49（铁氧体），或高磁导率环形磁芯
- 驱动频率 < 1MHz 时，变压器性价比高
- 高频（> 1MHz）建议用集成磁耦驱动IC
```

### 3.4 数字隔离器

#### 3.4.1 主流数字隔离器对比

| 器件系列 | 厂商 | 隔离技术 | CMTI | 工作电压 | 浪涌耐受 | 通道数 |
|---------|------|---------|------|---------|---------|--------|
| ADuM120x | ADI | iCoupler（磁） | 25~50V/ns | 560Vrms | 6kVpk | 2 |
| ADuM141x | ADI | iCoupler | 50V/ns | 560Vrms | 6kVpk | 4 |
| ISO77xx | TI | 容耦 | 50~100V/ns | 1000Vrms | 10kVpk | 1~6 |
| Si86xx | Silicon Labs | 容耦 | 50V/ns | 5000Vrms | 10kVpk | 1~6 |
| ISO78xx | TI | 容耦（增强） | 100V/ns | 8000Vrms | 12.5kVpk | 2~4 |
| ADuM540x | ADI | iCoupler+isoPower | 50V/ns | 560Vrms | 6kVpk | 4+电源 |

#### 3.4.2 数字隔离器关键指标

```
1) CMTI（共模瞬态抗扰度）：
   定义：隔离器承受共模 dv/dt 的能力
   单位：V/ns 或 kV/us
   测试方法：施加共模阶跃电压，测量输出误脉冲

   设计准则：
   - 一般工业：CMTI ≥ 25V/ns
   - 高压开关电源（SiC/GaN）：CMTI ≥ 50V/ns
   - 军用/大功率：CMTI ≥ 100V/ns

2) 工作电压（VIORM）：
   定义：隔离器可长期承受的最大重复峰值电压
   设计准则：VIORM ≥ 1.5 × 系统最大工作电压峰值

3) 浪涌耐受（VIOTM）：
   定义：短时（60s）可承受的瞬态电压
   设计准则：VIOTM ≥ 过电压类别对应值

4) 传播延时：
   - 普通数字隔离器：10~50ns
   - 高速型：< 10ns
   - 对PWM驱动：延时匹配（通道间偏差 < 5ns）重要

5) 失效模式：
   - 默认输出高或默认输出低（选型需匹配安全要求）
   - ISO77xx默认输出高，ADuM120x可选默认电平
```

#### 3.4.3 选型决策准则

```
- 通信隔离（SPI/UART/PMBus）：ISO7721（双通道）、ADuM1201
- 栅极驱动隔离：ADuM4135（集成驱动）、UCC21520（半桥驱动）
- 高压隔离（> 800V）：ISO7821（8000Vrms增强绝缘）
- 需要隔离电源：ADuM540x（集成isoPower，省外部DC-DC）
- 军用：选抗辐射版本或高CMTI（> 100V/ns）型号
- 低功耗：Si86xx（静态电流 < 1mA@1Mbps）
```

### 3.5 电容耦合隔离器

```
原理：利用SiO2介质电容耦合数字信号（差分传输）

特点：
- 介电强度高：SiO2击穿场强 500~1000V/um
- 寿命长：无LED老化问题
- CMTI：50~100V/ns（容耦天然抗共模）
- 传播延时：< 10ns（高速）

代表器件：TI ISO77xx、Silicon Labs Si86xx
应用：数字通信、PWM信号传输

与磁耦对比：
- 容耦：抗磁场干扰好，但抗电场瞬态需设计
- 磁耦：抗电场干扰好，但易受外部磁场影响
- 两者CMTI均可满足 > 50V/ns，工程上可互换
```

## 4. 隔离栅驱动设计

### 4.1 隔离驱动方案对比

| 方案 | 代表器件 | 驱动电流 | CMTI | 延时 | 适用开关管 | 优缺点 |
|------|---------|---------|------|------|----------|--------|
| 光耦驱动 | TLP250/HCPL3120 | 0.5~2A | 15~30V/ns | 300~500ns | Si MOSFET/IGBT | 成本低，延时大，CMTI低 |
| 光耦驱动（高速） | HCPL-316J | 2A | 30V/ns | 200ns | IGBT | 带DESAT保护 |
| 磁隔离驱动 | UCC21520 | 4A | 100V/ns | 30~50ns | SiC/GaN/Si | 高速高CMTI |
| 磁隔离驱动 | ADuM4135 | 2A | 50V/ns | 55ns | SiC MOSFET | 带DESAT/UVLO |
| 变压器驱动 | 分立脉冲变压器 | 5~10A | > 100V/ns | < 20ns | 高频大功率 | 超高速，体积大 |
| 容耦驱动 | ISO5852S | 2.5A | 100V/ns | 50ns | SiC/IGBT | 高CMTI，增强绝缘 |

### 4.2 光耦驱动设计要点

```
TLP250/HCPL3120 应用：
- 输入LED电流 If = 5~10mA
- 驱动电流：±0.5A（TLP250），±2A（HCPL3120）
- Vcc供电：15~30V（驱动IGBT常用 +15V/-5V双电源）

设计准则：
- 光耦驱动CMTI仅 15~30V/ns，不适用于SiC/GaN高dv/dt场合
- LED侧需限流电阻：R = (Vlogic - Vf_led) / If
- 输出侧旁路电容：0.1uF + 1uF，紧邻供电脚
- 传播延时大（300~500ns），死区需补偿
- 老化问题：LED CTR下降，驱动能力下降，设计降额 ≥ 50%

适用场景：
- Si MOSFET，开关频率 < 100kHz
- 成本敏感的民用电源
- 不推荐用于军用高压SiC驱动
```

### 4.3 磁隔离驱动设计要点

```
UCC21520（半桥磁隔离驱动）：
- 驱动能力：4A峰值
- CMTI：100V/ns（适用于SiC）
- 传播延时：30ns（高速）
- 死区可编程：内部死区 100ns，外部可扩展
- 工作电压：1500Vrms（基本绝缘）

ADuM4135（单通道SiC驱动）：
- 驱动能力：2A峰值
- CMTI：50V/ns
- 集成DESAT保护（去饱和检测）
- UVLO（欠压锁定）：11V（SiC推荐）

设计准则：
- SiC MOSFET推荐驱动电压 +18V/-3V（或 +20V/-5V）
- 驱动电阻 Rg：SiC取 2.2~10Ω（平衡开关速度与振铃）
- 栅极到驱动IC距离 < 50mm，减少寄生电感
- 驱动供电需隔离DC-DC（推荐5kVrms隔离）
- DESAT检测电容：100~470pF（滤波短路检测延时）
- DESAT阈值：7V（对应Vce_sat + 二极管压降）

关键参数验证：
- 驱动峰值电流 Ig_peak = (Vdrive - Vgate) / Rg
  示例：Vdrive = 18V，Rg = 4.7Ω → Ig = 3.8A（需驱动IC支持）
- 平均驱动功率 Pdrive = Qg × Vdrive × fsw
  示例：Qg = 60nC，Vdrive = 18V，fsw = 100kHz → P = 108mW
```

### 4.4 变压器驱动设计

```
适用：超高频（> 500kHz）或大功率（> 50kW）

优点：
- 超低延时（< 20ns）
- 超高CMTI（> 100V/ns）
- 可传输较大功率（自驱动）

缺点：
- 体积大，需手工绕制
- 占空比范围受限（伏秒平衡）
- 隔离耐压取决于绝缘层

设计要点：
- 磁芯：N30/N49铁氧体或高磁导率环形
- 变比：1:1 或 1:2（升压）
- 漏感 < 500nH（影响驱动边沿）
- 绝缘：三层聚酯薄膜，耐压 > 3kVAC
- 需复位电路防止磁饱和（齐纳钳位）
```

## 5. 隔离电源设计

### 5.1 隔离DC-DC模块选型

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 输入电压 | 5V/12V/24V | 匹配辅助电源 |
| 输出电压 | 5V/12V/15V/-5V | 匹配驱动IC供电 |
| 输出功率 | 0.5~5W | 栅极驱动功耗+裕量 |
| 隔离耐压 | 1.5~6kVDC | 按系统绝缘等级 |
| 效率 | 70~85% | 影响辅助电源设计 |
| 封装 | DIP/SMD | 贴装工艺性 |

### 5.2 隔离电源方案对比

```
1) 隔离DC-DC模块（成品）：
   - 代表：Murata MGJ2D系列、Cui PSD系列、TI DCP系列
   - 优点：认证齐全、即用、隔离耐压高（5kVAC+）
   - 缺点：成本高（$3~$15）、体积大
   - 适用：中小批量、快速开发、医疗/军规认证

2) 集成隔离电源IC（isoPower）：
   - 代表：ADuM540x（ADI）、ISOW7841（TI）
   - 优点：集成数字隔离器+隔离电源，体积小
   - 缺点：功率 < 0.5W，EMI需注意
   - 适用：数字信号隔离+小功率驱动

3) 反激式辅助电源（分立）：
   - 代表：自绕变压器 + 反激IC（如NCP1015）
   - 优点：灵活、多路输出、成本低
   - 缺点：需变压器设计、认证自做
   - 适用：大批量、多路隔离供电

设计准则：
- 驱动供电功率 P = Σ(Qg × Vdrive × fsw) × 1.5（裕量）
- 多路输出：半桥上管需隔离供电，下管可共地
- SiC驱动：推荐 +18V/-3V 双路输出，或稳压管分压
- 军用：隔离电源需满足宽温（-55~+125°C）和抗振动
```

## 6. 隔离运放选型

### 6.1 隔离运放对比

| 器件 | 厂商 | 隔离方式 | 带宽 | 精度 | CMTI | 应用 |
|------|------|---------|------|------|------|------|

| AMC1306 | TI | 容耦+ΣΔ调制 | — | 16bit | 50V/ns | 高精度电流采样 |
| ISO224 | TI | 容耦 | 350kHz | 0.3% | 70V/ns | 电压采样 |

| AD7403 | ADI | 磁耦+ΣΔ调制 | — | 16bit | 50V/ns | 高精度电流采样 |

### 6.2 隔离运放应用要点

```
AMC1301（电流采样隔离放大器）：
- 输入：±250mV（匹配分流器）
- 增益：8.2倍（输出 ±2.05V）
- 隔离耐压：4250Vrms
- 带宽：200kHz

设计公式：
- 分流器阻值 Rs = Vfull_scale / Ifull_scale
  示例：Ifull = 20A，Vfull = 250mV → Rs = 12.5mΩ
- 分流器功耗 P = I²×Rs = 20²×0.0125 = 5W（需降额）
- 输出电压 Vout = Vin × 8.2 + Vref（差分输出）

ISO224（电压采样隔离放大器）：
- 输入：±12V（高阻抗输入）
- 增益：1/3（输出 ±4V）
- 隔离耐压：5700Vrms（增强绝缘）

设计准则：
- 分流器需低电感型（四端Kelvin连接）
- 隔离运放供电需隔离DC-DC（5V或双电源）
- 输入滤波：RC低通，fc = 10~50kHz（抑制开关噪声）
- PCB布局：输入走线短而平行，减少差模噪声
- 军用：选增强绝缘（> 5kVrms）、高CMTI（> 50V/ns）型号
```

## 7. PCB隔离设计

### 7.1 爬电距离与电气间隙

```
定义：
- 爬电距离（Creepage）：沿绝缘表面的最短距离
- 电气间隙（Clearance）：空气中两导体间最短距离

最小间距要求（IEC 60664-1，污染等级2）：

| 工作电压（Vrms） | 爬电距离（mm） | 电气间隙（mm） | 加强绝缘爬电（mm） |
|-----------------|---------------|---------------|------------------|
| 250             | 2.5           | 1.6           | 5.0              |
| 400             | 4.0           | 2.4           | 8.0              |
| 600             | 6.3           | 3.6           | 12.6             |
| 1000            | 10.0          | 6.0           | 20.0             |
| 1500            | 16.0          | 9.0           | 32.0             |

军用要求（GJB 2645/MIL-STD-275）：
- 严格按高度降额（高空气压低，电气间隙需增大）
- 海拔 > 3000m：电气间隙 × 1.14
- 海拔 > 10000m：电气间隙 × 2.0
- 爬电距离按CTI（相比电痕化指数）分组：
  CTI > 600（FR4）：标准值
  CTI 175~400：× 1.25~2.0
```

### 7.2 开槽设计

```
开槽（Slot）用于增加爬电距离：
- 在原副边之间PCB开V型或U型槽
- 爬电距离沿槽壁计算，等效增加距离
- 槽宽 ≥ 1mm，槽深 ≥ 1mm（工艺限制）
- 槽内需保证无焊锡、铜屑

设计准则：
- 原副边铜箔最小间距 ≥ 爬电距离要求
- 变压器/光耦下方禁止铺铜跨越隔离带
- 隔离带内禁止过孔（除非绝缘等级验证）
- 元器件跨隔离带：需满足器件本体爬电距离
- 军用：隔离带宽度留 ≥ 2倍标准值裕量

布局原则：
- 原边高压区与副边低压区物理分离
- 隔离器件（光耦/变压器/数字隔离器）跨隔离带放置
- 隔离带内仅允许隔离器件本体
- 安规Y电容跨接原副边时需在指定位置
```

## 8. 隔离反馈环路稳定性分析

### 8.1 光耦极点影响

```
光耦在反馈环路中引入一个低频极点：
fp_opto = 1 / (2π × R_C · C_opto)

其中：
R_C = 光耦集电极上拉电阻（通常 1~10kΩ）
C_opto = 光耦寄生电容（PC817: 2~6pF，HCNR201: 1~3pF）

示例：R_C = 4.7kΩ，C_opto = 6pF
fp_opto = 1/(2π × 4700 × 6e-12) ≈ 5.6MHz

注意：实际光耦极点远低于理论值（基区存储效应）：
- PC817实测极点：30~80kHz
- 高速光耦（6N137）：500kHz~1MHz

环路影响：
- 光耦极点在穿越频率附近引入额外相移（-45°~-90°）
- 需在TL431补偿网络中预留相位提升
- 设计准则：穿越频率 fc < fp_opto / 5（留相位裕量）
```

### 8.2 TL431补偿网络设计

```
TL431+光耦 Type II 补偿：

传递函数：
G(s) = G0 × (1 + s/wz) / (1 + s/wp)

零点：wz = 1/(R3 × Cz)
极点：wp = 1/(R3 × Cp_total)，Cp_total = Cp + C_opto_equivalent

设计步骤：
1) 确定穿越频率 fc（通常 fsw/10）
2) 测量功率级在 fc 处增益 Gp(fc) 和相移 φp(fc)
3) 计算所需补偿：Gc = 1/Gp(fc)，φc = -180° + PM - φp(fc)
4) 配置零极点：
   - fz = fc / sqrt(K)，K = tan(φc/2 + 45°)
   - fp = fc × sqrt(K)
   - 或简化：fz = fc/5，fp = fc × 5（提供约90°相位提升）

元件值计算：
R3 = R_pullup × CTR × (Vout - Vtl431) / Vpullup （确定直流增益）
Cz = 1/(2π × R3 × fz)
Cp = 1/(2π × R3 × fp) - C_opto_eq

设计准则：
- TL431最小阴极电流 ≥ 1mA（精密应用 ≥ 5mA）
- 光耦If设计 1~5mA，留老化裕量
- 环路测试：注入变压器法，全负载/全输入范围验证
- 相位裕度 PM > 45°（军标 > 60°），增益裕度 GM > 6dB
```

## 9. 军用隔离特殊要求

### 9.1 抗辐射隔离器

```
抗辐射要求：
- TID（总电离剂量）：商用隔离器通常 < 10krad，不满足航天
- SEL（单粒子锁定）：CMOS工艺隔离器需评估
- 推荐方案：
  * 光耦：抗辐射性能较好（LED/光敏管对辐射不敏感），但带宽低
  * 变压器隔离：天然抗辐射（无半导体介质）
  * 抗辐射数字隔离器：可选ADuM140x-EP（增强型塑料），TID 30krad

设计准则：
- 航天/弹载：优先变压器隔离或光耦，数字隔离器选EP/Rad-Hard版本
- 定期刷新隔离器输出（防SEU导致状态翻转）
- 关键隔离信号双通道冗余
```

### 9.2 高CMTI要求

```
军用高压电源（SiC器件，dv/dt > 50V/ns）：
- 隔离驱动CMTI ≥ 100V/ns
- 推荐器件：UCC21520（100V/ns）、ISO5852S（100V/ns）
- 光耦驱动不适用（CMTI仅15~30V/ns）

验证方法：
- 共模阶跃测试：在隔离器输入输出间施加 dv/dt 阶跃
- 测量输出误脉冲宽度 < 10ns
- 军标要求：在最大 dv/dt 下无误触发
```

### 9.3 绝缘耐压与机械环境

```
绝缘耐压：
- 军用电源常按 3000VAC/60s 设计（高于民用1500VAC）
- 高空环境：气压降低，沿面放电电压下降，爬电距离需增大
- 湿热环境：绝缘电阻下降，需三防涂覆

机械环境：
- 振动：隔离器件需牢固固定，光耦引脚易疲劳断裂
- 冲击：变压器磁芯需固定胶加固
- 推荐封装：SMD优于DIP（抗振性好）
```

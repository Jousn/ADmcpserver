# 保护电路设计知识库

> 适用范围：军用及民用中高功率电源（50W~10kW级）
> 目标读者：AI设计辅助技能（用于设计建议与设计审查）
> 版本：v1.0

---

## 1. 概述

电源保护电路是保障电源系统和负载安全的关键设计环节。中高功率电源工作在高电压、大电流环境下，故障发生时能量巨大，保护电路必须在微秒级时间内响应并切断故障路径。军用电源还需满足冗余设计和故障隔离要求，确保在恶劣战场环境下持续可靠运行。

### 1.1 保护功能矩阵

| 保护类型 | 缩写 | 触发条件 | 响应时间要求 | 动作方式 |
|----------|------|----------|-------------|----------|
| 过压保护 | OVP | Vout > 阈值 | < 10μs | 关断输出/钳位 |
| 过流保护 | OCP | Iout > 阈值 | < 5μs（逐周期） | 限流/关断 |
| 过温保护 | OTP | Tj > 阈值 | < 100ms | 降功率/关断 |
| 短路保护 | SCP | Vout ≈ 0, Iout >> 额定 | < 2μs | 立即关断 |
| 欠压锁定 | UVLO | Vin < 阈值 | < 1ms | 拒绝启动 |
| 浪涌保护 | — | 瞬态过压 | < 1ns（器件级） | 钳位/旁路 |

## 2. 过压保护（OVP）

### 2.1 OVP实现方案对比

| 方案 | 响应时间 | 钳位精度 | 功耗 | 适用功率 | 军用推荐 |
|------|----------|----------|------|----------|----------|
| TVS钳位 | < 1ns | ±5%~±10% | 高 | 小功率辅助 | 仅辅助 |
| 齐纳钳位+光耦 | 10~100μs | ±2% | 低 | 中功率 | 可用 |
| 比较器截断 | 1~10μs | ±1% | 低 | 中高功率 | 推荐 |
| SCR撬棍 | 1~5μs | ±3% | 中（需复位） | 中高功率 | 推荐 |

### 2.2 TVS瞬态电压抑制器选型

#### 2.2.1 关键参数

| 参数 | 符号 | 说明 |
|------|------|------|
| 截止电压 | VRWM | 正常工作不导通的最高电压 |
| 击穿电压 | VBR | 开始导通的电压（@1mA测试电流） |
| 钳位电压 | VC | 峰值电流下的最大钳位电压 |
| 峰值脉冲电流 | IPP | 8/20μs波形下的最大电流 |
| 峰值脉冲功率 | PPP | 8/20μs或10/1000μs波形下的最大功率 |

#### 2.2.2 选型公式

```
VRWM ≥ 1.2 × Vout_max（正常工作电压）

VC ≤ Vmax_load（负载能承受的最大电压）

IPP ≥ I_surge（预期浪涌电流）
```

#### 2.2.3 推荐TVS型号

| 型号 | VRWM | VC | PPP | 封装 | 适用场景 |
|------|------|-----|------|------|----------|
| SMBJ5.0CA | 5.0V | 9.2V | 600W | SMB | 5V输出保护 |
| SMCJ12CA | 12V | 19.9V | 1500W | SMC | 12V输出保护 |
| SMDJ24CA | 24V | 38.9V | 1500W | SMD | 24V输出保护 |
| 5KP48CA | 48V | 77.4V | 5000W | DO-218 | 48V大功率 |
| 15KPA43A | 43V | 69.4V | 15000W | DO-218 | 军用大功率 |

### 2.3 比较器截断式OVP

#### 2.3.1 电路结构

```
Vout ──[分压网络]──► 比较器(+) ──► 驱动MOSFET关断
                        ↑
                   基准电压(-)
```

#### 2.3.2 设计公式

```
V_OVP_threshold = Vref × (R1 + R2) / R2

建议：
  V_OVP_threshold = 1.1 ~ 1.15 × Vout_nominal
  比较器响应延迟 < 5μs
  基准电压精度 ≤ 1%
```

#### 2.3.3 推荐比较器与基准

| 器件 | 类型 | 特点 | 适用场景 |
|------|------|------|----------|
| TLV3501 | 高速比较器 | 4.5ns延迟 | 快速OVP |
| LM311 | 通用比较器 | 200ns延迟 | 常规OVP |
| TL431 | 可调基准 | 2.5V±0.4% | 低成本OVP |
| REF3030 | 精密基准 | 3.0V±0.2% | 高精度OVP |

### 2.4 SCR撬棍保护（Crowbar）

SCR撬棍电路在过压时触发导通，将输出短路到地，迫使前级保护动作。

```
触发条件：Vout > V_OVP_threshold
动作：SCR导通 → 输出短路 → 前级保险丝/断路器断开
优点：保护彻底，故障隔离性好
缺点：动作后需手动复位，SCR需满足I²t要求
```

**SCR选型要求**：

```
Vdrm ≥ 1.5 × Vout_max
I_avg ≥ 5 × Iout_nominal（短路峰值电流）
I²t > 保险丝I²t（确保SCR先于保险丝熔断前承受）
```

## 3. 过流保护（OCP）

### 3.1 OCP实现方案对比

| 方案 | 响应时间 | 精度 | 复杂度 | 适用功率 | 军用推荐 |
|------|----------|------|--------|----------|----------|
| 逐周期限流 | < 5μs | ±10% | 中 | 中高功率 | 推荐 |
| 打嗝模式 | 10~100ms | ±10% | 中 | 中高功率 | 推荐 |
| 霍尔传感器 | 1~10μs | ±1%~±5% | 高 | 大功率 | 推荐 |
| 保险丝 | 10ms~10s | 差 | 低 | 所有 | 仅后备 |
| 电子保险丝(eFuse) | < 1μs | ±5% | 高 | 中功率 | 可用 |

### 3.2 逐周期限流

#### 3.2.1 工作原理

每个开关周期内检测电流，当电流超过阈值时立即关断当前周期PWM脉冲，下个周期重新检测。

#### 3.2.2 设计公式

```
I_limit = V_ref / (R_sense × Gain)

其中：
  V_ref:   电流检测比较器参考电压（典型0.5V~1V）
  R_sense: 检流电阻值
  Gain:    电流检测放大器增益（如使用）

建议：
  I_limit = 1.1 ~ 1.3 × Iout_nominal
  R_sense功率 ≥ I_limit² × R_sense × 2（降额）
```

#### 3.2.3 检流电阻选型

| 阻值 | 额定功率 | 封装 | 精度 | 适用电流 |
|------|----------|------|------|----------|
| 1mΩ | 3W | 2512 | ±1% | 30~50A |
| 5mΩ | 1W | 1206 | ±1% | 10~15A |
| 10mΩ | 0.5W | 0805 | ±1% | 5~7A |
| 50mΩ | 0.25W | 0603 | ±1% | 2~3A |

推荐低TCR（温度系数）检流电阻：TCR < 50 ppm/°C

### 3.3 打嗝模式（Hiccup Mode）

#### 3.3.1 工作原理

当过流持续超过设定时间后，控制器进入打嗝模式：关断输出一段较长时间（冷却期），然后尝试重新启动。如果过流仍存在则继续打嗝，避免持续过热。

#### 3.3.2 时序设计

```
打嗝周期参数：
  T_on:    正常尝试运行时间（通常1~10ms）
  T_off:   关断冷却时间（通常100ms~1s）
  打嗝比 = T_on / (T_on + T_off)

建议：
  T_on / T_off = 1/100 ~ 1/1000
  打嗝模式下平均功耗 < 额定功耗的5%
```

#### 3.3.3 打嗝模式优势

- 故障下功耗极低，保护功率器件
- 自动恢复：故障消除后自动重启
- 可通过LED指示灯区分瞬态过流与持续短路

### 3.4 霍尔电流传感器

#### 3.4.1 适用场景

- 大电流检测（> 50A），检流电阻损耗过大
- 需要电气隔离的电流检测
- 高精度电流检测（±1%）

#### 3.4.2 推荐型号

| 型号 | 量程 | 精度 | 带宽 | 隔离 | 适用场景 |
|------|------|------|------|------|----------|
| ACS712 | ±5~±30A | ±1.5% | 80kHz | 2.1kV | 中功率 |
| ACS758 | ±50~±200A | ±1% | 120kHz | 3kV | 大功率 |
| LEM HAS | ±100~±1000A | ±0.5% | 50kHz | 5kV | 超大功率 |
| LEM LTS | ±25~±100A | ±0.7% | 100kHz | 4.8kV | 军用级 |

### 3.5 保险丝后备保护

```
保险丝I²t选择：
  I²t_fuse > I²t_inrush（浪涌电流I²t）
  I²t_fuse < I²t_MOSFET（功率管承受能力）
  I_rated = 1.25 ~ 1.5 × Iout_nominal
```

## 4. 过温保护（OTP）

### 4.1 温度检测器件对比

| 器件类型 | 精度 | 响应时间 | 温度范围 | 成本 | 适用场景 |
|----------|------|----------|----------|------|----------|
| NTC热敏电阻 | ±1~±3°C | 1~5s | -40~+150°C | 低 | 功率器件散热器 |
| PTC自恢复保险丝 | ±5°C | 1~10s | -40~+85°C | 低 | 过热自保护 |
| 温度开关（机械） | ±2~±5°C | 5~30s | -20~+120°C | 低 | 后备保护 |
| PT100/PT1000 | ±0.1~±0.5°C | 1~5s | -200~+650°C | 中 | 高精度测温 |
| 数字温度传感器 | ±0.5~±2°C | 0.1~1s | -55~+125°C | 中 | MCU监控 |
| 红外温度传感器 | ±1~±2°C | 0.01~0.1s | -70~+380°C | 高 | 非接触测量 |

### 4.2 NTC热敏电阻设计

#### 4.2.1 NTC参数

```
R25:    25°C时的标称电阻值（常用10kΩ）
B值:    材料常数（典型3380K~3950K）
精度:   ±1%~±5%
耗散常数:δ (mW/°C)，表示自热效应
```

#### 4.2.2 温度计算公式

```
1/T = 1/T25 + (1/B) × ln(R/R25)

简化（线性化近似，窄温区）：
T(°C) ≈ (R_ntc - R_ref) / (R_ref × α_T) + T_ref

OTP阈值设定：
  T_OTP_warn  = 85°C ~ 95°C（警告，降功率运行）
  T_OTP_trip  = 100°C ~ 110°C（关断保护）
  T_OTP_reset = 80°C ~ 90°C（恢复温度，需有滞后）
```

#### 4.2.3 NTC安装位置

| 安装位置 | 检测对象 | 响应速度 | 推荐度 |
|----------|----------|----------|--------|
| MOSFET壳体 | 功率管温度 | 快 | 推荐 |
| 变压器磁芯 | 变压器温度 | 中 | 推荐 |
| 散热器表面 | 系统平均温度 | 慢 | 推荐 |
| PCB板面 | 环境温度 | 最慢 | 辅助 |

### 4.3 过温保护策略

```
分级保护策略：

Level 1 (T > 85°C):  风扇加速，降低最大输出功率20%
Level 2 (T > 95°C):  降低最大输出功率50%，发出警告
Level 3 (T > 105°C): 关断输出，进入保护锁定
Level 4 (T < 90°C):  允许手动/自动复位
```

### 4.4 军用OTP设计要求

- 温度传感器需双重冗余：两个NTC分别安装在关键器件上
- 温度告警与关断阈值需独立设置，不可共用同一传感器
- 高温材料选型：所有元件需满足 -55°C~+125°C 工作温度
- 灌封材料需考虑导热系数，确保热量有效传导

## 5. 短路保护（SCP）

### 5.1 硬件比较器SCP

#### 5.1.1 电路结构

```
检流电阻 ──► 差分放大 ──► 快速比较器 ──► PWM封锁信号
                                ↑
                           短路阈值基准

短路检测响应时间要求：< 2μs
```

#### 5.1.2 设计公式

```
I_SC_threshold = V_SC_ref / (R_sense × Gain)

建议：
  I_SC_threshold = 2 ~ 3 × Iout_nominal
  比较器带宽 ≥ 10MHz
  差分放大器带宽 ≥ 1MHz
  响应总延迟 < 2μs
```

### 5.2 软件检测SCP

#### 5.2.1 实现方式

- MCU通过ADC定期采样输出电流
- 当电流超过短路阈值时，MCU发送关断信号
- 适用于后备保护，响应时间受ADC采样率限制

#### 5.2.2 软件SCP参数

```
ADC采样率 ≥ 100kSPS（对应10μs检测周期）
数字滤波：连续2~3次超阈值才触发（防误触发）
MCU响应延迟（含中断处理）：< 50μs
```

### 5.3 SCP与OCP配合策略

| 故障类型 | 电流特征 | 保护动作 | 恢复方式 |
|----------|----------|----------|----------|
| 瞬态过流 | 1.1~1.5倍额定 | 逐周期限流 | 自动恢复 |
| 持续过流 | 1.5~2倍额定 | 打嗝模式 | 自动恢复 |
| 短路 | > 2倍额定 | 立即关断 | 打嗝尝试恢复 |
| 严重短路 | > 5倍额定 | 立即关断+保险丝 | 手动复位 |

## 6. 欠压锁定（UVLO）

### 6.1 UVLO设计要求

```
UVLO启动阈值（Vin上升）：
  V_UVLO_on = 0.85 ~ 0.90 × Vin_nominal
  
UVLO关断阈值（Vin下降）：
  V_UVLO_off = 0.70 ~ 0.80 × Vin_nominal

滞后量（Hysteresis）：
  V_hys = V_UVLO_on - V_UVLO_off ≥ 2V
  （防止输入电压波动导致频繁启停）
```

### 6.2 UVLO电路实现

#### 6.2.1 分立元件UVLO

```
Vin ──[R1]──┬──[R2]──GND
             │
         比较器(+) ──► EN/PWM控制器
             │
         基准(-)

V_UVLO_on = Vref × (R1+R2) / R2
V_UVLO_off = Vref × (R1+R2) / R2 - V_hys
```

#### 6.2.2 集成PWM控制器内置UVLO

大多数PWM控制器（如UC3842、LM5045）内置UVLO功能：

| 控制器 | UVLO启动 | UVLO关断 | 滞后量 |
|--------|----------|----------|--------|
| UC3842 | 16V | 10V | 6V |
| LM5045 | 7.5V | 6.9V | 0.6V |
| LT3845 | 15.5V | 8.5V | 7V |
| NCP1250 | 18V | 9V | 9V |

### 6.3 输入掉电保护

```
掉电保持时间要求：
  民用电源：≥ 10ms（半个工频周期）
  军用电源：≥ 50ms（GJB 181A要求）
  航空电源：≥ 200ms

保持电容计算：
  C_hold = 2 × Pout × t_hold / (Vin²_max - Vin²_min)
```

## 7. 浪涌保护

### 7.1 浪涌保护器件对比

| 器件 | 响应时间 | 钳位电压 | 通流能力 | 寿命 | 适用场景 |
|------|----------|----------|----------|------|----------|
| TVS二极管 | < 1ns | 低 | 小（< 5kA） | 长 | 精细保护 |
| 压敏电阻(MOV) | < 25ns | 中 | 大（< 70kA） | 有限（退化） | 前级粗保护 |
| 气体放电管(GDT) | < 1μs | 极低（电弧） | 极大（> 100kA） | 长 | 雷击保护 |
| 固态放电管 | < 1ns | 低 | 中 | 长 | 通信保护 |
| EMI滤波器 | N/A | N/A | N/A | 长 | 配合使用 |

### 7.2 压敏电阻（MOV）选型

#### 7.2.1 关键参数

```
压敏电压 V1mA: 1mA电流时的电压
最大连续电压 VAC/VDC: 可长期承受的电压
最大钳位电压 VC: 8/20μs波形下的钳位电压
通流容量 Imax: 8/20μs波形最大电流
能量耐量 E: 10/1000μs波形最大能量
```

#### 7.2.2 选型公式

```
V1mA ≥ 1.5 × Vin_rms（交流输入）

示例：220VAC输入
  V1mA ≥ 1.5 × 220 × √2 ≈ 466V
  选择 V1mA = 470V 的MOV

能量耐量：
  E_MOV ≥ 0.5 × V_surge × I_surge × t_surge
```

#### 7.2.3 推荐MOV型号

| 型号 | 压敏电压 | 最大连续电压 | 通流容量 | 直径 | 适用场景 |
|------|----------|-------------|----------|------|----------|
| 10D431K | 430V | 275VAC | 1.2kA | 10mm | 220V辅助 |
| 14D431K | 430V | 275VAC | 4.5kA | 14mm | 220V主路 |
| 20D431K | 430V | 275VAC | 6.5kA | 20mm | 220V大功率 |
| 25D511K | 510V | 320VAC | 10kA | 25mm | 380V输入 |

### 7.3 气体放电管（GDT）选型

```
直流击穿电压 Vdc:
  Vdc ≥ 1.2 × Vin_max（确保正常工作不误触发）

续流遮断问题：
  GDT导通后电弧电压很低（~15V），可能导致工频续流
  必须与MOV或TVS串联使用

推荐GDT型号：
  GT-230: 230V击穿, 5kA, 用于220V交流前端
  GT-350: 350V击穿, 5kA, 用于380V交流前端
  GT-600: 600V击穿, 10kA, 用于高可靠性场合
```

### 7.4 浪涌保护多级方案

```
雷击浪涌（10/350μs或8/20μs）
    │
    ▼
[GDT] ─── 第一级：泄放大电流（10kA~100kA）
    │
  [退耦电感/电阻] ─── 退耦，确保分级动作
    │
    ▼
[MOV] ─── 第二级：钳位中间电压（5kA~20kA）
    │
  [退耦电感/电阻]
    │
    ▼
[TVS] ─── 第三级：精确钳位保护后级电路（< 5kA）
    │
    ▼
  被保护电路
```

### 7.5 军用浪涌保护要求

依据 GJB 1804 和 MIL-STD-461：

| 标准 | 浪涌波形 | 电压 | 要求 |
|------|----------|------|------|
| GJB 181A | 50ms电压瞬变 | ±50% Vin | 电源不损坏 |
| MIL-STD-461 CS106 | 5μs脉冲 | 100~400V | 不误动作 |
| MIL-STD-461 CS115 | 2/30ns脉冲 | 5A | 不误动作 |
| DO-160 Section 17 | 电压尖峰 | 600V | 功能正常 |

## 8. 军用电源保护冗余设计要求

### 8.1 冗余设计原则

```
冗余等级要求：
  Level A（关键保护）：双重冗余，任一保护失效仍有保护
  Level B（重要保护）：双重冗余或自检监控
  Level C（一般保护）：单路保护+故障指示

典型冗余配置：
  OVP: 比较器截断 + SCR撬棍（双重独立通道）
  OCP: 逐周期限流 + 打嗝模式 + 保险丝（三重）
  OTP: NTC检测 + 温度开关（双重独立）
  SCP: 硬件比较器 + 软件检测（双重）
```

### 8.2 故障隔离要求

- 每个保护通道应使用独立电源供电
- 保护信号应通过光耦或磁隔离传输
- 故障状态应锁存并指示，不可自动清除（需人工确认）
- 故障记录应存入非易失存储器

### 8.3 军用标准依据

## 9. 保护电路自检与故障指示

### 9.1 自检（BIT, Built-In Test）

#### 9.1.1 上电BIT

```
上电自检流程：
1. 检测各保护通道基准电压是否正常（< 10ms）
2. 检测NTC温度传感器读数是否合理（< 5ms）
3. 检测检流电阻是否开路/短路（< 5ms）
4. 测试保护比较器响应（注入测试信号）（< 10ms）
5. 全部通过后才允许启动主功率级
```

#### 9.1.2 运行中BIT（周期性自检）

| 自检对象 | 方法 | 周期 | 判据 |
|----------|------|------|------|
| OVP比较器 | 注入微小偏移电压 | 1s | 响应在预期范围 |
| OCP检测 | 比较ADC与硬件检测 | 10ms | 差值 < 5% |
| OTP传感器 | 读取温度值 | 100ms | 在合理范围(-55~125°C) |
| UVLO基准 | ADC采样基准电压 | 1s | 误差 < 2% |
| 保险丝状态 | 检测保险丝通断 | 10ms | 连续导通 |

### 9.2 故障指示设计

```
故障指示分级：
  绿色LED常亮：  正常运行
  黄色LED闪烁：  警告（过温降额、输入欠压等）
  红色LED常亮：  保护动作（OVP/OCP/OTP/SCP）
  红色LED闪烁：  严重故障（需要维修）

故障信息输出：
  - 状态寄存器（MCU可读取）
  - 故障锁存（需断电或手动复位清除）
  - 故障时间戳记录（非易失存储器）
  - RS422/CAN总线故障上报（军用）
```

### 9.3 故障诊断码

| 故障码 | 故障类型 | 可能原因 | 处理建议 |
|--------|----------|----------|----------|
| E01 | OVP触发 | 反馈开路、负载突卸 | 检查反馈环路 |
| E02 | OCP触发 | 过载、电感饱和 | 检查负载、磁芯 |
| E03 | OTP触发 | 散热失效、风扇故障 | 检查散热系统 |
| E04 | SCP触发 | 输出短路 | 检查输出线路 |
| E05 | UVLO触发 | 输入掉电、保险丝断 | 检查输入电源 |
| E06 | BIT失败 | 保护电路自身故障 | 维修保护电路 |
| E07 | 通信故障 | 总线断线 | 检查通信线路 |

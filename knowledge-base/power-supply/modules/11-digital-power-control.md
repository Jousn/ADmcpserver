# 数字电源控制设计知识库

> 适用范围：军用及民用中高功率电源（100W~50kW）
> 目标受众：AI设计辅助Skill，用于数字电源控制方案选型、算法设计与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

数字电源控制利用DSP/MCU对电压、电流等模拟量进行采样，在离散时域内完成控制律计算并生成PWM驱动信号，相较模拟控制具有参数可编程、自适应能力强、通信与故障诊断丰富等优势。在中高功率电源特别是军用电源中，数字控制可实现复杂拓扑（移相全桥、LLC、交错并联）、在线参数优化、冗余管理与预测维护，是现代高可靠电源系统的核心。

---

## 2. 数字控制 vs 模拟控制对比

| 对比维度 | 模拟控制 | 数字控制 |
|---------|---------|---------|
| 稳压精度 | ±1%~±2%（受器件温漂影响） | ±0.1%~±0.5%（参考基准稳定） |
| 灵活性 | 参数固定（RC网络决定），改版需重设计PCB | 软件可编程，固件在线升级 |
| 控制带宽 | 高（连续时间，可达fs/2） | 受采样与计算延时限制，通常fs/5~fs/10 |
| 瞬态响应 | 固定补偿，无法自适应 | 可根据工况切换补偿参数或多模式控制 |
| 成本（单台） | 低（控制芯片< $2） | 中高（DSP $3~$15，含开发工具成本） |
| 可靠性 | 高（无软件跑飞风险） | 中高（需看门狗、冗余、SEU防护） |
| 通信能力 | 无或有限（I2C监测） | PMBus/CAN/UART全状态遥测与控制 |
| 均流精度 | ±5%~±10%（模拟总线） | ±1%~±2%（数字通信均流） |
| 故障诊断 | 硬件比较器，事件难复现 | 录波、黑匣子、预测维护 |
| 非线性控制 | 不支持 | 支持滑模/模糊/预测/重复控制 |
| 知识复用 | 每款新电源需重新设计 | 平台化固件，跨产品复用 |
| 适用功率 | < 2kW为主 | 500W~50kW+，复杂拓扑必选 |

### 3.2 选型决策准则

- **功率 < 1kW 且拓扑简单**：STM32G431/dsPIC33CK，性价比优先
- **功率 1kW~10kW（移相全桥/LLC）**：TMS320F280049 或 STM32G474，需高分辨率PWM
- **功率 > 10kW 或多模块并联**：TMS320F28379D 双核，一核控制一核通信/诊断
- **军用电源**：优先C2000系列（抗辐射版本可选），或NXP LPC55S69（带安全机制）
- **需要工业以太网（EtherCAT）**：Infineon XMC4800
- **关键指标核查**：PWM路数 ≥ 拓扑所需+裕量、ADC通道数与采样率、Flash/RAM容量、定时器与通信外设

### 3.3 军用MCU特殊要求

```
抗辐射要求（根据轨道/任务）：
- 低地球轨道LEO：TID ≥ 20krad(Si)，SEE需评估
- 地球同步轨道GEO：TID ≥ 100krad(Si)，SEL免疫
- 推荐器件：TI SM320F28335-EP（增强型塑料）、Microchip ATPIC
- 商用器件加固方案：定期三模冗余(TMR)刷新关键寄存器

SEU（单粒子翻转）防护：
- 关键配置寄存器三模冗余投票
- Flash关键参数ECC校验（汉明码）
- 看门狗超时 < 10ms，超时进入安全态
- 关键控制变量周期性自检（CRC校验）
```

## 4. ADC采样策略

### 4.1 采样模式对比

| 采样模式 | 原理 | 优点 | 缺点 | 应用场景 |
|---------|------|------|------|---------|
| 单次采样 | 每周期采样1次 | 简单 | 噪声大、带宽低 | 低频控制 |
| 过采样 | 高频多次采样求均值 | 提升SNR、降低量化噪声 | 占用ADC带宽 | 电压反馈、温度 |
| 同步采样 | 多通道同时采样（双ADC） | 消除通道间相位差 | 需双ADC硬件 | 三相PFC/逆变器 |
| 窗口采样 | 在PWM特定时刻触发采样 | 避开开关噪声窗口 | 需精确触发时序 | 峰值电流模式 |
| 采样保持(S/H) | 外部S/H电路保持瞬时值 | 消除孔径误差 | 增加硬件 | 高频/高压采样 |

### 4.2 过采样与噪声改善

```
过采样带来的SNR提升：
SNR_gain = 10 * log10(OSR)    （dB）

每4倍过采样提升1位有效分辨率（ENOB）：
ENOB_gain = log2(OSR) / 2

示例：
- 12bit ADC，4倍过采样 → 等效13bit，SNR提升6dB
- 12bit ADC，16倍过采样 → 等效14bit，SNR提升12dB

设计准则：
- 电压反馈过采样率：8~16倍（稳压精度优先）
- 电流反馈过采样率：4~8倍（兼顾带宽与精度）
- 注意：过采样后有效采样率 = 原始采样率 / OSR
```

### 4.3 采样时刻与PWM同步

```
同步采样时序设计（以峰值电流模式为例）：
- 采样触发点：PWM计数器到达周期值（TPWM）时触发ADC
- ADC转换完成中断 → 读取结果 → 计算控制律 → 更新PWM比较值
- 关键时序约束：
  Tadc_convert + Tcalc + Tpwm_update < Tpwm（一个开关周期）

采样点选择避开开关噪声：
- 开关管导通瞬间产生di/dt噪声，采样应延迟 200~500ns
- 使用PWM事件触发ADC SOC（Start of Conversion），硬件自动延时
- 推荐采样窗口：导通时刻后 0.1~0.3 × Tpwm
```

## 5. 数字PWM（DPWM）

### 5.1 DPWM分辨率

```
DPWM时间分辨率（HRPWM）：
Δt = Tclk / 2^N

其中：
Tclk = 系统时钟周期
N = DPWM计数器位数（或HRPWM延迟线分辨率）

示例（TMS320F280049）：
- 系统时钟 100MHz → Tclk = 10ns
- 普通PWM 16位计数器分辨率 = 10ns（高频时占空比分辨率受限）
- HRPPM 延迟线分辨率 = 150ps
- 在 fs = 200kHz 时：占空比分辨率 = 150ps / 5us = 0.003%（极优）

高频下占空比分辨率限制：
- fs = 100kHz，Tclk = 10ns → 占空比分辨率 = 10ns/10us = 0.1%
- fs = 500kHz，Tclk = 10ns → 占空比分辨率 = 10ns/2us = 0.5%（不够）
- 此时必须使用HRPWM（150ps分辨率 → 0.0075%@500kHz）
```

### 5.2 死区生成

```
数字死区设置（以TI ePWM为例）：
- 死区时间由DB模块红/黑路径延时设定
- 分辨率：普通 10ns，高分辨率 150ps

死区时间设计准则：
- Si MOSFET：200~500ns（toff + 裕量）
- SiC MOSFET：100~300ns（toff更短）
- GaN HEMT：20~100ns（极快开关）
- 实际需通过双脉冲测试验证，留 ≥ 1.5× 关断时间裕量

死区优化：
- 自适应死区：根据负载电流动态调整（小电流加大死区，大电流减小）
- 最小死区由器件Qgd和驱动电流决定：t_dead_min = Qgd / Ig_off + 50ns
```

### 5.3 移相控制

```
移相全桥（PSFB）数字移相：
- 主桥臂（领先臂）：PWM计数器生成固定占空比50%方波
- 从桥臂（滞后臂）：通过相位寄存器（TBPHS）相对领先臂移相
- 移相角 φ 对应时间：t_shift = φ/360 × Tpwm

数字移相优势：
- 分辨率：HRPWM可达 150ps（φ分辨率 < 0.01°）
- 可实现ZVS范围在线优化（根据负载调节移相角与死区）
- 可实现自适应延时（Adaptive Delay）补偿二极管反向恢复
```

## 6. 数字PID控制器设计

### 6.1 连续域PID到离散域变换

```
连续域PID：
u(t) = Kp*e(t) + Ki*∫e(t)dt + Kd*de(t)/dt

三种离散化方法对比：

1) 前向差分（Forward Euler）：
   u(k) = u(k-1) + Kp*(e(k)-e(k-1)) + Ki*Ts*e(k-1) + Kd/Ts*(e(k)-2*e(k-1)+e(k-2))
   - 简单但高频处可能不稳定（s=(z-1)/Ts，极点可能超出单位圆）

2) 后向差分（Backward Euler）：
   u(k) = u(k-1) + Kp*(e(k)-e(k-1)) + Ki*Ts*e(k) + Kd/Ts*(e(k)-2*e(k-1)+e(k-2))
   - 稳定性好（s=(z-1)/(z*Ts)），推荐使用
   - 高频处引入额外相位滞后

3) Tustin（双线性变换）：
   s = (2/Ts) * (z-1)/(z+1)
   - 频率畸变最小，保形映射
   - 推荐用于对频率响应精度要求高的场合
   - 离散积分项：Ki_d = Ki*Ts/2*(e(k)+e(k-1))
```

### 6.2 增量式PID与位置式PID

```
位置式PID（直接输出绝对控制量）：
u(k) = Kp*e(k) + Ki*Σe(j) + Kd*(e(k)-e(k-1))
- 优点：直观
- 缺点：积分项累积，需抗饱和；故障时输出可能跳变

增量式PID（输出增量）：
Δu(k) = Kp*(e(k)-e(k-1)) + Ki*Ts*e(k) + Kd*(e(k)-2*e(k-1)+e(k-2))
u(k) = u(k-1) + Δu(k)
- 优点：无积分累积，抗饱和简单；故障时可保持上一拍输出
- 推荐：电源控制优先使用增量式PID

数字PI实现（常用，忽略微分）：
u(k) = u(k-1) + Kp*(e(k)-e(k-1)) + Ki*Ts*e(k)
```

### 6.3 抗饱和（Anti-Windup）设计

```
方法1：条件积分法（积分钳位）
- 当输出饱和且误差与积分同号时，停止积分
- if (u_sat != u && e*∫e > 0) 则冻结积分

方法2：反计算抗饱和（Back-calculation）
u_unsat = Kp*e + Ki*∫e
u_sat = clamp(u_unsat, umin, umax)
∫e_next = ∫e + Ts*(e - Kt*(u_unsat - u_sat))
其中 Kt = 1/Ki 或经验取 0.1~1.0

方法3：积分限幅
- 直接对积分项限幅：I_out = clamp(I_acc, Imin, Imax)
- 简单可靠，工程常用

设计准则：
- 所有PID输出必须经过限幅（占空比 0~1，或移相角 0~180°）
- 积分限幅值应与输出限幅对应，避免恢复迟滞
- 软启动期间应预加载积分项，避免启动过冲
```

## 7. 数字滤波器设计

### 7.1 滤波器类型对比

| 类型 | 实现 | 相位延迟 | 计算量 | 适用场景 |
|------|------|---------|--------|---------|
| 一阶IIR（低通） | y(k) = α·x(k) + (1-α)·y(k-1) | 小 | 极小 | 通用噪声抑制 |
| 二阶IIR（陷波） | 双二阶节结构 | 中 | 小 | 消除特定频率谐振 |
| 移动平均（MA） | y(k) = Σx(k-N..k)/N | 大（N/2拍） | 中 | 直流采样平滑 |
| FIR | 卷积和 | 线性相位可选 | 大 | 精确相位要求 |
| 中值滤波 | 排序取中值 | N/2拍 | 中 | 剔除脉冲干扰 |

### 7.2 一阶IIR低通设计

```
截止频率 fc 对应的α系数：
α = 2π*fc*Ts / (1 + 2π*fc*Ts)
或等价：fc = α / (2π*Ts*(1-α))

示例：fs = 100kHz，目标fc = 1kHz
α = 2π*1000*1e-5 / (1 + 2π*1000*1e-5) ≈ 0.0593

设计准则：
- 反馈电压滤波：fc = 1~5kHz（不影响控制带宽）
- 电流采样滤波：fc = fc_control × 5~10
- 温度采样滤波：fc = 10~50Hz（慢变量）
- 注意：滤波器引入相位滞后，需在环路补偿中一并考虑
```

### 7.3 陷波滤波器（Notch）

```
用于消除特定频率谐振（如LLC谐振点、机械谐振）：
二阶陷波传递函数：
H(z) = (1 - 2cos(w0)*z^-1 + z^-2) / (1 - 2*r*cos(w0)*z^-1 + r^2*z^-2)

其中：
w0 = 2π*f_notch*Ts   （陷波中心角频率）
r = 1 - BW/(2*fs)     （带宽系数，r越接近1陷波越窄）

示例：抑制 fs = 100kHz 系统中 10kHz 谐振
w0 = 2π*10000*1e-5 = 0.628 rad
r = 0.95（陷波带宽 ≈ 1kHz）
```

## 8. 软件锁相环（SPLL）设计

### 8.1 SPLL在PFC中的应用

```
SPLL用于跟踪电网相位，为PFC提供同步参考：
1) 电网电压采样 → 坐标变换（αβ → dq）
2) 锁相环跟踪q轴分量趋零，输出相位θ

SOF-PLL（二阶广义积分器锁相环）结构：
- 产生正交信号（α、β）
- Park变换得dq分量
- PI控制器使 Vq → 0，输出频率与相位

PI参数设计：
ωn = 锁相环自然频率（典型 10~50Hz，对应电网带宽）
Kp_spll = 2*ζ*ωn
Ki_spll = ωn^2
ζ = 0.707（临界阻尼）

设计准则：
- 锁相环带宽远低于电网频率（50Hz带宽 < 5Hz）
- 电网畸变严重时使用SOGI-PLL或DSOGI-PLL
- 军用电源需应对频率突变（GJB 181A：47~63Hz范围内稳定锁相）
```

### 8.2 SPLL性能指标

| 指标 | 一般要求 | 军用要求 |
|------|---------|---------|
| 锁相稳态误差 | < 1° | < 0.5° |
| 锁定时间 | < 100ms | < 50ms |
| 频率跟踪范围 | 45~65Hz | 40~70Hz |
| 谐波抑制能力 | THD>10%时仍可锁相 | THD>20%时仍可锁相 |
| 频率突变恢复 | 5Hz突变 < 200ms | 5Hz突变 < 100ms |

## 9. 在线参数调优与自适应控制

### 9.1 增益调度（Gain Scheduling）

```
根据工况切换PID参数：
- 不同负载段使用不同Kp/Ki（重载需大Ki提升响应，轻载减小Ki防振荡）
- 不同输入电压段使用不同补偿（宽输入范围电源）
- 参数表存储于Flash，运行时插值查表

示例（移相全桥，2kW）：
| 负载区间 | Kp | Ki | 说明 |
|---------|-----|-----|------|
| 0~20%   | 0.5 | 50  | 轻载防振荡 |
| 20~60%  | 1.0 | 200 | 中载标准 |
| 60~100% | 2.0 | 500 | 重载快响应 |

切换平滑：参数变化限幅 ΔK/Δt，避免突变
```

### 9.2 自适应控制方法

| 方法 | 原理 | 复杂度 | 适用场景 |
|------|------|--------|---------|
| 增益调度 | 工况查表切换参数 | 低 | 工程主流方案 |
| 模型参考自适应（MRAC） | 参考模型与实际系统偏差驱动参数调整 | 中高 | 参数漂移大场合 |
| 自校正调节器（STR） | 在线辨识系统模型再设计控制器 | 高 | 负载变化大的系统 |
| 滑模控制（SMC） | 结构切换实现鲁棒控制 | 中 | 非线性/变结构系统 |
| 模糊控制 | 模糊规则推理输出 | 中 | 难建模的非线性系统 |
| 预测控制（MPC） | 基于模型预测未来状态优化控制量 | 高 | 多变量约束系统 |

## 10. 通信协议应用

### 10.1 协议对比

| 协议 | 速率 | 距离 | 节点数 | 典型应用 |
|------|------|------|--------|---------|
| PMBus | 100kHz~1MHz | 1m | 254 | 电源管理标准（电压/电流/温度遥测、配置） |
| I2C | 100kHz~1MHz | 0.5m | 128 | 板内传感器、EEPROM配置 |
| SMBus | 10~100kHz | 1m | 128 | 电池管理、兼容PMBus |
| CAN | 1Mbps | 40m@1Mbps | 110 | 多模块并联、军用车辆电源 |
| UART/RS485 | 115.2kbps~10Mbps | 1.2km@115k | 32 | 远程监控、工业现场 |
| SPI | 50Mbps | 0.3m | 1（片选扩展） | 板内高速ADC/DAC配置 |

### 10.2 PMBus应用要点

```
PMBus标准命令集（部分）：
- OPERATION (0x01)：开机/关机/输出电压调节
- VOUT_MODE (0x20)：电压模式与分辨率
- VOUT_COMMAND (0x21)：设置输出电压
- READ_VOUT (0x8B)：读取输出电压
- READ_IOUT (0x8C)：读取输出电流
- READ_TEMPERATURE_1 (0x8D)：读取温度
- STATUS_WORD (0x79)：故障状态字
- MFR_SPECIFIC (0xD0~0xFF)：厂商自定义命令

设计准则：
- PMBus地址通过硬件电阻配置，避免冲突
- 关键命令需写保护（Write Protect命令）
- 军用系统：PMBus总线需隔离（数字隔离器），并加TVS防护
- 通信超时处理：> 100ms无响应进入安全态
```

## 11. 故障录波与数字保护

### 11.1 故障录波（黑匣子）

```
录波数据结构：
- 触发条件：OVP/OCP/OTP/UVP/通信故障/看门狗超时
- 录波长度：故障前后各 100~500ms（可配置）
- 采样率：故障录波 10~50kHz（高于控制带宽）
- 存储通道：Vin, Vout, Iout, Iin, Temperature, PWM占空比, 状态字
- 存储：MCU内部RAM环形缓冲 + 掉电保持FRAM/EEPROM

实现要点：
- 环形缓冲区持续记录，触发时冻结并标记时间戳
- FRAM（铁电存储器）用于掉电保持，容量 4~64KB
- 军用要求：故障录波至少保留最近 3 次故障，可通过通信读取
```

### 11.2 数字保护策略

| 保护类型 | 采样源 | 阈值 | 响应时间 | 动作 |
|---------|--------|------|---------|------|
| OVP（过压） | 输出电压ADC | 110%~120%额定 | < 100us | 关断PWM，锁定 |
| OCP（过流） | 电流ADC/比较器 | 110%~150%额定 | < 50us | 关断PWM，重试N次 |
| OTP（过温） | 温度传感器 | 85~95°C（军标105°C） | < 10ms | 降额运行或关断 |
| UVP（欠压） | 输出电压ADC | 80%~90%额定 | < 1ms | 报警，重试 |
| 硬件比较器保护 | 模拟比较器 | 精度低但快 | < 5us | 直接硬件关断（兜底） |

```
设计准则：
- 关键保护（OCP/OVP）必须有独立硬件比较器作为兜底，不依赖软件
- 软件保护阈值 < 硬件保护阈值，形成两级保护
- 保护动作后状态锁定，需通信清除或断电重启
- 军用电源：保护动作需记录故障类型、时间、波形，供事后分析
```

## 12. 数字控制延时分析与补偿

### 12.1 延时来源

```
总控制延时 = 采样延时 + 计算延时 + PWM更新延时

1) 采样延时 T_sample：
   - ADC转换时间：12bit@3.4MSPS ≈ 300ns
   - 多通道顺序采样：N通道 × 300ns
   - 优化：使用双ADC同步采样，或并行SOC

2) 计算延时 T_calc：
   - 控制律计算（PI/PR/状态空间）：1~5us（C2000 100MHz）
   - 滤波/坐标变换：0.5~2us
   - 优化：使用定点运算、查表、DMA搬运数据

3) PWM更新延时 T_pwm_update：
   - 传统：PWM影子寄存器在下一个周期生效 → 最大1个Tpwm延迟
   - 优化：使用PWM事件触发即时更新（CMPA shadow load on event）
   - HRPWM支持周期内即时更新

总延时示例（fs = 100kHz, Tpwm = 10us）：
T_total = 0.3us(ADC) + 3us(Calc) + 5us(PWM更新半周期) ≈ 8.3us
对应相位滞后：φ = 360° × 8.3us / 10us = 298°（极大！）
→ 必须通过补偿或降低带宽解决
```

### 12.2 延时补偿方法

```
1) 降低控制带宽：
   - 控制带宽 fc << 1 / (2π × T_delay)
   - 示例：T_delay = 5us → fc < 32kHz（通常取1/5即6kHz）

2) 预测补偿（Smith预估器）：
   - 建立延时模型，在控制器中前馈预测
   - 适用于延时可精确建模的场合

3) 减小PWM更新延时：
   - 使用"双更新"模式（Double Update）：周期开始和中间各更新一次
   - 将延时从1个Tpwm降至0.5个Tpwm

4) 提前采样触发：
   - ADC在PWM周期前段触发，计算完成后立即更新本周期PWM
   - 延时降至 < 1个Tpwm

5) 多速率控制：
   - 内环（电流环）高速：每个开关周期执行
   - 外环（电压环）低速：每N个开关周期执行
   - 降低外环计算对内环延时的影响
```

## 13. 军用数字电源特殊要求

### 13.1 抗辐射与SEU防护

| 防护措施 | 实现方法 | 应用对象 |
|---------|---------|---------|
| 三模冗余（TMR） | 关键寄存器3份副本投票 | 控制寄存器、状态机 |
| ECC校验 | 汉明码/Spring编码 | Flash、RAM关键区 |
| 看门狗 | 独立硬件看门狗+软件看门狗 | 程序跑飞检测 |
| 周期自检 | CRC校验代码区、RAM March测试 | 上电及周期性 |
| 抗辐射器件 | 选用Rad-Hard或EP版本 | 航天/弹载电源 |

### 13.2 信息安全与功能安全

```
信息安全：
- 固件加密存储（AES-256），防止逆向工程
- 安全启动（Secure Boot），校验签名后执行
- 通信加密（PMBus over 加密通道），军用需符合GJB密码标准

功能安全（参考GJB 5000/MIL-STD-882E）：
- 关键控制变量双通道冗余采样与交叉校验
- 故障检测覆盖率 > 90%
- 安全态定义：故障时输出关断或切换至备份模块
- SIL2/SIL3等级设计（参考IEC 61508）
```

### 13.3 宽温与极端环境

```
- 工作温度：-55°C ~ +125°C（MCU结温）
- Flash在极端低温下访问时间增加，需降频或加等待状态
- ADC在高温下精度下降，需温度补偿校准
- 外部晶振在极端温度下频率漂移，推荐使用内部OSC或温补晶振
- 军用PCB需 conformal coating（三防漆），防护潮湿/盐雾/霉菌
```

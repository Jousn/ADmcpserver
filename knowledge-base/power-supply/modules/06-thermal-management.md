# 热管理设计知识库

> 适用范围：军用及民用中高功率电源（50W~10kW级）
> 目标读者：AI设计辅助技能（用于设计建议与设计审查）
> 版本：v1.0

---

## 1. 概述

热管理是电源可靠性设计的核心环节。统计表明，电子器件失效率随温度升高呈指数增长，温度每升高10°C，器件寿命约减半（Arrhenius法则）。中高功率电源中功率器件（MOSFET、二极管、磁性元件）的热损耗可达总功率的5%~15%，需要系统的热设计确保所有器件工作在安全温度范围内。

### 1.1 热管理设计目标

| 等级 | 结温降额要求 | 适用场景 |
|------|-------------|----------|
| 民用标准 | Tj ≤ 0.80 × Tj_max | 消费电子 |
| 工业标准 | Tj ≤ 0.75 × Tj_max | 工业电源 |
| 军用标准 | Tj ≤ 0.70 × Tj_max | 军用电源 |
| 高可靠 | Tj ≤ 0.65 × Tj_max | 航天/高可靠 |

## 2. 热阻模型

### 2.1 热阻网络模型

功率器件的热量传导路径可用串联热阻网络表示：

```
结温 Tj ──[RθJC]──► 壳温 Tc ──[RθCS]──► 散热器 Ts ──[RθSA]──► 环境温度 Ta

总热阻：RθJA = RθJC + RθCS + RθSA

结温计算：
Tj = Ta + Pd × (RθJC + RθCS + RθSA)

即：
Tj = Ta + Pd × RθJA
```

### 2.2 各级热阻定义

| 热阻 | 符号 | 含义 | 典型值范围 |
|------|------|------|-----------|
| 结-壳热阻 | RθJC | 芯片到封装外壳 | 0.3~5°C/W |
| 壳-散热器热阻 | RθCS | 外壳到散热器（含导热界面材料） | 0.1~2°C/W |
| 散热器-环境热阻 | RθSA | 散热器到环境 | 0.2~20°C/W |
| 结-环境热阻 | RθJA | 总热阻（自然冷却） | 20~100°C/W |

### 2.3 热阻计算示例

```
已知条件：
  MOSFET功耗 Pd = 5W
  RθJC = 0.5°C/W（器件数据手册）
  RθCS = 0.3°C/W（导热硅脂）
  RθSA = 2.0°C/W（散热器）
  环境温度 Ta = 55°C（军用机箱内）

计算：
  RθJA = 0.5 + 0.3 + 2.0 = 2.8°C/W
  Tj = 55 + 5 × 2.8 = 69°C

降额校验：
  Tj_max = 175°C（军用MOSFET）
  Tj / Tj_max = 69/175 = 0.39 < 0.70 ✓ 满足军用降额要求
```

## 3. 结温计算公式与降额设计

### 3.1 稳态结温计算

```
Tj = Ta + Pd × RθJA

其中：
  Tj:   器件结温
  Ta:   环境温度
  Pd:   器件稳态功耗
  RθJA: 结到环境总热阻
```

### 3.2 瞬态热阻抗

功率器件在脉冲负载下，结温取决于瞬态热阻抗而非稳态热阻。

```
瞬态热阻抗公式（ Foster网络近似）：

ZθJC(t) = Σ[Ri × (1 - exp(-t/τi))]

典型单脉冲瞬态热阻抗曲线：
  t = 1ms:   ZθJC ≈ 0.1 × RθJC
  t = 10ms:  ZθJC ≈ 0.3 × RθJC
  t = 100ms: ZθJC ≈ 0.6 × RθJC
  t = 1s:    ZθJC ≈ 0.9 × RθJC
  t = 10s:   ZθJC ≈ RθJC（接近稳态）
```

### 3.3 功率器件功耗计算

#### 3.3.1 MOSFET功耗

```
P_MOSFET = P_conduction + P_switching + P_drive + P_dead

P_conduction = Irms² × Rds_on(Tj) × D
P_switching  = 0.5 × Vin × Io × (tr + tf) × fsw
P_drive      = Qg × Vgs × fsw
P_dead       = Vsd × Io × tdt × fsw × 2

注意：Rds_on随温度升高而增大，125°C时约为25°C值的1.5~2倍
```

#### 3.3.2 二极管功耗

```
P_diode = Vf × Io_avg + P_rr

P_rr = 0.5 × Qrr × Vr × fsw

其中：
  Vf:     正向导通压降
  Io_avg: 平均正向电流
  Qrr:    反向恢复电荷
  Vr:     反向电压
  fsw:    开关频率
```

#### 3.3.3 变压器/电感铜损

```
P_copper = Irms² × Rac

Rac = Rdc × (1 + Δskin + Δ_proximity)

其中：
  Rac:       交流绕组电阻（含趋肤和邻近效应）
  Rdc:       直流绕组电阻
  Δskin:     趋肤效应系数
  Δ_proximity: 邻近效应系数
```

### 3.4 降额设计准则

```
军用降额设计规则：

1. 结温降额：
   Tj ≤ 0.70 × Tj_max
   若 Tj_max = 175°C，则 Tj ≤ 122°C

2. 功率降额：
   Pd_actual ≤ 0.50 × Pd_rated（稳态）
   Pd_actual ≤ 0.70 × Pd_rated（瞬态）

3. 温升限制：
   ΔT = Tj - Ta ≤ 60°C（军用户外环境Ta=85°C）
   即 Tj ≤ 145°C（但受结温降额约束，实际≤122°C）

4. 环境温度降额：
   设计环境温度 Ta_design = 1.1 × Ta_max
   Ta_max = 85°C → Ta_design = 93.5°C
```

## 4. 散热器选型

### 4.1 冷却方式对比

| 冷却方式 | 散热能力 | 复杂度 | 噪音 | 可靠性 | 军用适用 |
|----------|----------|--------|------|--------|----------|
| 自然冷却 | 最低（RθSA > 3°C/W） | 低 | 无 | 最高 | 推荐（低功率） |
| 强制风冷 | 中等（RθSA 0.5~3°C/W） | 中 | 有 | 中 | 推荐（中功率） |
| 液冷水冷板 | 高（RθSA 0.05~0.5°C/W） | 高 | 低 | 中高 | 推荐（大功率） |
| 热管散热 | 高（等效RθSA极低） | 中 | 无 | 高 | 推荐（紧凑型） |
| 蒸发冷却 | 极高 | 极高 | 低 | 中 | 特殊场合 |

### 4.2 自然冷却散热器选型

#### 4.2.1 散热器热阻估算

```
自然对流散热器热阻经验公式：

RθSA ≈ 1 / (h × A_total × η_fin)

其中：
  h:        对流换热系数（自然冷却 5~25 W/m²·°C）
  A_total:  散热器总表面积（含翅片）
  η_fin:    翅片效率（0.6~0.9）
```

#### 4.2.2 选型建议

| 功耗 | 推荐散热器尺寸 | RθSA | 安装方式 |
|------|---------------|------|----------|
| < 5W | 25×25×10mm | 8~15°C/W | PCB直插 |
| 5~15W | 40×40×20mm | 3~6°C/W | 螺钉固定 |
| 15~30W | 60×60×30mm | 1.5~3°C/W | 螺钉固定 |
| 30~60W | 80×80×40mm | 0.8~1.5°C/W | 螺钉固定 |
| 60~100W | 100×100×50mm | 0.5~1.0°C/W | 螺钉固定 |

### 4.3 强制风冷散热器选型

#### 4.3.1 风速对热阻的影响

```
RθSA(forced) = RθSA(natural) / (1 + k × v^n)

其中：
  v: 风速（m/s）
  k: 经验系数（0.5~1.0）
  n: 经验指数（0.5~0.8）

典型风速-热阻关系：
  0 m/s（自然冷却）: RθSA = 2.0°C/W
  1 m/s:             RθSA = 1.2°C/W
  2 m/s:             RθSA = 0.8°C/W
  3 m/s:             RθSA = 0.6°C/W
  5 m/s:             RθSA = 0.4°C/W
```

#### 4.3.2 风扇选型

| 风扇尺寸 | 转速 | 风量(CFM) | 噪音(dBA) | 适用功率 |
|----------|------|-----------|-----------|----------|
| 40×40×10mm | 8000rpm | 8 | 35 | 50~100W |
| 60×60×15mm | 5000rpm | 18 | 30 | 100~300W |
| 80×80×25mm | 3500rpm | 35 | 28 | 300~600W |
| 120×120×38mm | 2800rpm | 100 | 32 | 600~1500W |

#### 4.3.3 军用风扇特殊要求

- 宽温工作：-55°C~+85°C
- 抗振动：满足GJB 150A振动试验
- 长寿命：球轴承，MTBF ≥ 50,000小时（65°C）
- 冗余设计：双风扇并联，单风扇故障仍可运行
- 速度监控：内置转速传感器（TACH输出）

### 4.4 液冷水冷板选型

#### 4.4.1 水冷板热阻计算

```
RθSA(水冷) ≈ 1 / (h × A_contact)

水冷板换热系数 h：
  层流：h = 200~500 W/m²·°C
  湍流：h = 1000~10000 W/m²·°C

典型水冷板热阻：0.05~0.3°C/W
```

#### 4.4.2 冷却液选择

| 冷却液 | 冰点 | 沸点 | 导热系数 | 适用温度 | 特点 |
|--------|------|------|----------|----------|------|
| 去离子水 | 0°C | 100°C | 0.6 W/m·K | > 5°C | 导热最好，但不防冻 |
| 乙二醇水溶液(50%) | -35°C | 108°C | 0.4 W/m·K | -35~+100°C | 军用标准 |
| PAO（聚α烯烃） | -55°C | 163°C | 0.15 W/m·K | -55~+150°C | 航空专用 |
| 硅油 | -50°C | 200°C | 0.15 W/m·K | -50~+180°C | 高温应用 |

### 5.2 导热硅脂选型

#### 5.2.1 热阻计算

```
RθCS = t / (k × A)

其中：
  t: 硅脂厚度（m），典型0.05~0.15mm
  k: 导热系数（W/m·K）
  A: 接触面积（m²）

示例：
  t = 0.1mm = 0.0001m
  k = 3.0 W/m·K
  A = 100mm² = 0.0001m²（TO-220封装）
  
  RθCS = 0.0001 / (3.0 × 0.0001) = 0.33°C/W
```

|------|----------|----------|------|----------|

| Dow Corning TC-5688 | 8.5 W/m·K | -45~+200°C | 高温稳定 | 军用 |
| Laird Tgon805 | 5.0 W/m·K | -40~+150°C | 通用 | 标准应用 |
| Arctic Silver 5 | 8.9 W/m·K | -50~+130°C | 含银 | 高端民用 |

### 5.3 导热垫选型

```
导热垫选型要点：
1. 厚度需匹配安装间隙（压缩量10~30%）
2. 硬度（Shore OO）影响接触热阻，越软越好但强度降低
3. 击穿电压需满足隔离要求（> 4kV）
4. 军用需满足低放气要求（NASA ASTM E595）
```

| LTspice | Analog Devices | 电热联合仿真 | 中 | 免费 | 电路级估算 |

### 6.2 仿真流程

```
热仿真标准流程：

1. 建立几何模型（导入CAD或MCAD）
2. 定义材料热属性（导热系数、比热、密度）
3. 定义热源（功耗、位置）
4. 定义边界条件（环境温度、对流/辐射系数）
5. 网格划分（重点关注热源和散热器翅片）
6. 稳态/瞬态求解
7. 后处理分析（温度场、热流路径）
8. 设计优化迭代
```

### 6.3 仿真精度要求

```
仿真目标：
  结温误差 < ±5°C（与实测对比）
  热点位置准确（误差 < 2mm）
  
校准方法：
  - 使用红外热像仪校准外壳温度
  - 使用热电偶校准散热器温度
  - 使用器件内部温度敏感参数（TSP）校准结温
```

## 7. PCB热设计

### 7.1 铜皮散热

#### 7.1.1 铜皮热阻估算

```
单层铜皮（1oz, 35μm）的热扩散能力：

对于 25×25mm 铜皮：
  Rθ(copper) ≈ 20~40°C/W（自然冷却）
  Rθ(copper) ≈ 10~20°C/W（强制风冷）

增大铜皮面积效果递减：
  面积×4 → Rθ约降50%（非线形）
  面积×16 → Rθ约降75%
```

#### 7.1.2 铜皮设计准则

| 准则 | 说明 |
|------|------|
| 铜厚选择 | 功率器件区域用2oz（70μm）或更厚铜 |
| 铜皮面积 | 尽可能大，但避免热应力集中 |
| 绿油开窗 | 功率器件下方开绿油，直接暴露铜 |
| 铜皮形状 | 圆形或椭圆形优于方形，热扩散更均匀 |
| 避免热隔离 | 不要在铜皮上开信号走线槽 |

### 7.2 热过孔阵列

#### 7.2.1 热过孔设计参数

```
热过孔参数：
  孔径：0.2~0.3mm
  盘径：0.4~0.6mm
  间距：0.6~1.0mm
  铜厚：≥ 25μm（孔内镀铜）
  
热过孔热阻估算：
  单孔 Rθ_via ≈ t_board / (k_cu × A_via)
  
  对于1.6mm板厚，0.3mm孔径：
  Rθ_via ≈ 75~150°C/W（单孔）

  热过孔阵列（N个并联）：
  Rθ_array = Rθ_via / N

  典型 5×5 阵列（25孔）：
  Rθ_array ≈ 3~6°C/W
```

#### 7.2.2 热过孔设计要点

1. 在功率器件焊盘正下方密集排列热过孔
2. 热过孔应连接到内部大面积铜皮层和底层散热铜皮
3. 热过孔可填充导热树脂（避免焊接工艺问题）
4. 热过孔不应作为信号过孔使用
5. 热过孔数量与分布需通过热仿真优化

### 7.3 金属基板（MCPCB）

#### 7.3.1 MCPCB结构

```
MCPCB（金属芯PCB）结构层：

顶层：铜走线层（1~2oz，35~70μm）
     ↓ 介质层（导热绝缘层，厚度50~100μm）
底层：金属基板（铝板或铜板，厚度1~3mm）

导热路径：器件 → 铜走线 → 介质层 → 金属基板 → 散热器
```

#### 7.3.2 MCPCB热性能

|------|----------|------------|------------|
| 导热系数 | 0.3 W/m·K | 1.0~3.0 W/m·K | 2.0~8.0 W/m·K |
| 热阻(1cm²) | 50~70°C/W | 0.5~2.0°C/W | 0.2~1.0°C/W |
| 耐压 | > 2kV | 2~8kV | 2~8kV |

## 8. 功率器件布局热均衡策略

### 8.1 热源分散原则

```
布局策略：
1. 高发热器件均匀分布，避免热集中
2. 热源间距 ≥ 10mm（避免热叠加）
3. 温度敏感器件远离热源（间距 ≥ 20mm）
4. 热源不均匀时，高温器件放在散热器上游（进风侧）
5. 多个散热器并联时，风道设计需均衡流量
```

### 8.2 器件热耦合分析

| 布局关系 | 热影响 | 建议 |
|----------|--------|------|
| 相邻功率管（< 5mm） | 强耦合，温升叠加 | 增大间距或共用散热器 |
| 上下层功率管 | 通过PCB热耦合 | 铺热隔离铜皮 |
| 变压器与MOSFET | 中等耦合 | 适当间距，独立散热 |
| 电容与热源 | 电容寿命受温度影响 | 电容远离热源 > 15mm |
| 控制IC与热源 | IC温度漂移影响精度 | 控制IC远离热源或隔热 |

### 8.3 多器件均温设计

```
多MOSFET并联均温设计：

1. 并联MOSFET安装在同一散热器上，间距均匀
2. 散热器翅片方向与气流方向一致
3. 在散热器与MOSFET之间使用相同厚度、相同材料的导热材料
4. 安装力矩一致（数据手册规定值，如0.6~1.0 N·m）
5. 通过热仿真验证各器件温差 < 5°C
```

## 9. 军用电源宽温设计（-55°C ~ +85°C）

### 9.1 低温设计挑战与对策

| 挑战 | 影响 | 对策 |
|------|------|------|
| 电解电容容量下降 | -40°C容量降50~70% | 选用固态电容或宽温电解电容 |
| MOSFET Rds_on增大 | 导通损耗增加20~30% | 降额设计预留裕量 |
| 磁芯材料磁导率变化 | 电感量变化 | 选用宽温磁芯材料 |
| PCB基板CTE失配 | 焊点开裂 | 选用高Tg FR-4或陶瓷基板 |
| 润滑油凝固 | 风扇启动困难 | 选用宽温球轴承风扇 |
| 热胀冷缩 | 机械应力 | 增加机械应力释放设计 |

### 9.2 高温设计挑战与对策

| 挑战 | 影响 | 对策 |

## 10. 热循环与热冲击可靠性

### 10.1 热循环疲劳

#### 10.1.1 Coffin-Manson模型

```
热循环疲劳寿命（Coffin-Manson方程）：

Nf = C × (ΔT)^(-n)

其中：
  Nf: 失效前循环次数
  ΔT: 温度循环幅值（°C）
  C, n: 材料常数

对于Sn-Pb焊料：n ≈ 2.5
对于SAC305无铅焊料：n ≈ 2.0~2.5

Engelmaier修正模型（考虑频率和最高温度）：

Nf = 0.5 × (F / (Δε_p))^(1/c)

c = -0.442 - 6×10⁻⁴ × Tmax + 1.74×10⁻² × ln(1+f)
```

#### 10.1.2 热循环设计准则

| 温度循环条件 | 幅值ΔT | 要求循环次数 | 适用标准 |
|-------------|--------|-------------|----------|
| 民用 | 0~60°C | 1000次 | IPC-9701 |
| 工业 | -20~+70°C | 2000次 | IPC-9701 |
| 军用 | -40~+85°C | 5000次 | GJB 150A |
| 航天 | -55~+125°C | 3000次 | MIL-STD-883 |

### 10.2 热冲击（Thermal Shock）

#### 10.2.1 热冲击 vs 热循环

| 特性 | 热循环 | 热冲击 |
|------|--------|--------|
| 温变速率 | < 10°C/min | > 15°C/min（通常>30°C/min） |
| 失效模式 | 焊点疲劳裂纹 | 材料开裂、分层 |
| 典型条件 | -40~+85°C | -55~+125°C（液氮/烘箱） |
| 标准 | GJB 150A-2009 方法9 | GJB 150A-2009 方法10 |

#### 10.2.2 抗热冲击设计

```
设计措施：
1. 避免CTE（热膨胀系数）失配较大的材料直接连接
2. BGA/CSP器件底部加underfill（底部填充胶）
3. 大面积铜皮采用网格化设计（减少热应力）
4. PCB层叠结构对称设计（防翘曲）
5. 军用PCB选用高Tg材料（Tg ≥ 170°C）
6. 大器件增加机械固定（胶封或螺钉）
```

### 10.3 热设计加速寿命试验

```
加速寿命试验温度条件（依据Arrhenius模型）：

加速因子 AF = exp[Ea/k × (1/Tuse - 1/Ttest)]

其中：
  Ea: 激活能（硅器件典型0.7eV）
  k:  玻尔兹曼常数（8.617×10⁻⁵ eV/K）
  Tuse: 使用温度（K）
  Ttest: 试验温度（K）

示例：
  使用温度：85°C = 358K
  试验温度：125°C = 398K
  Ea = 0.7eV

  AF = exp[0.7/8.617e-5 × (1/358 - 1/398)]
     = exp[0.7/8.617e-5 × 2.8e-4]
     = exp[2.27]
     ≈ 9.7

  即125°C试验1小时 ≈ 85°C使用9.7小时
```

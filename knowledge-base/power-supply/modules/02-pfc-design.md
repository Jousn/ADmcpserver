> 适用范围：军用及民用中高功率电源（200W~50kW）
> 目标受众：AI设计辅助Skill，用于PFC电路设计咨询与审查
> 版本：v1.0 | 更新日期：2026-08

## 1. 概述

功率因数校正（PFC）电路是中大功率AC-DC电源的核心前端级，其作用是使输入电流跟踪输入电压波形，提高功率因数（PF），降低总谐波失真（THD），满足IEC 61000-3-2（民用）和GJB相关标准（军用）的谐波电流限值要求。

### 1.1 为什么需要PFC

| 无PFC电源问题 | 后果 |
|-------------|------|
| 功率因数低（0.5~0.7） | 视在功率大，电网利用率低 |
| 输入电流谐波丰富 | 谐波污染电网，导致中线过载 |
| 峰值电流大 | 断路器误跳，线缆损耗大 |
| 不满足EMC法规 | 无法通过认证（IEC 61000-3-2 Class A/B） |

### 1.2 PFC设计目标

| 指标 | 民用目标 | 军用目标 |
|------|---------|---------|
| 功率因数 PF | ≥0.95（满载） | ≥0.99（满载），≥0.95（半载） |
| 总谐波失真 THD | <5% | <3% |
| 效率 | ≥96%（满载） | ≥97%（满载） |
| 输入电压范围 | AC 90~264V | AC 85~305V（宽输入） |
| 输出电压纹波 | <5% | <3% |
| MTBF | >50000h | >200000h |

## 2. PFC类型对比

### 2.1 被动式PFC vs 主动式PFC

| 特性 | 被动式PFC | 主动式PFC |
|------|---------|---------|
| 拓扑 | LC滤波/谐振电感 | Boost/Buck-Boost等 |
| 功率因数 | 0.7~0.85 | 0.95~0.999 |
| THD | 20%~40% | 3%~10% |
| 效率 | 95%~98% | 94%~98% |
| 成本 | 低 | 中高 |
| 体积 | 大（低频电感） | 小（高频电感） |
| 适用功率 | <300W | 100W~50kW+ |
| 可靠性 | 高（无有源器件） | 中（含开关器件和控制IC） |

**结论：** 中高功率（>200W）必须使用主动式PFC。

### 2.2 主动式PFC工作模式对比

| 模式 | CCM（连续导通模式） | DCM（断续导通模式） | CRM/TCM（临界导通模式） |
|------|-------------------|-------------------|---------------------|
| 电感电流 | 连续 | 断续 | 临界（降为零即开通） |
| 适用功率 | >300W ~ 50kW+ | <300W | 100W~1kW |
| 开关频率 | 固定 | 固定 | 变频（峰点低频，谷点高频） |
| 开关管电流 | 三角波+直流分量 | 三角波（归零） | 三角波（归零） |
| 二极管反向恢复 | 有（需SiC或超快恢复） | 无 | 无（但有关断损耗） |
| 控制复杂度 | 高（需电流环补偿） | 低 | 中 |
| THD | 最好（<3%） | 一般（5%~10%） | 良好（3%~5%） |
| 效率 | 高（大功率最优） | 中 | 高（中小功率最优） |

**选型决策：**

```
功率 < 300W：       DCM Boost PFC 或 CRM Boost PFC
300W ~ 1kW：       CRM Boost PFC（单相）
1kW ~ 3kW：        CCM Boost PFC（单相）或 Interleaved CRM PFC
3kW ~ 10kW：       CCM Boost PFC（单相）或 Interleaved CCM PFC
10kW ~ 50kW：      Interleaved CCM PFC 或 Totem-Pole PFC
军用高可靠宽输入：   CCM Boost PFC（冗余设计）
```

## 3. Boost PFC电路设计（CCM模式）

### 3.1 基本拓扑与工作原理

```
        L_pfc            D_pfc
Vin ──┤├──┬─────────┬─────|>|────┬── Vout (+)
            │         │           │
           ─┤├─ Q1    │          ─┴─ C_out
            │         │          ─┬─
GND ────────┴─────────┴────────────┴── Vout (-)
```

- Q1导通：电感L储能，二极管D截止，输出由C_out供电
- Q1关断：电感L通过D向输出释放能量

### 3.2 PFC电感设计

#### 3.2.1 电感量计算

```
纹波率要求：ΔI = k × I_peak   （k通常取 0.15~0.30）

I_peak = √2 × P_out / (η × V_in_rms_min)

L_pfc = V_in_min × D / (f_sw × ΔI)

其中占空比：D = 1 - V_in_min / V_out

最大纹波出现在 V_in = V_out / 2 时：
D_max_ripple = 0.5
L_pfc = (V_out / 2) / (f_sw × k × I_peak)
```

**设计示例（1kW CCM Boost PFC）：**

| 参数 | 值 |
|-----|---|
| 输出功率 P_out | 1000W |
| 效率 η | 0.97 |
| 最低输入电压 V_in_min | 90VAC |
| 输出电压 V_out | 400VDC |
| 开关频率 f_sw | 100kHz |
| 纹波率 k | 0.20 |

```
I_peak = √2 × 1000 / (0.97 × 90) = 16.1A
L_pfc = (400/2) / (100000 × 0.20 × 16.1) = 621μH → 选 620μH
```

#### 3.2.2 磁芯选型与匝数

```
AP法（面积乘积）：
AP = (L × I_peak × I_rms) / (J × Ku × B_max) × 10^8  [mm⁴]

其中：
J = 400~600 A/cm²（电流密度）
Ku = 0.3~0.5（窗口填充系数）
B_max = 0.2~0.3T（峰值磁通密度，铁氧体）
```

| 功率等级 | 推荐磁芯 | 材料 | 匝数参考 | 线径/铜箔 |
|---------|---------|------|---------|---------|
| 200~500W | ETD34/EE35 | PC44/N87 | 50~70 | 0.1×15铜箔 |
| 500W~1kW | ETD39/EE42 | PC44/N87 | 45~60 | 0.1×25铜箔 |
| 1~3kW | ETD49/EE55 | PC44/N87 | 35~50 | 0.15×40铜箔 |
| 3~5kW | ETD59/PM62 | PC95/N97 | 30~45 | 0.2×50铜箔 |
| 5~10kW | EE65/PM74 | PC95/N97 | 25~40 | 0.2×70铜箔 |

#### 3.2.3 绕组损耗与趋肤效应

```
趋肤深度（铜，20°C）：δ = 65.5 / √f  [mm]

100kHz: δ ≈ 0.21mm → 铜箔厚度 ≤ 0.2mm
```

大功率PFC电感建议采用：
- 利兹线（多股0.1mm漆包线绞合）
- 薄铜箔（厚度<2δ）
- 交错绕制降低邻近效应

#### 3.2.4 气隙设计

```
气隙长度：lg = (μ0 × N² × Ae) / L - (le / μr)

磁通密度校验：B_peak = (L × I_peak) / (N × Ae)

要求：B_peak < B_sat × 80%（铁氧体B_sat ≈ 0.4T@100°C）
      B_peak < 0.3T（损耗约束，典型工作点）
```

### 3.3 开关管选型

#### 3.3.1 器件类型选型

| 器件类型 | 适用功率 | 优势 | 劣势 | 推荐型号（650V） |
|---------|---------|------|------|----------------|
| Si MOSFET | <1kW | 成本低，驱动简单 | 导通损耗大，体二极管差 | IPW60R099CP |
| SiC MOSFET | 1~50kW | 低损耗，高频，耐高温 | 成本高，驱动要求严 | C3M0060065K |
| GaN HEMT | 0.5~10kW | 超高频，无反向恢复 | 成本高，驱动要求严 | GPN65HS150F |
| IGBT | >3kW | 大电流，低成本 | 开关损耗大，低频适用 | IKW40N65H5 |

**军用推荐：** SiC MOSFET（耐高温、抗辐射、高可靠）

#### 3.3.2 耐压和电流设计

```
V_DS_max = V_out + V_spike + Margin
V_spike ≈ 50~100V（取决于寄生电感和缓冲电路）
Margin ≈ 20% × V_out

→ V_DS_rated ≥ 1.2 × V_out + 100V

示例：V_out = 400V → V_DS_rated ≥ 580V → 选 650V 器件

I_D_rms = I_in_rms × √(D_max) ≈ I_in_rms × √(1 - V_in_min/V_out)
I_D_peak = I_peak + ΔI/2

器件额定电流：I_D_rated ≥ 1.5 × I_D_rms（温升裕度）
```

### 3.4 二极管选型（CCM模式关键器件）

CCM模式下PFC二极管存在反向恢复问题，是主要的开关损耗来源。

| 二极管类型 | trr | VF | 适用频率 | 适用功率 | 推荐型号 |
|-----------|-----|-----|---------|---------|---------|
| Si超快恢复 | 25~50ns | 1.2~1.5V | <150kHz | <3kW | MUR1560, STTH8L06 |
| SiC肖特基 | ~0ns | 1.5~2.0V | 任意 | 1~50kW | C3D10170H, C6D20065D |
| Si肖特基(低压) | ~0ns | 0.5~0.8V | 任意 | <500W(低压) | 仅适用低输出电压 |

**CCM PFC关键选型：** 优先选用SiC肖特基二极管，消除反向恢复损耗。

### 3.5 输出电容设计

```
输出电容需满足：
1. 二次谐波纹波约束：
   C_out ≥ P_out / (2π × f_line × 2 × V_out × ΔV_ripple)

2. Hold-up时间约束：
   C_out ≥ 2 × P_out × t_holdup / (V_out² - V_drop²)

其中：
f_line = 50Hz（工频）
ΔV_ripple = 允许的工频纹波（通常 <5% × V_out）
t_holdup = 掉电保持时间（通常 ≥20ms，军用 ≥50ms）
V_drop = 后级最低工作电压（如350V）
```

**设计示例（1kW PFC）：**

```
纹波约束：C ≥ 1000 / (2π × 50 × 2 × 400 × 20) = 198μF
Holdup约束（20ms）：C ≥ 2 × 1000 × 0.02 / (400² - 350²) = 753μF
→ 取较大值，选 820μF / 450V 电解电容（或2颗470μF并联）
```

## 4. Interleaved PFC设计（两相交错PFC）

### 4.1 拓扑结构

```
            L1                    D1
Vin ──┬──┤├──┬────────┬─────|>|──┬
      │      │        │          │
      │     ─┤├─ Q1   │         ─┴─ C_out
      │      │        │         ─┬─
      │      │    ┌───┘          │
      │      │    │              │
      │     L2   │              │
      ├──┤├──┬──┤               │
      │      │  │               │
      │     ─┤├─ Q2             │
      │      │                  │
GND ──┴──────┴──────────────────┴── Vout (-)

两相驱动信号相位差180°
```

### 4.2 交错PFC优势

| 优势 | 说明 | 量化效果 |
|------|------|---------|
| 纹波抵消 | 两相纹波电流相位相反，输出纹波抵消 | 输出电容纹波电流减小50%~80% |
| 热分散 | 功率器件分布在两相 | 热点温度降低10~20°C |
| 电感体积 | 每相电感量减半 | 电感总体积减小~30% |
| EMI改善 | 有效开关频率翻倍 | EMI滤波器体积减小 |
| 效率提升 | 每相电流减半，导通损耗降低 | 效率提升0.5%~1% |

### 4.3 设计参数

```
每相电感：L_phase = L_single × 2（等效于单相设计）
每相开关频率：f_sw（与单相相同）
等效输出纹波频率：2 × f_sw

纹波抵消因子：
RCF = sin(π × D)  （在 D=0.5 时最大抵消）

最佳交错角度：180°
```

**适用功率范围：** 1kW~10kW（两相），10kW以上可扩展为三相或四相交错。

## 5. Totem-Pole PFC（无桥PFC）设计

### 5.1 拓扑结构

```
       L_pfc
Vin ──┤├──┬─────────┬── Vout (+)
           │         │
     ┌─────┤├─ Q1    │
     │     │         │
     │    Q2 ─├┤─┐   │
     │     │   │   │
     │    Q3 ─┤├─┘   │
     │     │         │
     └─────┤├─ Q4    │
                     │
GND ─────────────────┴── Vout (-)

Q1/Q4: 高频开关管（SiC MOSFET）
Q2/Q3: 工频换向管（Si MOSFET，低导通损耗）
```

### 5.2 工作原理

| 输入半周 | 高频臂 | 工频臂 | 电流路径 |
|---------|--------|--------|---------|
| 正半周 | Q1 PWM, Q4 同步整流 | Q2 常通 | Vin→L→Q1/Q4→Vout→Q2→Vin |
| 负半周 | Q4 PWM, Q1 同步整流 | Q3 常通 | Vin→Q3→Vout→Q4/Q1→L→Vin |

### 5.3 Totem-Pole PFC优势

| 指标 | 传统Boost PFC | Totem-Pole PFC |
|------|-------------|----------------|
| 导通路径器件数 | 2（整流桥2+开关管1+二极管1=4） | 2（工频管1+高频管1） |
| 导通损耗 | 高（整流桥损耗占3~5%） | 低（无整流桥） |
| 效率（满载） | 96~97% | 98~99% |
| 器件数量 | 多（整流桥+开关管+二极管） | 少（4颗MOSFET） |
| 控制复杂度 | 中 | 高（需工频换向逻辑） |
| 适用器件 | Si/SiC均可 | **必须SiC**（无反向恢复问题） |

### 5.4 设计要点

```
1. 必须使用SiC MOSFET作为高频开关管（消除反向恢复电流）
2. 工频臂选用低Rds(on) Si MOSFET（工频切换，损耗主要为导通损耗）
3. ZVS/软开关可实现（在CRM/GCM模式下）
4. 控制算法：数字控制（MCU/DSP）为主，需实现工频换向和PWM
5. 输入电流过零点处有畸变（工频管切换死区），需优化死区时间
6. 推荐控制IC：TI C2000系列MCU，或ST STM32G4系列
```

### 5.5 适用范围

- 功率范围：500W~10kW（单相），可扩展至多相
- 典型应用：服务器电源（80+ Titanium）、军用高效电源
- 前提条件：SiC MOSFET成本可接受

## 7. 功率因数与THD指标要求

### 7.1 功率因数定义

```
PF = P / S = cos(φ) × DPF

其中：
P = 有功功率
S = 视在功率
cos(φ) = 相位差功率因数（基波）
DPF = 畸变功率因数 = I_1 / I_total = 1 / √(1 + THD²)
```

### 7.2 THD计算

```
THD = √(Σ I_n²) / I_1 × 100%    （n = 2, 3, 4, ...）

PF ≈ DPF = 1 / √(1 + THD²)      （当相位差φ ≈ 0时）
```

| THD | 近似PF | 评价 |
|-----|--------|------|
| 30% | 0.958 | 勉强合格（民用低标） |
| 10% | 0.995 | 合格 |
| 5% | 0.999 | 良好 |
| 3% | 0.9996 | 优秀（军用目标） |
| 1% | 0.99995 | 极优（实验室水平） |

### 7.3 法规要求

| 标准 | 适用范围 | 限值要求 |
|------|---------|---------|
| IEC 61000-3-2 Class A | 工业设备 | 各次谐波电流限值 |
| IEC 61000-3-2 Class D | 个人计算机等 | 特定谐波限值 |
| IEC 61000-3-12 | >16A/相设备 | THD<20%, PF>0.95 |
| GJB（军用） | 军用电源 | THD<3%, PF>0.99 |
| 80+ Titanium | 服务器电源 | PF>0.95@50%负载 |

## 8. 大功率PFC热设计要点

### 8.1 功率损耗分布

| 损耗来源 | 占比（典型） | 优化方向 |
|---------|------------|---------|
| 开关管导通损耗 | 30%~40% | 选用低Rds(on) SiC MOSFET |
| 开关管开关损耗 | 20%~30% | 提高驱动速度，ZVS/软开关 |
| 二极管损耗 | 10%~20% | SiC肖特基消除反向恢复 |
| 电感铜损 | 15%~25% | 增大截面积，利兹线 |
| 电感铁损 | 5%~15% | 优化磁芯材料和工作磁通 |
| 控制电路损耗 | <2% | — |

### 8.2 热阻设计

```
T_j = T_a + P_loss × (R_θ_jc + R_θ_cs + R_θ_sa)

其中：
T_j = 结温（军品要求 <125°C，推荐<105°C）
T_a = 环境温度（军品按 +85°C 设计）
R_θ_jc = 结壳热阻（器件数据手册）
R_θ_cs = 壳散热器热阻（导热硅脂/垫，约0.1~0.5°C/W）
R_θ_sa = 散热器对环境热阻

→ R_θ_sa = (T_j_max - T_a) / P_loss - R_θ_jc - R_θ_cs
```

**设计示例（SiC MOSFET, P_loss=10W, T_a=85°C, T_j<105°C）：**

```
R_θ_sa = (105 - 85) / 10 - 0.5 - 0.3 = 1.2°C/W
→ 需要散热器热阻 ≤ 1.2°C/W（强制风冷）
```

### 8.3 散热方式选型

| 功率等级 | 散热方式 | 热阻范围 | 适用场景 |
|---------|---------|---------|---------|
| <500W | 自然对流 | >3°C/W | 民用小型电源 |
| 500W~3kW | 强制风冷 | 0.5~3°C/W | 通用电源 |
| 3kW~15kW | 强制风冷+热管 | 0.2~1°C/W | 大功率电源 |
| 15kW~50kW | 液冷 | <0.2°C/W | 军用/工业大功率 |
| 军用高可靠 | 冷板/液冷 | <0.1°C/W | 恶劣环境 |

### 8.4 电感热设计

```
铜损：P_cu = I_rms² × R_dc × (1 + Fr-1)

其中 Fr 为交直流电阻比（趋肤/邻近效应因子）

铁损：P_core = k × f^α × B^β × Ve

铁氧体典型：α ≈ 1.3~2.0, β ≈ 2.0~2.8
```

**温升估算：**

```
ΔT = (P_cu + P_core)^0.833 × 400  (经验公式, A^0.833型磁芯)

电感温升要求：
民用：ΔT < 50°C
军用：ΔT < 30°C（长寿命设计）
```

## 9. 军用电源PFC特殊要求

### 9.1 宽输入电压范围

```
民用标准输入：AC 90~264V（全范围）
军用宽输入：  AC 85~305V（或更宽）
军用特殊输入：AC 115V/220V/380V自适应
               DC 270V（航空）或DC 28V（车载）
```

**宽输入设计挑战：**

| 挑战 | 影响 | 解决方案 |
|------|------|---------|
| 低压大电流 | I_peak增大2~3倍 | 开关管并联，电感饱和校验 |
| 高压高占空比 | D减小，效率下降 | 提高V_out（如420V）或两级方案 |
| 全范围THD | 低压段THD恶化 | 自适应控制参数，前馈补偿 |
| 启动浪涌 | 浪涌电流大 | 软启动电路，NTC+继电器旁路 |

### 9.2 高可靠性设计

| 设计要求 | 具体措施 | 标准/参考 |
|---------|---------|---------|
| 冗余设计 | 双PFC并联，N+1冗余 | GJB/Z 35 |
| 降额设计 | 器件应力降额50%~70% | GJB/Z 35 |
| 抗振动 | 电感灌封，器件加固 | GJB 150.18 |
| 三防 | 敷形涂层（清漆/硅胶/聚氨酯） | GJB 150相关 |
| 抗辐射 | 抗辐射加固器件或评估 | 特殊军用要求 |
| 宽温工作 | -55°C~+85°C（或+125°C） | GJB 150A |
| 电磁兼容 | 满足GJB151B CE102/CS101等 | GJB 151B |

### 9.3 降额设计准则

| 器件类型 | 电压降额 | 电流降额 | 温度降额 | 功率降额 |
|---------|---------|---------|---------|---------|
| SiC MOSFET | <60% V_DS | <50% I_D | T_j < 100°C | <50% P_max |
| SiC 二极管 | <60% V_R | <50% I_F | T_j < 100°C | <50% P_max |
| 电解电容 | <80% V_rated | — | T_case < 85°C | — |
| 薄膜电容 | <70% V_rated | <70% I_ripple | T < 85°C | — |
| 磁芯磁通 | <70% B_sat | — | T < 居里×70% | — |

### 9.4 军用PFC控制策略特殊考虑

```
1. 电压环带宽限制：避免输入谐波注入
   → 电压环带宽 < f_line / 10 (典型 5~10Hz)

2. 前馈补偿：改善动态响应
   → 输入电压前馈，减小输入电压变化对输出影响

3. 软启动分级：限制启动浪涌
   → 预充电继电器 + PFC软启动

4. 掉电保护：hold-up时间
   → 军用要求 ≥50ms（民用 ≥20ms）

5. 过压/过流保护：硬件保护优先
   → 比较器硬件保护，不依赖软件
```

## 附录B：PFC控制环路设计流程

```
步骤1：电流环设计（内环）
  → 采样电感电流（电阻/CT/霍尔）
  → PI补偿器，带宽 = f_sw / 6 ~ f_sw / 10
  → 目标相位裕度 > 45°

步骤2：电压环设计（外环）
  → 采样输出电压（分压网络）
  → PI补偿器，带宽 < f_line / 10
  → 前馈补偿（输入电压RMS前馈）
  → 目标相位裕度 > 60°

步骤3：乘法器设计
  → 参考电流 = K × V_in × (V_error / V_in_rms²)
  → 保证全范围输入电流跟踪输入电压

步骤4：仿真验证
  → MATLAB/Simulink 或 PSIM 仿真
  → 验证稳态PF/THD和动态响应

步骤5：实验调试
  → 网络分析仪测试环路Bode图
  → 功率分析仪测试PF/THD
  → 迭代优化补偿参数
```

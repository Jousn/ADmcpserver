## 1. 概述与拓扑选型关键考量因素

DC-DC变换器是电源系统的核心功率级，实现电压/电流变换和电气隔离。拓扑选型直接决定电源的效率、功率密度、成本、可靠性和EMC特性。本知识库覆盖中高功率（100W~100kW+）隔离式DC-DC变换器的主流拓扑，包括移相全桥（PSFB）、LLC谐振变换器、双有源桥（DAB），以及辅助电源用正激、反激、推挽拓扑。

### 1.1 拓扑选型关键考量因素

| 考量因素 | 权重 | 说明与量化判据 |
|----------|------|----------------|
| 功率等级 | 高 | 直接决定可用拓扑范围，>1kW通常需隔离全桥/半桥类拓扑 |
| 隔离要求 | 高 | 安全隔离（基础/加强绝缘）、噪声隔离、电压比变换 |
| 输入/输出电压比 | 高 | 影响变压器匝比、占空比范围；比值过大需多级或特殊拓扑 |
| 效率目标 | 高 | 软开关（ZVS/ZCS）可提升2%~5%，>95%需谐振或移相拓扑 |
| 成本约束 | 中 | 器件数量、磁元件复杂度、控制IC成本 |
| 功率密度 | 中 | 开关频率越高体积越小，但受热和EMI制约 |
| 双向能力 | 中 | 储能/V2G场景需要双向功率流（如DAB） |
| 输出电压路数 | 低 | 单路选隔离拓扑，多路选反激/正激 |
| 环境条件 | 中 | 军用宽温（-55~+125℃）、抗辐射、振动 |
| 可靠性/冗余 | 中 | 军用需冗余并联、降额设计、长寿命 |

### 1.2 拓扑选型快速决策流程

```
Step 1: 确定功率等级
  <100W → 反激（Flyback）
  50W~500W → 正激（Forward）/ 推挽（Push-Pull）
  100W~5kW → LLC谐振变换器（半桥/全桥）
  500W~10kW → 移相全桥（PSFB）
  1kW~100kW+ → 移相全桥 / 双有源桥（DAB）
Step 2: 确定是否需要双向能量流
  单向 → PSFB / LLC / Forward / Flyback
  双向 → DAB（储能、充电桩、V2G）
Step 3: 确定输入电压与输出电压关系
  低压大电流输入（12V/24V/48V）→ 推挽（Push-Pull）
  高压输入（200V~800V）→ PSFB / LLC / DAB
  输出低压大电流（<12V, >10A）→ 需配合同步整流
Step 4: 确定效率与软开关要求
  η ≥ 92% → 硬开关正激/反激（低成本）
  η ≥ 95% → PSFB（ZVS）或 LLC（ZVS+ZCS）
  η ≥ 97% → LLC + 同步整流 + SiC/GaN器件
```

## 3. 移相全桥（PSFB）详细设计

移相全桥（Phase-Shift Full Bridge, PSFB）通过移相控制实现零电压开通（ZVS），是500W~10kW功率等级的主力拓扑，广泛应用于军用和工业电源。

### 3.1 ZVS原理

PSFB通过超前臂（Leading Leg）和滞后臂（Lagging Leg）的移相控制实现ZVS。每个开关周期包含12个工作阶段，核心在于利用谐振电感能量抽走即将开通开关管的输出电容电荷。

**超前臂（超前相）ZVS特性：**
- 超前臂换流时，输出滤波电感 $L_f$ 与变压器漏感 $L_{lk}$ 串联，储能充足
- 负载电流通过 $L_f$ 反映到初级，提供换流能量
- ZVS范围宽，从满载到约20%~30%负载均能实现ZVS

**滞后臂（滞后相）ZVS特性：**
- 恒流阶段（次级续流）换流，输出滤波电感被短路（变压器初级被钳位）
- 仅有谐振电感 $L_r$（含漏感）能量可用
- ZVS范围受限，轻载时无法实现ZVS，产生容性开通损耗

**滞后臂ZVS范围受限的原因：** 滞后臂换流发生在变压器初级被次级整流管钳位的恒流阶段，此时输出滤波电感 $L_f$ 被隔离，仅谐振电感 $L_r$ 参与换流。轻载时初级电流 $I_p$ 小，谐振电感储能不足以抽尽开关管输出电容电荷，导致容性开通损耗。

```
滞后臂ZVS条件：
0.5 * L_r * I_p^2 >= C_oss_eq * Vin^2
  L_r = 谐振电感（含漏感）, I_p = 换流时刻初级电流
  C_oss_eq = 2*C_oss（两管输出电容等效值）, Vin = 输入电压
→ 轻载时 I_p 小，无法满足ZVS条件
```

**改善滞后臂ZVS的方法：** 增加谐振电感 $L_r$（但增加占空比丢失和环流损耗）；加入辅助谐振网络（饱和电感、辅助电容）；采用电流型驱动或倍流同步整流。

### 3.2 变压器设计要点

**匝比计算：**

```
n = Np / Ns = (Vin_min * D_max) / (Vout + Vf_sr)
  D_max = 最大有效占空比（考虑占空比丢失，典型0.7~0.8）
  Vf_sr = 同步整流管压降（约 I*Rds_on）

占空比丢失：D_loss = (2 * L_r * I_o) / (n * Vin * Ts)
  L_r = 谐振电感, I_o = 输出电流, n = 匝比, Ts = 开关周期
有效占空比：D_eff = D - D_loss
设计要求：D_max - D_loss > D_nominal（保证满载调节裕量）
```

**磁复位：** PSFB变压器双向对称激磁，理论上自动磁复位，无需额外复位电路。但需注意直流偏磁问题（由不对称驱动或器件参数不对称引起），通常在变压器初级串联隔直电容（1~4μF薄膜电容）。

### 3.3 同步整流配合

PSFB次级通常采用全波整流（中心抽头）或全桥整流配合同步整流MOSFET。

| 整流方式 | 适用 | 优势 | 劣势 |
|----------|------|------|------|
| 中心抽头全波SR | 低压大电流（<48V） | 少一个MOSFET | 变压器利用率低、铜损大 |
| 全桥整流SR | 高压输出（>48V） | 变压器利用率高 | 多2个MOSFET、驱动复杂 |
| 倍流整流 | 超低压大电流（<12V） | 滤波电感小、SR电流应力低 | 需2个电感、结构复杂 |

同步整流驱动时序需精确控制死区时间（典型50~150ns），防止初级换流期间次级交叉导通。

### 3.4 关键参数计算公式

```
1. 谐振电感 L_r >= (2 * C_oss_eq * Vin^2) / I_p_min^2
   I_p_min = 滞后臂实现ZVS的最小初级电流

2. 死区时间 t_dead >= (2 * C_oss * Vin) / I_p
   典型值：100~300ns（需仿真优化）

3. 占空比丢失 D_loss = (4 * L_r * I_o * f_s) / (n * Vin)
   典型值：5%~15%（L_r越大丢失越多）

4. 有效输出电压 Vout = (n * Vin * D_eff) / 2 （全桥结构）
   D_eff = D - D_loss
```

**设计示例（1kW PSFB，Vin=400V，Vout=28V，Iout=35A，fs=100kHz）：**

```
n = 400 * 0.75 / (28 + 0.1) ≈ 10.7 → 取 Np=10, Ns=1（实际需调整）
L_r ≈ 15~25μH（含变压器漏感8~12μH，外加谐振电感）
t_dead ≈ 150ns, D_loss ≈ 8%~12%, C_oss_eq ≈ 400pF（Si MOSFET）
推荐开关管：IPW60R099CP（600V/99mΩ）或 SCT3060AL（SiC, 650V）
推荐控制IC：UCC28950（含同步整流自适应驱动）
```

### 3.5 典型应用场景

- 通信电源整流模块（48V/50A，2kW~3kW）
- 军用加固电源（28V/100A，3kW~5kW）
- 工业直流电源（24V~600V，1kW~10kW）
- 充电桩后级DC-DC（400V→12V/24V，3kW~7kW）

## 4. LLC谐振变换器详细设计

LLC谐振变换器利用谐振网络实现原边MOSFET的ZVS和副边整流二极管的ZCS，在全负载范围内实现高效率（>95%），是100W~10kW功率等级效率最优的隔离拓扑。

### 4.1 工作原理（三个工作区间）

LLC变换器通过调节开关频率实现输出调节，工作点相对于谐振频率 $f_r$ 分为三个区间：

```
谐振频率：f_r = 1 / (2π * sqrt(L_r * C_r))
特征阻抗：Z_r = sqrt(L_r / C_r)
品质因数：Q = (R_ac * sqrt(C_r / L_r)) / n^2
  R_ac = (8/π²) * (n*Vout)² / P_out （折算到初级的等效负载）
```

| 工作区间 | 频率范围 | 特性 | ZVS/ZCS状态 |
|----------|----------|------|-------------|
| 区间I（过谐振） | f_s > f_r | 降压模式，类似串联谐振 | 原边ZVS，副边近似ZCS |
| 区间II（谐振点） | f_s = f_r | 谐振点工作，增益=1 | 原边ZVS，副边ZCS（最优） |
| 区间III（欠谐振） | f_s < f_r | 升压模式，类似并联谐振 | 原边ZVS，副边ZCS |

**区间II（f_s = f_r）是最优点：** 增益恰好为1，环路增益最大，效率最高，输出电压对负载变化不敏感。设计时通常让额定工作点在谐振频率附近。

### 4.2 谐振参数计算

```
1. 变压器匝比 n：
   半桥：n = Vin_nom / (2 * Vout)   全桥：n = Vin_nom / Vout

2. 谐振频率 f_r（典型100kHz~500kHz）与谐振电容 C_r：
   C_r = 1 / (2π * f_r * Z_r),  Z_r 典型选择 30~80Ω

3. 谐振电感 L_r = 1 / ((2π * f_r)^2 * C_r)

4. 励磁电感 L_m 与电感比 Ln = L_m / L_r （典型值 3~8）：
   Ln越大→L_m越大→励磁电流越小→效率越高，但电压增益范围变窄
   Ln越小→增益范围越宽，但励磁电流增大、损耗增加

5. 归一化频率 fn = f_s / f_r

6. 最大/最小增益（半桥）：
   M_max = n * Vout_max / (Vin_min * 0.5)
   M_min = n * Vout_min / (Vin_max * 0.5)
   要求 M_min < 1 < M_max（确保谐振点在调节范围内）
```

### 4.3 增益曲线分析

```
增益公式：
M(fn, Q) = 1 / sqrt( (1 + 1/Ln - 1/(Ln*fn^2))^2 + Q^2 * (fn - 1/fn)^2 )

特征：
  Q越小（轻载）→ 增益曲线越陡，调频范围大
  Q越大（重载）→ 增益曲线越平，调频范围小
  谐振点 fn=1 处所有Q曲线交于一点（M=1）
  最高增益受最大Q限制（满载最低频率处）
```

设计准则：最大增益点（满载、最低输入电压、最低频率）需留10%~15%裕量；最低频率限制 $f_{min} \geq 0.5 \times f_r$（防止工作进入容性区导致破坏性硬开关）；最高频率限制 $f_{max} \leq 2 \times f_r$（超出后增益几乎不变，失去调节能力）。

### 4.4 变频控制策略

| 控制策略 | 原理 | 优缺点 |
|----------|------|--------|
| 变频控制（PFM） | 调节频率改变增益 | 最常用，简单；轻载时频率过高，需Burst模式 |
| 突发模式（Burst） | 轻载时间歇开关 | 降低轻载损耗；输出纹波增大 |
| PWM+PFM混合 | 大范围调压时引入占空比调节 | 扩展调压范围；控制复杂 |

典型控制IC：半桥LLC用UCC256301、NCP1399、L6699；全桥LLC用UCC25600 + 数字控制（DSP/CPLD）。

### 4.5 半桥LLC vs 全桥LLC选型

| 对比项 | 半桥LLC | 全桥LLC |
|--------|---------|---------|
| 适用功率 | 100W~3kW | 1kW~10kW+ |
| 初级开关管数量 | 2 | 4 |
| 开关管电压应力 | Vin | Vin |
| 变压器初级电压 | Vin/2 | Vin（方波） |
| 同等输出功率初级电流 | 全桥的2倍 | 较小 |
| 驱动复杂度 | 低 | 高（需4路隔离驱动） |
| 成本 | 低 | 高 |
| 效率 | 高（小功率更优） | 高（大功率更优） |

选型建议：功率<2kW选半桥LLC，>3kW选全桥LLC，2~3kW视具体效率/成本权衡。

### 4.6 典型应用场景

- 服务器电源（12V/100A+，1kW~3kW）— 半桥LLC + 同步整流
- 通信电源（48V/50A，2kW~3kW）— 全桥LLC + 同步整流
- 车载OBC（400V→12V，3.3kW~6.6kW）— 全桥LLC
- LED驱动电源（100W~500W）— 半桥LLC
- 军用模块电源（100W~1kW）— 半桥LLC

## 5. 双有源桥（DAB）设计要点

双有源桥（Dual Active Bridge, DAB）是支持双向功率流的隔离DC-DC拓扑，广泛用于储能系统、V2G充电和双向能量转换场景。

### 5.1 双向功率流原理

DAB由两个全桥（初级H桥 + 次级H桥）通过高频变压器连接。通过控制两个桥之间方波电压的移相角 $\phi$ 实现能量双向传输。

```
传输功率公式（单移相控制 SPS）：
P = (n * Vin * Vout * φ * (π - |φ|)) / (2 * π^2 * f_s * L_s)
  n = 变压器匝比, Vin/Vout = 初/次级电压
  φ = 移相角（弧度），范围 [-π/2, +π/2]
  f_s = 开关频率, L_s = 变压器漏感 + 外加电感（谐振电感）

功率方向：φ > 0 正向（初级→次级），φ < 0 反向（次级→初级），φ = 0 零功率
```

DAB的核心优势：天然双向功率流，无需额外开关管；全范围ZVS（在匹配电压比下）；电气隔离；适合高功率（kW~MW级）。

### 5.2 单移相控制（SPS）与扩展移相控制

| 控制方式 | 原理 | ZVS范围 | 电流应力 | 复杂度 |
|----------|------|---------|----------|--------|
| 单移相（SPS） | 仅调节内外桥移相角φ | 匹配电压比时全范围ZVS；不匹配时ZVS受限 | 高（环流大） | 低 |
| 扩展移相（EPS） | 内移相+外移相双自由度 | ZVS范围扩大 | 中 | 中 |
| 双移相（DPS） | 两个桥各自独立移相 | 较宽ZVS范围 | 中 | 中高 |
| 三重移相（TPS） | 三个移相自由度 | 最优ZVS范围 | 最低 | 高（需数字控制） |

**SPS局限性：** 当 $n \cdot Vout \neq Vin$（电压不匹配）时，回流功率增大，效率下降，ZVS范围缩小。典型匹配比 $d = n \cdot Vout / Vin$，d=1时效率最高。**扩展移相（EPS）优势：** 通过引入内移相角控制初级方波脉宽，在电压不匹配工况下也能保持高效率，适合宽输入电压范围应用。

### 5.3 ZVS范围分析

```
SPS控制下ZVS条件（正向功率流）：
初级桥：I_p(t0) < 0（换流时电流需足以放电Coss）
次级桥：I_s(t1) > 0

匹配工况（d=1）→ 全负载范围可实现ZVS
不匹配工况（d≠1，如d=0.7或1.3）→ 轻载区域ZVS丢失，需引入EPS/TPS或辅助谐振网络

改善ZVS方法：扩展移相控制（EPS/TPS）、增加谐振电感量、谐振参数优化（变DAB为CLLC）、SiC器件降低Coss影响
```

### 5.4 典型应用场景

- 储能系统PCS（电池↔直流母线，双向，10kW~100kW+）
- V2G/V2H充电桩（电动汽车↔电网，双向，3kW~22kW）
- 直流微电网互联（不同电压等级直流母线，双向隔离）
- 航空电源（270V↔28V，双向，5kW~50kW）

**设计示例（10kW DAB，Vin=750V，Vout=400V，fs=50kHz）：**

```
n = 750 / 400 = 1.875 → 取 n = 1.85
L_s = (n * Vin * Vout) / (8 * fs * P_max) ≈ 18~25μH
推荐开关管：SiC MOSFET（SCT3080AL, 650V/80mΩ 或 C3M0030090K, 900V/30mΩ）
控制方式：TPS三重移相（需DSP/TMS320F28377D）
```

## 6. 正激变换器（Forward）设计

正激变换器是50W~500W功率等级常用的隔离拓扑，结构简单、可靠性高，广泛用于辅助电源和中小功率工业电源。

### 6.1 单端正激 vs 双管正激

| 对比项 | 单端正激 | 双管正激 |
|--------|----------|----------|
| 开关管数量 | 1 | 2 |
| 开关管电压应力 | 2*Vin（含反射电压+漏感尖峰） | Vin（钳位到Vin） |
| 最大占空比 | <50%（受磁复位限制） | <50%（受磁复位限制） |
| 磁复位方式 | 需第三绕组/RCD/有源钳位 | 通过两管反并二极管自动复位 |
| 适用功率 | 50W~200W | 100W~500W |
| 成本 | 低 | 中 |
| 可靠性 | 中（开关管应力高） | 高（电压应力低） |

### 6.2 磁复位方案

| 复位方案 | 原理 | 优点 | 缺点 |
|----------|------|------|------|
| 第三绕组复位 | 复位绕组将磁能回馈输入 | 损耗低、效率高 | 变压器复杂、占空比受限<0.5 |
| RCD钳位 | 电阻电容二极管吸收磁能 | 简单、成本低 | 复位能量消耗在电阻上，效率低 |
| 有源钳位（Active Clamp） | 辅助开关管+电容钳位 | ZVS可实现、占空比可>0.5 | 需额外开关管和驱动、控制复杂 |

**有源钳位正激（ACF）优势：** 主开关和辅助开关均可实现ZVS，效率可达92%~95%，占空比可超过50%，适合宽输入范围，是近年高效率辅助电源的主流方案。

### 6.3 变压器设计要点

```
单端正激变压器设计：
1. 匝比：n = Np / Ns = (Vin_min * D_max) / Vout
2. 初级匝数：Np = (Vin * D * Ts) / (ΔB * Ae)
   ΔB = 磁通密度摆幅（典型0.1~0.2T，单端单向激磁）, Ae = 磁芯有效截面积
3. 磁芯选择（AP法）：AP = Ae * Aw = (P_out * 10^8) / (2 * f * J * Ku * Bm * η * Kt)
4. 注意：单端正激为单向激磁，ΔB仅为双端的一半，磁芯利用率低
   → 推荐使用有源钳位提升利用率，或选择双管正激
```

### 6.4 典型应用场景

- 军用辅助电源（28V→5V/12V，50W~200W）— 双管正激
- 工业控制电源（24V/48V输出，100W~500W）— 双管正激/有源钳位
- 车载DC-DC（12V/24V→5V，50W~200W）— 有源钳位正激（ACF）
- LED驱动辅助电源（<100W）— 单端正激

## 7. 反激变换器（Flyback）设计

反激变换器是100W以下辅助电源最常用的拓扑，结构最简单、成本最低、支持多路隔离输出。

### 7.1 CCM/DCM/CRM模式

| 工作模式 | 电感电流状态 | 适用功率 | 特点 |
|----------|-------------|----------|------|
| CCM（连续） | 不归零 | 50W~100W | 峰值电流小、输出纹波小；右半平面零点（RHPZ）需斜率补偿 |
| DCM（断续） | 归零 | <50W | 无RHPZ、控制简单；峰值电流大、纹波大 |
| CRM（临界） | 恰好归零 | 20W~75W | 准谐振（QR）、效率最高；变频工作 |

**选型建议：** 追求效率选CRM（QR反激），追求小纹波选CCM，追求简单和低成本选DCM。

### 7.2 变压器设计（储能电感特性）

反激变压器本质是耦合电感，初级储能、次级释放，设计方法与正激不同：

```
1. 初级电感量：
   CCM：L_p = (Vin^2 * D^2 * Ts) / (2 * P_out * (1 - D))
   DCM：L_p = (Vin^2 * D_max^2 * Ts) / (2 * P_out)
2. 匝比：n = Np / Ns = (Vin * D_max) / ((Vout + Vf) * (1 - D_max))
3. 峰值电流（DCM）：I_pk = (2 * P_out) / (Vin * D * η)
4. 磁芯选择（反激储能在气隙中，需开气隙）：
   L_g = (μ0 * Np^2 * Ae) / L_p（气隙会引起边缘磁场损耗和EMI）
5. 磁通密度摆幅：ΔB = (L_p * I_pk) / (Np * Ae)，建议ΔB < 0.25T（防止饱和）
```

### 7.3 RCD钳位设计

反激变换器初级开关管关断时，漏感能量产生电压尖峰，需RCD钳位保护：

```
钳位电压：V_clamp = 1.5 ~ 2.5 * (n * (Vout + Vf))（反射电压的1.5~2.5倍）
钳位电阻：R_clamp = (2 * V_clamp * (V_clamp - n * Vout)) / (L_lk * I_pk^2 * f_s)
钳位电容：C_clamp = V_clamp / (ΔV_clamp * R_clamp * f_s)
  ΔV_clamp = 钳位电压纹波（典型取 V_clamp 的5%~10%）
钳位二极管：选超快恢复二极管（如UF4007、MUR160）
损耗：P_clamp = 0.5 * L_lk * I_pk^2 * f_s（损耗在R上，是反激效率受限主要原因之一）
```

### 7.4 典型应用场景

- 开关电源辅助电源（Vcc供电，<10W）— DCM反激
- 机顶盒/适配器电源（5V~24V，5W~75W）— QR反激（CRM）
- 多路输出工业辅助电源（5V/±15V/24V，20W~100W）— CCM反激
- 军用模块电源辅助（<50W）— 反激（注意宽温变压器设计）

## 8. 推挽（Push-Pull）拓扑

推挽变换器适合低压大电流输入（12V/24V/48V电池），两个开关管交替工作，变压器双向对称激磁。

### 8.1 工作原理与磁偏磁问题

推挽变换器两个开关管交替导通（各占约45%占空比），变压器双向对称激磁，磁芯利用率高。

**磁偏磁问题：** 两开关管导通时间不对称、饱和压降不一致 → 变压器磁通逐周期偏移 → 偏磁导致磁芯饱和，初级电流激增，开关管损坏。

**磁偏磁解决方案：**

| 方案 | 原理 | 效果 |
|------|------|------|
| 峰值电流模式控制 | 逐周期限流，自动平衡两半周期 | 最有效 |
| 串联隔直电容 | 阻断直流分量 | 有效，但增加成本 |
| 磁芯开小气隙 | 增加抗饱和裕量 | 有效，但降低电感量 |
| 精确匹配驱动 | 对称驱动脉冲 | 缓解，非根治 |

```
推挽变压器匝比：n = Np / Ns = (Vin_min * D_max) / Vout
实际电压转换比：Vout = (2 * Vin * D) / n （D为单管占空比，<0.5）
开关管电压应力：V_ds = 2 * Vin（关断时承受2倍输入电压+漏感尖峰）
→ 限制了推挽在高压输入场合的应用
```

### 8.2 适合低压大电流输入

推挽拓扑优势在低压输入：初级开关管共地驱动（无需隔离驱动，驱动简单）；输入电流由两管分担（导通损耗降低）；变压器双向激磁（利用率高）；适合12V/24V/48V电池输入。

劣势：开关管承受2倍Vin电压应力（不适合高压输入）；磁偏磁问题需峰值电流模式控制。

### 8.3 典型应用场景

- 车载DC-DC（12V/24V→280V，200W~1000W）— 推挽 + 倍压整流
- 逆变器前端DC-DC（12V/48V→380V，500W~2000W）— 推挽升压
- 电池均衡/备份电源（48V→12V/24V，100W~500W）— 推挽
- 卫星电源（28V母线→各路输出，50W~300W）— 推挽（高可靠）

## 10. 军用电源拓扑选型特殊考虑

### 10.1 可靠性设计

| 可靠性措施 | 实施方法 | 对拓扑选型影响 |
|-----------|----------|---------------|
| 冗余并联 | N+1模块并联，均流控制 | 选可并联拓扑（PSFB/LLC优先） |
| 降额设计 | 开关管电压降额50%、电流降额60% | 影响器件选型，间接影响拓扑选择 |
| 热备份 | 冗余模块热备份运行 | 需低待机损耗拓扑 |
| 故障隔离 | 模块故障自动切除 | 需ORing二极管/MOSFET |
| 长寿命 | 电解电容减额或换固态/薄膜电容 | 影响谐振电容选型（LLC/PSFB） |

### 10.2 宽温设计

| 温度范围 | 拓扑选型考量 |
|----------|-------------|
| -55℃ ~ +85℃（地面装备） | 关注低温启动（MOSFET Rds_on变化小）、高温降额 |
| -55℃ ~ +125℃（航空/导弹） | 需高温SiC器件、避免电解电容、选陶瓷电容拓扑 |
| -40℃ ~ +85℃（车载加固） | 常规设计，关注低温变压器磁芯特性 |

**宽温设计要点：** 低温（-55℃）磁芯μ值下降、电感量减小 → 需增大电感裕量10%~20%；高温（+125℃）MOSFET Rds_on增大1.5~2倍 → 选SiC器件降低温度敏感性；全温范围避免使用电解电容（寿命受限），优先选陶瓷/薄膜电容；变压器磁芯选宽温材料（如TP4A/MnZn宽温系列，-55~+155℃）。

### 10.3 抗辐射考虑

| 抗辐射措施 | 适用场景 | 拓扑影响 |
|-----------|----------|---------|
| 抗辐射器件选型 | 航天/高空 | 选辐射加固MOSFET/IC，影响控制方案 |
| 避免单粒子翻转(SEU) | 航天 | 选分立控制而非复杂DSP，倾向简单拓扑 |
| 抗总剂量(TID) | 航天/核电 | 选SiC JFET（天然抗辐射） |
| 单粒子烧毁(SEB)防护 | 航天 | 选低压拓扑（推挽），避免高压全桥 |

**军用/航天拓扑推荐：** 低辐射环境（地面/车载）用常规PSFB/LLC + 工业级器件；高辐射环境（航天）用推挽/正激（简单可靠）+ 抗辐射加固器件；极高可靠需求用正激/推挽（拓扑简单、故障模式少）优于复杂谐振拓扑。

### 10.4 军用标准合规

| 标准 | 要求 | 拓扑相关 |
|------|------|---------|
| GJB 181B | 飞机供电特性 | 宽输入范围，需PSFB/LLC |
| GJB 151B | 电磁兼容性 | 软开关拓扑优先（LLC/PSFB EMI更优） |
| GJB 150A | 环境条件 | 宽温、振动、冲击 → 高可靠性拓扑 |
| MIL-STD-461 | EMC（美军标） | 软开关 + 良好PCB布局 |

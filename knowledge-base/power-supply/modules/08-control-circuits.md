# 控制电路设计知识库

> 适用范围：军用及民用中高功率电源（100W~50kW）
> 目标受众：AI设计辅助Skill，用于控制电路设计咨询与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

控制电路是电源系统的"大脑"，决定了电源的动态响应、稳压精度、稳定性和保护功能。在中高功率电源中，控制电路设计直接影响系统的可靠性、效率和EMC性能。军用电源更要求控制电路具备抗干扰能力、宽温工作能力和冗余设计。

### 2.3 选型决策准则

- **功率等级 < 500W**：模拟控制芯片（UC3846/UCC25600），成本低、可靠性高
- **功率等级 500W~5kW**：模拟或数字控制均可，数字控制利于参数优化
- **功率等级 > 5kW**：优先数字控制（C2000/STM32G4），支持复杂算法和均流
- **军用电源**：优先数字控制，支持在线诊断、冗余切换和通信

## 3. 控制模式对比

### 3.1 控制模式分类

| 控制模式 | 原理 | 优点 | 缺点 | 适用场景 |
|---------|------|------|------|---------|
| 电压模式控制（VMC） | 仅采样输出电压 | 单环结构简单，噪声抗扰度好 | 响应慢，需斜坡补偿 | LLC谐振、低噪声场合 |
|峰值电流模式控制（PCMC） | 采样电感电流峰值 + 输出电压 | 响应快，自动限流，易均流 | 需斜坡补偿，亚谐振荡 | Buck/Boost/正激/反激 |
| 平均电流模式控制（ACMC） | 采样电感电流平均值 | 无需斜坡补偿，噪声低 | 双环设计复杂 | PFC、电池充电 |
| 滞环控制（Hysteresis） | 上下限阈值比较 | 无需补偿，瞬态极快 | 开关频率变化，EMI难控 | 低功率VRM、实验室电源 |
| V2控制 | 采样输出电压 + 电压斜率 | 超快瞬态响应 | 设计复杂，对ESR敏感 | VRM、POL变换器 |

### 3.2 峰值电流模式斜坡补偿

峰值电流模式在占空比 D > 0.5 时会出现亚谐振荡，需引入斜坡补偿：

```
补偿斜率 Se 需满足：
Se >= (D - 0.5) / 0.5 * Sn

其中：
Sn = (Vin - Vout) * Rs / L    （电感电流上升斜率）
Se = 补偿斜坡斜率（由控制芯片内部产生或外部注入）
Rs = 电流采样电阻
L = 主电感量
```

实际设计中通常取 `Se = 0.75 * Sn` 以保证全范围稳定。

## 4. 补偿网络设计

### 4.1 补偿器类型

| 类型 | 零点/极点数 | 适用功率级 | 典型应用 |
|------|-----------|-----------|---------|
| Type I | 1极点 | 一阶系统（电流模式Buck） | 简单稳压，带宽要求低 |
| Type II | 1零点 + 1极点 | 一阶系统（电流模式） | 大多数电流模式电源 |
| Type III | 2零点 + 2极点 | 二阶系统（电压模式LC） | 电压模式控制的Buck/Boost |

### 4.2 Type II 补偿器设计（电流模式控制）

```
Type II 传递函数：
Gc(s) = K * (1 + s/wz) / (s * (1 + s/wp))

零点频率：wz = 1 / (Rz * Cz)
极点频率：wp = 1 / (Rz * Cp)
低频增益：K = 1 / (Ri * Cz)

设计步骤：
1. 确定期望穿越频率 fc（通常取开关频率的 1/5 ~ 1/10）
2. 在 fc 处测量功率级相移 φp
3. 计算所需补偿相位：φc = 180° - φp + PM（PM为期望相位裕度）
4. 由 φc 确定零极点频率比：
   fz = fc / sqrt(K_comp)
   fp = fc * sqrt(K_comp)
   其中 K_comp = tan(φc/2 + 45°)
```

### 4.3 Type III 补偿器设计（电压模式控制）

```
Type III 传递函数：
Gc(s) = K * (1 + s/wz1)(1 + s/wz2) / (s * (1 + s/wp1)(1 + s/wp2))

零点配置（提升相位）：
fz1 = 1 / (2π * R2 * C1)       置于LC谐振频率的 50%~100%
fz2 = 1 / (2π * (R1+R3) * C3)   置于LC谐振频率附近

极点配置（衰减高频噪声）：
fp1 = 1 / (2π * R2 * (C1*C2)/(C1+C2)) ≈ 1/(2π*R2*C2)   置于ESR零点频率
fp2 = 1 / (2π * R3 * C3)       置于开关频率的 1/2
```

## 5. 反馈回路稳定性判据

### 5.1 稳定性指标要求

| 指标 | 一般要求 | 军用要求 | 说明 |
|------|---------|---------|------|
| 相位裕度（PM） | > 45° | > 60° | 穿越频率处相角距-180°的余量 |
| 增益裕度（GM） | > 6dB | > 10dB | 相位达-180°时增益距0dB的余量 |
| 穿越频率（fc） | fsw/5 ~ fsw/10 | fsw/10 | 响应速度与噪声抑制的平衡 |
| 增益曲线斜率 | -20dB/dec | -20dB/dec | 穿越频率处应为单极点斜率 |

### 5.2 环路测试方法

```
1. 注入小信号扰动（通过变压器串联注入电阻，典型 5~20Ω）
2. 扫频范围：10Hz ~ fs/2（奈奎斯特频率）
3. 测量注入点两端信号比，计算闭环增益与相位
4. 验证全负载范围（10%、50%、100%负载）及全输入电压范围
5. 注意：注入电阻应位于反馈路径中，且上下两端阻抗比 > 10:1
```

## 6. 数字控制优势

| 特性 | 模拟控制 | 数字控制 |
|------|---------|---------|
| 参数调整 | 固定（由RC决定） | 在线可编程 |
| 自适应控制 | 不支持 | 支持（根据负载/输入自适应PI参数） |
| 通信接口 | 无/有限 | PMBus/CAN/SPI/UART |
| 故障诊断 | 简单硬件保护 | 全状态监测、录波、预测维护 |
| 非线性控制 | 不支持 | 支持滑模、模糊、预测控制 |
| 均流精度 | ±5%~10% | ±1%~2% |
| 知识复用 | 需重新设计PCB | 固件升级即可 |

### 6.1 数字PI控制器设计

```
数字PI控制器（离散域）：
u(k) = u(k-1) + Kp * (e(k) - e(k-1)) + Ki * Ts * e(k)

其中：
Kp = 比例增益
Ki = 积分增益
Ts = 采样周期
e(k) = 第k拍误差（参考值 - 反馈值）

离散化（双线性变换）：
Kp_d = Kp
Ki_d = Ki * Ts / 2
```

## 7. 均流控制方案

### 7.1 均流方案对比

| 方案 | 原理 | 均流精度 | 冗余能力 | 复杂度 | 适用场景 |
|------|------|---------|---------|--------|---------|
| 主从均流 | 指定主模块，从模块跟随 | ±2% | 差（主模块故障则全停） | 低 | 少量模块并联 |
| 自动均流（民主均流） | 自动选举主模块 | ±3% | 好 | 中 | N+1冗余系统 |
| 外部均流总线 | 专用均流母线 | ±1%~2% | 好 | 中高 | 大功率并联系统 |
| 下垂均流（Droop） | 利用输出阻抗差异 | ±5%~10% | 优（无通信依赖） | 最低 | 简单并联、分布式 |
| 数字均流 | 通过总线通信调参 | ±1% | 优 | 高 | 智能电源系统 |

### 7.2 均流总线设计要点

- 均流总线电压范围通常 0~5V 或 0~10V，对应 0~100% 负载电流
- 总线需加滤波电容（0.1μF）抑制噪声
- 军用系统需对总线进行瞬态抑制（TVS + 滤波）
- 单点故障不应导致总线短路（使用二极管隔离）

## 8. 软启动设计

### 8.1 软启动原理与参数

```
软启动时间计算：
Tss = Css * Vref / Iss

其中：
Css = 软启动电容
Vref = 基准电压（典型 2.5V 或 5V）
Iss = 软启动充电电流（典型 5~20μA）

设计准则：
- 软启动期间输出电压单调上升，无过冲
- 软启动时间应大于输入滤波电容充电时间
- 典型值：50ms ~ 500ms（大功率电源取大值）
- 军用电源需考虑极端低温下电容容值下降的影响
```

### 8.2 软启动注意事项

- 限流点在软启动期间应逐步放开，避免开机浪涌
- 对于LLC谐振变换器，软启动应从高频率开始逐步降低频率
- 并联系统各模块软启动时间需一致，偏差 < 5%

## 9. 空载/轻载管理

### 9.1 轻载问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 输出过压 | 脉冲跳跃、Burst模式 | 假负载、数字脉冲跳周期控制 |
| 效率下降 | 驱动损耗占比增大 | Burst模式、关断不必要驱动 |
| 变压器饱和 | 不连续电流模式偏磁 | 直流恢复电路、峰值电流限制 |
| 可闻噪声 | Burst模式频率落入音频 | 控制Burst频率 > 20kHz |

### 9.2 轻载管理策略

- **Burst模式**：低于阈值负载时进入打嗝模式，阈值通常设 5%~10% 额定负载
- **降频运行**：轻载降低开关频率，保持连续电流模式（CCM）
- **二极管模拟**：同步整流在轻载时切换为二极管整流，防止电流倒灌
- **假负载**：军用电源常设固定假负载（0.5%~1%额定功率）确保最小稳定性

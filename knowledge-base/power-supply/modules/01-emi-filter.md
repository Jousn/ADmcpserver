# EMI滤波器设计知识库

> 适用范围：军用及民用中高功率电源（100W~50kW）
> 目标受众：AI设计辅助Skill，用于EMI滤波器设计咨询与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

EMI（电磁干扰）滤波器是电源系统中抑制传导干扰和辐射干扰的第一道防线。在军用电源中，需满足GJB151B系列标准；在民用电源中，需满足CISPR 22 / EN 55032 / FCC Part 15等标准。EMI滤波器的设计直接影响电源能否通过EMC认证，同时也关系到系统的效率、体积和成本。

### 1.1 EMI噪声分类

| 噪声类型 | 传播方式 | 频率范围 | 抑制方法 |
|---------|---------|---------|---------|
| 共模噪声（CM） | 相线/中线→地线 | 150kHz~30MHz（传导），30MHz~1GHz（辐射） | 共模电感 + Y电容 |
| 差模噪声（DM） | 相线→中线 | 150kHz~10MHz | 差模电感 + X电容 |
| 辐射噪声 | 空间电磁场 | 30MHz~1GHz | 屏蔽、PCB布局、磁性元件设计 |

## 2. 共模/差模噪声分析

### 2.1 共模噪声产生机理

共模噪声主要由开关管的高频开关动作（dv/dt）通过寄生电容耦合到地线产生。主要噪声源包括：
- MOSFET/IGBT的漏极对散热器（地）的寄生电容 $C_{oss}$
- 变压器初次级间寄生电容 $C_{ps}$
- PCB走线对地的寄生电容

共模噪声电流路径：

```
开关管 → 寄生电容 → 地 → LISN → 相线/中线 → 滤波器 → 开关管
```

### 2.2 差模噪声产生机理

差模噪声主要由开关电流的脉动分量和整流后的纹波电流产生。主要噪声源包括：
- 输入整流后的脉动电流
- DC-DC级的输入纹波电流
- 开关管开通/关断时的di/dt引起的电压尖峰

### 2.3 噪声分离方法

在EMI调试中，需要分离共模和差模噪声以针对性设计滤波器：

```
V_cm = (V_L + V_N) / 2
V_dm = (V_L - V_N) / 2
```

其中 $V_L$ 为相线LISN测量电压，$V_N$ 为中线LISN测量电压。

## 3. EMI滤波器拓扑结构

### 3.1 常见拓扑对比

| 拓扑类型 | 结构特点 | 适用场景 | 优缺点 |
|---------|---------|---------|--------|
| π型（C-LC） | 两端电容中间电感 | 通用场景，源阻抗和负载阻抗均较低 | 插入损耗高，但可能产生谐振尖峰 |
| T型（L-C-L） | 两端电感中间电容 | 源阻抗和负载阻抗均较高 | 高频抑制好，电感体积大 |
| L型（C-L或L-C） | 单电感单电容 | 源阻抗或负载阻抗差异大的场景 | 结构简单，插入损耗有限 |
| 多级π型 | 多个π级联 | 高衰减需求，军品/高可靠场合 | 衰减大，体积成本高 |

### 3.2 典型AC输入EMI滤波器结构

```
L ──┬── X1 ──┬── L_cm ──┬── X2 ──┬──>
    │        │   ║║     │        │
   X1      CM choke  DM choke    X2
    │        │   ║║     │        │
N ──┴── X1 ──┴── L_cm ──┴── X2 ──┴──>

    │──Y1──┐  │──Y1──┐
    │      │  │      │
   PE ─────┘  PE ─────┘
```

### 3.3 拓扑选型决策

```
功率 < 500W：       单级L型或π型
500W ~ 3kW：        单级π型 + 共模电感
3kW ~ 10kW：        双级π型 + 独立差模电感
10kW ~ 50kW：       多级滤波 + 差共模分离设计
军用高可靠：         双级冗余 + 抑爆型安规电容
```

## 4. 共模电感设计

### 4.1 磁芯选型

| 磁芯材料 | 初始磁导率 μi | 饱和磁通密度 Bs | 居里温度 | 适用频率 | 适用场景 |
|---------|-------------|---------------|---------|---------|---------|
| 锰锌铁氧体（高μ） | 5000~15000 | ~400mT | ~150°C | <1MHz | 共模电感主选 |
| 锰锌铁氧体（功率） | 2000~3000 | ~500mT | ~200°C | <300kHz | 差模电感 |
| 镍锌铁氧体 | 100~1000 | ~300mT | >350°C | 1MHz~100MHz | 高频共模抑制 |
| 非晶/纳米晶 | 30000~150000 | ~1200mT | ~600°C | <500kHz | 大功率共模，高μ |
| 粉末磁芯（铁粉/合金粉） | 10~100 | ~1000mT | — | <100kHz | 差模电感，分布式气隙 |

**选型建议：**
- 民用中小功率（<3kW）：锰锌铁氧体高μ磁芯（如EE/ETD/环形）
- 军用大功率（>3kW）：纳米晶磁芯（高μ、高Bs、温度稳定性好）
- 高频段（>1MHz）辅助：镍锌铁氧体磁珠或小磁环

### 4.2 共模电感匝数计算

共模电感量需求由目标插入损耗决定。典型设计值为1mH~10mH（视功率等级和EMC等级）。

```
L_cm = (μ0 * μr * Ae * N^2) / (le + μr * lg)
```

对于闭合磁路环形磁芯（无气隙 $l_g = 0$）：

```
L_cm = μ0 * μr * Ae * N^2 / le
```

其中：
- $\mu_0 = 4\pi \times 10^{-7}$ H/m
- $\mu_r$：相对磁导率
- $A_e$：有效截面积（m²）
- $N$：匝数
- $l_e$：有效磁路长度（m）

**设计示例（3kW电源共模电感）：**

| 参数 | 值 |
|-----|---|
| 目标电感量 | 5 mH |
| 磁芯 | 纳米晶环形磁环 (μr ≈ 50000) |
| 磁路长度 le | 0.12 m |
| 有效截面积 Ae | 1.2×10⁻⁴ m² |
| 计算匝数 N | N = √(L·le / (μ0·μr·Ae)) ≈ √(5e-3 × 0.12 / (4πe-7 × 50000 × 1.2e-4)) ≈ 18 匝 |

### 4.3 漏感控制

共模电感的漏感即差模电感分量，是双线并绕结构中不可避免产生的。漏感过大可能导致差模谐振问题；漏感过小则无法提供差模抑制。

```
L_leakage ≈ μ0 * N^2 * (Ae / le) * ( Leakage factor )
```

**漏感控制原则：**

| 绕组方式 | 漏感（相对值） | 共模抑制 | 差模抑制 | 适用场景 |
|---------|-------------|---------|---------|---------|
| 双线并绕（紧密耦合） | ~0.5%~1% × L_cm | 最优 | 弱 | 需独立差模电感 |
| 分段绕制 | ~1%~3% × L_cm | 良好 | 中等 | 通用 |
| 分离绕制（分开绕） | ~3%~8% × L_cm | 一般 | 较强 | 紧凑设计，利用漏感作差模 |

**实用建议：**
- 3kW以下：双线并绕 + 独立差模电感（漏感控制<1%）
- 3kW以上：分段绕制，漏感控制在1%~3%，可省去独立差模电感
- 军用高可靠：优先双线并绕，降低温升热点

### 4.4 共模电感饱和校验

共模电感在理想情况下不流过差模电流，但实际存在不平衡电流和浪涌电流。需校验在最恶劣浪涌电流下不饱和：

```
B_max = (L_leakage * I_peak) / (N * Ae)

要求：B_max < B_sat（通常取 Bs 的 70%~80% 留余量）
```

## 5. 差模电感设计

### 5.1 差模电感量需求计算

差模电感量需求取决于EMC标准限值和开关频率处的噪声强度：

```
所需衰减量 Att = Noise_level - Limit - Margin

L_dm_required = Att / (ω^2 * C_x_total)    （简化估算）
```

其中 $\omega = 2\pi f$，$C_{x\_total}$ 为X电容总量。

### 5.2 差模电感磁芯选型

差模电感需承受直流偏磁（工频电流+开关纹波），必须选用带气隙的磁芯：

| 磁芯类型 | 特点 | 适用功率 |
|---------|------|---------|
| 铁粉芯 | 分布式气隙，低成本，损耗大 | <1kW |
| 铁硅铝（Sendust） | 低损耗，温度稳定性好 | 1~10kW |
| 钼坡莫合金（MPP） | 损耗最低，温度稳定性最优，成本高 | 军品/高可靠 |
| 铁硅（FeSi） | 高Bs，低成本，大功率 | 5~50kW |

### 5.3 差模电感设计步骤

```
1. 确定峰值电流 I_peak = I_rms * √2 * (1 + 纹波率)
2. 确定目标电感量 L_dm（通常 50μH ~ 500μH）
3. 选择磁芯材料并确定饱和裕度
4. 计算匝数：N = √(L * le / (μ0 * μe * Ae))
5. 校验磁通密度：B = L * I_peak / (N * Ae) < B_sat × 80%
6. 校验铜损和温升
```

## 6. X电容/Y电容选型与安规要求

### 6.1 X电容（跨接L-N）

| 安规等级 | 适用场合 | 浪涌耐压 | 典型容值 |
|---------|---------|---------|---------|
| X1 | 高脉冲应用 | 4kV | 0.1μF ~ 4.7μF |
| X2 | 通用场合 | 2.5kV | 0.1μF ~ 2.2μF |

**选型要点：**
- 优先选用X2等级（通用民用）
- 军用要求X1等级或更高浪涌耐压
- 电容值越大，低频差模抑制越好，但浪涌电流增大
- 并联放电电阻满足安规泄放要求（断电后1秒内电压<34V）

```
放电电阻要求：R ≤ t_discharge / (C × ln(√2 × V_in / 34))

示例：C = 1μF, V_in = 220V, t = 1s
R ≤ 1 / (1e-6 × ln(311/34)) ≈ 1 / (1e-6 × 2.21) ≈ 452kΩ → 选 470kΩ
```

### 6.2 Y电容（跨接L-PE/N-PE）

| 安规等级 | 适用场合 | 脉冲耐压 | 典型容值 |
|---------|---------|---------|---------|
| Y1 | 跨接一次-二次（高压隔离） | 8kV | 1nF ~ 4.7nF |
| Y2 | 跨接L-PE/N-PE | 5kV | 1nF ~ 10nF |

**选型要点：**
- Y电容总量受漏电流限制约束
- 民用设备漏电流限值：0.25mA~3.5mA（按设备类别）
- 军用设备漏电流限值：通常<0.5mA，部分场合<0.1mA

```
漏电流计算：I_leak = 2π × f × C_y_total × V_y

示例：C_y = 4.7nF (两颗Y2并联=9.4nF), f=50Hz, V_y=220V
I_leak = 2π × 50 × 9.4e-9 × 220 ≈ 0.65mA → 满足民用<3.5mA，不满足军用<0.5mA

军用建议：每路Y电容 ≤ 2.2nF，总Y电容 ≤ 4.4nF
```

### 6.3 安规认证要求

| 认证体系 | 标准 | 适用区域 |
|---------|------|---------|
| UL | UL60950 / UL62368 | 北美 |
| EN | EN60384-14 | 欧洲 |
| GB | GB/T14472 | 中国 |
| CQC | — | 中国自愿认证 |
| GJB | GJB151B (EMC) | 军用 |

## 7. 插入损耗计算方法

### 7.1 插入损耗定义

```
IL = 20 × log10(V_without_filter / V_with_filter)  [dB]
```

### 7.2 单级LC滤波器插入损耗

对于源阻抗 $R_s$ 和负载阻抗 $R_L$ 的LC滤波器：

```
高频近似（f >> fc）：
IL ≈ 20 × log10(ω² × L × C)    [dB]

截止频率：
fc = 1 / (2π × √(L × C))
```

### 7.3 共模/差模插入损耗分别计算

**差模等效电路：**

```
源（LISN 50Ω）→ [L_dm, C_x] → 负载（50Ω）

f_c_dm = 1 / (2π × √(L_dm × C_x))
```

**共模等效电路：**

```
源（LISN 25Ω）→ [L_cm/2, C_y] → 负载（25Ω）

f_c_cm = 1 / (2π × √(L_cm × C_y))
```

### 7.4 设计目标

| 频段 | 标准限值（CISPR Class B） | 设计目标衰减 |
|-----|------------------------|------------|
| 150kHz~500kHz | 56~46 dBμV | ≥20dB余量 |
| 500kHz~5MHz | 56 dBμV | ≥20dB余量 |
| 5MHz~30MHz | 60 dBμV | ≥20dB余量 |

| 频段 | 标准限值（GJB151B CE102） | 设计目标衰减 |
|-----|------------------------|------------|
| 10kHz~500kHz | 94~60 dBμV | ≥6dB余量 |
| 500kHz~10MHz | 60 dBμV | ≥6dB余量 |

## 8. 大功率EMI滤波器特殊考虑

### 8.1 趋肤效应（Skin Effect）

高频电流集中在导体表面，有效截面积减小，交流电阻增大：

```
趋肤深度：δ = √(2ρ / (ω × μ0 × μr))

铜导体在20°C下：
δ = 65.5 / √f  [mm]  （f单位Hz）

示例：
100kHz: δ ≈ 0.21mm
1MHz:   δ ≈ 0.066mm
10MHz:  δ ≈ 0.021mm
```

**设计对策：**
- 导体厚度/直径 < 2δ时趋肤效应可忽略
- 大电流采用利兹线（Litz wire）或多股并联
- 铜箔厚度建议：<0.2mm（100kHz），<0.07mm（1MHz）

### 8.2 邻近效应（Proximity Effect）

相邻导线交变磁场导致电流集中于导体一侧，使交流电阻进一步增大：

```
Dowell公式（多层绕组交流电阻因子）：
Fr = Δ [ sinh(2Δ) + sin(2Δ) ] / [ cosh(2Δ) - cos(2Δ) ]

其中 Δ = d / δ （d为导体厚度，δ为趋肤深度）
```

**设计对策：**
- 绕组层数最小化
- 采用交错绕制（interleaved winding）降低邻近效应
- 导体间距适当增大
- 大功率采用铜箔绕制时，铜箔宽度尽量大、厚度尽量薄

### 8.3 大功率滤波器热设计

| 功率等级 | 典型损耗（滤波器自身） | 散热方式 |
|---------|-------------------|---------|
| 1~3kW | 5~15W | 自然对流 |
| 3~10kW | 15~50W | 强制风冷 |
| 10~50kW | 50~200W | 水冷/油冷 |

**温升控制目标：**
- 电感绕组温升 < 40°C（民用）
- 电感绕组温升 < 25°C（军用，长寿命）
- 电容外壳温度 < 额定温度的80%

### 8.4 高压绝缘考虑

军用电源输入电压范围宽（如AC 115V/220V/380V或DC 270V），需考虑：
- X电容耐压 ≥ 1.5 × V_max
- Y电容耐压 ≥ 2 × V_max（一次-二次隔离）
- 共模电感线间绝缘：加强绝缘，耐压≥3000VAC
- PCB爬电距离/电气间隙按GJB相关要求执行

## 9. 军用EMC标准GJB151B对应要求

### 9.1 相关测试项目

| 测试项目 | 名称 | 频率范围 | 限值要求 | EMI滤波器设计关联 |
|---------|------|---------|---------|-----------------|
| CE101 | 25Hz~10kHz传导发射 | 25Hz~10kHz | 低频传导限值 | 低频滤波，输入电感设计 |
| CE102 | 10kHz~10MHz传导发射 | 10kHz~10MHz | 见下表 | **核心设计目标** |
| CE106 | 天线端传导发射 | 10kHz~40GHz | 传导发射限值 | 输出端滤波 |
| CS101 | 25Hz~50kHz传导敏感度 | 25Hz~50kHz | 注入正弦干扰 | 低频阻抗设计 |
| CS114 | 10kHz~200MHz传导敏感度 | 10kHz~200MHz | 注入共模干扰 | 共模滤波裕量 |
| CS115 | 50ns脉冲激励 | — | 脉冲注入 | 高频瞬态抑制 |
| CS116 | 10kHz~100MHz阻尼正弦 | 10kHz~100MHz | 阻尼振荡注入 | 谐振点避让 |
| RE101 | 25Hz~100kHz磁场辐射 | 25Hz~100kHz | 磁场限值 | 磁性元件屏蔽 |
| RE102 | 10kHz~18GHz电场辐射 | 10kHz~18GHz | 电场限值 | 滤波器+屏蔽设计 |

### 9.2 CE102限值详解

```
CE102限值（GJB151B，普通安装平台）：
10kHz ~ 500kHz：  94 - 20×log(f/10kHz) dBμV  （斜线下降）
500kHz ~ 10MHz：  60 dBμV  （平坦）
```

**设计要求：**
- 10kHz处限值约94dBμV，要求滤波器在低频段有足够衰减
- 需要较大的差模电感和X电容来压低10kHz~150kHz频段噪声
- 共模电感量需足够大以覆盖150kHz~10MHz频段

### 9.3 CS101传导敏感度要求

CS101向电源线注入25Hz~50kHz正弦干扰信号，要求设备正常工作：

```
注入电压：V_inject = 136 dBμV (开路，约6.3Vrms) 或 按功率曲线
```

**设计对策：**
- 增加输入级电感量，提高低频阻抗
- 后级DC-DC需有足够输入电压裕量
- 输入滤波器谐振频率需避开CS101注入频率范围

### 9.4 CS114传导敏感度要求

CS114通过电流探头注入10kHz~200MHz共模/差模电流：

```
注入电流等级：
曲线1：40~80 dBμA
曲线2：43~89 dBμA
曲线3：49~109 dBμA（最严格）
```

**设计对策：**
- 共模电感在10kHz~200MHz范围内保持足够阻抗
- Y电容提供高频旁路通路
- 避免滤波器谐振尖峰落在注入频段内

### 9.5 RE102辐射发射要求

```
RE102限值（典型）：
2MHz~100MHz：  24 dBμV/m（3m距离）
100MHz~1GHz：  30 dBμV/m
1GHz~18GHz：   按频段递增
```

**滤波器设计关联：**
- 滤波器自身高频泄漏控制（磁芯高频特性、寄生参数）
- 滤波器输出端高频滤波防止辐射
- 线缆共模电流控制（共模电感 + Y电容）

## 10. 设计审查要点清单

### 10.1 原理设计审查

| 序号 | 审查项 | 合格判据 | 优先级 |
|-----|--------|---------|--------|
| 1 | 共模电感量是否满足CE102/RE102要求 | ≥设计目标值，含温度降额 | 高 |
| 2 | 差模电感量是否满足CE102低频段要求 | ≥设计目标值 | 高 |

## 附录B：EMI滤波器设计快速参考

```
入门级设计流程（500W~3kW AC输入电源）：

1. 确定EMC标准 → 查限值表
2. 估算原始噪声 → 开关频率处约 80~100 dBμV
3. 计算所需衰减 → Att = 噪声 - 限值 - 余量
4. 选定拓扑 → 单级π型
5. 确定截止频率 → fc = f_noise_low / 3~5
6. 分配L和C → 优先大C（X电容），再定L
7. 共模/差模分离计算
8. 磁芯选型 → 查附录A
9. 匝数/线径计算
10. 热校验和饱和校验
11. 样机制作 → EMI测试验证
12. 迭代优化
```

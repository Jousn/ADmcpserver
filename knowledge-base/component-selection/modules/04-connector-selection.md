# 连接器选型知识库

> 适用范围：USB 接口、板对板连接、线对板连接、电源连接器、射频连接器
> 目标受众：AI设计辅助Skill，用于连接器选型咨询与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

连接器是电子系统中实现板间、板线、设备间互连的关键器件。选型需要综合考虑接口标准、引脚数、电流额定值、电压额定值、间距、堆叠高度、插拔次数、机械寿命和 PCB 封装可行性。不同类型的连接器（USB、板对板、线对板、电源、射频）有各自专门的选型准则，错误的选型会导致接触不良、信号完整性问题或电流过载。

## 2. USB 连接器

### 2.1 USB 接口类型对比

| 接口类型 | 引脚数 | 最大电流 | 最大电压 | 数据速率 | 插拔次数 | 特点 |
|----------|--------|---------|---------|---------|---------|------|
| USB Type-A | 4/9 | 5V/0.9A（USB 2.0） | 5V | 480Mbps（USB 2.0） | 1500 | 经典主机/设备接口 |
| USB Type-C | 24 | 5V/3A（默认），20V/5A（PD） | 20V | 10Gbps（USB 3.1 Gen2），40Gbps（TB4） | 10000 | 正反插，多协议复用 |
| Micro-USB | 5 | 5V/1.8A | 5V | 480Mbps | 10000 | 移动设备通用 |
| Mini-USB | 5 | 5V/0.5A | 5V | 480Mbps | 5000 | 老式设备 |

### 2.2 USB Type-C 引脚定义

Type-C 连接器有 24 引脚，支持正反插（对称设计）：

```
Type-C 母座引脚排列（俯视）：

A1  A2  A3  A4  A5  A6  A7  A8  A9  A10 A11 A12
│   │   │   │   │   │   │   │   │   │   │   │
└─────────────────────────────────────────────┘
┌─────────────────────────────────────────────┐
│   │   │   │   │   │   │   │   │   │   │   │
B1  B2  B3  B4  B5  B6  B7  B8  B9  B10 B11 B12

引脚说明：
A1/B1: GND（地）
A2/A3, B10/B11: TX1+/-（高速差分发送）
A4/B4: VBUS（电源）
A5/B5: CC（通道配置，方向检测/PD 通信）
A6/A7, B6/B7: D+/-（USB 2.0 差分）
A8/B8: SBU1/SBU2（辅助总线，模拟/备用）
A9/B9: VBUS（电源）
A10/A11, B2/B3: RX1+/-, RX2+/-（高速差分接收）
A12/B12: GND（地）
```

**CC 引脚功能：**
- 拉下电阻（5.1kΩ）：DFP（主机）识别 UFP（设备）
- 拉上电阻（Rp）：UFP 识别 DFP
- PD（Power Delivery）通信：通过 CC 线 BMC 编码通信，协商电压/电流

### 2.3 USB Type-C PD 功率配置

| PD 配置 | 电压 | 电流 | 功率 | 说明 |
|---------|------|------|------|------|
| 默认（非 PD） | 5V | 0.9A (USB 3.0) / 1.5A (BC 1.2) | 4.5W / 7.5W | 无 PD 芯片时的默认 |
| USB 2.0 Type-C | 5V | 1.5A | 7.5W | CC 拉下为 Ra（1kΩ） |
| USB 3.x Type-C | 5V | 3A | 15W | 默认功率上限 |
| PD 5V | 5V | 3A | 15W | PD 协商 |
| PD 9V | 9V | 3A | 27W | PD 协商 |
| PD 15V | 15V | 3A | 45W | PD 协商 |
| PD 20V | 20V | 3A | 60W | PD 协商 |
| PD EPR | 20V | 5A | 100W | 扩展功率（需 5A 线缆） |
| PD EPR | 48V | 5A | 240W | 最新 PD 3.1 规范 |

### 2.4 USB 连接器选型要点

| 审查项 | 要求 | 说明 |
|--------|------|------|
| 插拔次数 | ≥ 5000（商用）/ ≥ 10000（工业） | Type-C 标称 10000 次 |
| VBUS 触点电流 | 单触点 ≥ 1.5A，多触点并联 ≥ 5A | Type-C 有 4 个 VBUS 触点 |
| PD 控制器 | 支持 PD 时需配置 PD 芯片 | 如 TI TPS25750, ST STUSB |
| ESD 保护 | VBUS/D±/SBU/CC 需 ESD 防护 | 选用 USB 专用 ESD 阵列 |
| 可焊性 | SMT 贴片优先，通孔用于加固 | 高插拔力场合用通孔 |

## 3. 板对板（Board-to-Board）连接器

### 3.1 间距与堆叠高度

| 间距 (mm) | 典型应用 | 特点 |
|-----------|---------|------|
| 0.35 | 超高密度 | 移动设备堆叠 |
| 0.40 | 高密度 | 模组互连 |
| 0.50 | 高密度通用 | 摄像头模组、FPC |
| 0.80 | 中密度 | 模块板互连 |
| 1.00 | 通用 | 工业/消费电子 |
| 1.27 | 标准 | 工业主流 |
| 2.00 | 大间距 | 电源/通用 |
| 2.54 | 标准 | 工业通用，兼容排针 |

### 3.2 堆叠高度类型

| 类型 | 堆叠高度范围 | 特点 |
|------|------------|------|
| Mezzanine（夹层） | 3~8mm | 两板平行堆叠，间距小 |
| 标准 | 5~10mm | 通用板间互连 |
| 高堆叠 | 10~20mm | 需容纳中间器件 |
| 板对板+FPC | 混合 | 结合柔性排线 |

**选型原则：**
- 堆叠高度需容纳两板间最高器件（如连接器自身、电容、屏蔽罩）
- 留 0.5~1mm 机械余量，防止装配应力
- Mezzanine 连接器优先选自校准型（盲插容差大）

### 3.3 PCIe 插槽连接器

PCIe 插槽是标准化的板对板高速连接器：

| PCIe 版本 | 通道数 | 速率 | 插槽长度 |
|-----------|--------|------|---------|
| PCIe 3.0 | x1/x4/x8/x16 | 8 GT/s/lane | 36/164/258/494 脚 |
| PCIe 4.0 | x1/x4/x8/x16 | 16 GT/s/lane | 同上 |
| PCIe 5.0 | x1/x4/x8/x16 | 32 GT/s/lane | 同上 |

**PCIe PCB 设计要点：**
- 插槽区域需 12 层以上叠层保证阻抗控制
- 差分对等长控制在 ±5mil
- 焊盘区域做反焊盘优化避免阻抗突变

## 6. 射频（RF）连接器

### 6.1 射频连接器对比

| 类型 | 频率上限 | 阻抗 | 尺寸 | 插拔次数 | 特点 |
|------|---------|------|------|---------|------|
| SMA | 18GHz | 50Ω | 中 | 500+ | 工业标准，螺纹锁紧 |
| SMB | 10GHz | 50Ω | 小 | 500+ | 推入自锁，快速 |
| MMCX | 6GHz | 50Ω | 超小 | 500+ | 微型推入锁扣 |
| U.FL (IPEX) | 6GHz | 50Ω | 极小 | 30+ | 超薄 PCB 端子，寿命低 |
| BNC | 4GHz | 50/75Ω | 中 | 500+ | 卡口快锁，实验室通用 |
| N 型 | 11GHz | 50Ω | 大 | 500+ | 大功率射频 |
| 2.92mm/3.5mm | 40GHz | 50Ω | 中 | 500+ | 毫米波 |

### 6.2 U.FL (IPEX) 连接器

U.FL 是超小型 PCB 端子型 RF 连接器，广泛用于 Wi-Fi/蓝牙模块：

```
参数：
- 频率上限：6GHz
- 阻抗：50Ω
- 高度：1.2mm（超薄）
- 插拔次数：约 30 次（寿命低，不建议频繁插拔）
- 接触电阻：< 20mΩ

应用：
- Wi-Fi 模组天线接口
- 蓝牙模块天线接口
- GPS 模块天线接口
```

### 6.3 SMA 连接器

SMA 是最常用的射频连接器，螺纹锁紧可靠：

```
参数：
- 频率上限：18GHz（标准）/ 26.5GHz（精密）
- 阻抗：50Ω
- 电压额定：500V RMS
- 插拔次数：500+ 次
- 接触电阻：< 5mΩ

PCB 安装方式：
- 端接式（Edge Mount）：焊在板边
- 垂直式（Vertical / Through-Hole）：直立于 PCB
- 直角式（Right Angle）：侧向出线
```

## 7. 选型准则汇总

### 7.1 通用选型准则

| 准则 | 说明 |
|------|------|
| 引脚数 | 满足信号数 + 电源/地引脚冗余 |
| 电流额定值 | 按单触点额定值计算，并联触点降额 20% |
| 电压额定值 | ≥ 工作电压 × 1.5（考虑浪涌） |
| 间距 | 满足安规爬电/电气间隙要求 |
| 堆叠高度 | 容纳板间最高器件 + 机械余量 |
| 插拔次数 | 满足产品生命周期内插拔需求 |
| 锁扣方式 | 振动环境选带锁扣连接器 |
| 工作温度 | 满足应用温度范围（工业 -40~85°C） |
| 防护等级 | 户外/潮湿环境选 IP67 防水型 |
| EMI | 高速信号连接器选带屏蔽壳型号 |

### 7.2 按应用场景选型决策

```
接口类型选型流程：

确定接口标准
    │
    ├─ USB → Type-C（新设计优先）/ Micro-USB（低成本）
    ├─ 板间互连 → 按间距和高度选 B2B
    ├─ 线对板 → 按电流选间距（1A→1.0mm, 2A→2.0mm, 3A→2.5mm）
    ├─ 电源输入 → DC 圆孔（小功率）/ XT60（大功率）/ 端子排（工业）
    └─ 射频 → U.FL（超薄模组）/ SMA（标准）/ MMCX（微型可锁）
```

## 8. PCB 封装设计考量

### 8.1 焊盘设计

| 连接器类型 | 焊盘要求 | 备注 |
|-----------|---------|------|
| SMT 连接器 | 焊盘尺寸严格按数据手册 | 过大/过小均影响焊接强度 |
| 通孔连接器 | 孔径 = 引脚直径 + 0.2mm | 保证可焊性和插拔强度 |
| 大电流连接器 | 焊盘加宽，多过孔散热 | 防止焊接时热容量不足 |
| RF 连接器 | 焊盘匹配 50Ω 阻抗 | 参考厂商阻抗优化文件 |

### 8.2 过孔布置

```
连接器过孔设计原则：

1. 高速信号：信号过孔就近连接，短 stub
2. 电源引脚：每引脚 2~4 个过孔，降低电流密度
3. GND 引脚：阵列过孔，低阻抗接地
4. 散热焊盘：过孔阵列 0.3mm 孔径，1~2mm 间距
5. EMI 屏蔽壳：接地过孔沿屏蔽墙均匀分布

过孔尺寸推荐：
- 信号过孔：0.2~0.3mm 孔径
- 电源过孔：0.3~0.5mm 孔径
- 散热过孔：0.3mm 孔径，密集阵列
```

### 8.3 电镀与表面处理

| 表面处理 | 可焊性 | 接触电阻 | 成本 | 适用 |
|----------|--------|---------|------|------|
| HASL（喷锡） | 好 | 中 | 低 | 通用 |
| ENIG（沉金） | 优 | 低 | 中 | 高可靠/高频 |
| OSP（有机保焊膜） | 好 | 中 | 低 | 消费电子 |
| 沉银 | 好 | 低 | 中 | 高频 |
| 沉锡 | 好 | 中 | 中 | 精密连接器 |

**RF 连接器专用：** SMA/U.FL 焊盘区域推荐 ENIG，保证接触电阻稳定和阻抗一致性。

### 8.4 机械固定

```
连接器机械固定方式：

1. SMT 焊盘：靠焊盘粘接片（黏胶焊盘）固定
2. 通孔引脚：金属化孔焊接，强度最高
3. 定位孔：连接器自带定位柱，PCB 开孔定位
4. 螺丝固定：大电流/大尺寸连接器用螺丝固定到 PCB 或壳体
5. 灌封固定：振动环境灌胶加固

选型建议：
- 振动/冲击环境：通孔 + 定位柱 + 灌胶
- 手持/消费：SMT + 定位柱
- 大电流电源：通孔 + 螺丝
- 高频 RF：SMT + 定位柱
```

> 适用范围：模拟电路、混合信号系统、电源控制、传感器信号调理
> 目标受众：AI设计辅助Skill，用于运算放大器选型咨询与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

运算放大器（Operational Amplifier, Op Amp）是模拟电路设计中最核心的有源器件之一。选型需要综合考虑增益带宽积（GBW）、压摆率（Slew Rate）、失调电压（Vos）、输入偏置电流（Ib）、电源电压范围、轨到轨能力以及噪声特性等参数。不同应用场景对参数的要求差异极大，错误的选型会导致带宽不足、失真、噪声过大或功耗超标等问题。

---

## 2. 关键选型参数详解

### 2.1 增益带宽积（GBW）

GBW 是指运放在开环增益降为 1 时的频率，是衡量运放带宽能力的核心指标。

```
闭环带宽 = GBW / 闭环增益（对电压反馈型运放）

示例：GBW = 10MHz，闭环增益 = 10
闭环带宽 = 10MHz / 10 = 1MHz
```

**选型原则：**
- 实际工作频率所需的闭环带宽应低于 GBW/增益 的 1/5~1/10，留足相位裕量
- 电流反馈型运放（CFB）的带宽不随增益变化，适合高增益高频场景

### 2.2 压摆率（Slew Rate, SR）

压摆率决定运放在大信号条件下的最大不失真频率：

```
满功率带宽：f_fp = SR / (2π × V_peak)

示例：SR = 0.5V/μs, V_peak = 5V
f_fp = 0.5e6 / (2π × 5) = 15.9 kHz
```

**选型原则：**
- 对于正弦波信号，SR ≥ 2π × f_max × V_peak
- 对于脉冲信号，SR 决定上升/下降时间，t_rise ≈ 0.35 / f_3dB（小信号）

### 2.3 失调电压（Vos）

失调电压是运放输入端为零差分电压时输出端的偏移折算到输入端的值。

| 等级 | 典型 Vos | 适用场景 |
|------|---------|---------|
| 通用 | 1~10 mV | 消费电子、一般放大 |
| 精密 | 100~500 μV | 仪器仪表、传感器 |
| 超精密 | 1~50 μV | 计量、高精度 ADC 前端 |

**失调温漂（TCVos）：**
- 通用运放：5~20 μV/°C
- 精密运放：0.05~2 μV/°C
- 零漂移运放（Zero-Drift）：< 0.05 μV/°C（斩波稳零技术）

### 2.4 输入偏置电流（Ib）

输入偏置电流影响高阻抗源电路的精度。

| 输入级类型 | 典型 Ib | 适用场景 |
|-----------|---------|---------|
| BJT 输入 | 10nA~1μA | 低噪声、低源阻抗 |
| JFET 输入 | 1pA~1nA | 高阻抗源、通用 |
| CMOS 输入 | 1fA~1pA | 超高阻抗源、静电计 |

### 2.5 电源电压范围

| 类别 | 电源范围 | 说明 |
|------|---------|------|
| 高压运放 | ±15V~±22V (或 44V) | 工业传统模拟系统 |
| 低压运放 | 2.7V~5.5V（单电源） | 便携式、电池供电 |
| 超低压运放 | 1.6V~3.3V | 低功耗 IoT 设备 |

### 2.6 轨到轨（Rail-to-Rail）

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| 输入轨到轨（RRIO） | 共模电压覆盖电源轨 | 传感器前端、单电源系统 |
| 输出轨到轨（RRO） | 输出摆幅接近电源轨 | 单电源系统、低压系统 |
| 输入输出轨到轨 | 输入和输出均为轨到轨 | 低压电池供电系统 |

**注意：** 轨到轨运放在接近电源轨时线性度会下降，数据手册中需关注 THD 与输出负载能力。

### 2.7 噪声

运放噪声分为电压噪声（en）和电流噪声（in）：

```
总输入噪声 = √(en² + (in × Rs)² + 4kT × Rs)

其中：
- en：运放电压噪声密度 (nV/√Hz)
- in：运放电流噪声密度 (fA/√Hz or pA/√Hz)
- Rs：源阻抗
- 4kT × Rs：电阻热噪声
```

| 噪声等级 | 典型 en (nV/√Hz) | 适用场景 |
|----------|-----------------|---------|
| 超低噪声 | 0.8~3 | 音频前置、精密测量 |
| 低噪声 | 3~10 | 通用精密放大 |
| 一般 | 10~30 | 消费电子、一般用途 |

## 3. 运放分类与典型型号

### 3.1 型号选型速查表

| 型号 | 通道 | 类型 | GBW | SR (V/μs) | Vos (max) | Ib | 电源范围 | 封装 |
|------|------|------|-----|-----------|-----------|-----|---------|------|
| LM358 | 双 | 通用 BJT | 1 MHz | 0.5 | ±3 mV (±7 typ) | 45 nA | 3~32V | DIP-8/SO-8 |
| TL084 | 四 | JFET | 3 MHz | 13 | ±3 mV (typ) | 65 pA | ±4.5~±18V | DIP-14/SO-14 |
| OPA2333 | 双 | 零漂移 CMOS | 0.35 MHz | 0.16 | 2 μV (10 μV max) | 70 pA | 1.8~5.5V | MSOP-8/SO-8 |
| OPA2350 | 双 | RRIO CMOS | 38 MHz | 22 | 150 μV (500 μV max) | 1 pA | 2.5~5.5V | MSOP-8/SO-8 |
| AD8605 | 单 | 精密 CMOS RRIO | 10 MHz | 5 | 80 μV (max) | 1 pA | 2.7~5.5V | SOT-23-5/MSOP-8 |
| AD620 | 单 | 仪表放大器 | — (Gain 1~10000) | 1.2 | 50 μV (max) | 1 nA | ±2.3~±18V | DIP-8/SOIC-8 |

### 3.2 分类详解

#### 通用型（General Purpose）

- **代表型号**：LM358、LM324、TL072、TL084
- **特点**：低成本、性能适中、供货稳定
- **典型 GBW**：1~3 MHz
- **典型 Vos**：1~10 mV
- **适用场景**：消费电子、简单信号调理、比较器、缓冲器、低频滤波

#### 精密型（Precision）

- **代表型号**：AD8605、OPA277、OP07、ADA4522
- **特点**：低失调、低温漂、高 CMRR
- **典型 Vos**：< 500 μV
- **典型 TCVos**：< 2 μV/°C
- **适用场景**：仪器仪表、传感器信号调理、ADC 前端、精密电流检测

#### 高速型（High-Speed）

- **代表型号**：OPA2350、AD8051、THS3091、LM7171
- **特点**：高 GBW、高压摆率、低失真
- **典型 GBW**：> 20 MHz
- **适用场景**：视频信号处理、高速 ADC 驱动、有源滤波器、脉冲放大

#### 低功耗型（Low-Power / Micropower）

- **代表型号**：OPA2333、LPV321、TLV2401
- **特点**：静态电流极低（μA 级）、低压供电
- **典型 Iq**：< 100 μA
- **适用场景**：电池供电设备、IoT 传感器、便携式仪器

#### 轨到轨型（Rail-to-Rail）

- **代表型号**：OPA2350、AD8605、MCP6001
- **特点**：输入共模范围和/或输出摆幅覆盖电源轨
- **适用场景**：单电源系统、低压电池系统、传感器接口

## 4. 应用场景选型指南

### 4.1 各电路类型推荐

| 应用场景 | 关键参数要求 | 推荐型号 | 选型理由 |
|----------|------------|---------|---------|
| 传感器信号调理（高阻抗源） | 低 Ib、低 Vos | TL084 / OPA2333 | JFET/CMOS 输入，Ib 极低 |
| 精密电流检测（低边） | 低 Vos、低 TCVos | AD8605 / OPA2333 | 低失调保证检测精度 |
| 仪表放大（差分小信号） | 高 CMRR、增益可调 | AD620 | 集成仪表放大器，仅需一只外接电阻设定增益 |
| 音频前置放大 | 低噪声、高 GBW | NE5532 / OPA2134 | 低 en (< 5 nV/√Hz)，低失真 |
| 高速 ADC 驱动（全差分） | 高 SR、低失真 | THS4501 / ADA4940 | 全差分驱动，高频线性度 |
| 电池供电便携设备 | 低功耗、低压 | OPA2333 / MCP6001 | 静态电流 μA 级，1.8V 供电 |
| 有源滤波器（高频） | 高 GBW、高 SR | OPA2350 | 38 MHz GBW，22 V/μs SR |
| 比较器/振荡器 | 通用、低成本 | LM358 / LM393 | 成本低，供货稳定 |
| 电压跟随/缓冲 | 高输入阻抗 | TL072 / OPA2350 | 高输入阻抗，低输出阻抗 |

### 4.2 仪表放大器 AD620 应用说明

AD620 是经典仪表放大器（Instrumentation Amplifier），通过单只外接电阻 $R_G$ 设定增益：

```
Gain = 1 + (49.4 kΩ / R_G)

示例：
R_G = 49.4 kΩ → Gain = 2
R_G = 4.99 kΩ → Gain ≈ 10
R_G = 499 Ω  → Gain ≈ 100
R_G = 49.9 Ω → Gain ≈ 1000
```

**适用场景**：应变片/电桥信号放大、生物电信号采集（ECG/EEG）、热电偶前端、4~20mA 电流环接收。

## 5. 选型流程图

```
确定应用需求
    │
    ├─ 信号频率 > 1MHz？
    │     ├─ 是 → 需要高速型（GBW > 20MHz）→ OPA2350 / AD8051
    │     └─ 否 → 继续
    │
    ├─ 需要高精度（Vos < 100μV）？
    │     ├─ 是 → 精密型/零漂移型 → OPA2333 / AD8605 / ADA4522
    │     └─ 否 → 继续
    │
    ├─ 源阻抗 > 100kΩ？
    │     ├─ 是 → 需要 JFET/CMOS 输入（Ib < 1nA）→ TL084 / OPA2333
    │     └─ 否 → BJT 输入亦可（低噪声）→ LM358 / NE5532
    │
    ├─ 单电源/低压供电？
    │     ├─ 是 → 轨到轨型 → OPA2350 / AD8605 / OPA2333
    │     └─ 否 → 传统双电源 → TL084 / NE5532 / LM358
    │
    ├─ 功耗受限（电池供电）？
    │     ├─ 是 → 低功耗型（Iq < 100μA）→ OPA2333 / MCP6001
    │     └─ 否 → 继续
    │
    ├─ 差分小信号采集？
    │     ├─ 是 → 仪表放大器 → AD620 / INA128
    │     └─ 否 → 通用型 → LM358 / TL084
    │
    └─ 输出选型结果
```

## 6. PCB 设计考量

### 6.1 去耦电容配置

| 电源类型 | 去耦方案 | 说明 |
|----------|---------|------|
| 通用运放 | 0.1μF X7R 陶瓷电容 | 每个电源引脚就近放置 |
| 高速运放 | 0.1μF + 10μF（并联） | 高频小电容 + 低频大电容 |
| 精密运放 | 0.1μF + 1μF + 铁氧体磁珠 | 多级去耦，降低电源噪声 |
| 低功耗运放 | 0.1μF | 简单去耦即可 |

**去耦电容布局原则：**
- 电容尽量靠近运放电源引脚（< 2mm）
- 过孔就近连接到电源/地平面
- 高速运放可增加 1000pF 陶瓷电容应对更高频段

### 6.2 高阻抗节点保护环（Guard Ring）

高阻抗输入（如 pH 传感器、静电计）需要保护环防止漏电流：

```
              ┌── 保护环（接运放同相输入参考电位）
              │
    信号源 ──┤  ┌────────┐
              │  │ 运放   │
              └──│ IN+    │
                  │        │
    保护环包围输入引脚、焊盘及走线  │ OUT ── 输出
                  │ IN-    │
                  └────────┘
```

**保护环设计原则：**
- 保护环接至与输入信号相同电位的低阻抗点（如跟随器输出）
- 保护环走线包围输入焊盘和走线，形成等电位屏蔽
- 保护环与信号走线之间保持足够间距，避免寄生电容
- 双面板需在两面均布设保护环，并通过过孔连接

### 6.3 热电偶效应与温度梯度

精密运放电路中，不同金属的接合点会产生热电偶效应（热电势），影响精度：

| 金属对 | 热电势 (μV/°C) | 来源 |
|--------|---------------|------|
| 铜-可伐（引脚框架） | ~40 | 器件引脚 |
| 铜-焊锡（SnPb） | ~1~3 | 焊点 |
| 铜-焊锡（无铅 SAC） | ~3~5 | 无铅焊点 |

**设计对策：**
- 精密运放尽量远离热源（如功率器件、稳压器）
- 避免温度梯度跨越输入差分对（两个输入端保持对称热环境）
- 热敏感元件放在板上等温线上
- 采用零漂移运放（OPA2333）可大幅降低热电偶效应影响

### 6.4 布局布线要点

| 要点 | 说明 | 适用场景 |
|------|------|---------|
| 反馈走线最短 | 减小寄生电容/电感，避免振荡 | 高速/高频运放 |
| 输入/输出远离 | 防止寄生反馈耦合 | 高增益电路 |
| 对称布局 | 同相/反相输入走线等长、等宽 | 精密差分电路 |
| 地平面完整 | 运放下方保持完整地平面 | 所有模拟电路 |
| 数字噪声隔离 | 数字走线不穿过模拟区 | 混合信号系统 |

## 7. 设计审查要点清单

| 序号 | 审查项 | 合格判据 | 优先级 |
|-----|--------|---------|--------|
| 1 | GBW 是否满足闭环带宽需求 | 闭环带宽 = GBW/Gain，实际带宽 < 此值的 1/5 | 高 |
| 2 | 压摆率是否满足信号幅度/频率 | SR ≥ 2π × f_max × V_peak | 高 |
| 3 | 失调电压是否满足精度要求 | Vos × 增益 < 允许输出误差 | 高 |
| 4 | 输入偏置电流与源阻抗匹配 | Ib × Rs < 允许输入误差 | 高 |
| 5 | 电源电压范围是否覆盖 | 供电电压在数据手册范围内 | 高 |
| 6 | 轨到轨需求是否满足 | 输入共模范围/输出摆幅覆盖信号范围 | 高 |
| 7 | 噪声是否满足系统 SNR | 总输入噪声 < 信号最小值的 1/3 | 中 |
| 8 | 去耦电容配置正确 | 每个电源引脚就近配置 0.1μF | 高 |
| 9 | 高阻抗节点保护环 | 保护环正确布设（适用时） | 中 |
| 10 | 热环境对称 | 精密运放输入对无温度梯度 | 中 |

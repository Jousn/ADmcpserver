# MOSFET 选型知识库

> 适用范围：电源开关、负载开关、DC-DC 变换器、电机驱动、保护电路
> 目标受众：AI设计辅助Skill，用于MOSFET选型咨询与审查
> 版本：v1.0 | 更新日期：2026-08

---

## 1. 概述

MOSFET（金属-氧化物-半导体场效应晶体管）是功率电子系统中最常用的开关器件。选型需要综合考虑漏源电压（Vds）、漏极电流（Id）、导通电阻（Rds(on)）、栅极电荷（Qg）、开关时间、热阻等参数。不同应用场景（开关电源、负载开关、电机驱动、线性放大）对参数的优先级不同，错误的选型会导致效率下降、发热严重甚至器件失效。

---

## 2. 关键选型参数详解

### 2.1 漏源击穿电压（Vds）

Vds 是 MOSFET 能承受的最大漏源电压，选型时需留有降额裕量：

```
选型原则：
Vds_rated ≥ Vds_max × 降额系数

降额系数：
- 商用：1.2~1.3 倍（降额 20~30%）
- 工业：1.3~1.5 倍（降额 30~50%）
- 军用：1.5~2.0 倍（降额 50~100%）

示例：
电路最高电压 24V
选型 Vds ≥ 24 × 1.3 = 31.2V → 选 30V 或更高额定
（注意 24V 电路常选 30V 或 40V 额定 MOSFET）
```

### 2.2 漏极电流（Id）

Id 是 MOSFET 能连续承受的最大漏极电流，受封装热阻和结温限制：

```
实际可用电流受热限制：

I_cont = √((Tj_max - Ta) / (Rth(ja) × Rds(on)))

其中：
- Tj_max：最大结温（通常 150°C 或 175°C）
- Ta：环境温度
- Rth(ja)：结到环境热阻（取决于封装和散热）
- Rds(on)：导通电阻（需按结温修正，通常取 1.5~2 倍 25°C 值）
```

**注意：** 数据手册标称 Id 通常在特定散热条件下（如 Tc=25°C）给出，实际应用中远低于标称值。

### 2.3 导通电阻（Rds(on)）

Rds(on) 是 MOSFET 完全导通时漏源之间的电阻，决定导通损耗：

```
导通损耗：P_cond = I_rms² × Rds(on)

Rds(on) 温度修正：
Rds(on)_hot = Rds(on)_25C × (1 + TCE × ΔT)

典型温度系数 TCE ≈ 0.6~1.0%/°C
100°C 时 Rds(on) 约为 25°C 时的 1.5~2 倍
```

**选型原则：**
- 以工作结温下的 Rds(on) 计算损耗，不能用 25°C 标称值
- 低电压 MOSFET 的 Rds(on) 更低（相同芯片面积）
- Rds(on) 与 Qg 是权衡关系：低 Rds(on) 通常意味着大芯片面积和高 Qg

### 2.4 栅极电荷（Qg）及开关参数

| 参数 | 定义 | 影响 |
|------|------|------|
| Qg | 总栅极电荷 | 决定驱动功率和开关速度 |
| Qgs | 栅源电荷 | 米勒平台前的充电量 |
| Qgd | 栅漏电荷（米勒电荷） | 决定开关过渡时间 |
| tdon | 开通延迟时间 | 驱动响应速度 |
| tr | 上升时间 | 开通过渡时间 |
| tdoff | 关断延迟时间 | 关断响应速度 |
| tf | 下降时间 | 关断过渡时间 |

```
开关损耗：P_sw = 0.5 × Vds × Id × (tr + tf) × f_sw

驱动功率：P_gate = Qg × Vgs × f_sw

示例：
Qg = 10nC, Vgs = 10V, f_sw = 500kHz
P_gate = 10e-9 × 10 × 500e3 = 50mW
```

### 2.5 热阻

| 热阻参数 | 含义 | 典型值（TO-220） |
|----------|------|-----------------|
| Rth(jc) | 结到外壳热阻 | 1~3 °C/W |
| Rth(ja) | 结到环境热阻（无散热器） | 50~65 °C/W |
| Rth(cs) | 外壳到散热器（含导热硅脂） | 0.5~1 °C/W |
| Rth(sa) | 散热器到环境 | 取决于散热器设计 |

## 3. N 沟道与 P 沟道选型

| 特性 | N 沟道 MOSFET | P 沟道 MOSFET |
|------|---------------|---------------|
| 载流子 | 电子（迁移率高） | 空穴（迁移率低） |
| Rds(on) | 低（相同面积） | 高（约 2~3 倍） |
| Qg | 低 | 高 |
| 成本 | 低 | 高 |
| 驱动 | 需高于源极电压（高压侧需自举/电荷泵） | 源极接电源，栅极拉低即可导通 |
| 应用 | 低边开关、DC-DC 主开关、高压侧（配合驱动） | 高边负载开关（简单驱动）、电池保护 |

**选型决策：**
- 优先选 N 沟道（性能优、成本低）
- 仅在驱动简化要求高的小功率高边开关场合选 P 沟道
- 大功率高压侧开关用 N 沟道 + 栅极驱动 IC（自举驱动）

## 4. 开关应用 vs 线性应用

### 4.1 开关应用（DC-DC、负载开关、电机驱动）

| 参数 | 要求 | 理由 |
|------|------|------|
| Rds(on) | 尽可能低 | 降低导通损耗 |
| Qg | 适当低 | 减小驱动功率和开关损耗 |
| 开关速度 | 快（低 Qgd） | 降低开关损耗 |
| 寄生电容 | 低 | 高频效率 |

### 4.2 线性应用（线性稳压、电流源、射频放大）

| 参数 | 要求 | 理由 |
|------|------|------|
| SOA（安全工作区） | 宽，需有热稳定区 | 线性工作有持续 Vds×Id 功耗 |
| 热设计 | 充分散热 | 持续高功耗 |
| Rds(on) | 不重要 | 工作在可变电阻区 |
| 低频/DC | — | 不涉及高频开关损耗 |

**线性应用特殊考虑：**
- 低压 MOSFET 的 SOA 在高压低流区域受限（螺旋效应，热失控风险）
- 线性稳压/恒流源需选专门面向线性应用的 MOSFET（如 IXYS 线性系列）

## 5. 逻辑级 vs 标准 Vgs(th)

| 类型 | Vgs(th) | Vgs(on) | 驱动方式 |
|------|---------|---------|---------|
| 逻辑级（Logic Level） | 0.5~2V | 3.3V 或 5V | MCU 直接驱动 |
| 标准（Standard Level） | 2~4V | 10V | 专用栅极驱动 IC |
| 亚逻辑级（Sub-logic） | < 1V | 1.8V | 超低压驱动 |

```
判断方法：
查数据手册 Rds(on) 测试条件：
- 在 Vgs = 4.5V 或更低时有完整 Rds(on) 规格 → 逻辑级
- 仅在 Vgs = 10V 有 Rds(on) 规格 → 标准级

逻辑级 MOSFET 标识：
型号中常含 "L" 前缀或规格书标明 Logic Level
如 IRLZ44N（逻辑级）vs IRFZ44N（标准级）
```

## 7. 按应用场景选型

### 7.1 负载开关

```
需求：控制电源通断，低频开关
关键参数：低 Rds(on)，逻辑级驱动
推荐：
- 小电流（< 3A）：SI2302（20V, 2.8A, SOT-23）
- 中电流（3~6A）：AO3400（30V, 5.7A, SOT-23）
- 大电流（> 10A）：IRLZ44N（55V, 47A, TO-220）
- 高边开关：SI4435DY（P 沟道, -30V, 8.6A）
```

### 7.2 DC-DC 变换器

```
需求：高频开关（> 100kHz），低损耗
关键参数：低 Rds(on) × Qg 乘积（FOM, Figure of Merit）
推荐：
- 低压 DC-DC（12V/24V 输入）：IPB019N08N / IRF1404（低压大电流）
- 中压 DC-DC（48V 输入）：IRF3205 / IRFZ44N（55V）
- 高压 DC-DC（100V+）：IRF540N / FDD 系列
FOM = Rds(on) × Qg，越小越好
```

### 7.3 电机驱动

```
需求：H 桥/三相桥，承受反向电流和续流
关键参数：体二极管特性，雪崩能力，dv/dt 耐受
推荐：
- 小功率有刷/步进电机：AO3400 × 4（H 桥，SOT-23）
- 中功率 BLDC：IRFZ44N × 6（三相桥，TO-220）
- 大功率电机：IPB019N08N × 6（超低 Rds）
注意：体二极管续流损耗 = Vsd × I × t_dead
```

### 7.4 保护电路（过流/反接保护）

```
需求：快速切断，低 Rds(on)
关键参数：雪崩能力，开关速度
推荐：
- 反接保护（串联）：IRLZ44N（逻辑级，单管串联）
- 过流保护：IRFZ44N + 检测电阻 + 比较器
注意：保护 MOSFET 需承受故障瞬态能量
```

## 8. 栅极驱动设计考量

### 8.1 栅极驱动电压

| 驱动电压 | 适用 MOSFET | 说明 |
|----------|-----------|------|
| 3.3V / 5V | 逻辑级 | MCU 直接驱动，限于小功率 |
| 10V | 标准级 | 专用驱动 IC，Rds(on) 最优 |
| 12V | 标准/逻辑 | 汽车常用，保证低温导通 |
| 15~20V | 标准级 | 工业大功率，注意 Vgs 绝对最大值（通常 ±20V） |

### 8.2 驱动峰值电流

```
驱动峰值电流 = Qg / t_rise

示例：
Qg = 67nC, 要求 t_rise = 50ns
I_peak = 67e-9 / 50e-9 = 1.34A

→ 需选驱动峰值电流 ≥ 1.5A 的驱动 IC
```

### 8.3 dv/dt 免疫与米勒效应

```
米勒效应导致的问题：
- 高边 MOSFET 开关时，dv/dt 通过 Cgd 耦合到栅极
- 若栅极驱动阻抗高，可能误开通对管 → 直通短路

预防措施：
- 栅极驱动阻抗足够低（强驱动）
- 栅源并联小电阻（10~100Ω）加速关断
- 死区时间足够长
- 选低 Qgd/Qgs 比值的 MOSFET（抗米勒能力强）
```

### 8.4 栅极电阻选择

```
栅极电阻作用：
1. 控制开关速度（限流）→ 平衡开关损耗与 EMI
2. 抑制栅极振铃 → 防止过压损坏

典型值：
- 开通电阻 Rg(on)：10~47Ω（限制 di/dt，减少 EMI）
- 关断电阻 Rg(off)：5~22Ω（加速关断，防直通）
- 小功率：10Ω 通用
- 大功率：需要独立开通/关断电阻
```

## 9. 热计算

### 9.1 基本热计算

```
结温计算：Tj = Ta + P_total × Rth(ja)

其中：
- P_total = P_cond + P_sw + P_gate
- P_cond = I_rms² × Rds(on)_hot（导通损耗）
- P_sw = 0.5 × Vds × Id × (tr + tf) × f_sw（开关损耗）
- P_gate = Qg × Vgs × f_sw（驱动损耗，通常很小）

示例：
IRFZ44N, Id = 10A, Vds = 48V, f_sw = 100kHz
Rds(on)_hot ≈ 35mΩ (100°C)
P_cond = 10² × 0.035 = 3.5W
P_sw ≈ 0.5 × 48 × 10 × (50ns + 50ns) × 100kHz = 2.4W
P_total ≈ 5.9W

TO-220 无散热器 Rth(ja) ≈ 62°C/W
Tj = 25 + 5.9 × 62 = 391°C → 远超 175°C，必须加散热器

加散热器 Rth(ja) = Rth(jc) + Rth(cs) + Rth(sa)
= 1.5 + 0.5 + 10 = 12°C/W
Tj = 25 + 5.9 × 12 = 96°C → 可接受
```

### 9.2 散热设计

```
散热器热阻需求：
Rth(sa) ≤ (Tj_max - Ta) / P_total - Rth(jc) - Rth(cs)

示例：
Tj_max = 150°C, Ta = 50°C, P_total = 5.9W
Rth(jc) = 1.5°C/W, Rth(cs) = 0.5°C/W

Rth(sa) ≤ (150 - 50) / 5.9 - 1.5 - 0.5 = 16.9 - 2 = 14.9°C/W
→ 需散热器热阻 ≤ 14.9°C/W（小型铝散热器即可）
```

### 9.3 铜皮散热（表贴封装）

对于 SOT-23 / SO-8 / DPAK / D2PAK 等表贴封装，依赖 PCB 铜皮散热：

| 封装 | Rth(ja)（无额外铜皮） | Rth(ja)（1oz, 1in² 铜皮） | Rth(ja)（2oz, 2in² 铜皮） |
|------|----------------------|--------------------------|--------------------------|
| SOT-23 | 150~200°C/W | 80~100°C/W | 60~80°C/W |
| SO-8 | 100~150°C/W | 50~70°C/W | 40~50°C/W |
| DPAK | 80~100°C/W | 40~50°C/W | 25~35°C/W |
| D2PAK | 60~80°C/W | 30~40°C/W | 20~25°C/W |

**PCB 散热设计要点：**
- 在 MOSFET 下方铺设大面积铜皮作为散热面
- 增加过孔阵列将热量传导到内部地层或底层
- 底层对应区域也铺设铜皮
- 过孔阵列间距 1~2mm，孔径 0.3mm

## 10. 设计审查要点清单

| 序号 | 审查项 | 合格判据 | 优先级 |
|-----|--------|---------|--------|
| 1 | Vds 降额 | Vds_rated ≥ Vds_max × 1.3（工业）/ 1.5（军用） | 高 |
| 2 | Id 热校验 | 按实际热阻计算 Tj < 150°C（或 175°C） | 高 |
| 3 | Rds(on) 温度修正 | 用工作结温下的 Rds(on) 计算损耗 | 高 |
| 4 | 栅极驱动电压匹配 | 逻辑级选 5V 驱动，标准级选 10V | 高 |
| 5 | 开关损耗校验 | P_sw + P_cond 在散热能力内 | 高 |
| 6 | 栅极驱动电流 | I_peak ≥ Qg / t_rise | 中 |
| 7 | 米勒效应防护 | 低 Qgd/Qgs 比或栅极下拉电阻 | 高 |
| 8 | 死区时间 | H 桥/半桥死区 > 最大关断延迟 | 高 |
| 9 | 体二极管续流 | 续流功耗在安全范围 | 中 |
| 10 | 散热设计 | Rth(ja) 满足 Tj 要求 | 高 |

## 附录A：MOSFET 品质因数（FOM）

```
FOM = Rds(on) × Qg

FOM 越小 → 综合性能越好（低损耗 + 高速）

典型 FOM 对比：
IRFZ44N:     17.5mΩ × 67nC = 1172 mΩ·nC
IPB019N08N:  1.9mΩ × 220nC = 418 mΩ·nC
AO3400:      33mΩ × 6.9nC = 228 mΩ·nC

→ 低电压小功率 MOSFET 的 FOM 优于高压大功率
→ 选型时先按 Vds/Id 筛选，再按 FOM 优选
```

## 附录B：MOSFET 选型快速参考

```
入门级选型流程：

1. 确定电压（Vds）→ 选额定电压（含降额）
2. 确定电流（Id）→ 选额定电流（按散热校验）
3. 确定驱动方式 → 选逻辑级或标准级
4. 确定通道类型 → N 沟道优先，高边可选用 P 沟道
5. 确定开关频率 → 计算开关损耗需求
6. 按 FOM (Rds×Qg) 优选型号
7. 热计算 → Tj = Ta + P×Rth(ja) < Tj_max
8. 设计栅极驱动 → 选 Rg 和驱动 IC
9. PCB 布局 → 铜皮散热/散热器设计
10. 样机验证温升和效率
```

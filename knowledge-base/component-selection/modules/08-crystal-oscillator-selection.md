## 2. 按应用场景选型

### 2.1 MCU 时钟晶振

```
选型步骤:
  1. 确定频率 (MCU 数据手册要求, 如 STM32 通常 8MHz/25MHz HSE)
  2. 确定负载电容 CL (MCU 内部 + 外部)
     - CL = (C1×C2)/(C1+C2) + C_stray
     - C1=C2 → CL = C1/2 + C_stray (C_stray ≈ 3~5pF)
     - 例: CL=9pF → C1=C2=(9-3)×2=12pF
  3. 确定精度:
     - 通用: ±30~50ppm (足够 UART/SPI)
     - 通信: ±10~20ppm (USB/CAN/以太网)
     - 高精度: ±1~2ppm (RTC/计量)
  4. 确定工作温度范围
  5. 确定驱动功率 (ESR/CL 要求)
  6. 封装选择: 3215/5032 插件或 2016/2520 贴片
```

## 3. 关键参数详解

### 3.1 精度与稳定度

| 术语 | 定义 | 典型值 |
|------|------|--------|
| 初始精度 | 25°C 时的频率偏差 | ±10~50ppm |
| 温度稳定度 | 全温范围内最大偏差 | ±30~100ppm |
| 老化率 | 年漂移 | ±1~3ppm/年 (晶振), ±5ppb/年 (OCXO) |
| 综合精度 | 初始+温度+老化(1年) | ±50~150ppm (晶振), ±0.5~5ppm (TCXO) |

### 3.2 负载电容 (CL)

```
负载电容计算:
  CL_spec = 晶振规格书上标注的负载电容值
  CL_actual = (C1×C2)/(C1+C2) + C_stray
  其中 C_stray ≈ 3~5pF (PCB+引脚寄生)

  匹配要求: CL_actual = CL_spec (误差 < 0.5pF)
  频率偏差: Δf/f ≈ -C1/(2×CL_spec²) × ΔCL (近似)
  
  典型:
    CL_spec=9pF, C_stray=4pF → C1=C2 = 2×(9-4) = 10pF
    CL_spec=18pF, C_stray=4pF → C1=C2 = 2×(18-4) = 28pF
```

**常见错误**：直接用 C1=C2=CL_spec，忽略了杂散电容，导致频率偏低。

### 3.3 相位噪声与抖动

- **相位噪声**（频域）：L(f) dBc/Hz，越低越好
  - 无源晶振：-100~-120 dBc/Hz@1kHz
  - TCXO：-120~-140 dBc/Hz@1kHz
  - OCXO：-140~-160 dBc/Hz@1kHz
- **抖动**（时域）：rms 秒级抖动
  - 通用：1~10ps rms
  - 高速通信：<0.5ps rms
  - 计量级：<0.1ps rms

### 3.4 驱动功率 (DL)

| 参数 | 说明 | 选型检查 |
|------|------|----------|
| 额定驱动功率 | 晶振规格书标注 (典型 10uW~100uW) | DL < 额定值 |
| ESR (等效串联电阻) | 晶振内部阻抗 (50~200Ω) | ESR < MCU 规格要求 |
| 负电阻 (-R) | 振荡电路提供的负阻 | |R| > 3~5×ESR (起振裕量) |

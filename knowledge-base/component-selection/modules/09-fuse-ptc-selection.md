## 1. 类型总览

| 类型 | 材料 | 动作特性 | 可恢复性 | 响应速度 | 适用场景 |
|------|------|----------|----------|----------|----------|
| 快断保险丝 | 银铜合金丝 | 快速熔断 | 不可恢复 | <1ms | 精密电路/IC保护 |
| 慢断保险丝 | 低熔点合金 | 延时熔断 | 不可恢复 | 10ms~10s | 电机/电容容性负载 |

## 2. 按应用场景选型

### 2.1 电源输入保护

```
选型步骤:
  1. 确定正常工作电流 I_normal
  2. 确定故障电流 I_fault 和最大分断能力 I_break
  3. 确定故障类型:
     - 短路(I_fault > 10×I_normal) → 快断
     - 容性浪涌(启动) → 慢断(T=I²t 额定值)
     - 过载(I_fault < 5×I_normal) → PTC
  4. 确定电压: AC/DC, V_rated ≥ 1.5×V_normal
  5. 确定环境温度 → 降额系数
  6. 确定是否需要可恢复 → PTC/eFuse vs 保险丝
```

| 输入电源 | 工作电流 | 故障类型 | 推荐类型 | 推荐型号 | 封装 |
|----------|----------|----------|----------|----------|------|
| USB 5V | 500mA | 过流 | PTC | MF-R050 | 插件 |
| USB 5V | 900mA | 过流+ESD | PTC | MF-R090 | 插件 |
| DC 12V | 1A | 短路 | 快断 | 0805L-1A | SMD |
| DC 12V | 5A | 容性启动 | 慢断 | 326033P | SMD 5x20 |
| DC 24V | 2A | 过载 | PTC | TMOV20A | 插件 |
| AC 220V | 2A | 短路 | 慢断 | F2A 250V | 5x20 |
| AC 220V | 5A | 短路 | 慢断 | F5A 250V | 6x30 |
| PoE 48V | 350mA | 短路 | 快断 | 0467001.NR | SMD |

### 2.2 USB 接口保护

```
USB 2.0 端口保护方案:
  VBUS → PTC(500mA~900mA) → TVS(SMAJ5.0A) → 共模扼流 → USB连接器
  D+/D- → TVS阵列(USBLC6-4) → 串联电阻(22Ω) → MCU
```

| USB 版本 | 最大电流 | PTC推荐 | TVS推荐 | 备注 |

| USB 1.1 | 500mA | MF-R050 | SMAJ5.0A | 标准口 |

| USB 3.0 | 900mA | MF-R090 | USBLC6-4 | 含信号保护 |
| USB PD | 3A | eFuse(可恢复) | SMAJ5.0A | 电子保护 |
| Type-C | 3A~5A | eFuse(可恢复) | USBLC6-4 | 电子保护 |

### 2.3 电机/感性负载保护

```
电机启动浪涌:
  I_inrush = 5~10× I_rated (持续 100ms~1s)
  → 必须选慢断保险丝 (T=I²t 额定值)
  → PTC 可能误动作 (PTC 对长脉冲敏感)
```

| 电机类型 | 额定电流 | 浪涌倍数 | 推荐保险丝 | I²t 值 |
|----------|----------|----------|-----------|--------|
| 直流有刷 12V | 1A | 8× | 慢断 1.5A | >5 A²s |
| 直流有刷 24V | 2A | 6× | 慢断 3A | >20 A²s |
| 步进电机 12V | 1.5A | 5× | 慢断 2A | >10 A²s |
| 舵机 5V | 0.5A | 10× | 慢断 1A | >3 A²s |
| 无刷BLDC 24V | 5A | 4× | 慢断 7A | >50 A²s |

## 3. 关键参数详解

### 3.1 I²t 熔断值

```
I²t 定义: 电流的平方对时间的积分
用途: 选择能承受特定浪涌脉冲的保险丝

计算:
  快断: I²t_fuse > 1.5 × I²t_pulse (脉冲能量)
  慢断: I²t_fuse > 3 × I²t_pulse (脉冲能量)
  
脉冲耐受次数:
  I²t_pulse / I²t_fuse < 0.1 → 可承受 >100,000 次
  I²t_pulse / I²t_fuse < 0.3 → 可承受 >10,000 次
  I²t_pulse / I²t_fuse < 0.5 → 可承受 >100 次
```

### 3.2 PTC 保持电流与跳闸电流

| 参数 | 定义 | 选型基准 |
|------|------|----------|
| I_hold | 不跳闸的最大持续电流 | ≥ 1.2×I_normal (20°C) |
| I_trip | 保证跳闸的最小电流 | ≤ I_fault |
| I_max | 最大短路电流承受能力 | > 预期短路电流 |
| R_initial | 正常工作阻抗 | 影响压降和功耗 |
| R_tripped | 跳闸后阻抗 | 通常 >10×R_initial |

**温度降额**：PTC 的 I_hold 随温度升高而降低

| 温度 | I_hold 降额系数 |
|------|----------------|
| 20°C | 1.0 |
| 40°C | 0.85 |
| 60°C | 0.70 |
| 80°C | 0.50 |

### 3.3 快断 vs 慢断选择

| 特征 | 快断(F) | 慢断(T) |
|------|---------|---------|
| 动作时间(2×I_rated) | <1s | 1~10s |
| 动作时间(5×I_rated) | <0.1s | 0.5~5s |
| 浪涌耐受 | 低 | 高 |
| 适用负载 | 阻性/精密 | 容性/感性 |
| 保护精度 | 高 | 中 |

## 4. 降额原则

| 参数 | 商用 | 工业 | 军用 |
|------|------|------|------|
| 额定电流 | ≤75% | ≤65% | ≤50% |
| 额定电压 | ≤80% | ≤70% | ≤60% |
| 分断能力 | ≥5×I_fault | ≥10×I_fault | ≥20×I_fault |
| 温度 | ≤60°C | ≤75°C | ≤85°C |

## 5. Fuse + TVS 协调策略

```
电源端口保护协调:
  输入 → 保险丝(过流) → TVS(过压) → 滤波 → 后级电路

设计原则:
  1. 保险丝必须在 TVS 损坏前断开:
     I²t_fuse < I²t_TVS × 0.7
  2. TVS 钳位电压 < 后级器件最大耐压
  3. 保险丝额定电压 > 最大工作电压 × 1.5
  4. TVS 反向工作电压 > 最大工作电压 × 1.2

测试验证:
  - 过压浪涌(IEC 61000-4-5): TVS 钳位, 保险丝不断
  - 短路: 保险丝断开, TVS 不动作
  - 持续过压: TVS 先钳位, 电流上升后保险丝断开
```

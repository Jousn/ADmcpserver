# 绘制前布局规划流程（Pre-Draw Layout Planning）

> 适用范围：所有原理图绘制任务——单模块、整页、多页系列设计
> 目标受众：AI 绘图助手（altium-mcp 三阶段工作流的 STAGE 0）
> 版本：v1.0 | 更新日期：2026-09
> **核心纪律：坐标是设计的结果，不是绘制的起点。先形成完整方案，再动第一笔。**

---

## 1. 为什么必须先规划

直接逐个放置元件再连线，必然产生：拥挤在下方的元件堆、穿过元件本体的导线、互相重叠的位号与标签、绕远路的反馈线。修复成本远高于规划成本——**布局是组合优化问题，必须在落盘前在"纸上"完成**。

规划产出物是一份**布局方案**（Layout Plan），包含分块图、轨道图、间距预算表、走线草案四要素，全部通过后才进入放置。

---

## 2. 规划八步法

### 第 1 步：检索知识库（强制）

```
search_knowledge_base("<电路类型> layout")        → 布局模式（如 05 电源模块模式）
search_knowledge_base("schematic-design", category="schematic-design") → 本分类规则
```

有匹配模块模板时优先用模板（`list_module_templates`）——模板已承载经过验证的布局约定。

### 第 2 步：功能分块（Block Map）

把网表切成功能块，每块回答三个问题：
- 块名与功能（电源输入 / 功率级 / 反馈 / 接口 / MCU...）
- 块的输入引脚和输出引脚（决定块在页面上的左右界面）
- 块内元件清单（含去耦、反馈等"附属"元件——附属元件跟主人走，不单独成块）

**>50 元件必须层次化**：顶层方块图 + 每功能块一页。

### 第 3 步：信号流定向（Flow Axes）

- 主信号流：**左 → 右**（输入连接器在最左，输出/执行在最右）
- 电源电位：**高上低下**（VCC 轨在块顶部，GND 轨在块底部）
- 反馈路径（电源 FB、运放反馈）允许右 → 左，但**必须用网络标签**，不允许长导线回穿
- 每块按此定出块的"轨道平面"：顶部电源轨 y、中部信号行 y、底部地轨 y

### 第 4 步：轨道图（Rail Map）

对每个功能块画出水平轨道（这是布局的骨架）：
- 每条轨道：网络名 + y 坐标 + 落轨引脚清单（如 VIN 轨：D1.1/C1.1/C2.1/R1.1）
- **轨道必须直**：落轨引脚热点全部同 y。用锚点引脚放置（anchor_pin）把引脚落点上轨，不靠事后对齐
- 轨间距 ≥ 300 mil（留给标签和跨轨元件）
- GND 用汇流总线 + 电源端口符号，不画长地线

### 第 5 步：元件布局草案（Placement Sketch）

逐块摆放（只有相对位置，没有绝对坐标）：
- 每个元件：槽位名、旋转角、**朝向理由**（哪个引脚需要朝哪个方向——"J1 引脚朝右进入电路"、"分压上电阻 VIN 端朝上"）
- 两引脚元件优先水平串在信号行 / 垂直跨在两轨之间
- **旋转语义查实测**：不要凭直觉——Cap rot270 = pin1 顶/pin2 底；Res1 rot270 = pin1 顶/pin2 底；连接器 rot180 = 引脚朝右（见 06 平台特性）

### 第 6 步：间距预算表（Spacing Budget）

对每个相邻元件对和每条轨道核算（数值规则见 02）：

| 项 | 预算 | 说明 |
|----|------|------|
| 元件间净空 | ≥ 500 mil | 含两侧位号文本 |
| 标签槽净空 | 40 + 60×字符数 + 30 mil | 网络标签文本宽度预算 |
| 轨间距 | ≥ 300 mil | 跨轨元件 + 标签 |
| 导线距元件本体 | > 0（禁入区） | 导线永不穿本体 |

**间距不足时在规划期挪元件，不要画完再补**。

### 第 7 步：走线草案（Routing Sketch）

- 每个网络：连接顺序（拓扑）、预期路径形态（直线轨 / L / 短支路）、结点位置
- 预估交叉点：目标 0 交叉；不可避免的交叉用网络标签消除
- 电源/地：确认全部用电源端口符号 + 短引线，不画长轨到每个引脚
- 多位信号：确认用总线表示（DATA[7:0]）

### 第 8 步：方案自检（Plan Review）

布局方案必须全部通过后才进入 STAGE 1/2/3：
- [ ] 每个元件的旋转都有"朝向理由"，无凭感觉的旋转
- [ ] 每条轨道的落轨引脚清单与网表一致
- [ ] 每个网络标签有所在导线段 + 净空槽位
- [ ] 无导线穿元件本体的路径
- [ ] 反馈路径用标签，无右到左长线
- [ ] 去耦电容跟着 IC，不在无源区

## 3. 与三阶段工作流的衔接

| 阶段 | 内容 | 工具 |
|------|------|------|
| **STAGE 0 规划** | 本文件八步法 → 产出布局方案 | search_knowledge_base / list_module_templates / pin_table |
| STAGE 1 选型 | 元件选型 + 网表冻结 | pin_table / validate_netlist |
| STAGE 2 放置 | 按方案放置（锚点语义） | place_component(anchor_pin) / instantiate_module |
| STAGE 3 连线 | 按走线草案布线 | wire_pins / place_gnd / add_net_label / check_connectivity |

**禁止跳过 STAGE 0 直接放置。** 模板化模块（instantiate_module）可视为 STAGE 0-2 已由模板完成，但仍需检查模块间接口轨道的对齐。

## 4. 布局方案模板（产出物格式）

```
# Layout Plan: <设计名> @ <sheet>
## 块图: [电源输入] → [Buck功率级] → [输出滤波] → [反馈]
## 轨道图:
  VIN  轨 y=1500: D1.1, C1.1, C2.1, R1.1
  GND  汇流 y=600: (端口符号: C1.2, C2.2, R2.2)
  EN   支路: R1.2 → R2.1（竖直中缝 300mil）
## 元件: J1 rot180(引脚朝右) / D1 rot0(A左K右) / C1,C2 rot270(pin1顶=VIN) / R1,R2 rot270(分压链)
## 间距: J1↔D1 600(VIN_RAW 7字符) / C↔C 500 / 分压中缝 300(EN)
## 走线: VIN 轨直线 3 段 / GND 汇流+端口 / EN 直连 100mil / 反馈 FB 用标签
```

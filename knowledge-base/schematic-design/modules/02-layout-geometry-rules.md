# 布局几何规则（Layout Geometry Rules）

> 适用范围：原理图元件摆放、轨道设计、间距与朝向的数值级规则（mil）
> 目标受众：AI 绘图助手（STAGE 0 规划 / STAGE 2 放置）
> 版本：v1.0 | 更新日期：2026-09 | 数值经 AD22 实机验证

---

## 1. 网格

- 一切坐标落在 **100 mil 网格**（2.54mm）上；引脚热点天然在网格上（引脚长度 100/200mil）
- 元件原点、导线顶点、标签锚点全部取整到 100 mil

## 2. 轨道（Rail）设计

轨道是布局的骨架——同一网络的多引脚水平共线：

| 规则 | 数值/说明 |
|------|----------|
| 轨道笔直 | 落轨引脚热点全部同 y（用 anchor_pin 放置保证，见 06） |
| 电源轨在上 | VCC/VIN 等高电位轨在块顶部；电压从上到下递减 |
| GND 在下 | 地不画长轨：短引线下垂到汇流点 + GND 端口符号 |
| 轨间距 | ≥ 300 mil（容纳跨轨元件引线 + 标签） |
| 轨上支路 | 跨轨元件（去耦电容、分压电阻）垂直跨在两轨之间，pin 朝向见 §4 |

## 3. 间距数值表

| 项 | 最小值 | 依据 |
|----|--------|------|
| 相邻元件本体净空 | 500 mil | 两侧位号文本 + Value 文本不重叠 |
| 含长网络名的槽位 | 40 + 60×字符数 + 30 mil | 标签文本宽（如 VIN_RAW 7 字符 → ≥570 mil） |
| 分压链中缝（上下两元件） | 300 mil | 中缝放 EN/FB 标签 |
| 元件与无关导线 | > 0 | 导线永不穿元件本体（禁入区） |
| 标签与标签 | 30 mil | 文本框 pad |
| 引脚出口直线段 | ≥ 100 mil（1 格） | 引脚热点出来至少走一格再转弯 |

**间距不足 = 布局方案错误，回到规划改位置，不要画完再挪。**

## 4. 朝向纪律（Orientation Discipline）

每个元件的旋转必须有"朝向理由"。两引脚元件实测语义（Miscellaneous Devices，AD22）：

| 符号 | 旋转 | 引脚朝向 | 典型用途 |
|------|------|---------|---------|
| Res1/Cap | 0 | pin1 左 / pin2 右 | 水平串信号行 |
| Res1/Cap | 90 | pin1 底 / pin2 顶 | 垂直（pin2 在上） |
| Res1/Cap | 270 | pin1 顶 / pin2 底 | **垂直跨轨首选**（pin1=上轨网络） |
| Header 2 | 180 | 引脚朝右 | 输入连接器（电路在右侧） |
| Header 2 | 0 | 引脚朝左 | 输出连接器（电路在左侧） |
| 二极管 | 0 | A 左 / K 右 | 串联在电源行（A 朝输入） |

规则：
- **对向引脚跨轨**：电容/电阻跨 VIN-GND 两轨 → 270（pin1 顶接电源轨）
- **同向引脚连接器**：引脚必须朝向电路，不允许背对（导线会穿本体）
- **分压链**：上下两只电阻同旋转（270），pin 头尾相接，中缝引出标签
- 有源器件（MOSFET/IC）：保持标准朝向，禁止镜像翻转（P 沟道翻转会误读为 N 沟道）

## 5. 锚点放置（Anchor-Pin Placement）

放置语义用**接口点**而不是原点：

```
place_component(lib_reference="Cap", anchor_pin="1", x_mils=7000, y_mils=1500, rotation_deg=270)
→ 含义：Cap 的 pin1 热点精确落在 (7000,1500)——即 VIN 轨上
```

- AD 绕元件 Location 原点（通常偏心）旋转，转 90° 整个符号甩位（详见 06）——锚点语义完全吸收此问题
- 轨道对齐由构造保证：把落轨引脚的锚点都放到轨道 y 上即可，无需事后对齐
- 布局方案中的"元件位置"应表达为**引脚落点**（"C1.1 @ (7000,1500)"），不是原点

## 6. 禁入区（Keep-Out）

- 每个元件的禁入区 = **实测引脚热点 ∪ 原点** 凸包（导出的 BoundingRectangle 对旋转符号不可信，禁用）
- 导线（任何网络）不得穿越元件禁入区内部；沿边界贴行允许
- wire_pins 工具已内置禁入区回避；手工画线（add_wire/draw_plan）时自行检查

## 7. 标签与端口的几何放置

| 对象 | 规则 |
|------|------|
| 网络标签 | 锚点必须落在**本网络导线上**；优先水平段；靠下靠左；文本框不压元件凸包/其他标签 |
| VCC 端口 | 挂在引脚热点/导线顶点，符号朝上（T 型：电源自上方进入） |
| GND 端口 | 挂在引脚热点/汇流点，符号朝下；多个 GND 端口优于长地线 |
| 位号/Value | 元件放置后 AD 自动摆位；规划时按"元件两侧各留 100mil 文本区"预算 |

## 8. 反模式（立即回炉）

- 元件全部挤在一行/一角（拥挤在下方 = 无轨道规划）
- 同一网络引脚不同 y → 轨道变成阶梯
- 连接器引脚背对电路 → 导线穿本体
- 分压电阻一只正一只反 → 中缝错位 + 绕行线
- 标签放在两元件之间的缝隙里但缝隙小于文本宽 → 压字

# 审查清单与常见错误（Review Checklist & Common Mistakes）

> 适用范围：原理图绘制完成后的交付前审查（AI 自检 + 人工复核底稿）
> 目标受众：AI 绘图助手（STAGE 3 完成后、宣称"完成"之前）
> 版本：v1.0 | 更新日期：2026-09

---

## 1. 机器审计（必须全过，不可跳过）

```
check_connectivity  → errors=0, pins_floating=0
编译分区比对        → 每网引脚集合与设计网表完全一致
```

- 工具调用成功 ≠ 电路正确——只有编译器验证通过才算数
- 有错误必须修复后重跑审计，禁止带错交付

## 2. 布局审查清单

- [ ] 信号流左→右，无右→左长线（反馈已用标签）
- [ ] 电压上高下低：电源轨在块顶、GND 在块底
- [ ] 每条轨道笔直（落轨引脚同 y，无台阶/绕行）
- [ ] 连接器引脚朝向电路（无背对）
- [ ] 每个元件旋转有朝向理由（对向引脚跨轨 270 / 分压链同旋转）
- [ ] 相邻元件净空 ≥500mil，标签槽 ≥ 文本宽
- [ ] 无导线穿越元件本体
- [ ] 位号/标签/Value 无重叠压字
- [ ] 交叉数 = 0（或每个交叉有明确理由）

## 3. 连接审查清单

- [ ] 每个 T 接有结点；无四路十字结点
- [ ] 电源/地全部用端口符号就近放置，极性朝向正确（VCC 上/GND 下）
- [ ] 每个网络有名（描述功能），无 NET1/WIRE5
- [ ] 跨页 Port 名称逐字一致
- [ ] 每个 IC 电源引脚有去耦电容且图上可见
- [ ] 悬空引脚有 NC/X 标记

## 4. 标注审查清单

- [ ] 位号从左到右、从上到下递增
- [ ] 同一电压轨全图一名（3V3 不与 VDD 混用；禁止模糊 VCC）
- [ ] Value 直写阻容值（1K/1uF，无 102/105 数码）
- [ ] 极性元件有极性标记（电解+、二极管阴极杠、LED 方向）
- [ ] 分压/增益等关键计算有注释文本
- [ ] 低有效信号全图统一一种写法

## 5. 常见错误速查表

| 错误 | 后果 | 本库对应规则 |
|------|------|-------------|
| 不规划直接画 | 元件堆挤一角、绕线混乱 | 01 绘制前规划 |
| 按原点直觉放旋转元件 | 引脚全部偏离预期位置 | 06 §1 锚点放置 |
| 连接器引脚背对电路 | 导线穿本体 | 02 §4 朝向纪律 |
| 分压电阻一正一反 | 中缝错位 + 绕行线 | 05 §2/§4 |
| 标签槽没算文本宽 | 标签压元件/互相压 | 02 §3 间距预算 |
| GND 画长轨 | 图面杂乱 | 03 §5 端口就近 |
| 反馈画长线回穿 | 交叉+误读 | 05 §4 FB 标签 |
| 导线连引脚根部 | 不导通 | 06 §2 热点 |
| T 接忘结点 | 读图误判连接 | 06 §6 结点语义 |
| 跳过编译验证 | 悬空/短路流入 PCB | 本文件 §1 |

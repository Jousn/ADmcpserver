# 电源模块布局模式（Power Module Layout Patterns）

> 适用范围：开关电源（Buck/Boost）、LDO、输入保护、反馈网络的原理图画法
> 目标受众：AI 绘图助手（公司主业：电源设计系列原理图）
> 版本：v1.0 | 更新日期：2026-09 | 双轨模式经 AD22 实机验证（buck-input-stage 模板 v4）

---

## 1. 双轨模式（Two-Rail Pattern）——电源模块的标准骨架

每个电源模块用三条水平结构线组织：

```
VCC/VIN 轨（顶部）  ─────────●────────●────────●────
                          │(跨轨元件) │         │
信号行/功率路径（中部）  D_REV → [功率级] → [输出滤波]
                          │         │         │
GND 汇流（底部）     ─────●────────●────────●──── (GND端口)
```

- **高电位轨在顶**，信号/功率路径在中，**GND 在底**——电压上高下低
- 落轨引脚用锚点放置（anchor_pin）直接上轨，轨道笔直无台阶
- GND 不画长轨：引脚下垂到汇流线 + GND 端口符号，或直接挂端口

## 2. 输入级模式（Input Stage）

功能链：连接器 → 保护（保险丝/TVS/防反二极管）→ 大容量电容 ∥ 高频电容 → 使能分压

布局要点（实测验证）：
- 连接器最左，**rot180 引脚朝右**进入电路
- 防反二极管水平串在电源行：A 极朝左（朝输入），K 极朝右
- 电容对（C_BULK ∥ C_HF）**垂直跨在 VIN 轨与 GND 之间**：rot270（pin1 顶=VIN，pin2 底=GND），两只并排间距 500
- UVLO/使能分压链在右端独立竖列：R_UV1（上，rot270，pin1 顶接 VIN 轨）、R_UV2（下，同旋转，头尾相接），**中缝 ≥300mil 放 EN 标签**，R_UV2 底端接 GND
- VIN_RAW（保护前）标签槽 ≥570mil（7 字符）

参考模板：`buck-input-stage`（instantiate_module 一键生成，布局约定已固化）。

## 3. 功率级模式（Power Stage）

Buck：高边开关 → 开关节点 → 电感 → 输出电容
- 高边 MOSFET/内置开关 IC 在 VIN 轨下方，输入电容紧邻 IC 电源引脚（图上体现相邻）
- **开关节点（SW/LX）是热节点**：短粗路径，标签 SW；不与弱信号交叉
- 电感水平串在功率路径；输出电容对（大容量+高频）跨在 VOUT 轨与 GND 之间（同输入级电容模式）
- 续流二极管/低边开关垂直挂在开关节点与 GND 之间

## 4. 反馈分压模式（Feedback Divider）

- 反馈分压 R_FB1/R_FB2 竖直链跨在 VOUT 轨与 GND 之间，**紧邻 IC 的 FB 引脚**（PCB 上靠近采样点，原理图上读作一个单元）
- **中点用 FB 网络标签**连接 IC——禁止从输出画长线回到左侧 IC（右→左反馈一律用标签）
- 采样点标在输出电容处（远离开关噪声）；可加注释文本标注目标电压与分压公式

## 5. 去耦电容模式（Decoupling）

| 位置 | 电容 | 图上摆放 |
|------|------|---------|
| 每个 IC 电源引脚 | 100nF | 紧邻引脚，垂直跨电源轨-GND |
| 每个电源域入口 | 1uF~10uF | 电源进入模块处 |
| 模拟 IC（运放/ADC） | π 型（10~100Ω + 100nF） | 供电线上串联 + 就地跨轨 |

- **图上必须有**：原理图是权威来源，图上没有的板上就不会有
- 去耦电容跟 IC 同区摆放，禁止集中到"无件页"
- 多容值并联按容值从大到小、距引脚由远到近排列

## 6. 多轨电源树（Power Tree）

- 顶层页画电源树：输入 → 保护 → 各级变换 → 负载域，每级标注电压/电流
- 每个变换器一个功能块，块间用电压轨名（3V3/5V/12V）+ 端口连接
- 上电时序要求用注释文本标注在对应使能脚旁

## 7. 隔离边界（系列设计预留）

- 原副边分块：变压器/光耦是边界元件，原边块与副边块左右分置，中间留隔离带（图上 ≥1000mil 视觉分隔）
- 跨边界信号全部通过隔离器件（变压器/光耦/隔离 IC），禁止直接连线
- 副边地独立命名（GND_S），单点汇接处标注

## 8. 反模式

- 输入电容画在远离 IC 的"电容区"（应紧邻）
- 反馈线从输出画长线穿功率级回 IC（应用 FB 标签）
- 开关节点走细长路径与模拟信号并排（热节点要短）
- 分压电阻中缝太小导致 FB 标签压件（规划期算标签槽宽）
- GND 画长轨接每个元件（应用端口符号就近接地）

# 标注与命名规范（Annotation & Naming）

> 适用范围：元件位号、网络命名、电源命名、极性标记、参数标注
> 目标受众：AI 绘图助手（STAGE 1 选型定稿 / STAGE 3 标注）
> 版本：v1.0 | 更新日期：2026-09 | 来源：内部方法论第三/七层 + Altium 官方标注实践

---

## 1. 元件位号（Reference Designators）

| 类型 | 前缀 | 示例 |
|------|------|------|
| 电阻 | R | R1, R2 |
| 电容 | C | C1, C5 |
| 电感 | L | L1 |
| 二极管/LED | D | D1, D5 |
| 三极管/MOSFET | Q | Q1 |
| IC | U | U1, U3 |
| 连接器 | J/P | J1 |
| 开关 | SW | SW1 |
| 晶振 | Y | Y1 |
| 保险丝 | F | F1 |
| 测试点 | TP | TP1, TP_VCC |

- 编号顺序 = 阅读顺序：**从左到右、从上到下**，严格递增
- 文字方向只用 0° / ±90°，禁止任意角度和倒置
- 多实例模块（instantiate_module）自动分配位号，避开在用位号

## 2. 网络命名

- **描述功能，不描述连接**：SPI_MOSI、I2C_SDA、PWM_MOTOR、ADC_TEMP、FB（反馈）
- 禁止：NET1、WIRE5、U1_PIN5
- 全大写 + 下划线分词；全图统一风格
- 低有效信号统一一种写法：RESET_N（或 nRESET，全图只能有一种）
- 电位命名不混用：VDD 与 3V3 不能同时代表同一网络

## 3. 电源网络命名

| 网络名 | 含义 |
|--------|------|
| +3V3 / 3V3 | 3.3V 轨（**禁止 VCC 泛称**——必须写明电压） |
| +5V / 5V | 5V 轨 |
| +12V / 12V | 12V 轨 |
| VBUS | USB 总线电压 |
| VIN / VIN_RAW | 稳压器输入（RAW = 保护前） |
| GND / DGND / AGND | 地 / 数字地 / 模拟地 |

- 小数点禁用：3.3V 写 3V3（防止读成 33V）
- 端口名短于符号宽度；电气功能在前（截断后仍可读）
- 同一电压轨全图一种写法

## 4. 极性标记

- 电解电容：+ 号标正端
- 二极管：阴极杠可见；LED 加电流方向箭头或 +/−
- 电源端口：VCC 端口符号朝上在元件上方，GND 朝下在下方——极性一眼可读，禁止横放

## 5. 参数标注（Value 文本）

| 器件 | 标注格式 | 示例 |
|------|---------|------|
| 电阻 | 阻值+精度（高精度时） | 10K、4.7K 1% |
| 电容 | 容值+耐压（高压时） | 100nF、10uF 25V |
| 电感 | 感值 | 4.7uH |
| 磁珠 | 阻抗@频率 | 600R@100MHz |
| 晶振 | 频率+精度 | 8MHz 50ppm |

- **禁止数码标注**（102/105）——直接写 1K/1uF
- 默认只显示位号 + Value；公差/材质等特殊参数仅在关键处显示（处处高亮 = 处处不突出）
- 大功率电阻加功率标注（2W），高 Q 电容加材质（NP0/X7R）

## 6. 设计说明文本

在图上加说明性文字（计算、选择理由）提升可审查性：
- 分压电阻旁标注分压公式与结果电压（如 `VOUT = 0.8×(1+R1/R2)`）
- LED 限流电阻旁标注电流（`2.1Vf, 10mA`）
- 运放旁标注增益（`G = -R2/R1 = 10`）
- 说明文字用区分色（如紫色注释层），与电气文本区分

## 7. NC/NF 与悬空引脚

- 不连接的引脚：加 X 标记或 NC 标签（ERC 才能区分"忘了连"和"故意不连"）
- NF（Not Fix，不贴装）：兼容设计预留位标注 NF
- 预留电路：0Ω 电阻隔离 + 注释说明启用条件

## 8. 反模式

- 位号乱序（R7 在 R3 左边）
- 同一网络两种名（3V3 与 VDD3.3 混用）
- 模糊 VCC（不知是 3.3V 还是 5V 还是 12V）
- Value 写 103（读图要心算）
- 低有效信号三种写法混用（/RST、nRST、RESET_N 并存）

# 连线组织规则（Routing & Organization）

> 适用范围：原理图导线、结点、网络标签、电源端口、总线的组织方式
> 目标受众：AI 绘图助手（STAGE 0 走线草案 / STAGE 3 布线执行）
> 版本：v1.0 | 更新日期：2026-09

---

## 1. 走线形态

- **只用水平/垂直正交线**（曼哈顿走线），禁止斜线
- 引脚热点出来**至少 100 mil（1 格）直线**再转弯
- 转弯用 L（直角），连续转弯避免来回抖动（S 型爬梯是布局错误的表现，回去挪元件）
- 导线**永不穿越元件本体**（禁入区规则，见 02 §6）
- **多网交汇的连接点必须互相错开**：同一节点的多个引脚热点不得落在同一点（引脚叠引脚，即使同网络）——节点用短母线段展开（如 SW 节点：开关管E — 续流管K(下垂) — 电感左，三点沿轨分布各距 400-500mil）

## 1.5 布网顺序（wire_pins 逐网调用时）

**先短后长、先结构后汇流**：
1. 短结构网先布（分压中缝、基极驱动等 100-300mil 段）——它们必须占据自己的列/段
2. 信号网其次
3. **汇流网（GND/VCC 类多引脚总线）最后**——汇流线的路由自由度最高（可绕行），先布会抄近路穿过后布网络需要的通道（实测：GND 先布沿分压列直下，堵死 FB 中缝）

STAGE 0 的走线草案里应写明布网顺序。

## 2. 结点（Junction）规则

- 每个 3+ 线交汇点（T 接）**必须有结点**——无结点 = 视觉上"不连接"
- **T 接优于十字**：四路交汇点无法与"两线交叉不连接"区分，尽量拆成两个 T 接
- 纯交叉（无连接）：保持一次 90° 穿越，不加结点
- wire_pins 自动在 T 接放结点；手工 draw_plan 时 junctions_csv 必须显式列出

## 3. 最小化交叉

优先级从高到低：
1. **调整元件位置消除**（回到布局——交叉多的图是布局问题不是走线问题）
2. 网络标签替代长飞线（跨块连接、反馈路径一律用标签）
3. 不可避免的交叉：单点 90° 穿越，远离结点/引脚

**目标：可见交叉 = 0。**

## 4. 网络标签策略

| 场景 | 用标签还是画线 |
|------|---------------|
| 块内短连接（轨上相邻引脚） | 画线（轨本身就是线） |
| 跨块连接 | 标签（每块边界处） |
| 反馈路径（右→左） | **必须标签** |
| 电源/地 | **电源端口符号**（place_gnd/place_vcc），不是标签 |
| 多位总线 DATA[7:0] | 总线 + 各分支标签 |

标签放置几何：锚点在本网导线上、水平段优先、避开元件凸包（见 02 §7）。

## 5. 电源与地分布

- **电源端口就近放置**：每个 IC/模块的电源引脚旁挂端口符号，不画长电源线穿越整图
- VCC 类端口在元件**上方**（T 型进入），GND 端口在**下方**（朝下）
- 禁止电源端口横放/倒放——极性必须一眼可读
- 混合信号：AGND/DGND 分开命名，单点连接（ADC 参考附近），图上明确标出汇接点

## 6. 跨页/层次连接

- 每页一个功能块；顶层方块图 + Sheet Entry/Port 连接
- 跨页信号：源页右边缘、目标页左边缘的 Port，名称完全一致（I2C_SDA vs I2C_SCA 是经典事故）
- 成组跨页信号用 Signal Harness（一束线一个入口），不用十个独立 Port

## 7. 走线质量度量（analyze_schematic_quality / optimize_layout）

| 指标 | 目标 |
|------|------|
| 交叉数 (crossings) | 0 |
| 多余弯曲 (bends) | 越少越好（轨道化后趋近 0） |
| 总线长 (total_length) | 块内最小化 |
| 浮空线头 (dangling) | 0 |

optimize_layout 爬山重排后必须重放网络标签/电源端口（旧位置全部失效）。

## 8. 反模式

- 电源线画成长轨穿越整图接每个引脚（应该用端口符号）
- 反馈线从右画到左横穿功率级（应该用 FB 标签）
- 十字四路结点（拆两个 T）
- 导线贴着元件引脚根部走（应连热点自由端）
- 无结点的 T 接（读图者无法判断连不连）

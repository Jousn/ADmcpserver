# PCB 设计规则知识库 — 总索引

> 本知识库面向 AI Skills 和 Agent 的结构化检索，覆盖 PCB 设计全流程的布局布线规则（去耦电容 → 接地策略 → 线宽间距 → 差分对 → EMC/EMI），适用于 Altium Designer 环境下的数字、模拟、混合信号、高速和射频电路设计与审查场景。

## 3. 按设计阶段的推荐检索路径

### 3.1 原理图/元件选型阶段

```
确定 IC 和拓扑后
    │
    ├─▶ [模块 01] 去耦电容方案 → 确定电容容值/数量/封装
    ├─▶ [模块 02] 接地策略选型 → 确定接地方式（单点/多点/混合）
    └─▶ [模块 03] 阻抗预算 → 确定目标阻抗（50/90/100 Ohm）
```

### 3.2 PCB 叠层设计阶段

```
设计层叠结构时
    │
    ├─▶ [模块 02] 地平面/电源平面规划 → 确定层叠方案
    ├─▶ [模块 03] 叠层阻抗查表 → 确定线宽/间距
    ├─▶ [模块 05] EMC 层叠原则 → 验证每信号层有参考面
    └─▶ [模块 01] 电源平面间距 → 平面电容优化（< 0.15mm）
```

### 3.3 布局阶段

```
放置元件时
    │
    ├─▶ [模块 01] 去耦电容放置 → 100nF 在 VDD 3mm 内
    ├─▶ [模块 02] 数模分区 → AGND/DGND 单点连接
    ├─▶ [模块 05] 噪声分区 → 高噪声/低噪声区域隔离
    └─▶ [模块 04] 差分对元件对称 → AC 耦合电容镜像放置
```

### 3.4 布线阶段

```
走线时
    │
    ├─▶ [模块 03] 线宽计算 → 电源线 20mil/A、阻抗线查表
    ├─▶ [模块 03] 间距控制 → 3W 规则、高压爬电距离
    ├─▶ [模块 04] 差分对布线 → 等宽等距、等长匹配
    ├─▶ [模块 02] 回流路径 → 信号不跨越地平面分割
    └─▶ [模块 05] 时钟布线 → 走内层、地保护走线
```

### 3.5 审查与验证阶段

```
设计完成后
    │
    ├─▶ [模块 01] 去耦审查清单（DC-01 ~ DC-12）
    ├─▶ [模块 02] 接地审查清单（GD-01 ~ GD-12）
    ├─▶ [模块 03] 线宽审查清单（TW-01 ~ TW-10）
    ├─▶ [模块 04] 差分对审查清单（DP-CHK-01 ~ DP-CHK-12）
    ├─▶ [模块 05] EMC 审查清单（EMC-01 ~ EMC-15）
    └─▶ [全部模块] Altium DRC 规则验证
```

## 9. 知识库使用指南

### 9.1 AI Skills 检索建议

1. **关键词检索优先**：每个模块文件头部均包含主题摘要和适用范围，支持关键词快速定位
2. **数值速查**：使用本索引第 7 节速查表快速获取常用数值
3. **阶段化检索**：按设计阶段（选型 → 叠层 → 布局 → 布线 → 审查）选择对应检索路径（见第 3 节）
4. **DRC 关联**：需要配置 Altium DRC 规则时，参考第 4 节索引定位到对应模块

### 9.2 Agent 开发建议

1. **设计规则推导 Agent**：以本知识库为规则引擎，结合 MCP 工具读取 PCB 现有规则，输出 DRC 配置建议
2. **EMC 审查 Agent**：以模块 05 的审查清单（EMC-01 ~ EMC-15）为核心检查项，结合模块 01/02 辅助审查
3. **差分对布线 Agent**：以模块 04 的阻抗目标和长度匹配表为核心，结合 Altium 差分对规则设置
4. **去耦审查 Agent**：以模块 01 的审查清单（DC-01 ~ DC-12）为检查项

### 9.3 知识库维护

- 新增模块文件按 `NN-topic-name.md` 编号规则命名
- 数值更新需同步更新本索引第 7 节速查表
- Altium DRC 规则变更需同步更新第 4 节 DRC 索引
- 交叉引用变更需同步更新第 5 节
